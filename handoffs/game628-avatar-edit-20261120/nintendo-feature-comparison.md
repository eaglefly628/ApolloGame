# G628-AVATAR-EDIT 平台功能对照

## Wii

| 功能 | 原厂手册定位 | Game 628 |
| --- | --- | --- |
| 从头创建、逐步选择相似脸 | 《Wii Channels & Settings》Mii Channel，Creating More Mii Characters / Starting from Scratch / Choosing a Look-alike | 全身页提供三种原创脸部起点，独立捏脸页有 81 个固定五官组合。 |
| 改头形、肤色、发型、五官、眼镜等 | Making Your First Mii / Modifying a Mii | 体验稿可选眼、眉、鼻、嘴及戴帽状态。头形、肤色与眼镜为待做项。 |
| 发型左右翻转，部件颜色、上下移动、缩放、角度、成对间距 | Modifying a Mii / Feature Adjustment Menu | 当前用已有五官样式切换展示差异。参数编辑待装配方案。 |
| 独立调身高与体型 | Modifying a Mii / Body Type | 三种同身高胖瘦，身高与连续参数待接。 |
| 编辑中转一圈，退出时选择保存，广场重编/删除/浏览 | Modifying a Mii / Seeing Your Mii Characters in Mii Plaza | 当前候选固定机位、实时预览、单次编辑会话应用与重置。 |
| 昵称等资料、收藏、交流及遥控器传输 | Creating a Profile / Mii Plaza / Storing Your Mii Characters in a Wii Remote Plus | 本票范围为外观和动作。 |

来源：[任天堂 Wii 欧洲版官方手册，Mii Channel](https://www.nintendo.com/eu/media/downloads/support_1/wii_21/Wii_Channels_Settings_RVK_MAN_UK_NFRP.pdf)，[原厂日文功能篇，第 20–27 页](https://www.nintendo.co.jp/wii/support/pdf/wiimanual_functions.pdf#page=20)。

## Nintendo Switch 初代系列

| 功能 | 原厂说明定位 | Game 628 |
| --- | --- | --- |

| 浏览分类选部件，指南例举脸、眉、鼻、胡须等。填写昵称并完成，单机最多 100 个 | 创建指南 Complete these steps 与 Additional information | 以角色预览应用代替系统档案流程。昵称、跨会话存储和列表是本轮未覆盖项。 |
| Mii List 选既有角色、编辑完成、二次确认删除 | 编辑／删除指南 Edit Mii / Delete Mii | 现候选只有本次会话草稿及已应用外观。 |

| 体型控制、部件精确数值范围 | 已查原厂初代 Switch 创建和编辑步骤，仅举部件例子，未列出完整体型及调参字段 | 证据不足，暂列未逐项确认。Wii 的手册证据单列。 |
