# Game 628《小生活》入口 UI Demo

试玩地址 <http://127.0.0.1:18841/>。双击 `start.command` 会启动本机服务并打开浏览器，请在试玩期间保留启动终端。也可以在仓库根目录运行 `./handoffs/game628-entry-ui-demo/start.command`。

## 给 PM 和视觉总监的复验

1. 「开始游戏」→「模拟登录并继续」，另走一次「游客进入」。账户信息不会被请求或保存。
2. 换任一五官，确认角色进入梧桐街。原型有 4 类五官、每类 3 个，确认读取当前真实可见面部编号。选脸页和街景通过现有本地试玩包在内嵌浏览区运行，街景沿用原有主角。
3. 用 WASD 或方向键行走，按 Esc 或点底栏「菜单」。菜单打开时街景区域不接收玩家输入，动画和场景内部时钟仍运行。返回后可以继续移动。
4. 从菜单和底栏分别进设置，调界面音量、试听、切换操作提示再返回。音量作用到试听提示音，设置在本页重复进出时保留。返回标题后可再开一轮。
5. 以 390 px 窄屏走同一条路线，用 Tab、Shift+Tab、Enter、Esc 验证键盘操作。

## 交付边界

- 界面控件复用 LayoutNode、mountUI、apolloBrocade 的暖色变体。所有页面状态都通过 validateLayoutNode 校验。宿主布局和与内嵌试玩包接线集中在本目录。
- 本地 Vite 通过同源路由读取兄弟目录 `game628-life-controls-20261117/dist`。原试玩地址继续独立使用。缺少该本地构建时会提示场景加载失败。
- 主角换脸、全身编辑、正式账号与存档、全局音频通道、仿真暂停和手游触控输入属于后续正式接入。本次为可回退入口 Demo。前置美术和设计门仍按正式工作流验收。
- 实机对照版流程板 `flow-preview-runtime.png` 使用入口、模拟登录、捏脸、试玩、街坊菜单、设置六张真实浏览器截图。右栏附重建文档记录的原始梧桐街参考图。截图保留原始比例和实际 UI 分区，可运行 `python3 render-reference-board.py` 重建。
- 初版概念流程图 `flow-preview.png` 由内建 imagegen 生成并原生展示。它表达暖纸、软陶 3D 街区和四步界面层级，部分字段是概念图示意。Demo 以实际原型的眼、眉、鼻、嘴和单音量设置为准。主页面实际背景取用现有 `evening-v4.jpg` 证据图。
- 验证脚本 `verify.mjs`，桌面及窄屏截图和结果见 `evidence/`。测试基于 macOS Chrome。PM 与视觉总监独立复验待签。

内建 imagegen 提示词见 `image-prompt.txt`。
