# Game628 街区天气

接入当前街区的 `reference-street`、`reference-walk`、`reference-lighting`。底部天气按钮切换晴天、下雨、飘雪和薄雾。街景与散步之间保留已选天气，时间按钮恢复对应时段的晴天。

雨丝按米制场景调整尺寸、倾角、速度和相位。水洼和落点涟漪为浅灰蓝，雪花和覆雪为偏冷白。天气预设和全部效果实体写入场景 JSON，由现有 Mesh3D、Anim3D、Decal3D、Fog3D 和环境切换宿主解释。

运行 `node handoffs/game628-life-controls-20261117/weather/assemble.mjs` 可重新生成天气数据。生成器读取街区的实际 GLB，对每条雨线离线做三角面射线检测，记录屋檐、屋顶、树木、道具或地面上的首个落点。雨丝在该落点结束，地面水洼的部分落点与涟漪扩张共享周期。原街区资产保持原位，雨雪仅使用新增效果实体。所有实体共用固定数量的基础几何和材质进行批绘制。

`collision-samples.json` 保留落点与法线。街区模型改变后需要重新运行生成器。当前遮挡来自静态街区模型，移动人物和移动遮挡物尚未加入检测。覆雪是表面斑块，涟漪是重复播放的小环。此版本为本机原型，GPU预算尚需目标设备实测。

开发预览为 `http://127.0.0.1:18828/?scene=reference-walk`，构建预览为 `http://127.0.0.1:18829/?scene=reference-walk`。按上级 README 的命令验证和构建。
