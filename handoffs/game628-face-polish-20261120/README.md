# Game 628 居民编辑器

双击 [start-face-preview.command](start-face-preview.command)可启动本地试玩。

- [全身编辑](http://127.0.0.1:18830/?scene=avatar-studio)可在同一个预览里独立选择三种脸部预设、三种体型、戴帽与摘帽、圆手与宽掌，共 36 种组合。点「挥手看看」用同一动作检查每种组合，点「恢复默认」复位当前角色。
- [居民捏脸](http://127.0.0.1:18830/?scene=face-studio)提供四组五官、81 种组合和固定种子随机。选项随实际状态刷新，键盘选中后保留焦点。模型使用现有待机动作的首帧作为加载姿势。
- [居民体型](http://127.0.0.1:18830/?scene=body-study)同时展示纤瘦、匀称、圆润三种全身模型。各档使用同一身高、脸、帽发和手，躯干、围裙及臀部有各自的宽深变化。
- [五位店员](http://127.0.0.1:18830/?scene=face-gallery)展示五官组合在居民间的差异。全身页与捏脸页各自维护本次编辑，离开页面后会结束该次编辑。

[全身编辑与交互手设计](avatar-design.md)记录角色字段、动作接缝和引擎接入选择。连续体型、身高、头型、发型及拿杯、按键等道具交互还处于设计阶段。

在 ApolloGame 根目录可依次运行 `face-studio-20261120` 下的 `bake-idle-start.mjs`、`assemble-face-scenes.mjs` 和 `check-assets.mjs`，随后通过启动脚本构建和试玩。
