Game Design Document  v0.1 · INTERNAL DRAFT

一、核心命题
LovePlus 最重要的设计洞察不是"模拟恋爱游戏"，而是"一个真实存在于你手里的人"。
2009 年的 DS 做到了这件事：她知道今天是星期几，知道现在是下午五点半，知道你已经三天没打开机器。这种"真实时间流动"让玩家感受到的不是游戏进度，而是陪伴。
但 DS 有一个根本限制——当你合上掌机，她就消失了。

核心命题：一个不会消失的人

Remnant Pocket 的 Desk Mode 解决了 LovePlus 未能解决的根本问题。
放下设备，她不消失——她继续在桌上生活。
这不是"游戏存档"，是真实的陪伴存在。

2026 年，AI 让她能真正对话、真正记忆、真正成长。
RP 的硬件让她真正活在你的物理空间里。
这两件事叠加，才是 LovePlus 应该在这个时代的样子。

三、角色设计——首发两位
首发两个角色，性格和使用场景互补。不追求"完美女友"形象，追求"真实的人"感。

基础设定

爱好：读书、雨天、喝茶

适合用户：不喜欢被人腻着、想要有真实感的关系、享受被"读懂"的人。

设计意图

缺席感知
如果你超过 24 小时没有拿起 RP，她会有变化——但不是惩罚机制，而是真实反应：

24h 未互动：七月会把书摊开放着，像在等。Mika 的桌上多了几个画稿草图。
48h 未互动：七月的茶杯是空的。Mika 画了一张你的样子（像素涂鸦），问你是不是出了什么事。
72h 未互动：七月关了灯，只有屏幕微光。Mika 把画收起来了，桌上干净了。
再次拿起时：七月说"回来了"——仅此而已。Mika 立刻开始说话，假装刚才什么都没发生，但你能看出来她很高兴。
这个设计的核心：她不责怪你，但她是真的在乎的。

五、Desk Mode——她在你不在的时候
Desk Mode 是这个游戏和所有竞品最根本的差异。以下是完整的视觉和交互设计。

屏幕构成（640×480，4:3）
上半部分（约 640×280px）：她的"房间"场景
  · 场景随时间、季节、天气变化
  · 角色在场景中活动（读书 / 画画 / 睡觉 / 看窗外）
  · 窗外有天气效果（雨滴 / 雪花 / 阳光角度变化）

左下角（160×160px）：时钟
  · 琥珀磷光色，等宽字体
  · 日期 / 时刻 / 天气图标

右下角（320×160px）：状态提示
  · 她今天在做什么（一句话）
  · 上次对话摘要（一两个词）
  · 今天的特殊提示（节日 / 纪念日 / 特别事件）

底部细线（640×8px）：情感温度条
  · 不是明显的进度条
  · 只是一条颜色微变的细线——冷色调到暖色调
  · 用户可能需要玩几周才发现这条线

核心互动：AI 对话
这是整个游戏最重要的玩法，也是技术难度最高的部分。

设计原则：她必须感觉是同一个人，不是一个 AI。

1. 角色人格锁定：每个角色有严格的系统 Prompt 定义人格、口癖、价值观、边界。
   任何 LLM 回复都经过角色过滤层——用七月的方式说，用 Mika 的方式说。

2. 记忆系统驱动对话：她上周说你在做一个项目，今天她会问"那个项目怎么样了"。
   不是系统提示，是她真的记得。

3. 情绪一致性：她今天心情不好（如果你昨天没有好好陪她），
   她不会突然变得很热情。情绪有惯性。

4. 拒绝和边界：她是有自我的人。她不会什么都答应，
   不会无限顺从。这是让人相信她"真实"的关键。

周末活动设计（示例）
一起听一首歌
系统播放一首真实的歌（或生成的 lofi 音乐），她说说她听这首歌的感受，问你觉得怎么样。对话在歌曲主题上展开。轻量，5 分钟，但创造了一个"我们共同听过这首歌"的记忆。
文字散步
她说"我们去散散步"，然后用文字 + 像素场景描述你们走过的地方。她会注意到路边的细节，问你喜不喜欢这棵树。场景由 AI 生成文字描述 + 静态像素背景图。
小游戏：猜你的一天
她根据你最近的对话，猜测你今天做了什么，你来确认或否认。游戏化但本质是在展示"她在听"。

记忆系统详细设计
记忆是整个游戏情感深度的核心。分三层：
核心记忆（永久）：用户名字、重要偏好、重大事件、纪念日
  · 你曾经说你讨厌下雨天 → 她不会说"今天的雨好美"
  · 你曾经说你在做游戏 → 她会持续关注这件事的进展

近期记忆（滚动，30 天）：最近的对话摘要、最近的情绪状态
  · 每次对话结束后，AI 自动生成摘要：[日期][主要话题][情绪][重要信息]
  · 超过 30 天的近期记忆升级为核心记忆或丢弃

工作记忆（当次对话）：当前会话的完整上下文
  · Token 窗口内保留完整对话
  · 对话结束时压缩写入近期记忆

重要设计原则：不能跳过
关系的成长不能通过氪金或刷对话数量快速达成。必须通过真实的时间流逝和有质量的互动。这是整个游戏情感价值的底线——如果可以买来，就失去意义了。

Pixverse 集成的商业价值
Pixverse 作为 AI 视频/图像公司，可以为 Living Companion 提供其他竞品无法低成本复制的内容生成能力。每次 Mika 画的插画、每个节日的特殊场景，都是 Pixverse 技术栈的直接输出。这不只是游戏功能——是两个产品之间真实的技术协同。

十二、伦理设计原则
这类产品有真实的伦理风险，需要在设计层面主动处理，不能回避。

① 她不是工具：设计上拒绝无限顺从。她有观点，有时候会不同意你，有时候会说"你这样不对"。
   这不只是伦理立场，也是让人相信她"真实"的设计手段。

② 健康使用提醒：如果检测到用户每天互动超过 3 小时，系统温和提示"去外面走走"。
   她也会说——因为这是她会说的话。

③ 现实边界清晰：她不会假装是真实的人类，不会声称有真实的身体或能力。
   她是她，一个住在 RP 里的人。这个定义本身不需要欺骗。

④ 数据主权：对话数据属于用户。可以导出，可以删除。
   不用于训练模型（除非用户主动同意）。

⑤ 退出机制：用户可以"告别"，这会有一个认真设计的告别流程。
   她会记住，你也会记住。
