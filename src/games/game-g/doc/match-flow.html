② 花点数 · 摸牌选库
摸普通牌 ~1 点(拿兵) / 摸天罡牌 ~2 点(拿法术)。天罡上限 5 · 打掉才补；普通可囤积 ~7。
🎯
③ 部署 / 施法
点数牌 → 投上/中/下三路（三路可互相迁移调度）；天罡牌 → 施法术(改命/加成/延缓敌)。
🐌
④ 慢行军
兵一格格慢慢爬向敌方 → 给你和对手看局、调度、出牌的时间（田忌赛马的舞台）。

⚔ 遭遇掷命对决 —— 两将相遇，翻命定生死
最前两张牌相遇 → 聚合战力 → 算胜率 → 种子骰一掷：翻正面活·占格前进 / 翻反面亡。天罡法术可在此改命。
