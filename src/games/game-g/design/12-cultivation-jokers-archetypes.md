# 12 · 培养 · 小丑牌 / 星球牌 / 流派（长期丰满与重玩性）

> game design G ｜ 2026-06-15 ｜ 承 `07` 培养线 + owner 愿景"小丑牌/星球牌**融在牌面上**培养牌组"。
> 现状：单 run 已有深度（布阵/干预/牌型/将领/战役），但**跨 run 的"我的牌组身份"**还没展开——本篇补它（炉石/Balatro 的持久层），让"越玩越想玩"。

---

## 〇、为什么需要它

单 run 再爽也会腻。**持久牌组身份**给长期动力："这副牌是我的"——融了哪些小丑、升了哪些星球、走哪个流派。每局武将（54 标准牌）roguelike 公平清零；**真正积累的是融在牌面上的小丑/星球 + 你的流派 know-how**。这把"公平"与"养成"解耦（owner 立项内核）。

## 二、小丑牌目录（首批 10，融牌面；每张 = `{时机,效果}` 复用现成）

| 小丑 | 效果（首版 TUNE）| 数据形 / 复用 |
|---|---|---|
| **死士** | 这张反面死时，同路相邻友军 +favor（报仇）| condition(死) → effect(邻路位 favor) ✅ |
| **不屈** | 这张首次反面 → 自动重翻一次 | status 免死/reroll（同护盾族）✅ |
| **旗手** | 这张所在路，主将士气加成 +50% | 放大 `06` 士气系数 ✅ |
| **同袍** | 本路每有 1 张同花色，这张 +favor | 计数法（同 `10` D）✅ |
| **赌徒** | 这张 favor 两极化（上限↑下限↓）= 高风险高回报 | favor 区间数据 ✅ |
| **督粮** | 这张活 → 本场 +1◈ 干预能量 | condition(活) → effect(能量) ✅ |
| **影武者** | 敌斩首令命中本路主将时，这张替死（诱饵）| 斩首目标重定向（`10` B counter）⚠️待核小接线 |
| **连环** | 这张活 → 指定同路相邻友军必活一次 | condition → effect(邻位 favor=高) ✅ |
| **枭雄** | 这张当主将时，全路士气加成翻倍 | 放大 `06`（条件 该牌=主将）✅ |
| **先登** | 这张在「上军」时 +favor（路偏好）| lane 条件 → favor ✅ |

> 9/10 纯复用 effect/condition/favor/计数；**影武者**的"斩首目标重定向"是唯一待核小接线（不行则换"该路主将被斩时全路 +favor 复仇"重组，零缺口）。

**CORE RULE 裁定（2026-06-15，program G 回驳 → design G 复核）**：
- ⛔ **星球·路 砍**：与「星球·军 + 开局布阵(`09`)」重叠——你本就每局选哪路堆兵/堆官；再加"永久某路 favor"既冗余、又要"选哪路"UI，**不值**。**program G 回驳成立。**
- 🔧 **星球·型 改全局**：原"+某牌型档"需"选哪档"UI（program G 点出的交互缺口）。**改为整条牌型阶梯全局 +X/级**（同星球·军的全局形）→ **零目标 UI、不与改造坊 per-card favor 重叠**，可直接接。
- ✅ 与改造坊正交确认：改造坊=**per-card** favor/融小丑；星球=**全局派生档**(命/能/军/型)，两轴不重叠。

## 四、流派 archetypes（首批 6 · 像 gameF 10 套；流派=身份）

| 流派 | 钥匙小丑/卡 | 打法 | 围绕 |
|---|---|---|---|
| **斩首流** | 督粮 + 斩首令 + 影武者 | 攒能量秒敌主将引溃散 | 干预能量 + `06` 溃散 |
| **牌型流** | 同袍 + 同花/顺子 + 星球·型 | 往某路堆同花色/连号 | `10` D 牌型 |
| **将领流** | 旗手 + 枭雄 + 高军衔集中布阵 | 主将士气碾压一路 | `06` 将领 + `09` 布阵 |
| **铺场流** | 增援 + 死士 + 连环 | go-wide + 连锁必活 | spawn + 连锁 |
| **概率流** | 祝福/护盾 + 不屈 + 赌徒 | 改命堆高 favor、稳翻正 | `01` favor/干预 |
| **弃一保二流** | 田忌布阵 + 弃车保帅 + 督粮 | 弃一路、经济滚两路 | `09` 田忌 + 经济 |

> **克制网**（石头剪刀布，无唯一最优）：斩首流 克 将领流（专杀主将）；将领流 克 铺场流（碾压）；铺场流 克 斩首流（主将多、斩不完）；牌型流/概率流/弃一保二 各有猎物与天敌 → 看对手流派临场调布阵+干预。

## 五.5 · 结局联动族小丑的 outcome-first 落地语义（2026-06-15，答 program G 开放问题）

> program G 巩固时挂起这族（死士/连环/督粮/影武者），因"on death/on live"在 build-时定胜负下时机不明。钉死如下——**全在 `resolveArmy` 的确定性单遍顺序解析里前向生效（不回头改已翻牌 → 单遍确定、可重放、hash 稳）。**

| 小丑 | 落地语义（build 时·前向单遍）| 时机 |
|---|---|---|
| **死士** | 解析到它=反面死 → 给**本路尚未翻牌**的友军 +X favor（报仇）；已翻的不动 | resolveArmy 顺序解析中 |
| **连环** | 解析到它=正面活 → **本路下一张未翻牌强制活**（跳掷命置活，同护盾族）| 同上 |
| **督粮** | 解析到它=活 → **+1◈ 入 run 能量池、下场备战可用**（本场能量已在揭晓前花掉 → 是 run 经济、非本场）| 结算后 post-resolve |
| **影武者** | **优先**：敌斩首(favor→8)命中本路主将时，在 `applyInterventions` 里**重定向到影武者**(替死、主将留)；**退路**(重定向难接)：该路主将被斩→该路 +favor 复仇（§五，零缺口）| 揭晓前 applyInterventions |

- **纪律**：死士/连环只影响**未翻牌**（前向）→ 保单遍确定性、无需二次解析、hash 稳。
- 督粮 ◈ 跨场（run 经济），不破"本场揭晓前花能量"的相位。
- 影武者优先重定向、退路复仇 buff——两条均**零新引擎能力**。

## 六、验收（未来 T-G6+）

1. 改造坊：融小丑牌（10 选）+ 星球牌（5 选）+ 附魔，消材料、持久存档。
2. 小丑被动在局内生效（死士复仇/旗手放大/同袍计数…），同牌组+seed 逐拍 hash 一致。
3. 6 流派可组、克制网成立。
4. tsc + vitest + build 全绿。

> 复诵：武将公平清零，**牌组身份持久**——融小丑（改规则）、升星球（升档）、走流派（身份）。这是"越玩越想玩"的长期层，几乎全复用 Game E joker + effect/计数，零新能力（仅影武者一处小待核、有退路）。
