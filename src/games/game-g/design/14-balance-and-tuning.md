## 七、平衡设计意图（北极星）

1. **公平与养成解耦**：武将 54 标准牌人人同池；强度只在牌组（小丑/星球/流派）"倾向"，靠 5%/95% favor 边界保翻盘——**强度可成长、永不必然**。
2. **三路 best-of-3 = 弃一保二的读心**：布阵（`09`）+ AI 暗布阵 → 无唯一最优。
3. **干预能量 = 取舍**：不能全甩，逼"这场花还是攒终局"。
4. **流派克制网（`12`）**：石头剪刀布，看对手调布阵+干预。
5. **run 难度坡**：序易终难 + Boss 性格 → 每把不同、差一点通关的留存钩。

## 八、调参纪律

- 改平衡只动本表的值（+ 各文档对应数据）；**逻辑/算法不动**（确定性 hash 不变）。
- playtest 优先核：① 斩首流是否过强（士气±/斩首门）；② 干预能量松紧；③ 终局过墙；④ 布阵是否有唯一最优（克制网是否成立）。
- 真机 playtest 数据回来后，本表逐项收敛。

## 九、回合制经济（`24`）—— 召唤源泉 + 放牌费用（owner 2026-06-21）

| 项 | 值（起手种子·sim 调） |
|---|---|
| 召唤源泉 起步 / 每回合 | `MANA_START=4` / `MANA_PER_TURN=1`（owner 2026-06-23：实装 6→**4**·**双方对称**·收紧开局·别让玩家一上来铺满） |
| **放牌费用·免费档**（点数 2–4） | **0 源泉**（纯铺场肉·spam 待 sim 裁） |
| **放牌费用·低档**（点数 5–7） | **1 源泉** |
| **放牌费用·中档**（点数 8–10） | **2 源泉** |
| **放牌费用·高档**（点数 J/Q/K/A=11–14） | **3 源泉** |
| 抽牌 / 打天罡 / 弃牌 | `DRAW_COST=1` / `CAST_COST=1` / 弃免费 |

> **意图**：放牌按点数收费（推翻 6-20 免费）= 给低牌"便宜节奏/铺场弹药"身份、坐实铺场流。A=14 归高档（最强牌不能 1 费）。王/JOKER 不在玩家库、无档位。
> ⚠️ **风险/sim 重点**：① 全低牌 spam 是否过强（→ 调高档差 or MANA_PER_TURN）；② 高牌是否永远不值（→ 收窄费差 or 抬高牌威力）；③ turn1=1 源泉只放得起低牌 = 低牌开局垄断（特性·非 bug）。**3D-SIM 扫费用曲线 × 流派 → 胜率矩阵 + 退化告警**，目标各流派可达 ~50% 对镜像。
> **实装**：`turn-combat` `DEPLOY_COST` 常量 0 → `deployCost(rank)` 查本表（接 `deployUnit`/`canAct`）·纯数据·零引擎（详 `doc24 §4.1`）。

## 十、基础连携（`19 §4.1`）—— 一条路内 同点 / 同花 连线（owner 2026-06-21）

| 项 | 值（起手种子·sim 调） |
|---|---|
| `COMBO_PAIR` 同点对子（路内 ≥2 同点·各+） | **+6** |
| `COMBO_TRIPS` 同点三条（路内 ≥3 同点·取最高不叠对子） | **+12** |
| `SUIT_PER` 同花每张（路内同花张数−1 ×此·各+） | **+3** |
| `SUIT_CAP` 同花封顶 | **+12** |

> **意图**：让"带哪些英雄"有策略——同点=占位高投入高回报、同花=易凑缓回报。两轴并存防唯一最优。
> ⚠️ **sim 重点**：① 全同花/全同点流是否唯一最优（→ 调 SUIT_PER/CAP 与 COMBO 值平衡）；② 与放牌费用曲线交互（堆同花低牌 spam？）。**3D-SIM 扫连携流 vs 其它流派 → 各 ~50% 对镜像。**
> **实装**：`turn-combat`/clash 一条路扫同点（复用现 `combo` 检测）+ 新增同花扫描 → 加 buff 进 P_eff。纯 game-side·零引擎（详 `doc19 §4.1`）。
