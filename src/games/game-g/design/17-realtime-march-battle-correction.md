# 17 · 战斗模型纠偏：实时三路行军 → 遭遇掷命 → 攻克大本营（owner 2026-06-16 纠正）

> ⛔ **重大纠偏。最高优先，盖过 VIS 收尾。** owner 跑游戏后指出：现战斗是"瞬间翻牌"，不是他要的**实时三路行军战**。诊断属实——核心战斗被做成 instant-resolve best-of-3、丢了"兵行走/遭遇/推进/攻克大本营/长战斗"。
> **本篇取代 instant-resolve**（`resolveArmy`/`buildGameGArmyMatch` 的瞬间结算 + best-of-3 + 抛飞瞬翻），改回**实时整数行军**（doc 08 §一/§3.2 本来就这么写）。

---

## 〇、owner 要的模型（逐字钉死，2026-06-16）

> **局前排兵布阵**：选哪些扑克走上路、哪些走中路、哪些走下路。
> **实时运行**：双方布阵一一对应 → **兵沿三路行走（非常长的战斗时间）** → **遭遇即翻牌（掷命定生死）** → 胜者继续推进 → **直到大本营被攻克 = 胜**。

## 一、诚实复盘（为什么错了）

- v0.1(peaceful-volta) 曾有 RTS 行军（寻路/接触掷命），后因 owner "不是物理决定胜负" 被回退成 outcome-first。
- **回退过头**：把"实时行军"连同"物理决定胜负"一起扔了。owner 要的是 **实时行军(确定性整数移动) + 遭遇掷命(规则定，非物理)**——两者不矛盾。
- program G 的 T-G2 实装成 instant-resolve（一次性掷所有牌→数存活→best-of-3），**design G 核验时没抓出它丢了 doc 08 §3.2 的逐格行军**；后续 VIS 把错模型越描越漂亮 → owner 一跑就看出"什么玩意"。**design G 失误，纠。**

---

## 二、正确模型 = 实时整数行军（= doc 08 §一/§3.2）

| 环节 | 规则 | 复用/实现 |
|---|---|---|
| **布阵** | 每张牌指派一路(上/中/下) + 路内次序 | showFormation 升级：从"每路军官数"→"哪些牌入哪路"（保留预设快选）|
| **行军** | 每路双方牌从各自大本营出发、**逐格整数推进**（每拍 +1 格，确定性、lockstep 安全）| 复用 gameF 移动/Timer；track_pos 整数 |
| **遭遇** | 两军前锋进到同格 → **掷命 `decideFaceUp`**（favor 加权种子、规则定，**非物理**）→ 反面死/正面活 | 复用现 decideFaceUp + 将领牵动/干预/牌型/流派 favor |
| **推进** | 胜者继续前进；favor 修正(将领/干预/牌型/流派)全在遭遇那一掷生效 | 复用现 favor 链 |
| **大本营** | 每方 `home_hp`；敌牌抵达攻击 → 扣 hp；**hp=0 → 大本营被攻克 = 该方负** | 复用 gameF Resource/Zone |
| **长战斗** | 行军+遭遇+推进 = 有时间纵深（owner 要的"非常长"）、非瞬间 | 实时 tick 循环 |

> **胜负载体改变**：从"best-of-3 数存活" → **"攻克大本营 hp"**。三路是通往大本营的路；待 owner 定细节：①破对方大本营即胜，还是②三路各通一个分基地/综合。**首版建议：一个大本营、三路皆通向它，先破者胜**（最贴"大本营被攻克"原话）。

---

## 三、与 outcome-first 不矛盾（澄清）

- **掷命结果仍规则定**（decideFaceUp 确定性种子）→ 守住"不是物理决定胜负"。
- **行军是确定性整数移动**（每拍 +1 格、进 hash、lockstep 安全）→ 这不是"物理决定胜负"，是"按时间推进的确定性 sim"（同 gameF HexPos）。
- 结论：**outcome-first 管"每次遭遇的翻牌结果"；实时行军是战斗的时间结构。两者并存、都确定性。**

## 四、复用 vs 重做（成本诚实账）

- **复用（大头都在）**：decideFaceUp / 将领牵动 favor / 干预 / 牌型阶梯 / 流派激活 / 布阵数据 / 三路结构 / **VIS 画面（三路战场/老家牌王座/卡牌/金石翻面——这画面正好就是行军战场！）**。
- **重做（核心）**：战斗执行层——从 `resolveArmy`(瞬间) 改为 **逐拍行军 + 遭遇掷命 + 大本营 hp + 攻克判负**（doc 08 §3.2 整数推进）。复用 gameF 移动/Timer/Zone/flow。
- **VIS 几乎不浪费**：现画面已是三路战场+老家+卡牌，**只差让卡牌真"走"起来 + 遭遇翻 + 推到老家**，把"抛飞瞬翻"换成"行军遭遇推进"。
