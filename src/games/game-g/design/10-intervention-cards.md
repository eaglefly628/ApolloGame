# 10 · 干预卡 / 功能牌目录（局内能动性 · Levers）

> game design G ｜ 2026-06-15 ｜ 承 `07` §二 + owner 愿景"用手法改概率 + 功能牌改战场（进攻/埋伏/特殊出现）" + UI 左栏「干预卡·Levers」。
> 现状：布阵（`09`，已落）给**开战前策略**，掷命（`01`）给**运气**，将领（`06`）给**连锁**——但**开战那一刻玩家无操作**。干预卡补上**局内战术能动性**。

---

## 〇、设计定位 + 红线

- **干预卡 = 花「干预能量◈」改 favor / 规则输入 / 布阵**，在**备战·干预相位**打出 → 然后三路揭晓掷命（承早期"对战"稿的 `备战·干预 → 掷命` 相位）。
- ⛔ **outcome-first 红线**：干预只改**掷命前的输入**（favor / 主将 / 兵力 / 阵型），胜负仍 build 时由规则定、可回放。**绝不改物理、不在揭晓后回灌。**（与 program G 的"build 时逐级掷命"模型天然合拍：干预 = 揭晓前调输入。）
- **每张卡 = `{时机, 目标, 效果, cost}` 数据**，最弱 LLM 能填 → 数据接口。零新能力（condition/effect/spawn/group-count/poker-hand 重组）。

---

## 一、干预能量◈ 经济（取舍的来源）

| 项 | 首版值（TUNE）|
|---|---|
| 开局能量 | 3◈ |
| 每关/每轮回能 | +2◈（banded）|
| 卡费 | 小手法 1◈ / 战术 2◈ / 决定性(斩首/增援) 3◈ |
| 上限 | 6◈（逼"这关花还是攒"）|

> 数据：`Resource{id:'lever_energy'}` + banded 回能 + `craft-recipe` 原子扣费（同 gameF 商店）。**能量不够=打不出 → 取舍张力。**

## 二、目录（5 类 · 咬合已落系统）

> 标注：✅纯复用 ｜ 时机 P=备战相位 / R=best-of-3 路间。

### A. 概率手法（改命 —— 童年"手法"的数字化）
| 卡 | cost | 效果 | 数据形 |
|---|---|---|---|
| **祝福** | 1◈ | 选 1 友方牌 favor +20 | effect 改 favor ✅ |
| **诅咒** | 1◈ | 选 1 敌方牌 favor −20 | effect ✅ |
| **护盾** | 2◈ | 选 1 友方牌：反面免死一次 | status 免死位（掷命读）✅ |
| **重翻** | 2◈ | 揭晓后选 1 反面友方牌再 roll 一次（同序列）| 重 roll 信号 ✅ |

### B. 擒贼先擒王（将领系 —— 咬合 `06` 溃散）
| 卡 | cost | 效果 | 数据形 |
|---|---|---|---|
| **斩首令** ⭐ | 3◈ | 直接对敌某路**主将**掷命；死则触发该路 −14 溃散连锁（`06`§三）| 对主将单掷 + 复用溃散 ✅ |
| **督战** | 2◈ | 我某路主将 favor↑ 且本路士气加成翻倍（活则 +16）| 改主将 favor + 士气系数 ✅ |
| **临阵换将** | 2◈ | 把我某路一张高军衔牌升为主将（换主将、防斩首）| 改"该路主将"指针 ✅ |

### C. 三路战略（咬合 best-of-3）
| 卡 | cost | 效果 | 数据形 |
|---|---|---|---|
| **增援**（特殊出现）| 3◈ | 向我某路 spawn 2 兵（go-wide 该路）| `self-rule` spawn(REQ-021) ✅ |
| **弃车保帅** | 2◈ | 主动认输我最弱一路 → 把它的能量/favor 注入另两路（固化弃一保二）| 路级 favor 转移 effect ✅ |
| **声东击西**（埋伏）| 2◈ | 隐藏我某路真实强度、误导 AI 暗布阵读心（`09`§四）| 改 AI 可读的"历史/预估"输入 ✅ |

### D. 牌型阶梯（咬合 军衔=点数 + 扑克身份 —— "52 张"的最大变现）
> **已实装 + 设计锁定（2026-06-15，program G 综合 → design G 批准）**：路是 18+张、非 5 张手牌，故 `evaluateHand`（限恰 5 张）不直接套；但 program G **复用 poker-hand 的 `isStraightRanks` 真算法 + `HandType` 枚举**，按"路"语义评本路凑成的**最高扑克牌型**（同花=≥5 同色 / 顺子=路内含 5 连点 / 对·三·四条=rank 计数）→ 逐级 +favor。**牌型阶梯成立、零新能力**（我上轮"撤回阶梯改纯计数"的判断据此收回——program G 的综合更优）。

| `laneHandTier` 该路最高牌型 | favor 加成（首版已落 3→18，TUNE）| 算法 |
|---|---|---|
| 对子 / 两对 | +3 / +5 | rank 计数 |
| 三条 / 顺子 / 同花 | +8 / +11 / +13 | `isStraightRanks` / 数同色 |
| 葫芦 / 四条 | +15 / +17 | rank 计数 |
| 同花顺 | +18（招牌一击）| isStraightRanks ∧ 同色 |

- **「牌型」卡**（2◈，已实装）：揭晓前选一路，按 `laneHandTier` 给上表 favor。
- **对王**（3◈，叠加）：两张大队长(王/K)同路 → 双双 favor++（group-count 军衔）。
- → **"52 张扑克"身份变现**：往某路塞同花色/连号/同点 = 开战前的微型组牌博弈。

### E. 伏击（条件触发 —— "埋伏"）
| 卡 | cost | 效果 | 数据形 |
|---|---|---|---|
| **伏兵** | 2◈ | 在某路设伏：敌主将该路掷命时 −favor | condition(敌主将该路) → effect ✅ |
| **诈败** | 1◈ | 我某路本轮 −favor、下一对局 +favor（赛季/连战时）| banded by 局次 ✅ |

## 五、复用 / 缺口（CORE RULE）

| 机制 | 判定 |
|---|---|
| 改 favor/主将/能量 | ✅ effect + craft-recipe |
| 斩首+溃散 | ✅ 复用 `06` 主将掷命 + −14 连锁 |
| 增援 spawn | ✅ `self-rule` spawn(REQ-021) |
| 牌型阶梯(对子→同花顺/对王) | ✅ 复用 poker-hand `isStraightRanks`+`HandType`（按"路"18+张语义），零新能力（已实装）|
| 护盾免死/重翻 | ✅ status 位 + 重 roll 信号（掷命已有 rng）|

> **零新引擎能力**。✅ **D0 已核+锁定（2026-06-15）**：牌型阶梯按"路"语义复用 poker-hand `isStraightRanks`+`HandType`（`evaluateHand` 限恰 5 张、不直接套到 18 张路），零缺口、无需 REQ-G。joker 更花哨算子若后续要再核。

## 六、验收（T-G4）

1. 干预能量◈ 经济（开局 3 / 回能 / 上限 6 / 扣费原子）。
2. 首发 6 卡可在备战相位打出、改 favor/spawn/主将、揭晓掷命读改后值。
3. 斩首令打掉敌主将 → 该路溃散（−14 连锁，`06`）。
4. 同 seed + 同干预序列 → 逐拍 hash 一致（确定性，干预进 sim）。
5. tsc + vitest + build 全绿。

> 复诵：干预卡=花◈在揭晓前改 favor/主将/兵力/阵型，把"开战无操作"补成局内战术；斩首令让"擒贼先擒王"可玩、同花顺让"52 张扑克"身份有回报。全在揭晓前生效 → outcome-first 不破，零新能力。
