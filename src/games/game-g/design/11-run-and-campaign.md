# 11 · 战役 / Run 结构（把单场对战串成有弧线的征程）

> game design G ｜ 2026-06-15 ｜ 承"让游戏丰满"。现状：战斗核（`06`）+ 布阵（`09`）+ 干预卡（`10`,建设中）给了**单场**深度，但一局玩到尾还缺**进程弧**——本篇补 run 结构（roguelike 元层），呼应 owner 的"假想一整场战役"。

---

## 〇、为什么需要 run 结构

单场掷命再好玩，也只是一场。**run = 一场战役**：连打 N 场、逐场抬难度、场间养成、终局 Boss 决战。它给三样东西：**节奏弧**（起承转合）、**养成动力**（场间变强）、**留存钩子**（差一点通关，再来一把）。这正是 owner 童年"假想一整场战役（进攻/埋伏/特殊出现）"的数字化骨架。

---

## 一、run = 一场战役（连战 + 命线）

```
[选牌组/势力] → 第1场 → 场间(改造/掉牌/回能) → 第2场 → … → 终局 Boss 决战
                  │胜:奖励+1命? / 败:扣命                         │
                  └──────── 命线(lives) 尽 = run 结束 ◀───────────┘
```

- **命线**：开 run 给 N 条「命」（首版 3）。一场对战 = best-of-3 三路；**输一场扣 1 命**，命尽 = run 失败。胜则进下一场。
- **长度**：首版一场战役 = **5 场**（序2·中2·终1），约 10–15 分钟一 run。

---

## 二、战役节奏（敌将曲线 = 数据关卡表）

| 场 | 段 | 敌方 | favor 偏置 / AI |
|---|---|---|---|
| 1–2 | 序战 | 杂兵海 + 低军衔将 | 低偏置 / AI 均衡布阵 |
| 3–4 | 中段 | 名将（高军衔主将）+ 台面机关（河道等表现）| 中偏置 / AI 变阵 |
| 5 | 终局 | **Boss 牌王座**（满军衔主将 + 专属机关 + 起手干预）| 高偏置 / **AI 克制你历史布阵** |

> 关卡 = 数据条目（敌方 `Formation` + favor 偏置 + AI 难度 + 掉落表），最弱 LLM 能填 → 数据接口。复用 gameF 的 run/round flow 思路（关卡表 + flow），零新能力。

---

## 三、场间间歇（roguelike 养成 = 留存核心）

每场胜后，一个**短暂选择窗**（≈杀戮尖塔场间）：

| 给什么 | 数据形（复用） |
|---|---|
| **掉材/掉牌**（按胜势/贡献）| banded `event-when→effect` + `card-pile` |
| **改造一次**（升某牌 favor / 融小丑·星球，`07`）| `craft-recipe` |
| **回干预能量◈ + 可选购干预卡**（`10`）| 资源 + 庄家货架 |
| **三选一增益**（roguelike 选牌：升一路/加一命/换阵型解锁）| `card-pile` 三选一（同 gameF 选秀同形）|

> 场间 = 把"单场"黏成"越打越强"的链条。**强度可成长、掷命永留 5% 翻盘**（`01`）→ 公平与养成并存。

---

## 四、难度与 AI 升级曲线（让 5 场有递进张力）

- **敌方 favor 偏置**逐场 +（序低终高）= 越后越难活。
- **AI 布阵**逐场升级（`09`§四）：序=均衡 → 中=变阵 → 终=克制你这 run 的布阵偏好（读心拉满）。
- **终局 Boss**：主将全满军衔 + 起手就甩干预卡（斩首/增援）→ 逼你留干预能量决战。

---

## 五、复用 / 缺口（CORE RULE）

| 机制 | 判定 |
|---|---|
| 连战关卡表 / 进位 | ✅ 复用 flow + 关卡数据（gameF run/round 思路）|
| 命线（lives）| ✅ `Resource{lives}` + flow 终止判定 |
| 场间掉材/改造/三选一 | ✅ banded + `craft-recipe` + `card-pile` 三选一 |
| 难度/AI 曲线 | ✅ 纯数据（每场偏置 + AI 难度字段）|
| 终局 Boss | ✅ 一条特殊关卡条目（高 favor 主将 + 起手干预）|

> **零新引擎能力**。run 结构 = 关卡表数据 + flow + 现成经济/卡池重组。

---

## 六、验收（未来 T-G5）

1. 一 run = 5 场连战 + 命线（3 命，败扣命、命尽结束、打穿=通关）。
2. 场间窗：掉材 + 改造一次 + 三选一增益 + 回◈。
3. 敌方 favor/AI 逐场升；终局 Boss 成立。
4. 同 seed + 同决策序列 → 整 run 逐拍 hash 一致（确定性）。
5. tsc + vitest + build 全绿。

> 复诵：run = 一场 5 战的战役，命线兜底、场间养成、敌将与 AI 逐场抬、终局 Boss 牌王座决战。把"单场掷命"黏成"越打越强、差一点就通关"的征程——丰满与留存的骨架，全数据零新能力。
