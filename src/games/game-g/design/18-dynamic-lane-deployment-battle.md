# 18 · 动态三路投放战斗 —— 核心博弈层（玩家实时控盘 · 田忌赛马 · 以少胜多）

> game design G ｜ 2026-06-17 ｜ 触发：owner 定义核心战斗博弈。
> **与 17 的关系**：`17` 立了"实时三路行军"的**时间骨架**（兵走 → 遭遇掷命 → 攻克大本营）。
> **18 在骨架上长出"玩家控盘"的博弈肉**——把「开局定死、自动跑完」升级为「**全程读敌 → 投放 → 干预**的连续博弈」。这是 Game G 真正的灵魂层。
> 本文供 owner **反复推敲**：框架已搭、机制已分解，**§七 是推敲菜单**（每个开放岔口给推荐 + 备选）。

## 一、owner 愿景 · 忠实拆解（钉死，勿漂移）

| owner 原话 | 拆成机制 |
|---|---|
| 「不是牌一下子刷过去」 | ❌ 取消"瞬间结算 / 一次性翻完"。战斗是**有时间纵深的过程**。 |
| 「玩家控制往通路里放牌、分配扑克走哪些路」 | ⭐ **玩家投放层**：兵力不自动铺满，是玩家**把具体牌投进上/中/下**。 |
| 「开始定义好上中下也可以」 | **预布阵**（开局先分）= 可选起手。 |
| 「也可以战斗中根据敌人情况去摆、动态把兵力投放到三路」 | ⭐ **战斗中动态投放**：留预备队，看敌情**实时补哪路**。这是博弈主舞台。 |
| 「投放过多别的路就会失败」 | ⭐ **田忌赛马**：兵力**有限**，堆一路 = 弱别路。分配即取舍。 |
| 「用牌组对一路干预、敌人某路特别多时配合特定牌以少胜多」 | ⭐ **干预/牌组组合**：针对某路打组合牌，**以少胜多**翻盘。 |
| 「牌慢慢往对方阵地移动、给双方思考和决定的时间」 | ⭐ **慢行军 = 决策窗**：移动慢是**设计目的**，不是表现——它**制造博弈的时间空间**。 |
| 「过程中极强的博弈」 | 北极星：乐趣 = **用分配 + 时机 + 组合 outsmart 对手**，不是数值碾压。 |

> 一句话：**Game G 战斗 = 一局"慢速三路兵棋"——双方边看边投放、边读边干预，用田忌赛马的取舍 + 以少胜多的组合，掰动掷命的随机。**

## 二、核心循环（moment-to-moment）

```
开战：三路就位，牌从己方老家「慢慢」向敌方老家行军（敌方同时反向压来）
  │
  ▼ （循环，全程实时、可暂停/缓速思考）
①  看  ── 三路敌我兵力/牌型/主将一眼可读；哪路要崩、哪路能赢
②  断  ── 田忌赛马：守 or 弃？这路压上预备队，还是弃它保另两路（弃一保二）？
③  投  ── 把"具体牌"投进某路（强牌=高点数大将，投了就开始走、且耗调兵点）
④  干  ── 敌某路堆太猛 → 落"干预/牌组组合"到那路（祝福/斩首/顺子加成…）以少胜多
  │
  ▼ 牌在中线附近相遇 → 「遭遇掷命」decideFaceUp 规则定生死（正面活/反面死，看得见地翻）
        胜方余部继续推进 → 抵敌老家 → 逐拍 chip 敌 home_hp
  │
  ▼ 谁先把对方 home_hp 打到 0 = 攻克大本营 = 胜（长战斗，net 突破累积）
```

**慢行军是命门**：行军越慢，①看→②断→③投→④干 的窗口越大、博弈越深；越快 = 越像手速比拼。**这是首要手感旋钮（§八）。**

## 三、和 outcome-first 的和解（最高 law · 必须钉死）

> ⚠️ 引入"战斗中投放"后，**翻牌不再能全在 build(t=0) 时算完**——因为玩家中途的投放/干预会改变"谁和谁遭遇、带多少 favor"。这看似冲撞 `01`/`17` 的"build 时定胜负"。**但不冲撞 manifesto 本质，反而是它的深化。**

manifesto / outcome-first 的**本质三条**（不是"t=0 算完"）：
1. **生死由确定性"规则"定，不由浮点物理** —— `decideFaceUp(favor, seededRng)`，不是飞牌碰撞的物理结果。
2. **表现单向、不回灌** —— 渲染器只演出 sim 真相，永不把物理/像素喂回 gameplay。
3. **可确定性复现** —— 给定相同输入 + seed，逐拍 hash 一致、可回放。

**18 全部满足**，只把"何时算每张牌的命"从「t=0 批量」改为「**遭遇那一拍**」：
- 翻牌仍是 `decideFaceUp`（**规则**，非物理）在遭遇拍调用，吃**那一刻**的 favor（= 布阵 + 已投放 + 已落干预 累积）。✅ 本质①
- 玩家的**投放/干预 = 确定性输入指令**（同任何 RTS 的"在第 T 拍把单位 X 派往 Y"），进 lockstep **输入流**；不是物理、不是回灌。✅ 本质②
- 确定性复现 = **相同输入流 + seed → 相同结果**（标准 RTS lockstep；从"输入日志 + seed"完整回放）。✅ 本质③

> **精确改写（取代 `17` 的"build 时定"）**：
> 「**胜负由确定性规则 `decideFaceUp` 在遭遇拍逐次裁定（非物理）；favor 由布阵 + 实时投放 + 干预这些确定性输入累积；行军是确定性整数时间结构。给定相同输入流 + seed 可逐拍回放。表现层单向不回灌。**」

**多人**（`04`）：从"纯 seed 同步"升为**输入 lockstep**（每拍交换双方投放/干预指令）——这本就是 RTS 同步标准，且 `04` 服务器权威 outcome-first 架构已铺。**首发 vs AI**：AI 投放是**种子化确定性策略**，玩家投放本地确定，整局可从输入日志回放。**浮点债仍不卡 gameplay**（生死是整数规则，不是物理）。

> 复诵：**18 没有打破 outcome-first，它把"规则定生死、表现不回灌、可复现"这三条原样保留，只是让 favor 在一条确定性时间线上被玩家的输入逐步塑形——这正是博弈之所在。**

## 四、机制分解

### 4.1 兵力投放 + 田忌赛马（取舍的根）
- **有限兵力池**：你的牌组（54/方）是**总预算**。不会自动铺满三路——**投了才上场**。
- **调兵点 ◳**（pacing + 取舍旋钮）：投一张牌耗 ◳，**强牌（高点数大将）耗更多**；◳ 随时间慢回。→ 你不能同时把强牌堆满三路，**必须选**。
- **田忌赛马自然涌现**：◳/牌有限 → 上路压三张大将 = 中/下只能塞小兵 → 敌人若也在赌，就成"我强你弱处、避你强我弱处"的猜心。**弃一保二**（弃一路、把预算堆两路稳拿 2:1）是合法且常用策略。
- **不内卷经济**（YAGNI 守则）：田忌张力来自**简单的有限池**，不是复杂经济。◳ 只一个数 + 按点数计费，**不加多资源/科技树/建造**。

### 4.2 两种时机：预布阵 + 战斗中动态投放
- **预布阵（可选起手）**：开局可先把部分牌指派进上/中/下（= `MARCH-3` 的"指派具体牌入路"，保留 4 预设作快捷）。给"喜欢先定策略"的玩家。
- **战斗中动态投放（博弈主舞台）**：手里留**预备队**，开战后看敌情**实时把牌投进某路**。投了即从己方老家起步、沿该路行军。
- **混合是默认**（§七 Fork-1 推荐 C）：预布阵定基本盘 + 预备队打临场——既有计划、又有应变。

### 4.3 慢行军 = 决策窗（博弈的时间空间）
- 一路从己家到敌家 traverse 需 ~数十秒（§八 可调）；遭遇在中线一带**成波**发生，不是一瞬。
- **慢**给足①看②断③投④干 的时间；双方都在"牌还在路上"时反复读、补、骗。
- **缓速/暂停看局**（单人）：可给"慢动作/暂停部署"档降手速门槛、纯抬博弈（§七 Fork-4）。

### 4.4 读敌 + 反制投放（information）
- **敌三路兵力/牌型/主将可见**（已承诺到场上的）→ 你据此反制。
- **敌手牌/预备队隐藏** → 你读的是"对方已经押下的承诺 + 节奏"，不是未来；留下虚张/诱敌空间（推荐，§七 Fork-3）。
- **田忌猜心**：敌 AI 暗布阵 + 动态补援（`09` 已有 `pickAiFormation`，升级为实时补援策略）。

### 4.5 干预卡 / 牌组组合 · 以少胜多（翻盘杠杆）
- 复用 **`LEVER_CATALOG`**（祝福/诅咒/**斩首令**/增援/护盾/牌型羁绊，`10`）——但从"备战相位一次性"改为**战斗中实时落到某路**：改该路**尚未遭遇**牌的 favor（live resolution 天然吃到）。
- **以少胜多范式**：敌中路堆 5 大将、你只 2 张 → 落**斩首**(掉敌主将→该路溃散 −favor) + **顺子组合**(该路成顺子 → 整条牌型阶梯 +favor，`10`/`12`) → **2 掀 5**。这是 owner 要的"配合特定牌 + 牌组组合以少胜多"。
- **能量 ◈** 经济（`10`）管干预频率；调兵 ◳ 管投放频率——**两条独立节流**，避免一资源既管兵又管法。

### 4.6 遭遇掷命 · live resolution（核心改造）
- MARCH-1 的 `resolveArmy`（**build 时批量**算完所有翻牌）→ 改为 **逐拍 live**：每拍推进行军、检测中线遭遇、对每对遭遇牌调 `decideFaceUp(当前favor, rng.next())`。
- **RNG 确定性**：单一 seeded PRNG，遭遇按**确定顺序**消费（lane 序 + 列序）→ 逐拍 hash 稳。
- **favor 即时性**：遭遇拍读该牌当下 favor（含此前所有投放/干预）→ 中途干预**自然只影响未遭遇牌**（不二次解析已翻牌 → 不破 hash，同 `12` §五.5 前向单遍原则）。

### 4.7 胜负 · 攻克大本营（保留 MARCH-1）
- 各路胜方余部抵敌老家 → 逐拍 chip `home_hp`（`17`/MARCH-1，`HOME_HP`）。
- **谁先把对方 home_hp 打到 0 = 攻克 = 胜**。net 突破累积 = 长战斗、有来回、可翻盘。

## 五、数据驱动 / 架构评审（CORE RULE：先判该不该做 + 复用 + 缺口）

**判定：该做（这是核心愿景，非可回驳的 feature）。** 我的架构增值：

**① 三分清楚（manifesto 尺子）**：
- **游戏 = 数据**：三路配置、每牌 favor、干预/小丑/星球定义、调兵点计费表、行军速度/遭遇规则的**参数**。
- **解释器 = 引擎/技能固定代码**：live 行军 + 遭遇 + 掷命解析器（确定性、审计过）。
- **玩家投放/干预 = 运行时输入**（不是被作者写死的数据，是玩家当场的指令）——解释器消费它。
> "最弱 LLM 能否产出一模一样的数据？" 能（配置全是数表）；live 解析器是**固定解释器**那部分（不是每局新写的自由代码）→ 合规。

**② 复用清单（绝大部分已在，零/极少新引擎能力）**：

| 要素 | 复用 | 状态 |
|---|---|---|
| 三路 / 行军 / 遭遇点 / home_hp | MARCH-1/2 + `scene.marchScreenPos` | ✅ 已在 |
| 掷命 `decideFaceUp` / 将领牵动 / 溃散 | `01`/`06`/`resolveArmy` favor 层 | ✅ 已在（拆成 live 调用）|
| 干预（祝福/斩首/增援/牌型…）| `LEVER_CATALOG` / `applyInterventions(caster)` | ✅ 已在（改实时触发）|
| 牌组组合（顺子/同花 → favor）| `poker-hand` / `laneHandTier` | ✅ 已在 |
| 调兵点 ◳ 经济 | 资源/计数原子（同 ◈ 能量） | ✅ 复用 |
| 行军移动 / Timer / 区域 | gameF 移动 / Timer / Zone | ✅ 已在 |
| 战场 UI（三路/单位/干预坞/选路）| `battle-screen.ts`（owner 已确认）| ✅ 已在 |

**③ 真缺口（要新做的，game-side 为主）**：
- **live 遭遇解析器**：`resolveArmy`(批量) → 逐拍推进+遭遇+掷命。**game-side 重构**（同 MARCH-1 性质），复用 `decideFaceUp`/seeded PRNG/Timer。**预判零新引擎能力**。
- **投放指令队列**：玩家/AI 的"第 T 拍投牌 X 入路 L"作为确定性输入喂 sim。Engine 已确定性 tick；指令只是 game-side 状态变更。**预判零新引擎能力**。
  - ⚠️ **若**真冒出通用缺口（如"确定性定时输入指令流"想做成可复用框架）→ 按铁律**提 REQ-G 给主程下沉**，game 层不私写引擎。**但 YAGNI：先不预建框架**，game-side 朴素实现，缺了再下沉。
- **AI 实时补援策略**：`pickAiFormation`(开局) → 加"看战况动态补哪路"（game-side 数据策略，种子化确定性）。

**④ YAGNI / 过度设计守则**：
- 调兵点**只一个数**；不加多币种/建造/科技。
- **不**做自由跨路（除"调度"干预）——保田忌干净（§七 Fork-5）。
- live 解析器**先朴素**（每拍线性扫遭遇），不预优化、不预抽象成通用 RTS 引擎。

## 七、开放选择 · 待 owner 推敲（推敲菜单 —— 每岔口给推荐 + 备选）

> ⬇️ **owner 第一轮推敲已拍板（2026-06-17）→ 见 §十 决议 v2**（投放=手牌+抽牌混合池/慢+读秒暂停/短带迷雾/net 破家）。本节存档推敲过程与备选。
> 这些是会改变手感/深度的真岔口。**我已标推荐，但请你反复推敲、拍板或改。**

**Fork-1 · 兵力投放模型** ⭐最关键
- (A) 全 54 张随时自由分配（无手牌概念，纯分配）
- (B) 手牌 + 抽牌（◳/抽牌门控节奏，CCG 味）
- **(C) 预布阵 + 预备队动态投放**（开局定基本盘 + 留预备队临场补）← **推荐**：最贴 owner"开始定也可以、战斗中也可以"
- 推敲点：你想要"全程都能动每张牌"，还是"基本盘定了、只动预备队"？预备队多大比例？

**Fork-2 · 调兵点 ◳ 经济**
- 推荐：开局给一笔 + **慢回**（每数秒 +1），投牌按点数计费（大将贵、小兵便宜）。
- 推敲点：节奏要"紧"（◳ 少、步步算计）还是"宽"（◳ 多、铺得开）？回复速率 = 战斗张力旋钮。

**Fork-3 · 情报 / 迷雾**
- 推荐：**敌已上场兵力可见、敌预备队/手牌隐藏**（读承诺不读未来，留诱敌空间）。
- 备选：全可见（纯田忌兵棋）/ 全迷雾（侦察玩法）。推敲点：你要"明牌博弈"还是"藏手骗招"？

**Fork-4 · 行军速度 / 决策窗** ⭐手感命门
- 推荐：**慢**（一路 traverse ~30–45s，遭遇成波），单人可加**暂停部署/缓速**档。
- 推敲点：你心里的"慢慢移动"具体多慢？要不要暂停思考？（这条直接决定"博弈 vs 手速"）

**Fork-5 · 跨路移动**
- 推荐：投了即锁该路、**不能自由跨路**（保田忌取舍干净）；仅"调度/增援"干预可移兵。
- 推敲点：你要不要"已投的牌还能撤/转路"？（能转 = 更灵活但稀释田忌取舍）

**Fork-6 · 以少胜多的强度**
- 推荐：组合（斩首 + 顺子）能**逆一档差**（2 掀 5 这种），但不能**无脑翻**（赌性留着）。
- 推敲点：你要翻盘多容易？太易 = 兵力分配没意义；太难 = 干预没用。这是平衡核心，需真机调。

**Fork-7 · 胜负载体**
- 推荐：**net 突破 chip home_hp、先破者胜**（保 MARCH-1，长战斗有来回）。
- 备选：三路 best-of-3 即时判（短平快）。推敲点：要长拉锯还是快决？

## 十、owner 推敲 v2 · 决议 + 心流抽牌深化（2026-06-17）

> owner 第一轮推敲拍了 4 项 + 大幅细化投放模型为"混合手牌 + 非线性抽牌 + 基础布局"。本节锁决议 + 把 owner 要"慢慢磨"的**心流抽牌**展开成可推敲框架。**取代 §七 对应岔口。**

### 10.1 锁定决议
| 岔口 | 决议 |
|---|---|
| 投放模型(Fork-1) | **手牌 + 抽牌**——但**混合牌池** + **基础布局打底** + **非线性抽牌**（10.2/10.3）|
| 节奏(Fork-4) | **慢 + 可暂停部署，暂停时间有限**（围棋读秒式·双方公平时间银行，10.4）|
| 情报(Fork-3) | **短带起手迷雾**：仅靠近各自老家一小段看不见、走出即显形；**显形/侦查牌**可提前刺破（10.5）|

| 以少胜多强度(Fork-6) | 留真机调（10.6 初值）|

### 10.2 混合手牌牌池（"前线"桌游味）
- 战斗牌库 = **扑克牌(单位) + 功能牌(干预) + 小丑/星球牌(质变)** 混在一起抽。
- **打扑克牌** = 把该单位投进某路（沿路行军、参与遭遇掷命，强牌=高点数大将）。
- **打功能牌** = 对某路/某点干预（祝福/斩首/增援/牌型羁绊… = `LEVER_CATALOG` 复用）。
- **打小丑/星球牌** = 局内质变（形态见 10.7 待推敲）。
- **起手基础布局**：每路预铺 ~3 张（共 9）打底，余牌进抽牌堆 → 开局不空、又留大量临场空间。

### 10.3 ⭐ 战潮抽牌（心流引擎 · owner 要"慢慢磨"的核心）
> owner：抽牌**非线性**——"根据战斗情况，有时候跳进来几张、有时候少一点"，要心流。

**设计内核：抽牌不靠固定计时，靠「一条慢底流 + 战斗事件脉冲」——让抽牌节奏 = 战斗节奏的镜像。**
- **手牌上限** ~5–7；**抽牌堆** = 库减基础布局，seeded 洗牌（抽序确定性、可回放）。
- **底流**：每 ~6–8s +1（保底不干手）。
- **事件脉冲**（战越激烈、牌越涌）：

| 战斗事件 | 抽牌脉冲 | 心流意图 |
|---|---|---|
| 一波遭遇翻牌 | +1 | 打得越多、牌越多 |
| **某路告急**（home 被压近破）| **+2~3 援牌** | **绝境涌牌**——张力峰值正好把工具塞你手里 |
| 推进 / 破阵（赢一波突破）| +1 | 趁胜追击 |
| 主将阵亡 / 被斩 | +1 | 动荡期给应对牌 |

- → "有时候跳进来几张、有时候少一点" = **事件驱动的非线性**，且与战斗张力同步 = 心流。
- **确定性**：事件是 sim 确定性触发、抽哪张 seeded → 逐拍 hash 稳，不破 outcome-first。

**3 个抽牌节奏变体（供 owner 磨）**：
- **(甲) 纯事件驱动**（无底流）：完全跟战斗，干旱期真干手 → 最硬核、逼你打牌换牌。
- **(乙) 底流 + 事件脉冲**（**design 推荐**）：保底慢抽 + 激战涌牌，稳中有峰、心流好控。
- **(丙) 打出才抽**（StS 式）：手满则停、打一张抽一张 → 节奏全在你手、最稳但少"涌牌爽"。

### 10.4 暂停预算（围棋读秒）
- 一局给**有限暂停/思考时间**（如 ~90s 时间银行），双方各一份、公平。
- 暂停时从容部署；**花暂停 = 花一种资源** → "何时停下来想"本身成博弈。
- 单人练习档可宽松、天梯严格读秒。

### 10.5 短带起手迷雾 + 显形
- **仅起手短带迷雾**：靠各自老家一小段（staging 区，~路长 20%）看不见；单位走出该带即对敌可见。
- **显形/侦查牌**（功能牌）：提前照亮敌 staging → 抢信息差。**藏手 vs 侦查 = 策略层**。
- 走出带后全程可见（读已承诺兵力，但仍看不见对方手牌/抽牌堆）。

## 十一、整局走一遍（最终模型 · 供 owner 通感校验"对不对、爽不爽"）

> 把 §一–§十 的决议串成一局具体体验。**这是校验核心手感的最佳介质——读着像不像你要的那局，告诉我哪不对。**

- **赛前（改造坊）**：你的 ~54 张战斗库已构筑——一堆扑克单位 + 几张功能牌（斩首/增援/顺子羁绊…）+ 你流派的小丑牌（斩首流的"白衣""先登"）+ 升好的星球。
- **开局**：选基础布局，每路预铺 3 张打底（共 9）；余牌洗成抽牌堆；起手摸 5 张手牌；暂停银行 90s 满。三路**雾带**亮起（双方老家前一小段看不见）。
- **T+0~10s · 慢推**：双方底牌从老家慢慢往中线走。你手里 5 张（3 扑克 + 斩首 + 侦查）。打出**侦查** → 照亮敌中路 staging → 看见雾里压了俩大将（K、Q）。读到了。
- **T+10~25s · 田忌断舍**：敌中路重兵。你**断：弃中、保上下**——不往中路加牌（让 3 张底牌拖住），把手里 2 大将投上、下路。投牌耗手牌；底流每 6–8s 回 1 张。
- **T+25~40s · 涌牌心流（峰值）**：上路先遭遇翻牌（你两将翻正、压制）→ 脉冲涌进 2 张；同时**中路告急**（敌 K 压近你中 home）→ **绝境涌援牌塞你 3 张**！你正好抽到**增援 + 顺子牌** → 赌一把：中路砸增援（铺场）+ 顺子羁绊（中路成顺子 → 整条牌型阶梯 +favor）→ **以少胜多反杀敌 K**。张力拉满、手牌也最多——**心流峰值**。
- **T+40~60s · 收口**：上下路已突破、余部抵敌老家逐拍 chip home_hp；中路反杀后也压过去。三路 net 突破累积 → 敌 home_hp 见底 → **攻克大本营 = 胜**。
- **全程**：看雾 → 侦查 → 读敌 → 田忌断 → 投牌 → 涌牌 → 以少胜多干预，**反复博弈**；牌慢慢移动给足每步思考（+ 读秒暂停）；随机（掷命 + 抽牌）被你的**构筑 + 时机 + 组合**掰动。
