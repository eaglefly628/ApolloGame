# 09 · 开局布阵 / 分兵（灵魂第二层 · 田忌赛马）

> game design G ｜ 2026-06-15 ｜ 承 `06` §四 + program G 在 PG-finish-list 的请求（"布阵交互形态需 design G 定"）。
> 现状：G2 已落「军衔/三路/将领/best-of-3」，但布阵是**自动均衡发牌**——**玩家能动性缺一大块**。本篇把布阵做成**开战前的核心博弈**。

---

## 〇、为什么布阵是灵魂第二层

掷命（`01`）给"运气与手法"，将领（`06`）给"指挥与连锁"，**布阵给"战略与猜心"**。它和 best-of-3 咬合出本作最核心的一道选择题：

> **三路只需赢两路。你是「三路均摊、赌每路险胜」，还是「弃一路、把精锐堆进两路、稳拿二比一」？**

这就是**田忌赛马**：用你的"下等马"（兵 + 低军衔）填一路认输，把"上中等马"（大队长/中队长）集中到另两路碾压。**而 AI 也在布阵**——你弃哪路、它堆哪路，变成开战前的猜心层。一句话：**布阵把"掷命"从运气，升级成"运气 × 策略 × 读心"。**

---

## 一、决策本质（数据约束）

- 一军 = **30 名军官（大队长 6 / 中队长 8 / 小队长 16）+ 24 兵**，共 54。
- 三路各 **18 张**，兵自动补位。**玩家真正分配的是 30 名军官**（军官＝高 favor + 当主将牵动全路，`06` §三）。
- **每路首席（最高军衔）= 该路主将**：主将军衔越高 → 士气加成基数越高、活则全路 +favor、亡则溃散（擒贼先擒王）。
- → **"把几个大队长/中队长放哪路"** = 决定哪路强、哪路弃。

---

## 二、交互形态（回答 program G：**预设 + 拖拽 混合**）

不二选一，两者叠加（易上手 + 有深度）：

| 层 | 形态 | 作用 |
|---|---|---|
| **快速** | **预设阵型**（一键套用）| 新手/快节奏；4 个命名分布（§三）|
| **进阶** | **拖拽微调**（把军官卡从一路拖到另一路，兵自动补平到 18/路）| 老手抠细节；drag-place 能力 |
| **反馈** | 每路**实时预估条**（Σfavor / 主将军衔 / 预估胜率★）| 让"弃一保二"看得见 |

- 流程：进对战 → **布阵屏**（默认套「均衡」预设）→ 可一键换预设 或 拖拽微调 → 确认「出征」→ 三路抛飞掷命。
- 实现：布阵屏=GameShell 面板 + 三路落区（canvas drag-place）；输出 = 一张 `Formation` 数据表（§五）喂战斗。**棋盘外的纯数据决策，不碰 outcome-first 内核。**

---

## 三、预设阵型（命名分布 = 数据；首版 4 个）

| 阵型 | 军官分布（上/中/下）| 打法 | 克制关系 |
|---|---|---|---|
| **均衡** | 10 / 10 / 10 | 三路都想险胜 | 被"弃一保二"针对单路碾压 |
| **锋矢·攻中** | 6 / 18 / 6 | 中路绝对优势，赌中+1边 | 怕对手也弃中、两翼对拼 |
| **两翼·弃中** | 13 / 4 / 13 | 中路认输，吃上下两路 | 怕对手猛攻中后转一翼 |
| **田忌** | 2 / 14 / 14（上路丢兵认输）| 经典弃一保二，最稳的 2:1 | 怕对手也田忌、撞同弃路 |

> 数值=首版待平衡（军官"分布"按军衔加权，不只数量；详细权重交战斗调参）。**石头剪刀布闭环**：均衡↔锋矢↔两翼↔田忌 互有克制 → 读心有意义、无唯一最优。

---

## 四、vs AI（让猜心成立）

- **AI 也布阵**：按关卡难度从阵型池选（数据策略）。低难=固定「均衡」；中难=随机阵型；**高难=读你"近 N 局布阵偏好"反制**（你老弃上路→AI 猛攻上路）。
- AI 布阵**对你隐藏**，开战才揭晓 → 田忌赛马的"猜对了爽/猜错了亏"张力。
- 全是**数据**：AI 阵型选择=查表 + 你的历史布阵统计（localStorage，已有存档底子）。零新能力。

---

## 四.5 · AI 反制布阵·意图映射（答 program G "AI 反制需映射意图"，给 U6）

> §四 立了"高难读历史反制"的方向；本节钉死**具体反制策略**，让 AI 像真对手（猜心兑现）。全数据：AI 读可见情报 → 查策略表，零新能力、确定性安全（进 sim）。

**AI 可见情报（intel）**：① 你近 N run 的**布阵偏好**（常弃哪路/常堆哪路，localStorage 存档）；② 你**出战流派**（`save.jokers`→`detectArchetype`，作敌方情报暴露给 AI）。

**反制三轴（按难度递增启用）**：

| 轴 | 反制意图 | 数据 |
|---|---|---|
| **布阵反制** | 你常**弃**某路→AI **猛攻**该路（罚弃路）；你常**堆**某路→AI **避其锋、弃该路、吃另两路**（田忌反制）| 读历史→选阵型 |
| **流派反制(Boss)** | 终局 Boss 选 archetype **克制你流派**那名（克制网 `12`）| detectArchetype→`archetypeMatchup` 选 Boss |
| **干预反制(openingLevers)** | 斩首你**最强路主将**；诅咒你**主攻路** | 读你布阵→定 openingLevers 目标 |

**难度档**：低关=均衡无反制（教学）；中关=随机变阵+随机 Boss（有变数无针对）；**高关=三轴全开**（读历史反制布阵+克制流派 Boss+针对性起手干预）=真·猜心对手。

> 反制非作弊：AI 只读**可见情报**（历史+已揭流派）、按公开克制表行动；你可**变阵/换流派**反读它。

## 五、数据形（喂战斗，program G 照填）

```jsonc
// 一次布阵 = 把 30 军官分三路（兵自动补到 18/路）
"Formation": {
  "lanes": {
    "top":    { "officers": ["JOKER","K♠","Q♥", ...], "fillTroops": true },
    "mid":    { "officers": [...], "fillTroops": true },
    "bottom": { "officers": [...], "fillTroops": true }
  }
}
// 预设 = 命名的 officer→lane 分配函数(确定性)；玩家拖拽 = 改这张表
// 战斗侧：standardArmy 改为「读 Formation 发三路」(替代现在的蛇形均衡)
```

- **接点**：G2 的 `standardArmy` 现在是"军衔降序蛇形发三路"——改成"**按 Formation 发**"（无 Formation 时回退蛇形=均衡，零迁移）。
- 布阵屏交互 = GameShell（预设按钮 + 预估条）+ canvas drag-place（拖军官卡到路）。

## 六、复用 / 缺口（CORE RULE）

| 机制 | 判定 |
|---|---|
| 布阵分配（30 军官→三路）| ✅ 纯数据 `Formation` 表；`standardArmy` 改读它 |
| 预设阵型 | ✅ 命名分布（确定性函数/数据）|
| 拖拽微调 | ✅ 复用 drag-place（gameF 有）+ 兵自动补平 |
| 预估条 | ✅ build 时算 Σfavor/主将军衔（同 06 掷命前）|
| AI 布阵 | ✅ 数据策略 + 历史统计（localStorage）|

> **零新引擎能力**。布阵是棋盘外的纯数据决策，开战前喂给已有的 G2 战斗核。

---

## 七、验收

1. 布阵屏：默认「均衡」，4 预设一键切换，拖军官跨路、兵自动补平 18/路，三路预估条实时更新。
2. `standardArmy` 改读 `Formation`（无则回退蛇形），同 Formation+seed → 逐拍 hash 一致。
3. vs AI：AI 按难度选阵型、对玩家隐藏、开战揭晓。
4. tsc + vitest + build 全绿。

> 复诵：三路只需赢两路 → "弃一保二 vs 三路均摊"是核心选择题；预设给易上手、拖拽给深度、AI 暗布阵给读心。布阵=开战前的纯数据决策，把掷命从运气升级成运气×策略×猜心。
