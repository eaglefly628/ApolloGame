# 27 · Campaign 关卡数据库（给主程一关关加载 · owner 2026-06-19）

> game design G ｜ 2026-06-19 ｜ owner：把 52 关战场**系统化入库**——地煞配置 + Boss 随机 12 天罡 + 战役背景/对白 + 难度/奖励，做成**主程读取、逐关加载**的数据结构。**数据驱动**：关卡 = 数据，引擎 = 解释器。

## 一、关卡数据 schema（一关一条 · 主程读）
```
Level {
  id:        1..52,                       // 关序(= 难度序·关1最易→关52孙武终章)
  heroId:    string,                      // 对应英雄(doc23 §三 rank)
  battle:    { name, oneLine },           // 战役名+一句(doc23 §七)
  intro:     string,                      // 战役背景介绍(开场旁白·本doc §五)
  bossLines: { open[], mid[], lose[] },   // Boss 对白(开场/劣势/败北·本doc §五)
  boss: {
    homeHp:   number,                     // 大本营血(难度档·§四)
    deckTier: number,                     // 兵牌强度档(§四)
    tiangang: { pool:"all36"|ids[], pick:12, weights?, seed },  // 随机12天罡(§三)
    disha:    [dishaId×3],                // 3 专属地煞(doc23 §八/§九)
    aiTier:   number,                     // AI 智能档(§四)
  },
  reward:    { unlock:[tiangangId×4], gold:number },  // 解锁+金币(doc25)
  loadoutCap: 2..5,                       // 玩家本关 天罡 loadout 上限(§四)
  targetWR:  number,                      // 基准牌组 sim 目标胜率(§四·平衡用)
}
```
> 全字段可选缺省·缺则用难度档默认。引擎按 `id` 逐关加载；`tiangang.seed` 保证同关随机可复现(配 sim 平衡)。

## 二、数据来源（拼装·不重复存）
- **英雄/战役** → `doc23 §三`(名册) + `§七`(52 战役表)。
- **地煞 3 张** → `doc23 §八`(关1-5) + `§九`(全 47)。
- **解锁/金币** → `doc25`(9 关×4 天罡解锁表 + 货币)。
- **背景/对白 + Boss 数值/随机法** → 本 doc（§三/四/五）。
> 主程 loader 按 schema 把这几处拼成 `Level[]`。

## 三、Boss 天罡随机法（12 张）
- **默认**：从 **36 天罡池**（或"玩家已解锁集"）**均匀随机抽 12**（不重复·一种算一张）。
- **确定性**：用 `seed = 关id`（同关同 seed → 同 12 张）→ 可复现、可喂 sim 扫平衡。
- **进阶(可选)**：每 Boss 配**偏好权重**贴其风格（攻击型偏 power/tempo、守势偏 siege/stamina…）；缺省=纯随机。

## 四、难度档（★ → 数值 · sim 兜底）
| 难度 | 大本营血 | 兵牌强度 | AI | loadoutCap | 目标胜率(基准牌) | 用于 |
|---|---|---|---|---|---|---|
| ★ | 3 | 弱 | 低 | 2 | ~80% | 关1-2 教学 |
| ★★ | 3 | 中 | 中 | 3 | ~70% | 关3-5 |
| ★★★ | 3-4 | 强 | 中高 | 3-4 | ~60% | 关6-15 |
| ★★★★ | 4 | 很强 | 高 | 4 | ~50% | 关16-40 |
| ★★★★★ | 5 | 终章 | 最高 | 5 | ~40% | 关41-52(孙武/成吉思汗) |
> 数值真机调；sim 扫"基准牌组 vs 该关"胜率落在目标档才放行。

## 五、战役背景 + Boss 对白（关1-5 全 · 关6-52 §六逐期）

### 关1 · 温泉关 · 列奥尼达 ★
- **背景**：公元前 480 年，波斯百万大军压境。列奥尼达率三百斯巴达勇士死守温泉关隘口——以血肉筑成不可逾越之墙。**而你，要翻动这场死战的结局。**
- **对白**：开场「波斯人！来取我的长矛吧——如果你们能。」｜劣势「斯巴达人，早餐尽情吃——晚餐我们在冥府享用！」｜败北「……斯巴达的荣耀，今日终结于你手。」

### 关2 · 高加米拉 · 亚历山大 ★★
- **背景**：公元前 331 年，高加米拉平原。亚历山大以四万直面大流士二十万波斯大军，亲率伙伴骑兵直取王旗。
- **对白**：开场「我不窃取胜利。来吧，让命运在阳光下见分晓。」｜劣势「看我的伙伴骑兵，如何凿穿你的中军！」｜败北「……连我，也有马失前蹄之日。了不起。」

### 关3 · 赤壁 · 曹操 ★★
- **背景**：建安十三年，赤壁。曹操列八十万众于江北、铁索连环。一把火，将改写天下三分。**这一回，你是那把火。**
- **对白**：开场「孤提百万雄师，踏平江东，弹指间耳。」｜劣势「区区火攻，也敢撼我连环巨舰？」｜败北「……华容道上，孤竟败于这一炬。」

### 关4 · 滑铁卢 · 拿破仑 ★★★
- **背景**：1815 年，滑铁卢。从厄尔巴归来的拿破仑，要在此重夺欧洲——或永远落幕。
- **对白**：开场「近卫军从未后退。今日，让世界再记住我的名字。」｜劣势「大炮是我最忠诚的女儿——听她歌唱吧。」｜败北「……普鲁士人来得太快。命运，终弃我而去。」

### 关5 · 霸王别姬 · 项羽 ★★★
- **背景**：垓下，四面楚歌。西楚霸王力能扛鼎、勇冠三军，却已陷十面埋伏。虞兮虞兮奈若何——**而你，能否为霸王翻这一局命？**
- **对白**：开场「力拔山兮气盖世！纵八千子弟散尽，此身亦战至最后一人！」｜劣势「此天亡我，非战之罪也！」｜败北「……无颜见江东父老。罢了，就让你来翻这命吧。」

- **背景**：公元前 506 年，吴师破楚，五战及郢。孙武以三万锐卒长驱千里，破楚二十万于柏举，旬日入郢——兵者，诡道也。这盘奇正之局已成定数，唯有你能翻动它。
- **对白**：开场「兵无常势，水无常形。你这一手，我早算在局中。」｜劣势「以正合，以奇胜……可你的奇，竟在我算路之外。」｜败北「我著兵法十三篇，算尽天下，独独算漏了你这执命之手。」

### 成吉思汗·野狐岭
- **背景**：公元 1211 年，野狐岭。金以四十五万据险，蒙古十万铁骑迎风而立。大汗一声令下，万马踏碎金国大军——苍狼的子孙从不问敌众我寡。可这一战的天命，今日由你改写。
- **对白**：开场「长生天在上，凡马蹄所至，皆我牧场。你也想当我的猎物么？」｜劣势「金人四十五万都挡不住我的箭……你算什么东西。」｜败北「我踏平过万里疆土，却被你勒住了缰绳。罢——这命，你翻吧。」

### 凯撒·阿莱西亚
- **背景**：公元前 52 年，阿莱西亚。凯撒以双重壕墙围困维钦托利，内拒突围、外抗援军，六万罗马军困住二十五万高卢人。围点打援，一战定高卢。而你，要翻动这座铁壁之内的命数。
- **对白**：开场「我来，我见，我征服。你不过是我下一行战报里的名字。」｜劣势「内墙、外墙都未曾溃……为何独独防不住你？」｜败北「骰子已经掷下，竟掷出了我的败局。来吧，由你执掌这命运的骰。」

### 汉尼拔·坎尼
- **背景**：公元前 216 年，坎尼平原。汉尼拔以弱势之军张开新月之阵，诱罗马八万深入、两翼合围。一日之间，罗马七万人横尸旷野——围歼的极致。如今，你要翻动这场屠戮的结局。
- **对白**：开场「罗马的孩子们，又来送死了么？我的两翼，正为你们张开。」｜劣势「我合围过整个罗马军团……怎会困不住你一人？」｜败北「我能胜罗马百次，却胜不过你一次。这命，交到你手里了。」

### 韩信·井陉
- **背景**：公元前 204 年，井陉口。韩信背水列阵、自陷死地，三万汉军对赵军二十万。拔旗易帜，置之死地而后生——兵法不曾写的奇谋，他偏要写。这背水一战的生死，由你来翻。
- **对白**：开场「背水列阵，自断归路。我手中之兵，已无退路——也无败理。」｜劣势「陷之死地而后生……可你竟在死地里，断了我的生路。」｜败北「成败一知己，存亡两妇人。今日方知，我这一生的命，原握在你手中。」

### 白起·长平
- **背景**：公元前 260 年，长平。白起佯败诱敌，断赵军粮道四十六日，合围赵括四十万。降卒尽坑，血染丹水——人屠之名自此响彻六国。可这场惨胜的命数，今日由你翻动。
- **对白**：开场「我一生未尝一败。你的命，不过是丹水里又一道亡魂。」｜劣势「断粮、合围、诱杀……我的杀局天衣无缝，破绽何来？」｜败北「我坑杀四十万，竟报应在你这一手。也好，这身血债，由你来清。」

### 哈立德·雅穆克

- **对白**：开场「罗马人把我们当待宰的牲口，关在这山崖上。可我们偏要活成人——你，是来锁我，还是来放我？」｜劣势「藤索会断，绝壁会陡……但被锁过的人，绝不肯再回那笼子里去！」｜败北「我点起的这把火，烧不到罗马的心脏了……就让你接过它。把我这条命，也一并翻了吧。」

### 维钦托利·格尔戈维亚
- **背景**：公元前 52 年，格尔戈维亚高地壁垒森严，连战无不胜的凯撒也在这里头一次尝到大败。高卢之王维钦托利据险游击、诱罗马军仰攻送死，把那位征服者打得仓皇撤兵。这位高卢人困在他唯一击败凯撒的山城，等你来翻。
- **对白**：开场「凯撒在这片高地上栽过跟头。你这执命之人，自以为就比凯撒更强么？」｜劣势「壁垒纵失一道，高地纵让一寸……高卢人的山，你休想轻易踏平！」｜败北「我能让凯撒败一回，却挡不住你翻命的手。高卢的山河，今后便看你的了。」

### 沙卡·祖鲁·牛角阵
- **背景**：十九世纪初的南部非洲，草原焚天。祖鲁战王沙卡持短矛、布"牛角"，两翼包抄合围、所向无敌——他用一支长矛把零散部族锻成一个帝国。这位非洲战王困在他的牛角阵中，等你来翻。
- **对白**：开场「投枪是懦夫的兵器。我的勇士只用短矛，贴上来、刺穿你的胸膛。牛角已张——你往哪里逃？」｜劣势「左角纵被撕开，右角纵被压住……牛角的尖，照样能扎进你的心口！」｜败北「我用一杆短矛铸了一个帝国……却刺不穿你这命数。来，执命的人——换你来铸了。」

### 狮心王理查·阿苏夫
- **背景**：1191 年 9 月，阿苏夫烈日炙烤海岸，萨拉丁轻骑如蝗群缠咬十字军纵队。狮心王理查严令死守不许追击、硬扛箭雨步步推进，待时机一到放出重骑反击，一举击溃这位令全欧胆寒的劲敌。这位十字军之王困在阿苏夫烈日下，等你来翻。
- **对白**：开场「萨拉丁的箭雨都没能乱我的阵脚。你算什么东西，敢拦狮心王的去路？」｜劣势「再忍一刻，再撑一阵……理查的反击，从来只在最后一刻才出鞘！」｜败北「我能压住萨拉丁，能压住满天的箭……独独压不住你这命。罢了——这命，由你去翻吧。」
