## 一、二阶菜单 · 英雄列传（UI 规格 · 优雅 · 给乙）

**触发**：英雄谱(COLL) 点一张牌 / 牌组屏·备战屏**点牌背** → 二阶详情**如展开一卷古书**（非生硬弹窗）。

**布局（自上而下 · 古风纸卷 / 书法感）**
1. **卷首**：立绘（古风拟人·缺则剪影占位）+ 牌面(rank+suit) + 姓名 + **称号印**（朱红印章质感）+ 时代·文明 + 「贡献度第 N 位」徽记。
2. **诅咒·序**（氛围 · 1–2 句 · 小字楷书）：这位英雄的魂如何被封进此牌——**掷命 = 翻他的命**。
3. **列传·生平**（主体 · 详细文案 · 分段）：真实历史——出身 → 成名之战 → 巅峰 → 结局。**知识传递的核心**。
4. **名战**（点睛小卡）：1 个标志战役（名 + 一句战果）。
5. **名言**（若有 · 书法横幅）：一句传世之言。
6. **称号由来**：为何得此称号。
7. **战绩 / 成长弧**（占位 · doc22 §三 杀敌→称号 · 数值后定）：你用这张牌立下的战功（叙事养成 · 现为「尚未立功」占位）。

**优雅原则**
- ① 像翻《史记·列传》/ 一卷古书——纸质感、留白、书法标题、朱印称号；② 渐入 / 卷轴展开动画；③ **先叙事后数值**（rank/数据收进底部小字，不喧宾夺主）；④ 缺内容**优雅占位**（「命运待解封」），绝不空白突兀。

## 二、内容 schema（每位 · 纯数据 · 弱 LLM 可填 · 全字段可选）
`hero{ rank, suit, contribRank, name, nameEn, title(称号), era, civ(文明), curseIntro(诅咒序), bio(生平·多段), famousBattle{name,result}, quote?(名言), titleOrigin(称号由来) }`
→ 缺字段则该处优雅占位；不进任何对战 hash。

## 四、列传文案（逐期填 · 先 3 篇样板定调）

> 调性：**《史记·列传》式**——真实、凝练、有气韵；序句扣"被诅咒/掷命"世界观。每篇 ≈ 序 + 生平 + 名战 + 名言 + 称号由来。

### A♠ ① 孙武 · 兵圣
- **诅咒序**：兵圣之魂，封于黑桃之尖。每一次掷命，都是吴宫教战的那一斩——令出如山，生死立判。
- **生平**：孙武，春秋齐国人，避乱奔吴。以兵法十三篇见吴王阖闾。王欲试其能，命以宫女演阵；宫女嬉笑不从，孙武三令五申而队伍再乱，遂斩王之爱姬二人以肃军令——于是众皆股栗、进退如一。阖闾由是知其善将，拜为将军。前 506 年，孙武与伍子胥率吴师伐楚，五战五捷，柏举一役长驱破郢，以三万之众破楚二十万，春秋第一远征。功成不居，孙武飘然归隐，唯留《孙子兵法》传世。
- **名战**：柏举之战 —— 三万吴师破楚二十万、攻入楚都郢。
- **名言**：知己知彼，百战不殆。
- **称号由来**：兵学之祖，后世尊为「兵圣」；十三篇为古今中外兵家圭臬。

### A♥ ② 成吉思汗 · 一代天骄
- **诅咒序**：草原苍狼之魂，封于红心王座。掷命之时，铁蹄声起——如海洋般的大汗，重临人间。
- **生平**：铁木真，蒙古乞颜部人。少年丧父、部众离散，于苦寒中崛起。以「札撒」立法、以千户制建军，二十余年间统一蒙古诸部。前 1206 年于斡难河源称「成吉思汗」。其后挥师西征，灭花剌子模、踏中亚、饮马里海；南向攻金、围中都。铁骑所至，疆域横跨欧亚，为史上最大之陆地帝国。临终犹定下灭金之策，遗志由子孙承续。
- **名战**：野狐岭之战 —— 十万蒙古铁骑大破金军四十五万。
- **称号由来**：「成吉思汗」意为「如海洋四方般拥有的大汗」——普世君主之号。

### K♦ ⑦ 韩信 · 兵仙
- **诅咒序**：兵仙之魂，封于黑桃之王。胯下之辱与垓下之围，皆在这一张牌的命运里轮回。
- **生平**：韩信，淮阴人。少时贫困，受漂母一饭之恩，亦忍恶少胯下之辱。初事项羽不见用，转投刘邦，经萧何月下追还、登坛拜为大将。其用兵如神：明修栈道、暗度陈仓还定三秦；井陉一役背水列阵，置之死地而后生，以数万破赵二十万；继下齐、围楚，垓下十面埋伏、四面楚歌，逼项羽自刎乌江，为汉定鼎天下。然功高震主，终以谋反之名被诛于长乐宫钟室——「狡兔死，走狗烹」。
- **名战**：井陉之战（背水一战）—— 背水列阵，以少胜多破赵。
- **名言**：（韩信点兵）多多益善。
- **称号由来**：用兵出神入化，世称「兵仙」；萧何誉为「国士无双」。
