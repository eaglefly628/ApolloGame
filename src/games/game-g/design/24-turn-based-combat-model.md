## 一、棋盘
- **三路**，每路一条 **9 格 slot 轨**：**[我方 4 格] · [中 1 格] · [敌方 4 格]**。
- **棋盘 = 3 路 × 9 格的格子盘**；**相邻 = 8 向**（上下左右 + 斜角）——供「斯巴达方阵」等"相邻加成"类地煞/天罡判定。**推进仍沿各路横向**走向敌方大本营。
- 兵占格，从我端走向敌方大本营（轨末）。**先破敌 3 血大本营 = 胜。**
- 9 格先定 · 后可扩。

## 二、回合结构（核心 = 互斥动作）
每回合：
1. **回合开始 +1 召唤源泉**（统一资源 · 起步值 1 · 真机调 ·「召唤源泉」名可改）。
2. **选「一类」动作（互斥 · 本回合只能一类）**：

| 动作 | 内容 | 数量 |
|---|---|---|
| **① 抽牌** | 抽**天罡** 或 **扑克兵**（你选种类） | **无限** · 每抽花召唤源泉 |
| **② 放牌** | 部署一张扑克兵到某路 → **附带一次可选「改机关」**（开/关捷径门 · 可不用） | 花召唤源泉（**按点数 1/2/3 档** · §4.1） |
| **③ 打天罡** | 施一张天罡 | 花召唤源泉 |
| **④ 弃牌 / 卖牌** | 清当前牌堆、腾手 | **无限 · 免费 · 不互斥**（owner 2026-06-21·弃后仍可再选一类主动作 抽/放/打天罡） |

3. **结束 → 棋盘推进一格**：双方场上兵各沿路前进 1 slot；两军相遇 → **掷命对决**（doc19 · 原封不动）。

> 互斥 + 同类无限 = 一个干净的抉择（"这回合我攒牌 / 铺场 / 放招 / 腾手？"），零实时负担、桌游式深思。

## 三、机关（捷径门）
- 三路之间的捷径门（保留 doc21 概念）：开了能换路（增援 / 堵敌）。
- **改机关 = 放牌回合的可选附赠权利**（桌游常见）：放了兵，顺手可开/关一道门，**也可不用**。
- 天罡「城门令」= 同一套门的主动控制（一张专门玩门的牌）。

## 四、召唤源泉经济（回合制版）
> **资源全名「召唤源泉点数」**（owner 2026-06-19 · 原「圣水」更名 · 太像皇室战争）· 行文简称「召唤源泉 / 源泉」。
- **+1 / 回合**（起步 · 调）· 攒着用。抽 / 放 / 打 都花召唤源泉（各 cost）· 弃免费。
- +1/回合是**紧经济** → 每回合做一件小事 = 深思熟虑的桌游节奏。各 cost 真机调（别太慢 / 太快）。

### 4.1 放牌费用 = 按点数分 4 档（owner 2026-06-21 · 低牌价值 · 推翻 6-20「放牌免费」）
> **问题**：低点数牌战力弱、若放牌免费则只是"弱鸡身体"，没有独立价值。**解法**：放牌**按点数收费**——低牌便宜=节奏/铺场弹药，高牌贵=单路决胜。给低牌"便宜、灵活、垄断开局、连携燃料"的身份，坐实**铺场流（go-wide）**。
> ⚠️ **改向**：`DEPLOY_COST` 从 0（6-20 免费）→ 按点数查表。源泉自此成为**铺场核心货币**（原只用于抽/打天罡）。

| 档 | 点数（公平骨架 cardPoints） | 牌 | 放牌费用 |
|---|---|---|---|
| 免费 | 2–4 | 2/3/4 | **0 源泉** |
| 低 | 5–7 | 5/6/7 | **1 源泉** |
| 中 | 8–10 | 8/9/10 | **2 源泉** |
| 高 | 11–14 | J/Q/K/**A** | **3 源泉** |

> **A 归高档**：公平骨架 A=14=全副最强普通牌（非"1"）→ 必 3 费，否则又便宜又最强=破。**王/JOKER 不在玩家牌库**（owner 2026-06-21：小王大王是 Boss、不作玩家可放牌）→ 无需档位。
> ⚠️ **0 费 spam 待裁（owner 2026-06-21）**：放牌"同类无限"+ 2-4 免费 → 一回合可铺一堆免费身体（受手牌/抽牌天然兜底）。**暂先放开**（16 牌组里低牌有限、且 2-4 战力 2-4 最弱=纯铺场肉），3D-SIM 测出退化再加「每回合放牌数软上限」。

#### 4.1.1 ⭐ 防"只带每档最高点"压制（owner 2026-06-21 关键问题）
> **陷阱**：同档高点严格压低点（同 1 费·7 强过 5/6）→ 只带 7/10/A？**四道结构性反制让杂牌必带**：
> 1. **同花连携逼点数多样**（最强·doc19 §4.1）：52 池每(点,花)仅一张 → 一条同花线只能用**不同点数的同花牌**拼（5♠6♠7♠…），**没法用三张 7 凑同花** → 想吃同花就得带"较弱"的 5♠6♠。
> 2. **费用曲线逼带低牌**：全 3 费牌开局放不动 → 必带 0/1 费做开局节奏与铺场；16 槽塞不下全高牌。
> 3. **养成/附魔/地支让"具体那张牌"强、非点数强**：练满的 5♠ > 白板 7。价值附在你投资的英雄上。
> 4. **同档原始差小**：5 vs 7 差 2 点·对 logistic(k) 影响轻 → 连携/曲线/养成盖过。压制=轻倾向非碾压。
> **结论**：解药已在设计（核心=同花连携）。**靠这四道·不再加新反压制机制（YAGNI）**；自动构筑也按"曲线铺开+连携成形"而非"每档塞最高"建。

> **数值真机调**：4 档值 + `MANA_PER_TURN` + 起步值 = `doc14 §九` 单一真相 tunable → **3D-SIM 蒙卡仿真台扫**（费用曲线 × 各流派牌组 → 胜率矩阵 + 退化告警：全低牌 spam 是否过强 / 高牌是否永不值）。起手种子：0/1/2/3、+1/回合、起步 1。
> **数据驱动**：纯数据 + 甲一点接线（机制现成：`canAct` 查 `mana≥cost`）。甲把 `DEPLOY_COST` 常量 0 → `deployCost(rank)` 查表，接进 `deployUnit`/`canAct`，零引擎、无新能力。**每张牌 UI 画费用角标**（乙·0/1/2/3）。

## 七、回合循环（refactor 流程 · 给甲）
**init（开战）**：三路 × 9 格空轨；双方大本营 3 hp；玩家召唤源泉 = 起步值；起手摸 N 张（待定）。AI 同构。
**玩家回合**：
1. **+1 召唤源泉**。
2. **选一类动作（互斥）**：抽 / 放(+可选改机关) / 打天罡 / 弃（见 §二）。
3. **结束 → 推进阶段**：
   - 我方兵各 **+1 slot**（向敌大本营）；
   - **遭遇**（我兵与敌兵相邻 / 将同格）→ `clash-resolve` 掷命对决 → 翻正活 / 翻反亡（胜者继续推进）；
   - 兵抵敌大本营轨末 → 敌大本营 **−1 hp**。
**AI 回合**：同结构（脚本 / 难度参数驱动）。
**判负**：任一大本营 hp = 0 → 该方负。
> 待定微决策（甲可先按建议做）：起手摸几张 · 推进是"每方回合后各推自己"还是"每轮后同步" · 遭遇精确触发(相邻 vs 同格) · 部署入场格。**建议**：各方回合后推进自己的兵；遭遇 = 相邻两格的我/敌最前兵；部署入我方最后格(第 4 格)。

## 九、战斗屏 UI 描述（给 owner → Cloud Design 出最终稿）
> 一句话：**一张桌游棋盘**，不是实时战场。古风基调（玄铁 / 锦霞双皮）。
- **棋盘（中央主体）**：三条横向赛道（上 / 中 / 下路）；每路 **9 格 slot**：左 4 格 = 我方区、中 1 格 = 交界、右 4 格 = 敌方区。格里放卡牌单位（扑克牌面 rank+suit + 战力数 + 已镶地支小角标）。两端 = **大本营**（我左 / 敌右·各 **3 血**·血灯）。路与路之间画**捷径门 / 机关**（开 / 关两态）。
- **手牌区（底部）**：你的手牌 —— 扑克兵牌 + 天罡牌（天罡带 icon + tint·doc20 配表）。
- **动作菜单（底 / 侧）**：四个按钮 **抽牌（天罡 / 扑克二选）· 放牌 · 打天罡 · 弃牌**；选一类后其余**灰掉**（互斥提示）。
- **召唤源泉条**：当前召唤源泉 + 本回合 +1 提示。
- **回合指示**：当前谁的回合 / 第几回合 / 「结束回合」按钮。
- **掷命对决时刻**：两军相遇 → 镜头聚焦该格 → **翻牌动画**（正面金光=活 / 反面碎裂=亡）+ **胜率可读**「76% : 24%」+ buff 明细。
- 氛围核心：**棋盘 + 格子 + 手牌 + 回合制**的桌游感、深思的节奏。

> 复诵：**单机优先、回合制桌游：三路 9 格 slot 轨 · 每回合 +1 召唤源泉 · 选一类互斥动作(抽/放[+机关]/打天罡/弃) · 推进一格 · 遭遇掷命 · 破 3 血大本营。深度尽情堆、零实时负担。掷命/天罡/地支全保留，只换驱动层。**
