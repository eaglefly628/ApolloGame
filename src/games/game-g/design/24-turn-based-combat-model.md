## 一、棋盘
- **三路**，每路一条 **9 格 slot 轨**：**[我方 4 格] · [中 1 格] · [敌方 4 格]**。
- 兵占格，从我端走向敌方大本营（轨末）。**先破敌 3 血大本营 = 胜。**
- 9 格先定 · 后可扩。

## 二、回合结构（核心 = 互斥动作）
每回合：
1. **回合开始 +1 召唤源泉**（统一资源 · 起步值 1 · 真机调 ·「召唤源泉」名可改）。
2. **选「一类」动作（互斥 · 本回合只能一类）**：

| 动作 | 内容 | 数量 |
|---|---|---|
| **① 抽牌** | 抽**天罡** 或 **扑克兵**（你选种类） | **无限** · 每抽花召唤源泉 |
| **② 放牌** | 部署一张扑克兵到某路 → **附带一次可选「改机关」**（开/关捷径门 · 可不用） | 花召唤源泉 |
| **③ 打天罡** | 施一张天罡 | 花召唤源泉 |
| **④ 弃牌 / 卖牌** | 清当前牌堆、腾手 | **无限 · 免费** |

3. **结束 → 棋盘推进一格**：双方场上兵各沿路前进 1 slot；两军相遇 → **掷命对决**（doc19 · 原封不动）。

> 互斥 + 同类无限 = 一个干净的抉择（"这回合我攒牌 / 铺场 / 放招 / 腾手？"），零实时负担、桌游式深思。

## 三、机关（捷径门）
- 三路之间的捷径门（保留 doc21 概念）：开了能换路（增援 / 堵敌）。
- **改机关 = 放牌回合的可选附赠权利**（桌游常见）：放了兵，顺手可开/关一道门，**也可不用**。
- 天罡「城门令」= 同一套门的主动控制（一张专门玩门的牌）。

## 四、召唤源泉经济（回合制版）
> **资源全名「召唤源泉点数」**（owner 2026-06-19 · 原「圣水」更名 · 太像皇室战争）· 行文简称「召唤源泉 / 源泉」。
- **+1 / 回合**（起步 · 调）· 攒着用。抽 / 放 / 打 都花召唤源泉（各 cost）· 弃免费。
- +1/回合是**紧经济** → 每回合做一件小事 = 深思熟虑的桌游节奏。各 cost 真机调（别太慢 / 太快）。

## 七、回合循环（refactor 流程 · 给甲）
**init（开战）**：三路 × 9 格空轨；双方大本营 3 hp；玩家召唤源泉 = 起步值；起手摸 N 张（待定）。AI 同构。
**玩家回合**：
1. **+1 召唤源泉**。
2. **选一类动作（互斥）**：抽 / 放(+可选改机关) / 打天罡 / 弃（见 §二）。
3. **结束 → 推进阶段**：
   - 我方兵各 **+1 slot**（向敌大本营）；
   - **遭遇**（我兵与敌兵相邻 / 将同格）→ `clash-resolve` 掷命对决 → 翻正活 / 翻反亡（胜者继续推进）；
   - 兵抵敌大本营轨末 → 敌大本营 **−1 hp**。
**AI 回合**：同结构（脚本 / 难度参数驱动）。
**判负**：任一大本营 hp = 0 → 该方负。
> 待定微决策（甲可先按建议做）：起手摸几张 · 推进是"每方回合后各推自己"还是"每轮后同步" · 遭遇精确触发(相邻 vs 同格) · 部署入场格。**建议**：各方回合后推进自己的兵；遭遇 = 相邻两格的我/敌最前兵；部署入我方最后格(第 4 格)。

## 九、战斗屏 UI 描述（给 owner → Cloud Design 出最终稿）
> 一句话：**一张桌游棋盘**，不是实时战场。古风基调（玄铁 / 锦霞双皮）。
- **棋盘（中央主体）**：三条横向赛道（上 / 中 / 下路）；每路 **9 格 slot**：左 4 格 = 我方区、中 1 格 = 交界、右 4 格 = 敌方区。格里放卡牌单位（扑克牌面 rank+suit + 战力数 + 已镶地支小角标）。两端 = **大本营**（我左 / 敌右·各 **3 血**·血灯）。路与路之间画**捷径门 / 机关**（开 / 关两态）。
- **手牌区（底部）**：你的手牌 —— 扑克兵牌 + 天罡牌（天罡带 icon + tint·doc20 配表）。
- **动作菜单（底 / 侧）**：四个按钮 **抽牌（天罡 / 扑克二选）· 放牌 · 打天罡 · 弃牌**；选一类后其余**灰掉**（互斥提示）。
- **召唤源泉条**：当前召唤源泉 + 本回合 +1 提示。
- **回合指示**：当前谁的回合 / 第几回合 / 「结束回合」按钮。
- **掷命对决时刻**：两军相遇 → 镜头聚焦该格 → **翻牌动画**（正面金光=活 / 反面碎裂=亡）+ **胜率可读**「76% : 24%」+ buff 明细。
- 氛围核心：**棋盘 + 格子 + 手牌 + 回合制**的桌游感、深思的节奏。

> 复诵：**单机优先、回合制桌游：三路 9 格 slot 轨 · 每回合 +1 召唤源泉 · 选一类互斥动作(抽/放[+机关]/打天罡/弃) · 推进一格 · 遭遇掷命 · 破 3 血大本营。深度尽情堆、零实时负担。掷命/天罡/地支全保留，只换驱动层。**
