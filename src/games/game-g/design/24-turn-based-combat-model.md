## 一、棋盘
- **三路**，每路一条 **9 格 slot 轨**：**[我方 4 格] · [中 1 格] · [敌方 4 格]**。
- **棋盘 = 3 路 × 9 格的格子盘**；**相邻 = 8 向**（上下左右 + 斜角）——供「斯巴达方阵」等"相邻加成"类地煞/天罡判定。**推进仍沿各路横向**走向敌方大本营。
- 兵占格，从我端走向敌方大本营（轨末）。**先破敌 3 血大本营 = 胜。**
- 9 格先定 · 后可扩。

## 二、回合结构（核心 = 互斥动作）
每回合：
1. **回合开始 +1 召唤源泉**（统一资源 · 起步值 1 · 真机调 ·「召唤源泉」名可改）。
2. **选「一类」动作（互斥 · 本回合只能一类）**：

| 动作 | 内容 | 数量 |
|---|---|---|
| **① 抽牌** | 抽**天罡** 或 **扑克兵**（你选种类） | **无限** · 每抽花召唤源泉 |
| **② 放牌** | 部署一张扑克兵到某路 → **附带一次可选「改机关」**（开/关捷径门 · 可不用） | 花召唤源泉（**按点数 1/2/3 档** · §4.1） |
| **③ 打天罡** | 施一张天罡 | 花召唤源泉 |
| **④ 弃牌 / 卖牌** | 清当前牌堆、腾手 | **无限 · 免费 · 不互斥**（owner 2026-06-21·弃后仍可再选一类主动作 抽/放/打天罡） |

3. **结束 → 棋盘推进一格**：双方场上兵各沿路前进 1 slot；两军相遇 → **掷命对决**（doc19 · 原封不动）。

> 互斥 + 同类无限 = 一个干净的抉择（"这回合我攒牌 / 铺场 / 放招 / 腾手？"），零实时负担、桌游式深思。

## 三、机关（捷径门）
- 三路之间的捷径门（保留 doc21 概念）：开了能换路（增援 / 堵敌）。
- **改机关 = 放牌回合的可选附赠权利**（桌游常见）：放了兵，顺手可开/关一道门，**也可不用**。
- 天罡「城门令」= 同一套门的主动控制（一张专门玩门的牌）。

## 四、召唤源泉经济（回合制版）
> **资源全名「召唤源泉点数」**（owner 2026-06-19 · 原「圣水」更名 · 太像皇室战争）· 行文简称「召唤源泉 / 源泉」。
- **+1 / 回合**（起步 · 调）· 攒着用。抽 / 放 / 打 都花召唤源泉（各 cost）· 弃免费。
- +1/回合是**紧经济** → 每回合做一件小事 = 深思熟虑的桌游节奏。各 cost 真机调（别太慢 / 太快）。

### 4.1 放牌费用 = 按点数分 4 档（owner 2026-06-21 · 低牌价值 · 推翻 6-20「放牌免费」）
> **问题**：低点数牌战力弱、若放牌免费则只是"弱鸡身体"，没有独立价值。**解法**：放牌**按点数收费**——低牌便宜=节奏/铺场弹药，高牌贵=单路决胜。给低牌"便宜、灵活、垄断开局、连携燃料"的身份，坐实**铺场流（go-wide）**。
> ⚠️ **改向**：`DEPLOY_COST` 从 0（6-20 免费）→ 按点数查表。源泉自此成为**铺场核心货币**（原只用于抽/打天罡）。

| 档 | 点数（公平骨架 cardPoints） | 牌 | 放牌费用 |
|---|---|---|---|
| 免费 | 2–4 | 2/3/4 | **0 源泉** |
| 低 | 5–7 | 5/6/7 | **1 源泉** |
| 中 | 8–10 | 8/9/10 | **2 源泉** |
| 高 | 11–14 | J/Q/K/**A** | **3 源泉** |

> **A 归高档**：公平骨架 A=14=全副最强普通牌（非"1"）→ 必 3 费，否则又便宜又最强=破。**王/JOKER 不在玩家牌库**（owner 2026-06-21：小王大王是 Boss、不作玩家可放牌）→ 无需档位。
> ⚠️ **0 费 spam 待裁（owner 2026-06-21）**：放牌"同类无限"+ 2-4 免费 → 一回合可铺一堆免费身体（受手牌/抽牌天然兜底）。**暂先放开**（16 牌组里低牌有限、且 2-4 战力 2-4 最弱=纯铺场肉），3D-SIM 测出退化再加「每回合放牌数软上限」。

#### 4.1.1 ⭐ 防"只带每档最高点"压制（owner 2026-06-21 关键问题）
> **陷阱**：同档高点严格压低点（同 1 费·7 强过 5/6）→ 只带 7/10/A？**四道结构性反制让杂牌必带**：
> 1. **同花连携逼点数多样**（最强·doc19 §4.1）：52 池每(点,花)仅一张 → 一条同花线只能用**不同点数的同花牌**拼（5♠6♠7♠…），**没法用三张 7 凑同花** → 想吃同花就得带"较弱"的 5♠6♠。
> 2. **费用曲线逼带低牌**：全 3 费牌开局放不动 → 必带 0/1 费做开局节奏与铺场；16 槽塞不下全高牌。
> 3. **养成/附魔/地支让"具体那张牌"强、非点数强**：练满的 5♠ > 白板 7。价值附在你投资的英雄上。
> 4. **同档原始差小**：5 vs 7 差 2 点·对 logistic(k) 影响轻 → 连携/曲线/养成盖过。压制=轻倾向非碾压。
> **结论**：解药已在设计（核心=同花连携）。**靠这四道·不再加新反压制机制（YAGNI）**；自动构筑也按"曲线铺开+连携成形"而非"每档塞最高"建。

> **数值真机调**：4 档值 + `MANA_PER_TURN` + 起步值 = `doc14 §九` 单一真相 tunable → **3D-SIM 蒙卡仿真台扫**（费用曲线 × 各流派牌组 → 胜率矩阵 + 退化告警：全低牌 spam 是否过强 / 高牌是否永不值）。起手种子：0/1/2/3、+1/回合、起步 1。
> **数据驱动**：纯数据 + 甲一点接线（机制现成：`canAct` 查 `mana≥cost`）。甲把 `DEPLOY_COST` 常量 0 → `deployCost(rank)` 查表，接进 `deployUnit`/`canAct`，零引擎、无新能力。**每张牌 UI 画费用角标**（乙·0/1/2/3）。

## 四·二、⭐ 掷命善后 = 胜者「掷人头·留场续攻」（owner 2026-06-21 拍板 · design G 细化 · 修复"牌力对胜负无效")

> **背景（design G sim 实测·见 doc27 §3.4）**：owner 6-21 把"掷命胜者立即回牌库离场"上线后，**没有一方能维持推进**（赢了的牌也走、前锋瞬清）→ Boss 攒不出一波持续攻势、玩家走空路即破家 → 关1 通关率恒 ~100%、对一切 Boss 数值免疫 → 牌力/地支/天罡对胜负近乎无效。**owner 裁决：胜者不再必定回库——掷一枚硬币，掷出「人头」就留在场上继续往前推。**

### 4.2.1 规则（掷命分出胜负后）
- **败者**：阵亡退场（不变）。
- **胜者**：掷一枚**确定性硬币**（`nextRandom(b.rng)`·进 turnHash·outcome-first）：
  - **人头（概率 `CLASH_WIN_STAY_P`·默认 0.5·tunable）** → **留在场上继续进攻**：保持前锋位、下次推进**继续向敌家推进**、再遇敌则再掷命。**强牌靠这枚币持续突破、一路碾过去。**
  - **非人头（1−P）** → **光荣回牌库**：返还半费、可再抽（= 现行奖励·保留·下场休整再上）。
- **续航兜底（防无限碾压）**：留场者每**连战/连推 1 次** `staminaLeft −1`；打光 → 退场回库（退场即得"回库可再抽"奖励）。故一张牌的连续突破 ≤ `cardStamina`，且每次还有 (1−P) 概率回库休整。期望连推 ≈ `min(stamina, 1/(1−P) − 1)`。

### 4.2.2 「让强牌更能往前推」= P 可随牌力上调（owner 重点 · design G 调）
- 基线：**flat P**（双方一律 0.5·先做最简）。
- 进阶 tunable（贴 owner「让强牌就有概率可以继续往前推」）：**留场概率随胜者掷命余量上调** —— `P_eff = clamp(P_base + k×(pEff_win − pEff_lose), [Pmin, Pmax])`。赢得越干脆(碾压)→ 越可能留场续推；险胜→ 大概率回库休整。**牌力 = 推进动能**坐实。`k` 由 sim 标定（先 k=0 跑通、再开）。

### 4.2.3 「死战不退 / 督战」类 = 把这枚币拉到顶（数据驱动·非新引擎）
- 某些**天罡 / 地煞**把胜者留场概率**拉到 1（永远留场猛推·不主动回库）**或上调。
  - 复用现成词汇：地煞 `lastStandGeneral`（死战不退·doc23 §八）、天罡 `noRout`（督战）→ 语义从"主将亡不溃散"**扩展**到"胜者必留场续攻"。**新增系数 `stayPMul`（或 `alwaysStayOnWin`）挂在 fx 上**，resolveClash 读它上调/锁定 P。
  - 例：项羽「破釜沉舟」= 该方胜者 P→1（不退·莽到底·一波流碾）；可给守势 Boss 不同配法（design G 配进 disha-pack）。

### 4.2.4 为什么这修复了平衡（design G 论证）
- 强牌打赢 → 大概率**留场续推** → 连战连捷 → **一波打穿一路破家**；弱牌赢也大概率被换下/或输掉 → **牌力真正转化为"推进/突破力"**。
- 关键：**Boss 用强牌就能攒出真攻势**（现行模型 Boss 赢了也走、永远破不了你家 → 必败）→ **bossDelta/favorBias/dishaScale 从此真正影响胜率** → 数值标定解锁。
- 进攻方走空路前若被对方留场强牌挡住，需真打穿 → 田忌赛马 / 强点突破成立。
- **P（+ 可选 k + 死战不退 stayPMul）+ stamina + dishaScale** 多 tunable → sim 扫胜率曲线 → 收敛 targetWR。

### 4.2.5 派甲（契约 · 引擎域）
- `turn-combat.ts` 加常量 `CLASH_WIN_STAY_P = 0.5`（tunable·doc14 §九 单一真相）；可选 `CLASH_STAY_P_K = 0`（牌力加成斜率·先 0）。
- `resolveClash`（L345-353 当前"无条件回库"）改为：胜者 `nextRandom(b.rng) < P_eff ? 留场(staminaLeft−1·≤0 才回库) : 回库(返半费·现行奖励)`。
  - `P_eff = clamp((CLASH_WIN_STAY_P + CLASH_STAY_P_K×(pEffWin−pEffLose)) × (该侧 fx.stayPMul ?? 1), 0, 1)`；死战不退/督战令 `stayPMul` 上调或锁 1。
- `TengangFx`/`DishaFx` 加 `stayPMul`（或 `alwaysStayOnWin`）字段；`aggregateTengang`/`aggregateDisha` 填；天罡/地煞数据写。
- **留场者位置**：保持当前 slot 与前锋次序，下回合走 `advanceBoth` 正常向敌家推进（= 续攻）。
- **不破坏现有**：`CLASH_WIN_STAY_P=0` 退化为当前"必回库"行为（向后兼容·测试可锚）。
- 落地后 **design G 跑 sim 扫 P(+k) + dishaScale → 收敛 targetWR**（doc27 §3.2/§3.4）。

> 复诵（善后）：**掷命定胜负 → 败者亡 → 胜者掷币：人头(P)留场续攻(强牌一波碾·stamina 兜底)、否则回库休整(奖励)；死战不退类把币拉到顶。Boss 强牌终于能攒出攻势 → 牌力/养成/天罡重新决定胜负 → 数值可标定。**

## 九、战斗屏 UI 描述（给 owner → Cloud Design 出最终稿）
> 一句话：**一张桌游棋盘**，不是实时战场。古风基调（玄铁 / 锦霞双皮）。
- **棋盘（中央主体）**：三条横向赛道（上 / 中 / 下路）；每路 **9 格 slot**：左 4 格 = 我方区、中 1 格 = 交界、右 4 格 = 敌方区。格里放卡牌单位（扑克牌面 rank+suit + 战力数 + 已镶地支小角标）。两端 = **大本营**（我左 / 敌右·各 **3 血**·血灯）。路与路之间画**捷径门 / 机关**（开 / 关两态）。

- **动作菜单（底 / 侧）**：四个按钮 **抽牌（天罡 / 扑克二选）· 放牌 · 打天罡 · 弃牌**；选一类后其余**灰掉**（互斥提示）。

- **⭐ 敌方（Boss）牌面板（顶部·owner 2026-06-21·"看得见对手的牌"）**：
