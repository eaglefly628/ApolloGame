# 22 · 世界观 · 被诅咒的历史英雄（每张牌一个人物 · 游戏的灵魂）

> game design G ｜ 2026-06-18 ｜ owner：**每一张牌都是一个真实的、有背景故事的人物**——被诅咒的历史英雄，映射进牌里。**这是整个游戏的世界观**，每张牌都有它的世界观。数值体系后面慢慢设计，本文先钉**世界观 + 养成方向**。

## 一、核心世界观（一句话）
**每张牌 = 一位被诅咒的历史英雄**（真实历史人物 + 背景故事），其魂被诅咒、封进一张牌；**掷命/翻命 = 你翻动这些被诅咒英雄的命运**（正面活 / 反面亡）。你是执掌命运之人。**收集牌 = 收集英雄魂**——"收集即灵魂"的灵魂，正来自这些人物的故事。

## 二、三牌组 = 三层英雄 / 天命
- **扑克牌组（52）= 52 位被诅咒的历史名将**——局内上场的兵，每张一个有名有姓的英雄（花色 → 阵营/文明，点数 → 军衔/地位；具体映射后定）。
- **天罡牌组（36）= 三十六天罡**——星宿/传奇英雄的法术化身（规则/法术 = 他们的神通）。
- **地支牌组（12）= 十二地支**——时辰/天命之轴，养成你麾下英雄的命格。

## 三、每张牌的养成弧（per-card · owner：数值后定）
- 每张牌（英雄）有**自己的成长弧**：**杀敌数 → 英雄称号 → 数值成长**（如 杀 10 → "百夫长"、杀 50 → "万人敌"…称号 + 数值；**阈值/加成 owner 后面慢慢设计**）。
- 这条弧 = 你和这张牌的**羁绊**：带着同一位英雄南征北战、看他从小兵长成名将（叙事养成，比纯 stat 更有魂）。
- **地支获得 → 强化牌组**：局内/run 抽中地支 → 加强你麾下英雄（地支 = **集体养成轴**，与 per-card 个体弧并行）。

## 四、⚠️ 设计考量（数值体系定时裁 · design G 标）
- **per-card 养成 ↔ 公平骨架**：52 公平 = 同起点。per-card 成长若**局内/run 内对称**（双方都能练）= 仍公平；若**永久 meta 成长带进 PvP** = 破公平 / P2W → 须谨慎。**建议**：run 内成长（局后结算称号、强度不永久进 PvP），或称号/背景**纯叙事+皮肤·不进对战强度**；具体 owner 定数值时裁。
- **不阻塞当前 build**：本层 = **叙事/养成内容层**（英雄名/故事/称号/美术），**不卡** CR 两牌库经济 + 三牌组菜单的当下开发；待核心玩法跑通后逐步铺。

## 五、内容池（给美术/文案 · 长期逐期）
- 每张牌一份：**英雄名 + 历史背景 + 被诅咒的故事 + 称号梯 + 拟人扑克美术（古风）**。= 长期内容池，逐期填（同天罡逐期）。
- 一致性：被诅咒英雄 + 古风拟人扑克，统一基调（玄铁/锦霞双皮）。

> 复诵：**每张牌都是一个被诅咒的历史英雄，有名有姓有故事；掷命 = 翻他们的命；三牌组 = 三层英雄（扑克名将 / 天罡星宿 / 地支天命）；每张牌有"杀敌→称号"的成长弧 + 地支集体养成；数值后定、不阻塞当前 build。这是致命翻牌的灵魂。**
