## 二、统一核心循环

```
赛前(改造坊=deckbuilding)：定你的「小丑/附魔/星球」构筑（点数牌是标准公平 54 副，不动）
  │
开局：三路就位，每路预铺基础布局；起手手牌(混合：点数牌+小丑/功能牌)；读秒暂停银行满；短带迷雾亮
  │
  ▼ 实时慢行军（一格格往前推，给思考时间；战潮抽牌按战况涌牌=心流）
①看/侦查/读题 ── 三路战线、敌我最前牌、胜率预览(76:24)一眼读
②布阵/田忌断 ── 往哪路投点数牌、弃哪路、续航/冷却下牌组怎么轮转
③调 buff/干涉 ── 打小丑/功能牌：给某路某牌加 buff、相邻协同、主动干涉对决（戳敌布阵缺陷）
  │
  ▼ 最前两张牌相邻 → 【对决解算核】P_eff 聚合 → logistic 胜率 → 种子骰 → 谁正(活·占格前进)谁反(亡)
        赢家续航 −1、战线接力前压；续航尽→沉牌底+冷却；输家→本局弃堆(牌库变薄)
  │
  ▼ 攻到敌大本营 −1 血（共 3 血）→ 先破者胜；回合上限到则按血/推进判（可平）
```

## 三、⭐ 对决解算核 clash-resolve（"谁赢谁输"的数学 · 单一真相）

> 取代 18/01 的 per-card `decideFaceUp`，收编为 pairwise 形式。**纯确定性函数、种子化、可回放、可当回归测。**

1. **有效战力** `P_eff(X) = clamp( 基础点数(X) + Σ buff_i(X), P_min, P_max )`，每个 `buff_i` 源**自带封顶 ±Δ_i**（防膨胀）。
2. **胜率** `Winrate(A) = clamp( logistic( (P_eff_A − P_eff_B) / k ), p_min, p_max )`
   - `logistic(x)=1/(1+e^−x)`；点数差大 → 趋近碾压但**永不 0/100%**；夹 `[p_min,p_max]`（初 [3%,97%]）= **爆冷缝**（留博弈悬念、防死局）。
3. **种子骰** `seededRand( 局种子 ⊕ 对决序号 ) < Winrate(A) → A 胜`（否则 B 胜）。**必须种子化**（镜像同步 + 回放不裂 = lockstep/outcome-first）。
4. **三个平衡旋钮**：`k`（点数多硬，小=点数为王/大=buff 为王）｜`[p_min,p_max]`（爆冷缝宽）｜各 buff `Δ`（膨胀上限）。**全进 `14` + 仿真台扫。**

> 视觉：赢家**翻正面·存活占格前进**，输家**翻反面·阵亡** = owner 童年"正面活/反面死"的精确落点。

## 四、点数牌 · 公平骨架 + buff 来源

- **点数牌 = 标准公平牌**：双方各一副标准 54（含 2 王），**点数固定**（军衔=点数，`06`）。**人人相同 → 公平**；强弱**全来自经营**（下表 buff），**不来自抽到强牌、也不靠泵点数**（退役"强化全军 favor"）。
- **续航**：每张带续航值（§五）。
- **buff 来源（全扁平数据、各自 bounded ±Δ，聚合进 P_eff）**：

| buff 源 | 来处 | 备注 |
|---|---|---|
| 基础点数 | 牌本身（军衔=点数）| 公平骨架 |
| 相邻协同 | 同路前一张/后一张牌（顺子/同花/同色…）| `poker-hand`/`laneHandTier` 复用 |
| 士气 | 累积（连胜/主将牵动，`06`）| 将领流载体 |
| 附魔能量 | 局外带入（养成）| 改造坊养成轴 |
| 路 buff | 上/中/下当前路的全局加成 | 星球·路/型 等 |
| 主动干涉 | 玩家打出的小丑/功能牌 | `LEVER_CATALOG` 复用 |

> 借力 **REQ-E-021「Card.mods 逐张内禀修正」**（引擎刚落）承载 per-牌 buff 聚合；**守 Lead 窄边界**（就地读数据、只复用 `{op,target,value}`，**不建统一 Buff 引擎**）。

## 五、续航 + 冷却 + 牌组轮转经济（战线接力、神牌也得歇）

- **赢一场对决** → 占敌格前进一步、**续航 −1**。
- **续航尽** → **沉牌底 + deploy 冷却（按行军波/回合）**；**输** → 进**本局弃牌堆**（这局牌库变薄；**局外收藏不减**）。
- **续航随牌阶**：数字牌 1 场 / 人头牌(A·J·Q·K) 2 场 / 小丑可延到 3（初值，仿真台调）。
- **设计内核**：单卡续航有限 + 冷却 → **战线靠一波波牌接力前压逼近大本营**；**推进的是战线、不是单卡** → 神牌凿几格就回家歇、不能包打天下 → **逼牌组轮转**（持续决策、解了"前锋赢了就走不到家"的矛盾）。

## 六、大本营（皇室战争模型）

- 大本营 **3 滴血**；攻克一次 **−1 血**；**先破者胜**。
- **回合/时间上限**：到点没破 → 按**剩余血 / 推进度**判，**可平局**。
- **不做大血条**（防无限拖、保节奏）。（HOME_HP 8 → 3，并入 `17`/`18`。）

---

## 七、小丑牌（不上场 · 构筑定库 · 被动槽 + 主动打出 · 收集即灵魂）

- **不上场行进**——点数牌才上场对决；小丑/功能牌是**功能/干涉/养成**牌。
- **构筑定库（18 iii）**：改造坊选哪些小丑/附魔/星球进你的构筑；流派身份 = 库成分。
- **用法（合 18 §10.8 + handoff 未拍项）= 两者都有（owner/F 双倾向一致）**：
  - **被动槽**：常驻 joker（开局生效的轻被动/流派印记 = **§10.8 折中 C · owner 2026-06-17 拍板**）。
  - **主动打出**：抽到手里 → 打出干涉某路某对决（克隆手牌/加 buff/改胜率…）。
- **平衡命门**：小丑是"收集即灵魂"的养成层，**极易破平衡** → 全过**仿真台**扫（§十），任何统治解/死牌亮红牌。

## 八、时间模型和解（owner 实时心流 压过 handoff 回合味）

- **主**：owner 拍的 **实时慢行军（一格格推）+ 读秒暂停银行 + 战潮抽牌心流 + 短带迷雾**（`18` §10，最高优先，不动）。

## 九、两条体验支柱（戳缺陷、给仪式感）

1. **胜率可读**：对决前**悬停显「A 76% : 24% B」+ 可展开 buff 明细**（哪几条 buff、各 ±多少）。**没有它 = 老虎机**，玩家戳不动对方布阵缺陷 = 博弈死。`battle-screen` 加 hover 概率条。
2. **关键对决 1v1 特写**：主将对撞/斩首/爆冷 → 切**单挑特写图层**给仪式感（`15` juice 具体化）。

## 十、仿真台（owner 强调 · 单开一趴 · 平衡的命脉）

- **离线蒙特卡洛**：全小丑配置 × 全牌组/布阵 × 对手分布，跑 N 万次 → **胜率矩阵 + 退化告警**（任何组合顶破 `[p_min,p_max]` / 出统治解 / 出死牌 → **红牌**）。
- **参数全扁平数据、仿真器=薄确定性函数** → **可直接当平衡回归测试**（CI 跑、改 buff 即知崩没崩）。完美符 manifesto。
- 是"小丑收集即灵魂"养成线**不崩盘**的唯一保险——**先有仿真台、再放开小丑池**。

## 十一、数据驱动 / 架构评审（CORE RULE）

- **三分**：游戏=数据（点数牌/小丑/附魔/路 buff/续航表/k/p_min,max/Δ/大本营血，全扁平）｜解释器=固定代码（clash-resolve 核 + 行军 + 仿真器）｜玩家投放/干涉=运行时输入。**"最弱 LLM 产一样的数据" ✓。**
- **复用**：三路行军/接敌/牌堆沉底/冷却 ← MARCH + card-pile + 资源/Timer；buff 聚合 ← **REQ-E-021 Card.mods**；牌型协同 ← poker-hand；干涉 ← LEVER_CATALOG。
- **待引擎评估的真触点只两个**（handoff 已点 + 我复核）：
  1. **in-sim 确定性种子 RNG（骰子）** —— **跨游戏基础原语**。我们 game-side 已有 mulberry32（decideFaceUp 用）；若 Lead 要立为共享引擎原语 → **提 REQ-G**（跨 game 复用，非阻塞）。
  2. **clash-resolve 解算核（buff 聚合→logistic→种子骰→正负）** —— **game-side 薄解算核**（读扁平 buff、借 Card.mods、守 Lead 窄边界、**不建统一 Buff 引擎**）。预判 game-side 可落、零/极少新引擎；真缺口才提 REQ-G。
- **YAGNI**：clash-resolve 先朴素（读数→logistic→骰）；仿真台先朴素蒙特卡洛；不预建通用 buff 框架。
