# 21 · 皇室战争模型（局内经济：点数 · 手牌 · 三路）—— owner 大改：抄皇室战争

> game design G ｜ 2026-06-18 ｜ owner 拍板：**局内玩法模拟皇室战争（Clash Royale）**——「牌不是时间到了就能放，是回复**点数(圣水)**、点数对应手里能放哪张；整个流程抄皇室战争」。
> **本文 = 局内经济单一真相**，**取代** `18` §10（战潮抽牌/调兵）+ `20` §〇（天机能量经济/三选一）。**保留** `17/19`（三路·慢行军·遭遇掷命 logistic 对决·续航·3 血大本营）。

---

## 一、核心 = 皇室战争 × 扑克掷命（一句话）
**点数(圣水)随时间回复 → 攒够 → 从手牌选一张花点数打出 → 点数牌部署到上/中/下路慢行军遭遇掷命、天罡牌施法 → 先破敌大本营 3 血者胜。** 把 CR 的「圣水+手牌+推塔」原样搬过来，塔战换成我们的「三路行军+掷命对决」。

## 二、局内经济（CR 五件套）
| 件 | 致命翻牌 | = 皇室战争 |
|---|---|---|
| **点数 ◈(圣水)** | 随时间**回复**（初值 ~1 点 / N 秒，上限 ~10）；**局内单一货币** | elixir |
| **手牌（可囤积·上限 ~7）** | 比 CR 4 张**大、可囤积**；抽牌**慢慢填到上限**（不打也攒）；打出→回 deck 底、空槽再补 | 大手牌 + cycle |
| **战斗 deck** | **52 扑克(单位) + ≤5 天罡(法术) = ~57 张 · 整副 cycle**（owner 拍·非 CR 小 deck）；每张带 **点数 cost** | (整副扑克) |
| **打牌** | 攒够点数→选手里一张→花掉它的 cost 打出 | drag card, spend elixir |
| **起手** | 手牌 4 张 + 起始点数若干，让你开始放 | starting hand + elixir |

- **点数牌打出** → 部署到你选的**一路(上/中/下)** → 沿路**慢行军**（doc17）→ 中线**遭遇掷命对决**（doc19 logistic）→ 续航/突破 → **攻克大本营**。
- **天罡牌打出** → 施**法术效果**（doc20 §二 36 天罡：改命/加成/延缓敌/斩首…），CR 的火球/冰冻/增益。
- **赢** = 先破敌**大本营 3 血**（= CR 推王塔）。

> **owner 节奏调（2026-06-18）**：52 副若手牌只 4 = **太慢** → **点数 regen 快 + 手牌大可囤积(~7) + 出牌快**（动作多 · 思考略降 · owner 接受、慢慢调）。**补牌触发**（owner 倾向①囤积）：① **慢 timed draw 填到上限**（不打也攒 = 真囤积·**推荐**）；② 纯"打一张补一张"(CR·手牌不增长·非囤积)。

## 三、三类牌 · 三个位置（owner 钉死）
- **点数牌（局内·上场打）**：标准扑克点数牌，cost ≈ 军衔/点数大小；**公平骨架**（人人同池、不泵点数·强弱靠经营）。
- **天罡牌（局内·法术）**：改造坊带的 **≤5 张**，混进战斗 deck、循环抽到、花点数打出（doc20 §二）。**= CR 的法术卡。**
- **地支牌（局外·meta）**：**不进局内手牌**；局外**升级你的牌组/底盘**（doc20 §三 12 地支·升档）。

## 四、取代 / 保留（与原设计对账）
- **取代**：`18` 战潮抽牌(事件涌牌)、`20` 天机能量经济(三选一+激活) → 统一为 **CR 点数回复 + 手牌循环**（更简、更成熟、owner 钦定）。
- **保留**：三路 · 慢行军 · 遭遇掷命 logistic 对决 · 续航 · 3 血大本营（`17/19`）。CR 的"兵走向塔"= 我们的"兵沿路行军遭遇掷命"，天衣无缝。
- ✅ **砍掉读秒暂停**（owner 2026-06-18 拍 · CR 纯实时无暂停 · 纯手速 + 心流）。

## 五、owner 已拍（2026-06-18）+ 余数值待调
1. ✅ **战斗 deck = 52 整副 cycle**（+ ≤5 天罡混编 = ~57 张 · 手牌 4）。owner 选"一副扑克"味（非 CR 8 张小 deck）：所有牌都会轮到、扑克感足。
   - ⚠️ **天罡频率隐患（design G 标·待 owner 定）**：57 张库一局只摸 ~10 张 → **天罡(5/57≈9%)平均一局摸不到 1 张** = 很稀有。天罡是"养成灵魂"、这样可能不露脸。**若要天罡更常见** → 给天罡**抽牌权重**(优先进手) 或 **减点数牌库**；**否则**天罡 = 稀有高光（看到就是大招）。真机感受后定。
2. ✅ **读秒暂停砍掉**（纯 CR 实时无暂停）。
3. ⏳ **数值待真机 + 仿真台调（owner 要快节奏）**：点数回复**快**、**手牌上限 ~7 可囤积**、点数牌 cost(按军衔 2–6)、天罡牌 cost(按牌力 2–5)。补牌触发：timed-fill(囤积·推荐) vs play→draw(CR)。owner「慢慢调」。

## 六、派单（改局内经济 · 甲为主）
- **甲（战斗）**：局内经济从 战潮/天机能量 → **CR：点数(回复)+手牌4(cycle)+花 cost 打牌**。`A1 战潮脉冲` **superseded**（"特殊事件多回点数"可留作 polish、非主 economy）。**march/clash/lane/续航/大本营 全保留**。新增：点数资源(regen) + 手牌 cycle + cost 打牌 + 三路部署（部分已有）。
- **乙（菜单）**：改造坊构筑**战斗 deck**（点数牌 + ≤5 天罡 + 各 cost 显示）；地支局外升级。
- **数据**：每张牌一个 `cost`；点数 regen/上限/手牌数 = tunable（入 `14`）。

> 复诵：**抄皇室战争——点数回复、手牌循环、花点数把点数牌放三路慢行军遭遇掷命、天罡牌当法术、先破 3 血大本营；天罡=局内法术(改造坊带≤5)、地支=局外升级。最大待定 = deck 大小(8 张 CR 忠实 / 52 整副)。**
