## 一、开场故事（首次启动 · 动画/旁白 · 可跳过但默认播）
> 基调：古风 × 一丝赌场宿命感。逐屏旁白 + 简单运镜（静帧 + 牌面光效即可）。

1. **〔夜·赌场〕** 霓虹昏暗，一张老旧牌桌。旁白：「传说，世上最伟大的将军，从未真正死去——他们只是，在等一个执牌的人。」
2. **〔开关〕** 一只手无意间拨动牌桌下一枚古旧黄铜开关。「**咔哒。**」
3. **〔异变〕** 灯火骤灭，整副扑克腾空、光芒大作。旁白：「远古以来，五十二位最负盛名的名将，魂魄被尽数封入这副牌中。」
4. **〔群像〕** 孙武、成吉思汗、亚历山大、项羽……剪影在牌面一一闪现。「他们困在各自一生最关键的那场战役里，命运永远定格在那一刻。」
5. **〔庄家〕** 牌桌尽头，**大王与小王**缓缓浮现——执掌这副命运之牌的两位庄家。「而坐庄的，是大王与小王。」
6. **〔召唤玩家〕** 「你，无意间成了**执掌命运之人**。重打这五十二场命运之战、翻动他们的命——最终，掀翻这庄家的牌桌。」
7. → 进入**新人引导**。

## 三、教学关脚本（关 0 · 可玩 · 逐步强制 · 教官旁白）
> 敌方 = 一个弱"训练稻草兵"（按脚本出牌、好赢）。每拍：高亮 + 旁白 + **强制玩家做一个动作**，做对才继续。教全套回合制基础。

| 拍 | 教什么 | 旁白 + 强制动作 |
|---|---|---|
| 1 | 战场/目标 | 高亮三路9格 + 两端大本营。「这是战场：三路、每路九格；两端大本营各 3 血。**把对面 3 血打光 = 你赢。**」 |
| 2 | 资源 | 高亮召唤源泉条。「每回合 +1 **召唤源泉点数**——你的行动力，攒着用。」 |
| 3 | 回合·四选一 | 高亮四动作按钮。「每回合只能选一类：抽牌 / 放牌 / 打天罡 / 弃牌。先【抽牌】。」→ **强制点抽牌** → 抽到一张扑克兵。 |
| 4 | 放牌 | 「下一回合，把这张兵**放到中路**。」→ **强制放牌·中路**。「（放牌还能顺手开关一道机关门——以后再用。）」 |
| 5 | 推进·遭遇 | 「回合结束，兵沿路走一格。」→ 兵前进；敌稻草兵也走近。「两军相遇——**掷命对决**！」 |
| 6 | 掷命对决 | 高亮胜率「你 75% : 25% 敌」。「比战力、算胜率、抛牌定生死：**正面活、反面亡**。你战力高、大概率赢——但永远有 3% 爆冷。」→ 抛牌·正面·你的兵存活继续。 |
| 7 | 天罡 | 「这回合【打天罡】——放‘虎符’，全军 +2 战力。」→ **强制打天罡** → 显示全军战力 +2 的反馈。 |
| 8 | 破大本营 | 「你的兵推到了敌方大本营——**扣 1 血**！」→ 连推、破光 3 血。 |
| 9 | 胜利 + 解封 | 「敌方大本营告破，你赢了！**你解封了第一缕英雄之魂。**」→ 教学关结束 → 自动进 关 1。 |

> 教学关只用最基础 1-2 张牌（扑克兵 + 虎符），不放复杂天罡/地煞——纯教操作循环。地支/构筑/解锁等留正式关里随解锁逐步引导。
