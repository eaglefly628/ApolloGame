## 一、keystone · 将领中心制（owner 半认同·「没完全想清楚」）
- **结构**：一战带 **1 主将 + 2 偏将（三路各一将领）+ 其余杂兵**（匿名/编号的通用兵）。
- **为何是抓手**（其余想法都从它长出来）：
  1. 治「武将失去感觉」——3 个你在乎/会 build 的将领，非 16 张匿名牌。
  2. 让天罡有意义——buff/护你那几个将（无疲劳、旗手光环…）。
  3. 让疲劳/恢复有意义——精心护少数宝贵将领。
  4. **现有机制早就按将领中心设计**：主将光环(+士气)/主将阵亡→该路士气-4溃散/死战不退3命/旗手·哀兵·督战天罡——全是将领中心。是「52张全名将」的**卡面在跟机制打架**。对齐后机制才唱起来（-4 士气从「莫名惩罚」变「这路主将没了·士气崩」）。
  5. 引擎 `general: bool` 标记**已存在**·数据模型半现成。
- **身份/收藏兼容**：52 历史名将 = **收藏/名册**；每战从中**点选 3 个当将领** + 通用杂兵。→ 每个名将是「你亲选的领军人物」·收藏感更重·战斗更清爽。**不冲突·可能更好。**

### 1.1 核心张力（owner 2026-07-04 自己撞到）：将领死亡必须有代价
- owner 设想：每战选 3 将（上中下各一）·战死能回牌堆。**自己发现 exploit**：「那我都派主将去打好了、打完重来」——若将领**战斗内**死了能回抽再上=死亡免费→塌回「刷最强一张」。→ **必须回答「损失一个将领付出什么代价」·否则将领中心制立不住。**
- **【GD 推荐解】将领=在场指挥官·死=本战该路失主将·战后才归队**：
  - 3 将是**棋盘持久指挥官**（非可回抽的牌）·战死→**本战剩余回合该路无主将**（触发现成 主将阵亡→士气崩-4·合理代价·该路残半场）→ **战毕才回收藏/名册**（非永久损失·下战再带）。
  - 「回牌堆」发生在**战与战之间·非战斗内** → 一战里将领唯一、死即无、无法重复派 → **exploit 消失**。死亡有份量（废一路）不狠（下战还在）。
  - **可回抽再上的是杂兵**（消耗品/编号肉）→ 将领稀缺 · 杂兵廉价循环 · 正对 owner「其他就是带编号杂兵」。
  - **优点**：不加新机制·复用现成「主将阵亡→士气崩」当死亡代价。
- **备选A·疗伤冷却**：将领战斗内可回但 N 回合不可再上（或回来残血/减战力需养）·逼轮换。
- **备选B·再上escalating涨价**：同将领每次阵亡后重部署越来越贵（源泉/疲劳跨死累积）·刷主将会破产。
- owner 态度：「我得想清楚·但觉得有点意思。」→ **待 owner 想透再定死亡代价模型**。

### 1.2 收敛：生死循环 = 指挥官轮换引擎（owner 2026-07-04 续想「战败回去恢复一段」+「也许加第四人」）
- owner 倾向**备选A（疗伤冷却）**：将领战败→回去**恢复一段时间**→再上。GD 判断：这一个机制**统一了三件事**——① 死亡代价（负伤疗伤=代价·非免费回抽）② 疲劳恢复（主动撤下养=「追击 vs 撤养」抉择）③ 第四人有了位置。
- **第四人 = 恢复循环逼出的替补**（非随便加）：3路=3活跃将领（上中下）·某将疗伤下场→空档→**替补顶上**。= **3上场+1轮换名册**·管理「谁打/谁养/谁顶」。逻辑自洽（有疗伤空档才需板凳）。
- **生死循环 v0（待 owner react）**：
  - 状态机：`出战(某路指挥) → 负伤(战败·疗伤N回合·该路暂无主将或替补顶) → 康复(可再部署)`
  - 玩家抉择：①乘胜but累→主动撤下养(保将·替补/杂兵顶)　②硬顶到死→更长疗伤+该路士气崩半场　③第四人轮换补空档
  - **代价刻度**：主动撤=疗伤短；战死=疗伤长+士气崩 → 鼓励「见好就收」护将·非拼光。
- **调参/复杂度风险（GD 提醒）**：疗伤 N 太长=常缺将难受·太短=死不痛（sim 标）；轮换=一层管理深度·好玩但要教→**关1 教学用简单版（3将无替补）**·轮换留后段关。
- **一句话价值**：这套「指挥官轮换+疗伤循环」= owner 要的**心流引擎**（节奏养/拼 × 管理轮换 × 将领稀缺）·且全数据（疗伤N=参数·名册=列表·疲劳=公式）。

## 二、疲劳模型 · 线性 + 恢复（数值线）
- **恢复 = 最值钱的新想法**：疲劳从「永久税」变「可管理资源」→ 产生「乘胜追击 vs 撤下养」抉择（缺的策略轴）。
- **线性的代价（须知）**：现对折 ×0.5 是故意的**车轮战反制**（强兵连胜越弱·弱兵群磨死它）。改线性→强兵吃完还强（爽「大牌吃小牌」）·**但弱兵磨强兵的反雪球没了**。= **战斗身份选择**（强者恒强 vs 强者会累）·非免费调值。
- **提案**：疲劳做**可恢复池**——每胜 −X战力(线性)·不打的回合 +Y/回合·下限 3（已定 owner 2026-07-04）。X/Y/下限皆数据参数·GD sim 标。若弱化车轮→需别的反雪球补（经济/AOE/将领结构天然限强兵数量）。

## 三、天罡深度（不是缺目录·是露脸太少）
- **catalog 不缺**：35 张 / 9 系（掷骰/点数/成组/将领/行军/续航/抽牌/攻守/AOE·刚重设计）。felt 少 = **露脸率低**（loadout 4张·上场cap2·抽得少·源泉紧→一局见1-2张）。**调携带量/抽取节奏·非加目录。**
- **真问题**：手里「策略牌:肉牌」比例太低→像掷骰肉搏。要提策略牌在实战的占比。
- **新卡种子**：「无疲劳/亲卫/无双」——将领系·主将战胜不折损（直接制造「护一个大将」玩法·将领中心抓手）。
- **携带量平衡**：限手牌上限 + 天罡上限·别全肉/别全罡·求平衡（deck 构筑杠杆·配合将领中心的 3将+杂兵+M天罡）。
