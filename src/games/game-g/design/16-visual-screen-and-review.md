## 六、持续迭代评审环（design G ↔ program G）

```
program G 做出画面 + 出帧 → design G 读图 + 读码 评 → 提改进需求 → 再迭代 → … 直到"好看 + 好玩"
```

**评审尺子（design G 每轮拿这把量）**：
1. **博弈悬念演出来没**——命运一掷有戏剧感吗？逐路揭晓紧张吗？
2. **可读性**——三路谁赢、牌型、流派、招牌激活，玩家看得懂吗？
3. **美术基调对没**——拟人扑克 + 古风，对齐 UI 稿玄铁/锦霞？
4. **布局顺手没**——干预/派牌/看战况的操作流顺吗？

## 八、第 1 轮评审（2026-06-16，design G 读 VIS-1 看帧）

**看帧成功**：`render-frame.ts` 出 3 帧 SVG（开战/揭晓/Boss），我从构图读出现状（54v54 卡、红 vs 蓝、金=活/石=死）。**enabler 立功——现在能评了。**

**评审结论（4 尺子）**：
1. **博弈悬念**：🟡 金石生死对比的**色彩语言已在**，但 **flat、无戏**——`radialGradient/filter=0`，活牌不发光、死牌不碎裂、底是纯黑 void。"命运一掷"该是高光时刻，现在像静态色块。
2. **可读性·三路**：❌ **仍有牌没战场**——无三路分区/老家牌王座/哨塔，"三路 best-of-3 弃一保二"完全看不出。
3. **美术**：⚠️ programmer-flat，缺古风/拟人扑克氛围（UI 稿玄铁/锦霞未体现）。

**改进直派（按优先级）**：
- **VIS-2 三路战场（最关键，确认必做）**：三路分区(上/中/下) + 左右老家牌王座(♔) + 哨塔 + 卡牌按路列阵；让"三路比分/弃一保二"一眼可读。**这是补"有牌没战场"的核心。**
- **VIS-2b 给"命运一掷"加戏（表现层，配合 VIS-4）**：活牌落定 **gold 辉光**（radialGradient/bloom）、死牌 **碎裂+去色压暗**、底换**战场地面/古风底**（非纯 void）、**逐路揭晓**（上→中→下，2:1 悬念）。让翻牌成为高光。
- **VIS-3 布局** / **VIS-5 美术氛围** 随后。

> 第 1 轮一句话：**看帧成了、能评了；画面证实"有牌没战场 + 命运一掷太平"。下一步把三路战场建出来 + 给翻牌加辉光/碎裂/逐路揭晓的戏。**

## 九、第 2 轮评审（2026-06-16，design G 读 VIS-2/2b 帧）—— ✅ 通过 + 放行进真渲染

读新帧（03-reveal）结构，第1轮两点**都补上了**：
1. **有牌没战场 → ✅ 修复**：三路(上15:5/中9:7/下14:7 比分可读) + 老家牌王座♔(我金/敌青) + 哨塔♜ + 我/敌分区 + 接敌中线。"三路 best-of-3 弃一保二"一眼可读。
2. **命运一掷太平 → ✅ 加戏**：活牌 `radialGradient` gold 辉光 + 死牌 `path` 碎裂纹+压暗 + `linearGradient` 古风战场底（非纯 void）+ 辉光晕 `circle`。

**裁定**：✅ **通过，批准把这套布局/辉光/碎裂从 SVG 评审帧同步进 `ThreeRenderer` 真渲染**（让浏览器里的真画面也长这样）。SVG 帧继续当评审介质。

**下一步（继续变好玩）**：
- **VIS-4 逐路揭晓（悬念动画）**：上→中→下**依次**翻揭、不要三路同闪——制造"2:1 还能不能翻盘"的连续悬念（best-of-3 的心跳）。这是动画时序、静态帧看不出，做进 ThreeRenderer + feel.ts。
- **斩首聚焦 / Boss 入场**（VIS-4 余）：斩首令命中敌主将 → 镜头/高光定格一拍；Boss 入场台词 + 起手干预的压迫感。
- 老家牌王座可再"王座感"一点（占老家=即胜，该有终结仪式）。

> 第 2 轮一句话：**三路战场 + 命运一掷的戏 都成了、通过、放行进真渲染；下一步把"逐路揭晓"的悬念心跳做进动画。**
