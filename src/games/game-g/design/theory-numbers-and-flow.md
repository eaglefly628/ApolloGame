## 0. 一页心智模型（整套系统一张图）

```
                    ┌─────────────────── 元养成循环（Loop 2·跨局·留存）───────────────────┐
                    │  通关 → 奖励(金币/解封英雄/地支/解锁专属牌) → 养成(强牌力/凑build)     │
                    │        ↑                                              ↓              │
                    │     更难的关卡  ←────────────  带着更强的「战力」再战              │
                    └────────────────────────────┬──────────────────────────────────────┘
                                                  │  养成 = 抬高「带进战场的战力」
                                                  ▼
        ┌────────────────────── 战斗循环（Loop 1·局内·心流）──────────────────────┐
        │  +源泉 → 一个动作(抽/部署/挂专属牌/天罡/弃) → 推进 → 遭遇                │
        │                                                   ↓                       │
        │                        【掷战力骰·仪式感】各掷[1,战力]·大者胜             │
        │                                                   ↓                       │
        │        胜→留场(战力对折·疲劳) / 负→阵亡     →   破家(敌3血)  →  胜负       │
        └───────────────────────────────────────────────────────────────────────────┘

  一切数值都汇成一个原子：兵的「战力 P」。对决 = 双方各掷 [1,P]、比大小。
  养成把 P 抬高（heating）；疲劳对折把 P 压低（cooling）；掷骰把 P 变成「有悬念的结果」。
```

**三句话记住整套系统**：
1. **战力是唯一货币**：所有加成（点数/天罡/地支/协同/地煞/专属牌）最后都变成一个数 `P`。
2. **对决是掷战力骰**：各掷 `[1,P]` 比大小——**战力决定期望、骰子留悬念**（强不必胜、弱不必输）。
3. **两个循环互喂**：局内打赢 → 局外养成 → 战力更高 → 打更难的关。**养成加热、疲劳冷却，系统在两者之间找平衡。**

## 1. 公理层：战力骰（整个数值系统的地基）

对决核（vision doc）：前锋 A、B 各掷一个整数 `roll ∈ [1, P]`，大者胜；平局走 点数→续航→先手。

**为什么这是"好地基"（三条数学性质·平衡全靠它们）**：

设 A 掷 `[1,A]`、B 掷 `[1,B]`，A 赢（含平局判给高战力）的概率：
```
A ≥ B :  P(A胜) = 1 − (B−1)/(2A)
A < B :  P(A胜) = A/(2B) 附近
例：A=17,B=9 → ≈76%（不是碾压·弱者仍 ~24% 翻盘窗口）
```

1. **饱和·无雪崩**：胜率是**饱和函数**——战力翻倍（10→20 打 10）胜率只 50%→~75%·**永远封不死**。→ **数值堆再高也不破坏游戏**·顶部平衡很宽容。
2. **边际递减·自压缩**：+1 战力的边际胜率 ≈ `1/(2P)`——**弱兵 P=4 时 +1≈+12%·强兵 P=20 时 +1≈+2.5%**。→ **buff 对弱者更值**·系统自动压缩差距·防强者通吃。
3. **永远有翻盘缝** ≈ `弱/(2·强)`——每场都有悬念 → 这是"爽"和"仪式感"的数学来源。

> **理论结论（这条决定我们怎么调平衡）**：因为输出（胜率）是**有界、平滑、饱和**的，我们**不需要为每种加成组合精算**——只需让**汇总的战力 P 落在正确的区间带**。**调的是"带"、不是"点"。** 这就是让复杂系统可控的钥匙。

## 2. 战力从哪来：五层模型（P 的来源分解）

一张兵上场那一刻，战力 `P` 由五层叠出（"战力是带进战场的资源"）：

| 层 | 来源 | 何时定 | 谁调 | 性质 |
|---|---|---|---|---|
| **① 基础层** | 扑克点数（2..A）| 建牌 | 固定 | 公平骨架·不可养成 |
| **② 养成层** | 天罡 loadout + 地支附魔 + deckBias | **上场前**（带进战场）| 元养成 Loop2 | 玩家的长期成长 = 主线动力 |
| **③ 局内层** | 相邻协同(方阵/连携) + 士气(旗手/主将) + 路 buff + 今日卦象 | 布局时·涌现 | 局内策略 | 位置/组合 → 涌现 depth |
| **④ 修饰层** | **地煞**(Boss招牌) + **专属牌**(玩家英雄自带) | **回合内预挂** | design G(数据) | `{target,op,value}`·add/mul/规则 |
| **⑤ 消耗层** | **疲劳对折**（每胜 `P×0.5`）| 战斗中 | 固定率 | **负反馈·冷却力** |

最终进对决的有效战力 `P_eff = clamp( (①+②+③+④) × 疲劳0.5^wins , 1, P_MAX=30 )` → 掷 `[1, P_eff]`。

**两个关键设计张力（系统的"温度平衡"）**：
- **加热 vs 冷却**：②④养成/招牌不断**抬 P**（heating）；⑤疲劳对折不断**压 P**（cooling）。一场仗、一个 run 的手感 = 这两股力的动态平衡点。**调对折率 = 调整个系统的"体温"。**
- **加法 vs 乘法**（④层·owner 2026-07-01）：`+战力`=稳定保底·低战力也吃到；`×战力(%)`=随基础放大·给"奇怪高战力 build"留 emergent 空间。乘法过防爆炸红线（乘不叠·夹 CAP）。

## 3. 两个循环（经济体系的骨架）

### Loop 1 · 战斗循环（局内 · 秒~分 · 心流引擎）
```
回合开始 +源泉(紧经济·前期+1/后期+2)
   → 选【一类】互斥动作：抽 / 部署(按点数收费) / 挂专属牌 / 打天罡 / 弃
   → 推进一格 → 前锋相遇
   → 【掷战力骰·仪式感】 → 胜(留场·对折) / 负(阵亡·回不回库看善后)
   → 攻进敌家 −1血(回库) → 破 3 血 = 胜
```
- **紧经济 = 一回合一个有意义决策** → 深思熟虑的桌游节奏（北极星 Balatro·非 APM）。
- **疲劳对折 → 续航/车轮成为策略**：强兵连胜越打越弱 → 弱兵能磨死强兵 → 破家要挑对方"疲劳空窗"。

### Loop 2 · 元养成循环（跨局 · 留存引擎）
```
通关 → 奖励：金币 + 解封新英雄 + 地支(关1首得1张) + 解锁英雄专属牌(每英雄≤3·渐进)
   → 养成：强化牌力 / 组新 build / 凑某英雄专属牌组
   → 带着更高的「养成层②」战力 → 挑战更难的关(targetWR 递降)
   → 通关 …（螺旋上升）
```

### 两循环怎么咬合（这就是"数值循环体系"）
```
   Loop2 养成 ──[抬高 P 的②层]──▶ Loop1 战斗   （投入变强）
   Loop1 战果 ──[金币/英雄/地支]──▶ Loop2 养成   （产出资源）
```
- 这是 roguelite/卡牌的**双循环**：局内爽（战斗心流）喂局外长（养成留存），局外长又反哺局内强。
- **牌组组合是枢纽**（owner「牌组组合很重要」）：收集英雄 → 解锁其专属牌 → 凑成一套打法（斯巴达克斯翻身流 / 拿破仑炮兵流…）→ 这是 Loop2 的"意义"所在。

## 4. 战斗心流（moment-to-moment 的体验设计）

### 4.1 微节拍（每一次遭遇的情绪曲线）
```
布局(decide) → 逼近(tension↑·两军接近) → 掷骰(peak·仪式感) → 结果(release) → 善后(留场/阵亡/破家)
     ↑你的回合做完所有决定           ↑自走棋·不再操作·只看命运
```
- **决策与观赏分离 = 引擎·不是妥协**（owner 2026-07-01 追问"零操作还掷一下·是不是掩耳盗铃？"）：Commit→Reveal 是最强的游戏循环之一（扑克翻河牌 / Balatro 结算跳分 / 点球 / XCOM 85%命中）。**分离正是张力之源**——因为命运已封、你才屏息等揭晓。**若掷时还能改结果·就没有"决胜一刻"了。** 所以"掷时零影响"不是限制·是设计本身。

### 4.1.1 ⭐ 掷骰不是"假操作"·是"结算仪式"（回应掩耳盗铃之问）
**两种零操作掷骰·长得一样·本质相反**：
- ❌ **假能动**（dishonest = 真掩耳盗铃）：假装你的时机/技巧影响结果·实则不影响。老虎机 cosplay。
- ✅ **结算仪式**（honest = 我们要的）：赌注早已下·掷 = **你亲手翻开已封的命运**。不假装控制·力量来自"已定·即将揭晓"。

**亲手掷给的是三样真东西（都不是结果控制·都诚实）**：
1. **节奏能动**：**你**决定何时揭晓 → 掌控自己屏息的时刻（不是控制结果·是控制"何时面对"）。
2. **归属感**：亲手翻的动作 → 这场赌是**你的**。
3. **主题**：游戏叫**翻命**·玩家亲手翻命 = 标题成真·不可让渡。
> 判定它诚不诚实：**只要不把掷骰包装成"技巧检定"·就不是掩耳盗铃。**

**职业铁律 + 诊断礼物**：
- **一个 Commit→Reveal 游戏的品质 = "承诺有多重要"·不是"揭晓有没有操作"。** 我们的决策**密集到封印前一刻**（田忌赛马选路 / 部署费用曲线 / 连携 / 挂哪张专属牌给谁 / 疲劳兵敢不敢赌这一路 / 弃不弃这路）。掷骰是**有意义吸气后的呼气**。
- **诊断**：某次掷骰**手感空**·永远是**上游决策不够重要**的症状 → **修布局的分量·绝不给掷骰加操作**。

### 4.1.2 ⭐ 铁律：仪式感必须"配得上"——按赌注缩放（防空洞的唯一办法）
> owner 的怀疑戳中真失败模式：**每个 trivial 遭遇都强制亲手掷 = 真空洞、真繁琐**（第40次为杂兵掷骰=折磨）。解法不是"去掉掷骰"也不是"加操作"·而是**让仪式配得上赌注**：
- **关键/悬念遭遇**（可能破家 / 可能折损 carry / ~50-70% 胜率）→ **完整两骰·亲手掷·满仪式**。仪式感在这里**挣来了**。
- **无关小遭遇**（杂兵挡路 / 悬殊胜率）→ **自动结算·一闪而过·不弹亲手掷**。别为定局消耗玩家注意力。
- **一次推进多场遭遇** → 只给**最关键那场**满仪式·其余自动。
> **同一个掷骰机制·配得上就是"扑克翻河牌"·配不上就是"老虎机折磨"**——差别只在**这一刻值不值得一场仪式**。

### 4.2 宏节拍（一场仗的起承转合）
```
开局铺场(低张力·占路/连携) → 中盘接触(张力↑·田忌赛马挑架打) → 关键路突破(高潮·集中破门) → 破家(收束)
```

### 4.3 为什么进入心流（Flow 条件逐条对上）
| Flow 条件 | 本作怎么满足 |
|---|---|
| **目标清晰** | 破敌 3 血大本营·一句话懂 |
| **即时反馈** | 每回合推进·每遭遇掷骰即揭晓·战力明细可读 |
| **挑战≈技巧** | 难度来自**明牌**(地煞/开局排阵)·技巧(田忌赛马/连携/专属牌 timing)可破；Player-AI 三档=不同技巧水位 |
| **掌控感** | 决策都在自己回合·结果可预报(掷命预报显真实%) |
| **无焦虑(不繁琐)** | 掷时零操作·紧经济一回合一决策·信息量受控(专属牌≤3·渐进解锁) |

## 5. 为什么平衡会"难"，理论怎么让它变"可控"

**难在哪**：五层战力 × 地煞/专属牌 × 疲劳 × 两个 AI × 关卡曲线 = 组合爆炸·感觉无从下手（owner 的焦虑真实）。

**理论给的三把钥匙**：
1. **调带不调点**（§1 饱和性）：输出胜率有界平滑 → 不必精算每种组合·只要**汇总 P 落进目标带**。80% 的精度浪费在不影响手感的地方。
2. **先温度后微调**（§2 加热/冷却）：**先把"体温"（源泉曲线·推进速度·homeHp·疲劳率·掷骰范围）调到战斗节奏对**，再动"招牌强度"。节奏错了·再精调胜率也是错的地基。
3. **渐进复杂度**（专属牌≤3·渐进解锁）：**早期关卡杠杆少 → 好调**；复杂度随进度慢慢加 → 每一步都可聚焦。**这既是玩家体验设计·也是平衡工程设计。**

## 6. 两条线的工作法（owner 的"两条线"落地）

> owner：「一条做理论 + 粗调把战斗**节奏**调通；一条花长时间做数值**对齐**。」理论说：**必须先节奏、后对齐**——顺序反了做无用功。

### 🟠 线 1 · 理论 + 粗调节奏（快·feel 驱动·先做）
- **产出本档**（理论基础·✅）。
- **升级仿真台玩家模型**：贪心 → "思考型玩家"（会算期望/留改掷牌·= Player-AI 高级档）——否则扫出来的数值对真人不准。
- **粗调"体温"旋钮**到**战斗节奏对**（不追精确胜率）：源泉曲线 · 推进速度/slot · homeHp · 疲劳对折率 · WIN_CAP · 掷骰范围/ROLL_CAP。
- **判据**：一场仗**长度对**（几回合到首遭遇/破家）、**张力对**（有接触、有翻盘时刻）、**续航/车轮成立**。= "**战斗手感对了**"·而非"胜率精确"。

### 🔵 线 2 · 精调对齐（慢·数据驱动·节奏锁定后）
- 锁定节奏后，才精调**招牌强度**（地煞/专属牌 add/mul 值）、**每英雄 baselineFavor**、**targetWR 曲线**（关1-10）。
- 工具：思考型仿真台 + 两个 AI（Boss-AI 已实装·Player-AI 待建）大规模扫。
- **这是"花很长时间对齐"的那条**——但站在锁好的节奏地基上·每次扫都收敛·不白做。
