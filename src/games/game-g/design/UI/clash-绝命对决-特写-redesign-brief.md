## 0. 这是什么屏

game-g「翻命扑克 Fateflip」回合制战斗里，两军前锋相遇触发的**「绝命对决」特写弹层**（居中面板，压在战斗棋盘上）。核心玩法：**各自掷战力骰**——双方各掷一颗 `[1, 自己战力]` 的骰子，比大小、大者胜（战力越高掷得越高，但弱者有翻盘缝）。

## 1. 重设诉求（owner 原话）

- 现在**太长太高**（信息竖着堆成一长条）。
- 把底部那两栏**「加成明细」（战力怎么算出来的）挪到骰子的左边和右边**（我方明细在左、敌方明细在右），让布局更紧凑、更美观、更平衡。
- 信息量够了，**不要增删信息**，只重排 + 美化。

**期望大结构**：中段做成**三栏** ——
```
                ⚔ 中路 · 绝命对决              (标题)
        🟠 我方·黑桃A·战力30   VS   敌方·红桃9·战力25 🔵   (阵营标)
                 [ 黑桃A 牌 ]   [ 红桃9 牌 ]              (两张对战牌·我左敌右·胜方高亮)
   ┌ 我方加成明细 ┐   ┌  骰子区  ┐   ┌ 敌方加成明细 ┐
   │ 点数    14  │   │ 🎲   🎲 │   │ 点数     9  │
   │ 养成   +22  │   │ 22   9  │   │ 养成    +10 │
   │ 天罡   +18  │   │ 我掷 敌掷 │   │ 天罡    +6  │
   │ 士气   +30  │   │◀我方掷高·胜│  │ …          │
   │ =战力  30   │   └─────────┘   │ =战力    25 │
   └────────────┘                  └────────────┘
              掷命预报  62% ———————— 38%           (胜率条·可选保留)
              [额外效果框：掷平裁定 / 战损对折]
              本场我方胜 ｜ [看明白了 · 继续 ▸]
```
> 骰子区居中、两侧加成明细对称贴着骰子 → 高度砍掉一大截、左右吃满宽度。具体美感（间距/描边/层次/骰子造型）交 Cloud Design 定。

## 3. 设计系统约束（comp 要能端口成数据 UI）

- **控件闭集**（我方能表达的组件）：面板 Panel、文字 Label、按钮 Button、双牌 Versus、进度/条。**别用自由花哨控件**——comp 要能 1:1 落成 `ui/components` 的 LayoutNode 数据。
- **色语义**：我方=暖橙 `#ff7a45`(mine)、敌方=冷蓝 `#3a86d4`(foe)、强调=金 `gold`、战损/负=红 `danger`、次要=灰 `sub/dim`。
- **双皮肤**：玄铁（`--accent:#ff7a45` 玄铁灰橙）/ 锦霞（`--accent:#cf5070` 锦霞红）——配色走 `--accent` 变量、别写死。
- **面板**：深色底 + 倒角(chamfer) + 金边强调，和现有战斗屏一致。
- **尺寸**：整屏画框 1340×858；此弹层居中，重设后**明显更矮更宽**（目标：一屏内不显拥挤、加成明细贴骰子两侧）。
