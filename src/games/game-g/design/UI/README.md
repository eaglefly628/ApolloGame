# Game G《翻命扑克 · Fateflip》— UI 设计参考

拟人化扑克的"空中掷命对决"：两张牌抛向空中相撞坠落，**落地正面者生、反面者死**。
基于 **Apollo UI Kit**（玄铁 / 锦霞双皮肤、同名 token、全交互态），沿用 Game F 布局骨架，
美术改造为**卡通扑克风**：四花色（♠♥♦♣）色板、扑克牌面/牌背、掷命落定演出。

## 设计系统

- **皮肤**：玄铁(暗·熔岩橙) / 锦霞(亮·胭脂玫瑰)，同名 CSS 变量换皮。
- **花色色板**：♠ 钢蓝 `#4a6390` · ♥ 朱红 `#d8504e` · ♦ 琥珀 `#e0973a` · ♣ 翠绿 `#3fae6e`。
- **阵营色**：我方红 = accent · 敌方蓝 `#3a86d4`。
- **字体**：玄铁 Zhi Mang Xing / Rajdhani / Noto Sans SC / Silkscreen；锦霞 Ma Shan Zheng / Cormorant Garamond / Noto Serif SC / Silkscreen。
- 牌面 / 立绘为占位（渐变 + 点数花色），需美术替换。

直接用浏览器打开任一 `.dc.html` 即可预览。
