# 20 · 天机牌全集（致命翻牌 · 牌力评估 · 逐期加厚）

> game design G ｜ 2026-06-18（v2 · owner 纠偏）｜ owner 三条：① 这套牌很重要、但**不叫小丑牌**——正式定名 **天机牌**（owner 拍板）。② **150 张一次堆=不行**——这是 design G 判定题，我判**不行**（堆数据≠设计、无法逐张平衡、低质塞满）。改「**逐期加厚 + 每张牌力评估**」。③ **每张牌必须有牌力评估**。
> 上游：`19`（对决核）·`18`（投放/抽牌/三路）·`12`（旧 10 张并入）。数据形纲领不变：**维度=效果 kind，天机牌=kind×参数**（弱 LLM 可填、非自由代码）。

## ⚖️ design G 判定（owner 让我判"150 多不多"）
- **150 一次性做 = 回驳**。理由：违 owner"慢慢加厚度种类"；一次堆无法逐张评牌力/平衡；质量被稀释成填表。
- **改法**：**catalog = 设计空间（储备池·见末节，候选池）；build = 一期 ~20 张精选**。一期落地 → **仿真台扫 ΔWR 校牌力** → 二期加变化 → …（像 Balatro 多年长出来，不是一天堆 150）。
- **每张牌力评估**（owner 点名）→ §二系统 + §三一期逐张标。

## 命名（owner 拍板 ✅ 2026-06-18）
- **正式定名「天机牌」**（翻命扑克·掷命 → 天机定命运的牌，最贴主题）。
- 代码内部 `joker`/`GAME_G_JOKERS`/`save.jokers` 标识符**不强求改**（纯玩家面命名）；**菜单/UI/文案一律显「天机牌」**（乙菜单轨照此）。

## 二、牌力评估系统（每张牌的强度标尺）
> 牌力 = **设计 a-priori 估值 + 仿真台实测 ΔWR 校准**，两者对齐才算定。
- **牌力 ⭐1–5**：⭐1 **地基**（微稳·+1 掷命点/+2 点数·填库低方差）｜⭐2 **进阶**（明确条件/单路优势）｜⭐3 **强力**（稳定改变一场对决·如 owner 例「输了重摇」≈把败率砍半）｜⭐4 **史诗**（掀整条路/强联动）｜⭐5 **招牌**（定义流派·run-defining）。
- **牌力值 P̂（0–10）**：设计估的"对胜率期望影响"；**仿真台实测 ΔWR 校**（实测 > 估 → 降数值/提稀有；实测低且无人选 → 死牌回炉）。
- **挂钩**：牌力↑ → 稀有↑ + 改造坊成本↑；**库内总牌力有软上限**（防一套塞满 ⭐4–5 = 老虎机，仿真台红线）。库 ≤5 张（doc18 iii）。

## 二、稀有度 / 出率 / 平衡纪律

- **分布**：普 ~60 / 稀 ~45 / 史 ~30 / 传 ~15（传=10 流派招牌 + 5 跨界神卡）。
- **出率**（改造坊/抽卡）：普 50% / 稀 30% / 史 16% / 传 4%；十连保底 ≥1 史。
- **构筑上限**（doc18 iii）：战斗库带 **≤5 张天机牌**（防一局塞满质变 = 老虎机）；改造坊选哪 5 张进库。
- ⛔ **平衡命脉 = 3D-SIM 仿真台**：蒙特卡洛扫「每 5 张组合 × 牌组 × 对手」→ 胜率矩阵；**任何组合顶破爆冷缝 [3%,97%] / 出统治解(某 5 张胜率 >70%) / 出死牌(<5% 选取且无效) → 红牌**回炉。**catalog 全 150，可玩集随仿真台逐批放**（先放普/稀打地基，史/传验过再上）。
