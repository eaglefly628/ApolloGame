## 一句话模型
**致命翻牌 = 皇室战争（点数·实时·推塔）× Commands & Colors（三路·牌驱动·掷骰）× 标准扑克（公平 + 养成）。**
- **三个独立牌组**：① 扑克 52（局内固定单位·公平骨架·每张=一位被诅咒历史英雄）② 天罡 36（局内法术·收集即灵魂·远期可扩地煞 72→108）③ 地支 12（局外养成·升级牌组）。
- **局内**：点数(圣水)回复·两库共享池 → 花点数**摸牌选库**（普通~1/天罡~2）→ 部署**上/中/下三路**（经捷径门可迁移）→ 兵慢行军 → **遭遇掷命对决**（P_eff→logistic 胜率→种子骰→翻正活/翻反亡）→ **先破敌 3 血大本营 = 胜**。无暂停·纯实时。
