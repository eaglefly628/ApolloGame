# Boss 配置（关1-5）· 16牌组 + 地煞 + 留场/牌力 标定（design G 2026-06-21）

> owner 派：「把 5 关的 Boss 配置、16 张牌组、地煞**重新设置**，写成数据，自己跑一遍。」
> 本档 = **可直接喂 loader 的数据草案**（每 Boss：16 写死扑克 + 3 招牌地煞被动 + 留场P + 牌力偏置 + 大本营血 + 目标通关率）。
> **每个 Boss = 一个招牌被动（=它的地煞）**；轮到它掷命时全屏亮「XX 发作」(复用 `REQ-G-战斗逻辑批次·敌用地煞全屏通知`)。
>
> **标定方法**：design G 跑 16v16 原型（甲已实装"胜者掷人头留场续攻"硬币·我临时给硬币加每侧概率 + 16牌组 + 重设地煞值·跑完已撤）。玩家用逐关递进养成基线（doc27 §3.3）。N=400~500。
> ⚠ **简化模型·方向性**：原型牌力用 P 空间 buff 近似（非真 favor 系统）、玩家天罡折进 buff、AI 用通用 tier3。**甲接真 loader（16牌组 + favor 系统 + stayPMul + 诅咒）后，design G 用 `simulate-balance.ts` 重扫定稿。**

> **全局源泉（owner 2026-06-23）**：起手源泉 **6 → 4**（**双方对称**·玩家和 Boss 都起手 4）。理由：起手 6 太高·玩家一上来就能铺满·开局没张力。改 4 收紧开局节奏（前几回合得取舍）。`MANA_PER_TURN=1` 不变 → 派甲改 `MANA_START` 常量（见 `requests.md` REQ-G-起手源泉）。**目标 WR 曲线待两 AI + 4源泉落地后重标。**

> **⭐ 新难度杠杆·开局排阵（owner 2026-06-23·公平版的"加钱"）**：与其给 Boss **偷加源泉**（已禁·不公平·暗箱），不如让 Boss **开局已有 N 张牌排好在场上**（`boss.startFormation`）。这是**明牌**（玩家开局就看见这堵墙·可绕可针对）→ 公平·可破。专治"守势 boss 开局攒不出场面、威胁不到玩家"。**数据驱动**：boss 配置里一个 `[{rank,suit,lane}]` 列表·派甲在 init 摆好（见 `requests.md` REQ-G-开局排阵）。**张数随关爬·design G 用 sim 标。**

> **关1 玩家养成基线修正（owner 2026-06-23）**：**关1 新手没有任何地支附魔**（inlayFavor=**0**·真·零养成）；**首个地支是「通关关1」的奖励**（打完关1 得 1 张地支·从关2 起才带着养成进战）。
> → 关1 sim 的"新手"档应改 **`inlayFavor: 0`**（现 sim 写 20·偏高）；养成坡：关1 进=0地支 → 通关得第1张 → 关2 进=1地支 → … 逐关累积（详 `25-meta-economy-progression.md`）。**消融实测地支(5铜)仅 +1.6% WR·撤掉对关1 难度影响极小·但更真实（新手手里本就空）。**

## 一、关1 · 列奥尼达「温泉关死守」★ · 目标 **~70%**（owner 2026-06-21：不要 50%·往 70% 靠·教学但有挑战）
- **招牌被动（地煞）**：**温泉关死守** — 守墙硬汉·靠隘口与抱团把守，牌力中庸但**人多守厚**（每回合多铺守军）。
- **16 牌组**（同点抱团[三条7/三条8] + 黑桃同花墙·主题=300 斯巴达同质重步兵）：
  `5♠ 6♠ 6♠ 7♠ 7♠ 7♠ 8♠ 8♠ 8♥ 9♥ 9♣ 10♠ 10♠ J♠ K♠ A♠`（主将=A♠ 列奥尼达）
- **地煞 3**：`thermopylae`(温泉关死守·家**3**血+隘口守军) + `phalanx`(斯巴达方阵) + `laststand`(死战不退·主将**3命**)
- **★ 主将噱头「战败3次才退」（owner 2026-06-23）**：列奥尼达（主将 A♠）有温泉关属性 → **战败 3 次才退场**（不是 1 负即退）。`laststand` 现状 = `lastStandGeneral` 布尔(=主将 2 命)；**派甲把它参数化为命数 → 关1 列奥尼达 = 3 命**（见 `requests.md`）。
  - **设计意图（玩法教学）**：3 命主将那一路你很难啃下 → 玩家**自然学会"避开主将路、田忌赛马去打别的两路破家"**（owner：「我们一般来说都会避开主将嘛」）。这正是关1 要教的盘面取舍·噱头 + 教学一举两得。明牌（玩家看得见它 3 命）→ 可破不偷。
- **★ 开局排阵 `startFormation`（owner 2026-06-23·公平版"加钱"）**：列奥尼达**开局就有 2 张守军排在隘口**（贴 Boss 家·slot 8/7）→ 玩家一开局就撞上一堵现成的墙·得绕路或啃。**明牌**（看得见）→ 公平。
  - **把"隘口守军"做实**：原 `thermopylae` 的"隘口守军"只是抽象 `nearBasePower +1`（贴家兵 +战力）；现用 `startFormation` 摆**两张真守军卡**（如 `8♠ 9♥` 落 slot 8/7）→ 温泉关的"300 死守隘口"从一句 buff 变成**场上看得见的两张墙兵**。更直观·更契合幻想。
  - 关1 取 **2 张**（教学关·只给一点开局压力·别太多）；后续关可爬到 3-4 张。design G 用 sim 标张数。
  - **★ 守军行为 = 静守不动（owner 2026-06-23 拍板）**：开局排阵的守军是**死守隘口的静态墙**，不是抢先一波的攻势兵——
    1. **不前压**：每回合 `advanceBoth` **跳过它**·它**不向你家推进**·杵在原 slot（8/7）守隘口。
    2. **不自动冲家**：堵现有引擎反直觉行为——`advanceColumnToBase`（某路只有 Boss 兵时自动行军砸玩家家）对守军**不触发**（守军怎么会主动冲锋？）。
    3. **你来打才交战**：只有玩家**派兵进这路、推到它相邻格**才掷命（`resolveClash`）；你不碰它·它一直守着。
    4. **赢了守原位**：守军打赢掷命后**继续守原位·不追击**（不走留场前推·死守本色）。
  - **「看得见 ≠ 会动」**（owner 点的细节）：玩家开局看见这堵墙 = **可选择"去打 / 绕开"的情报**（田忌赛马素材），**不是**"它要来砸你家"的威胁。守势 boss 本色：它不来找你·你得决定要不要去啃这条路。
- **留场P**：0.5（base）·`laststand` 令**主将**留场更久（死战不退）
- **Boss 牌力偏置 `bossFavorBias`**：**0**（owner 2026-06-21：−2 反直觉·改 0=正常牌力）
- **⛔ 撤销"偷源泉"（owner 2026-06-21 公平性原则）**：原拟 `bonusMana +2` 让玩家觉得**不公平**（凭空多资源）→ **撤掉**。Boss 难度只来自**明牌地煞 + 明牌天罡**（可见可破），不靠偷资源/堆暗数值。
- **明牌天罡**：列奥尼达带 `[旗手 + 不屈]`（守势·明牌·见 §五·五）·与玩家对称。
- **大本营血 homeHp**：**3**（owner 2026-06-21：2→3·"死守"该厚不该薄）
- **✅ AI 修复后重扫（design G 2026-06-23·甲 commit aa8728c1 改进 Boss AI 后跑 `simulate-balance.ts`·N=500）**：
  - **结果（旧 favorBias=14 模型·关1 aiTier=1·homeHp=3·贪心玩家）**：单场 Boss(列奥尼达) 胜率 **86.6%**；**完整 5 战通关率：新手 76.0% / 进阶 81.8% / 老手 90.4%**。逐战难度坡健康：99.6→99.8→98.4→95.6→**86.6**(boss)。
  - **🎯 大突破：难度旋钮活了**。旧坏态 WR 卡 ~96-100%·对任何旋钮免疫；现 bossDelta 扫描 **0→76% · +3→63% · +6→54% · +12→37%**——AI 一修好，整个公平难度模型解锁。**新手 76% 已逼近 ~70% 目标·只差 bossDelta +1~2 或微调 dishaScale。**
  - **甲实装核对**：① 公平·公开盘面反应式启发（防漏路回防 / 趁势压优势路 / 疾行驰援）——**关1 仅靠这层就把 WR 从 ~96% 拉到 76%**（aiTier=1·不读手牌）；② 信息不对称 `foeIntel`（读玩家手牌 + 牌库顶3张预读）**仅 aiTier≥3 启用**（关3-5）·正合 `boss-ai-spec.md` 难度阶梯。**两层都忠实实装了。**
  - **⚠ 仍失真的两点（别据此定稿）**：(a) **玩家仍是贪心脚本**·`player-ai-spec.md` 强玩家 AI 未建——强玩家会把 76% **往上推**·故 76% 约等于"弱玩家地板"·真实高手数待 Player-AI 落地；(b) sim 用**旧 favorBias=14 + 旧关卡模型**·未接我更新的 boss-config（favorBias 0 / 起手源泉4 / 主将3命 / 破家回库 / 16写死牌组）→ 接 loader 后再重扫定稿。
- **⛔ 关1 明确不放**：主将 debuff / stay 偏置 / 偷源泉 / 任何暗箱压迫（owner：教学关干净·只基础推进+连携）。
