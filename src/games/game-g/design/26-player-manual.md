# 26 · 玩法手册（玩家可见 · 初级 → 中级 → 高级）

> game design G ｜ 2026-06-19 ｜ 基于**回合制新流**（doc24）+ 全系统（天罡/地支/52英雄/地煞/货币）。玩家话术·可直接喂游戏内"帮助"或新手手册。**派乙**：可作为 HOME「玩法手册」入口内容（分初/中/高三档展开）。

## 序：你是谁
你是**执掌命运之人**。历史上最伟大的 52 位名将——孙武、成吉思汗、亚历山大、项羽……他们的魂被诅咒、封进一副扑克，困在各自一生最关键的那场战役里。**掷命，即翻命**：你抛牌、正面则活反面则亡，用一掷之力翻动他们的命运。这是一款**单机 · 回合制 · 卡牌策略**游戏：配一副牌，闯 52 场命运之战，解封英雄、越战越强。

## 🟢 初级：打赢你的第一场

**战场长什么样**
- 三条横路（上 / 中 / 下），每路 **9 格**：你方 4 格 · 中间 1 格 · 敌方 4 格。
- 两端是**大本营**，各 **3 点血**。**先把对面 3 血打光 = 你赢。**

**怎么打——回合制，每回合做一件事**
每回合开始 **+1 召唤源泉**（行动资源），然后**四选一**（互斥·选了就专心做这一类）：

| 动作 | 干嘛 |
|---|---|
| **抽牌** | 花召唤源泉抽牌（你选抽「扑克兵」还是「天罡法术」） |
| **放牌** | 花召唤源泉把一张扑克兵摆上某一路（**费用按点数**：小点 2-4 免费 / 5-7=1 / 8-10=2 / J·Q·K·A=3；还能顺手开/关一道「机关门」） |
| **打天罡** | 花召唤源泉放一张法术 |
| **弃牌** | 丢掉不要的牌腾手（免费） |

做完 → **棋盘走一格**：场上的兵沿路前进一步。两军在格子里碰头 → **掷命对决**。

**掷命对决（核心）**
- 比双方这张牌的**战力** → 算出**胜率** → 抛牌定生死：**正面 = 活、继续前进；反面 = 亡、退场。**
- 战力高则胜率高——但**永远有「爆冷缝」**：再强也有 3% 翻车、再弱也有 3% 翻盘。运气在，但**战力决定大势**。

> **初级心法**：召唤源泉很紧（每回合只 +1）→ 每个抉择都重要；**小点数牌便宜（甚至免费）= 开局铺场的好手**、大牌贵但强；别把兵全堆一路；推到对面老家就扣血。

## 🟡 中级：三牌组 + 经营

**你有三套牌**
- **扑克 52（名将 · 收藏池）**：你解锁的历史名将收藏。每张 **点数 = 军衔(战力)**、**花色 = 阵营**。双方点数公平（同起点），强弱靠经营。
- **天罡 36（兵法 · 你的法术）**：赛前从解锁的天罡里挑 **≤5 张**带上场（你的「招牌套路」）。局内打出、立刻生效、持续整局。例：虎符(全军+2)、疾行(一路加速)、擒王(斩敌主将 → 该路崩)。
- **地支 12（天命 · 养成）**：**局外**镶到你的英雄牌上（每张英雄最多镶 3 颗），给他叠属性。

**出战牌组 = 你自己配的 13 扑克 + 5 天罡**
- 从 52 收藏里**选 13 位英雄**带上场（养/附魔最好的人带上去）+ 选 ≤5 张天罡。**这就是构筑——带谁不带谁就是策略。**
- 嫌麻烦？**「一键自动构筑」**帮你配一副均衡的（费用曲线铺开、不全大点、尽量凑连携）。
- **13** 个牌位很挤：要平衡**费用曲线**（够便宜牌开局铺场）+ **连携**（同点/同花）+ **养成**（镶了地支/附魔的核心牌）。

**经营要点**
- **召唤源泉**：每回合 +1、攒着用。互斥规则逼你**每回合专注一件事**：攒牌？铺场？放招？腾手？
- **机关 / 捷径门**：放牌时可顺手开关一道门，让兵在三路间换路（增援薄弱路 / 堵住敌人）。
- **续航**：一张牌能连扛几场掷命；打累了要退场，注意轮换。
- **基础连携（一条路内·自动亮线）**：同一路里 ① **同点数**凑**对子/三条** ② **同花色**凑同花线 → 这些牌**加战力**。这是**基础规则**（自动生效），天罡（双锋/鼎立/同花魁/双锋印）在此之上再放大。→ 这也是为什么你会带"较弱"的 5♠6♠：它们补全你的黑桃同花线。
- **田忌赛马**：三路分兵的艺术——以强避弱、弃一路、集中突破另一路。

> **中级心法**：先读对面想干嘛 → 决定哪路强攻、哪路防守；天罡卡准时机放；续航轮换，别让主力打废。

## 🔴 高级：构筑 · 克制 · 养成

**赛前构筑（深度在这里）**
- **天罡 loadout**：从解锁的 36 张里选 ≤5 带上场。**针对当关 Boss 配牌**——每关 Boss 会**明牌亮出他的 3 张专属地煞**（招牌历史战术），你照着配克制的天罡（counter-pick）。
- **地支镶嵌 + 连携**：把地支镶到核心英雄上。3 颗凑成**三合**（水=灵动 / 火=猛攻 / 金=肃杀 / 木=生生）或**六合** → **连携质变**，build 起飞。地支靠**打完一局「揉」**（加权掉落）+ **同生肖合成升档**（铜 → 银 → 金）。
- **流派印记**：集齐某流派的天罡 → 解锁**招牌印 · 质变**（斩首 / 将领 / 铺场 / 弃一保二 / 同rank / 概率 六流派）。

**Boss 战（非对称）**
- Boss 牌库 = **12 随机天罡 + 3 专属地煞 = 15 张**，比你猛——这就是难度来源。
- 每关开局**看清 Boss 的地煞**（如 汉尼拔「坎尼合围」、项羽「破釜沉舟」、孙武「兵形如水」），**明牌可破**：针对性构筑 + 临场应对。

**爆冷缝管理（硬核）**
- 战力 P = 军衔 + 一切加成；**胜率 = clamp( logistic((P我−P敌)/k), 3%, 97% )**。
- 用天罡掰这条曲线：**铁骰**(占优时封你上限到 100%·不被爆冷) · **磐石**(抬你下限·弱牌不白送) · **灌铅骰**(差距更极端·强者愈强) · **鬼手**(一次性押一场 +25%)。

**成长 · 重玩**
- **货币**：**金币**(打战斗赚·解锁天罡 / 地支) · **钻石**(付费·只加速不卖强度)。**前 5 关可反复刷**；通关 1-9 解锁全 36 天罡。
- **52 命运之战**：难度沿英雄贡献度爬升，终章是 **孙武 / 成吉思汗 / 亚历山大**。打赢一关 = **解封该英雄**、收入麾下。
- **Ascension**：通关后开更高难度·给老手。
- **公平不氪**：扑克 52 双方同起点，强弱全靠**构筑 + 养成 + 操作**，钻石只省时间。

> **高级心法**：看 Boss 地煞 → counter-pick 天罡 → 围绕一个连携 / 流派搭 build → 掌控三路节奏与续航 → 管理爆冷缝。**真正的深度在赛前的牌桌上，不在手速。**

## 一图速记（核心循环）
**配牌组**（自选 13 扑克 + ≤5 天罡 + 地支镶嵌）→ **进关** → 每回合 **+1 召唤源泉 · 四选一（按点数费用放牌）· 走一格 · 遭遇掷命**（同点/同花连携加战力）→ **破敌 3 血大本营** → **解封英雄 + 赚金币** → **解锁更多天罡 / 养地支** → 打下一关、爬向孙武终章。
