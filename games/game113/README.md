# 《雅趣：第二人生》可运行应用 Demo

从仓库启动开发服务后，访问 `/?game=game113`。电脑与手机浏览器共用同一套响应式页面。此版是**本机可交互的应用流程原型**，不是已上线的账号、社交、交易或游戏服务。

电脑网页顶部提供「切换手机版」按钮：在当前页面进入 390px 左右的手机宽度预览，内部可继续浏览；按「返回网页版」会回到手机预览里最后访问的页面。真实手机浏览器直接使用响应式布局，不额外套手机框。

## 页面与流程

- 初见与选兴趣 → 首页今日推荐／每日新鲜。
- 发现 → 已开爱好馆；下方「兴趣图谱」先展示六个策展领域，不一次展开全部分支。选领域或搜索后，分支每次显示六条，可继续展开、查看具体物件与五个深读样本。图谱其他分支仅为策展候选。
- 木工／清酒深读馆 → 木工提供五个观察点、五类器物档案、同好议题与本机私人手记，可转入虚拟小椅档案。清酒馆新增「名酒深读」「世界酒藏」「资料索引」，与酒藏索引、历史、工艺、鉴赏、同好和手记一起形成站内分卷。首批四座日本酒藏、四座海外酒藏与 27 条具体作品档案已写入本地，另有八座日本酒藏的基础索引；前台不跳外站，资料索引可下载本地 JSON 研究包。导览顺序是编辑编排，不是销量、品质或用户关注的真实排行榜；目前没有跨品牌人气指标。价格页只展示注明日期、地区、容量与税费口径的官方公开标价样本；没有交易入口。清酒不进入游戏市集或每日主动推荐。研究来源与扩充队列见 [`sake-research-ledger.md`](../../docs/design/game113/sake-research-ledger.md)。
- 市集 → 演示行情 → 藏品档案 → 本机雅钱买入 → 仓库待鉴 → 细看知识卡；仓库藏品可进入养护预览或演示卖出。
- 同好 → 兴趣圈／示例帖子 → 本机文字分享；文件选择只显示文件名，不保存或上传图片。
- 个人档案 → 雅钱明细、无奖励小考、阅读设置与本机数据清理。
- 养护／三消仅有静态接入位；真正的游戏判定、奖励结算应在恢复 S2 后使用 Apollo 能力实现。

清酒馆新增「2026 赛事与珍酿」：SAKE COMPETITION 2026 五个组别各摘录前三名，Super Premium 组另列有据可核的银、铜奖作品；高价酒只按同为日本公开含税价、720ml 的具体样本展示，并按酒藏名称陈列，不做虚构的跨赛事总榜或价格排名。品牌目录与两座名酒馆按地域名称排列，獺祭保留在档案中，但不占据各分卷的首位；精灵导览改用不同酒藏讲不同问题。收藏价值改用赛事、价签、实物、流通四层证据观察，不伪造涨幅。来源与更新口径见 [`sake-research-ledger.md`](../../docs/design/game113/sake-research-ledger.md)。

清酒馆入口是「杉翁带路」的五章长卷：阅历 0—5 依次为初访、辨史、识麹、读标、寻源、守藏。杉翁是**虚构的引路师傅**，不冒充真实杜氏。每章只打开当前观察点：跟师傅看三处细节，再做两道有明确答案的小考；答错可以听提示重试，通过后才获得章印并开启下一章和相应资料卷。第一章从酒藏门前的杉玉／酒林开始，辨别时节信号、民间故事与具体酒瓶证据。第一章只露出当前页、封存章位、独立的「2026 赛事公报」与资料出处；品牌目录到阅历 3 才开启。阅历是知识旅程进度，不是品味等级、消费等级或市场优势；不发雅钱、不计时、不靠购买解锁。赛事事实始终可直接查阅。进度保存在本机 `game113-guide-v3-sake`；旧版 v2 的“选择即通关”记录不迁入新考试，设置中的「清除本机演示数据」会一并清除。

雪茄馆现在也采用同一套五章长卷，专为完全外行的成年人编排：「一支雪茄的内外」→「一片叶的来处」→「工匠与木模」→「一圈纸上的世界」→「留下可信的卷」。虚构师傅「叶伯」每章带看三张真实资料图、两道看图小考；每个观察点另有可自愿打开的进阶追问。资料卷随阅历渐开，进度保存在本机 `game113-guide-v3-cigar`。它是农业、手工和历史纸本收藏的学习路径，不是吸食或品牌购买指南。雪茄实物已从游戏市集移除；本馆保留成人自我确认和健康提示。研究与 iOS 上架风险见 [`cigar-research-ledger.md`](../../docs/design/game113/cigar-research-ledger.md)。

赛事页的「官方公开名录」为收敛式搜索档案，已离线保存 528 条可辨认的 2026 年公开名单记录（38 金、74 银、116 铜、300 条仅从决审入围页读取）。它们不是全部 1,139 件参赛作品，也不能保证名单异名完全去重；SAKE COMPETITION 官网没有逐瓶公开评委评语。每条详情把准确结果、组别、酒标文字线索和缺失的评价证据分开，不编造风味。新增五份「逐瓶深读」示范：分别以赛事结果、酒藏具体产品说明、IWC 实际逐瓶评语或注明日期的零售观察为证据，不混用不同来源。十四代六条零售价格观察独立展示，不与酒藏官方标价混排。数据重建脚本：[`scripts/import-sake-competition-2026.mjs`](../../scripts/import-sake-competition-2026.mjs)。

所有演示雅钱、收藏、点赞、文字分享和私人手记只保存在当前浏览器的 `localStorage`。清酒馆与雪茄馆有 Demo 自我年龄确认；正式版仍需按上架地区落实年龄分级和访问控制。不存在真实交易、提现、跨用户社交或公开发布。充值、广告、真实评论、用户图片上传、内容审核、正式行情和服务端账户尚未接入。

## 图片真实性边界

`public/games/game113/demo/` 中的**九张图片全是 AI 生成示意**：六张原有爱好／藏品图片、两张兴趣图谱氛围图与一张清酒馆静物图。清酒和雪茄两馆的师傅观察点另使用逐张登记的真实资料照片／历史图像，来源及摄影信息见 [`public/games/game113/real/README.md`](../../public/games/game113/real/README.md)。雪茄馆入口卡仍是 AI 氛围示意，课程内则使用真图。正式构建中，未获授权的具体品牌瓶身／酒标位置保持 Placeholder；不得用 AI 图或别的实物照片代替。本机开发预览可见八张官网产品候选图，它们逐张核对了具体酒款，但**版权再利用许可待核**，只保存在被 Git 忽略的 `games/game113/preview-art-local/`，不进入发行包；来源清单见 [`sake-preview-images.ts`](./sake-preview-images.ts)。原有演示藏品图片仍显著标注 AI 来源。AI 素材与提示摘要见 [`public/games/game113/demo/README.md`](../../public/games/game113/demo/README.md)；目录策展规则与纵深样本见 [`interest-atlas-v3.md`](../../docs/design/game113/interest-atlas-v3.md)。

正式版需逐件提供有授权和来源记录的实物原始照片：整体多角度、重要局部、标记／刻印、瑕疵和品相证据。原图不可覆盖；修复与背景合成图必须留处理记录并标注，不能改变物件事实。知识热点和品相判断只依据可核验原图与人工审校资料。`ImageSource.kind` 只有完成这些核验后才可改为 `verified-photo`。
