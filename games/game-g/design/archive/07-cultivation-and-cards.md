# 07 · 培养牌组 · 牌面融合 · 功能牌

> 承 `02` 元循环 + owner 愿景：「小丑牌/星球牌**融在牌面上**培养牌组 + **功能牌**改战场（进攻/埋伏/特殊出现 = 卡牌配合）」。
> 两条线：**局外构筑（培养）**+ **局内战术（功能牌）**。

---

## 一、牌面融合（培养 = 给牌升级，Balatro 同构）

你的每张牌可被**融合**强化，形成持久身份（炉石 / Balatro 收集感）：

| 融合物 | 效果 | 数据形（复用 Game E） |
|---|---|---|
| **小丑牌**（融牌面） | 给该牌一条**改规则**的被动（如"此牌的队 +favor""此牌死时翻死一个敌""此牌必活一次"） | Game E joker 算子（trigger→when→{op,target,value}） |
| **星球牌**（升档） | 升级某**军衔 / 路 / 羁绊**的 favor 档（如"星球·上军"升上军全队 favor） | REQ-012 `op:mul/set` 档位升级 |
| **附魔**（品质） | +favor% / +触发次数（foil/holo 等价物） | modifier 数据 |

- **王牌（大队长）= 最佳"名将位"**，融小丑做招牌——精确对应 owner"融在牌面培养"。
- 这些是**局外持久层**（见 `02` 服务层边界：收藏/构筑不进确定性 ECS）。

---

## 二、功能牌（局内战术 = 进攻 / 埋伏 / 特殊出现）

owner 的"进攻、埋伏、自定义特殊出现方法"= **卡牌配合**，落为**功能牌目录**（局内打出、改战场）：

| 功能牌类 | 例 | 改什么 | 数据形 |
|---|---|---|---|
| **概率手法（改命）** | 祝福 / 诅咒 / 重翻 / 护盾 | 改某牌 favor / 重 roll / 免死一次 | `01` §三 干预（clickable→effect） |
| **进攻** | 突袭某路 | 该路敌方 −favor | effect 按 lane |
| **埋伏** | 伏兵 | 满足条件时特殊出牌 / 翻面 | condition → spawn / 翻面 |
| **特殊出现** | 援军 / 换位 | spawn 新牌 / 改站位 | `self-rule` spawn（REQ-021） |

- 全是 condition / effect / spawn 重组的**数据目录**，最弱 LLM 能填每条 `{触发, 效果}`。**零新能力。**
- 这是"卡牌配合"的载体：**功能牌 × 牌面融合 × 布阵 = 战术组合空间**——竞争性的深度来源。

---

## 三、培养循环（局外，≈ `02`）

```
打 AI 战役 ──掉素材/牌──► 融合升级(小丑/星球/附魔) ──► 改 favor & 解锁功能牌
     ▲                                                          │
     └──────────── 更强牌组 → 打更难 AI / 更深关卡 ◀────────────┘
```

- favor 成长 = 持久强度载体；但局内掷命永留翻盘窗口（5%/95% 边界，见 `01`）→ 强度可成长、**永不必然**。

---

## 四、复用 / 缺口（CORE RULE）

| 机制 | 判定 |
|---|---|
| 小丑融牌面 | ✅ 复用 Game E joker 算子 |
| 星球升档 | ✅ 复用 REQ-012 `mul/set` |
| 功能牌（进攻/埋伏/援军/换位） | ✅ 复用 condition / effect / `self-rule` spawn |
| 概率手法 | ✅ 已有（`01` 干预） |

> ⚠️ **D0 纪律**：落细节前先对一遍 **Game E joker 已实现哪些算子**（`game-e-joker-roguelike.md`），已覆盖则回驳、缺的才提 REQ-G（守"先查已覆盖"纪律）。
>
> 复诵：培养=给牌融小丑/星球做持久身份；功能牌=局内 condition/effect/spawn 的数据目录改战场。两层都是数据 + 现成能力，零新引擎面。
