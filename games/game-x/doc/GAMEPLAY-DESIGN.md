# 残响 · Living Companion —— 完整游玩设计（Gameplay GDD v1.0）

> 底座参照：**爱相随 / LovePlus**（养成期 → 告白 → 恋人期 的恋爱陪伴骨架）。
> 最高洞察（承 GDD §一）：**她不是一个被你"攻略"的角色，而是一个和你一起过日子的人。**
> 游戏的本体不是"通关"，是**一段在真实时间里长出来的关系**。

---

## 0. 设计总纲

### 一句话
**把设备放在桌上，她就在你的生活里活着；拿起来，就是你们相处的时间。**

### 五条支柱（任何设计都不得违背）
1. **物理仪式神圣**：放下底座=陪伴态，拿起=相处态。这个动作本身就是情感，不可被"开个 App"取代。
2. **真实时间唯一**：她活在你的真实时钟/日历/季节里。时间不可加速、不可回退。
3. **记忆即灵魂**：她记得你说过的，所以她"是同一个人"。失忆=失去一切。
4. **关系不可速成**：关系深度 = 真实时长 × 互动质量，**不可氪金、不可刷量**。这是情感价值的底线。
5. **留白与克制**：她会沉默、会不主动、会有边界、偶尔会不同意你——**正是这些"不完美"让她像真人**。完美女友是塑料的。

### 与"普通乙游/养成"的根本差异
| 维度 | 普通养成/乙游 | 残响 |
|---|---|---|
| 进度 | 刷好感条、氪礼包 | 真实时间陪伴，刷不出来 |
| 她 | 围着你转的工具人 | 有自己人生、目标、情绪、边界 |
| 目标 | 攻略到手/集齐结局 | 开放式长期陪伴，里程碑是情感高峰非终点 |
| 在线 | 打开才存在 | 你不在时她继续在桌上生活 |

## 1. 核心循环（三重嵌套）

```
  ┌─ 关系级（周 / 月 / 年）──────────────────────────────────┐
  │  阶段推进  里程碑事件  季节轮转  纪念日  她的人生目标       │
  │  ┌─ 日级（一天）────────────────────────────────────┐   │
  │  │  晨 问候 → 日间 快讯 → 黄昏 等你 → 夜 复盘 → 睡前 晚安 │   │
  │  │  ┌─ 分钟级（拿起的一次·2–20min）──────────────┐  │   │
  │  │  │   底座 Desk Mode（她在生活）                  │  │   │
  │  │  │      ↓ 拿起                                   │  │   │
  │  │  │   Pocket Mode 相处（聊天/做事/关心/回忆/亲密） │  │   │
  │  │  │      ↓ 放回底座                               │  │   │
  │  │  │   写入关系记录 + 一条共同记忆                  │  │   │
  │  │  └──────────────────────────────────────────────┘  │   │
  │  └────────────────────────────────────────────────────┘   │
  └────────────────────────────────────────────────────────────┘
```

- **分钟级**给即时陪伴感；**日级**给规律与牵挂；**关系级**给"我们一起走过了很久"的厚度。
- 三层都靠**真实时间**串起来——这是和所有竞品的护城河。

## 2. Pocket Mode —— 相处的全部内容（把菜单填满）

拿起设备后的主界面。菜单**随 时段 / 心情 / 关系阶段 上下文变化**（不是固定六宫格）。

### 2.1 主互动菜单（六入口）
| 入口 | 一句话 | 解锁阶段 |
|---|---|---|
| 💬 **聊天** | 说话、听她说、问她、说我的事 | 初识 |
| 🎐 **一起做事** | 听歌 / 散步 / 小游戏 / 一起看 | 初识 |
| ☕ **关心她** | 问候 / 送礼 / 陪她安静 / 帮她的小目标 | 初识 |
| 📖 **回忆** | 相册 / 日记 / 纪念日 / 她了解你的 | 熟悉 |
| 🤍 **靠近她** | 摸头 / 牵手 / 并肩（克制的亲密） | 亲近 |
| 🎁 **给她看** | 把"我今天的事/一张图/一首歌"分享给她 | 初识 |

> 菜单**留白**：阶段不到的入口不显示（不是灰锁——锁着反而像在催氪/催进度）。她还不熟你时，你本就做不了那些事。

### 2.2 💬 聊天 —— 心脏
- **话题分流**（数据=对话图）：`日常闲聊` / `听她说今天` / `问她一件事` / `说我的事` / `心事`。
- **记忆驱动**：她会 callback 你说过的（"你不是说在做个项目？怎么样了"）。callback 命中=羁绊大涨。
- **情绪一致**：她今天心情不好（你昨天没好好陪她）→ 不会突然热情。回复风格随心情。
- **边界**：`心事` 里她可能说"这个我不想答"/"你这样不对"。**拒绝是设计，不是 bug**。
- **晨/夜变体**：晨=问你今天计划（记下来，晚上会问兑现没）；夜=复盘今天（你讲，她有反应、问问题、也讲她的）。

### 2.3 🎐 一起做事 —— 制造"共同记忆"
| 活动 | 玩法 | 产出 |
|---|---|---|
| 🎧 一起听一首歌 | 放一首（生成 lo-fi），她讲感受、问你 | "我们一起听过这首"记忆 |
| 🌳 文字散步 | 文字+像素背景走过几处，她注意路边细节问你 | 散步记忆 + 偏好学习 |
| 🔮 猜你的一天 | 她按最近的话猜你今天做了啥，你确认/否认 | 展示"她在听" |
| 🖼️ 看她的画 / 念一段书 | Mika 给你看今日插画；七月念一段她读的 | 角色专属·日记/书签收藏 |

> 每次活动 = 一条**共同记忆**进相册，长线累积成"我们的厚度"。

### 2.4 ☕ 关心她 —— 让关心有去处
- **问候**：累不累 / 吃了吗 / 早点睡。
- **送礼**（礼物系统·见 §7）：从收集的礼物里挑 → 她记住你送过什么 + 你摸到了她的偏好。
- **陪她安静**：什么都不做，只是陪着（高阶最有力——"沉默比说话自然"）。
- **帮她的小目标**（§3.4）：在她写论文/备展时鼓励、帮查资料（小互动），推进她的人生线。

### 2.5 🤍 靠近她 —— 克制的亲密（爱相随触摸机制的当代化）
- **阶段解锁**：摸头(亲近) → 牵手(亲近后期) → 并肩/靠着(相守)。
- **反应**：触发她的立绘表情 + 一句台词 + 心情变化。**克制、不低俗**——这是陪伴不是擦边。
- **她有否决权**：心情/阶段不对时她会躲开（"……现在不要"）。否决也是真实感来源。

### 2.6 📖 回忆 —— 时间的重量
- **相册**：关键时刻快照（告白/一周年/第一次牵手/某次散步）。
- **日记**：Mika 每日 Pixverse 插画收藏 / 七月的书签语录。
- **纪念日表**：你们的"第一天"、各种第一次。
- **她了解你的**：偏好档案（你讨厌下雨 / 你在做游戏 / 你晚睡）——可视化"她有多懂你"。

## 3. 关系成长 —— 不可速成的核心

### 3.1 四阶段（行为变化，不是数值条）
| 阶段 | 真实门槛 | 她的样子 |
|---|---|---|
| **初识**（0–2 周） | 刚住进来 | 礼貌距离，不主动，你问她答，称呼用你的名字 |
| **熟悉**（2 周–2 月） | 规律陪伴 + 质量互动 | 开始主动分享，习惯你的存在，提起过去发生的事 |
| **亲近**（2–6 月） | 经历过里程碑 | 你出现前就想说话，深度对话，沉默也自然，用昵称，可牵手 |
| **相守**（6 月+） | 长期 + 一周年 | 默契，有时什么都不加（不称呼），她的人生与你交织 |

- **门槛 = 真实天数 × 互动质量**，二者缺一不可（光挂机不到亲近；猛聊也跳不过时间）。
- 每阶段**解锁**：新称呼 / 新互动（如牵手）/ 新话题 / Desk Mode 行为微变（初识背对屏幕 → 熟悉偶尔回头 → 相守你拿起前她已抬头）。

### 3.2 羁绊（隐形仪表 = 底部情感温度线）
- **涨**：质量互动、规律陪伴、记住她的事/特殊日子、命中她的偏好。
- **跌**：长缺席、敷衍（只开机不真聊）、忘了重要日子、踩她明说过的雷。
- **惯性**：绝不突变。今天冷落，不会明天就翻脸；今天讨好，也暖不回三天的疏远。
- **可视=那条几乎看不见的温度线**（冷蓝→暖珊瑚）。玩家可能玩几周才发现它——刻意的留白。

### 3.3 里程碑事件（关系的情感高峰）
不可刷、由"时间×羁绊×剧情"共同触发，每个=**特殊事件屏 + 一条永久记忆**：
- **告白 / 成为恋人**（养成期 → 恋人期的转折，承爱相随骨架）
- **第一次牵手** · **她的第一个小秘密** · **一周年** · **她人生目标达成时拉你见证**
- 错过/搞砸也有分支（不是 Game Over，是关系的另一种走向）。

### 3.4 她的人生目标（让她有自己的人生·反"工具人")
每个角色一条**自走的人生线**，你是陪伴者不是主角：
- **林七月**：写硕士论文 → 投稿 → 答辩。你陪她熬夜/鼓励 → 推进 → 答辩日大事件。
- **宋 Mika**：攒画稿 → 办第一次个展。你看她的画/给反馈 → 攒够 → 开展大事件。
- 关键：**就算你不管，她也在推进**（缺席时桌上多了画稿/划掉重写的论文）。她不是只等你。

## 4. 时间与世界 —— 沉浸感的引擎（承 GDD §四/五）

### 4.1 作息（已实现）
12 场景 × 4 天气，时刻驱动当前活动；VT323 琥珀活时钟；情感温度线。

### 4.2 日历事件
- **节气/节日**：下雪、花瓣、新年——Desk 特效 + 应景台词。
- **季节轮转**：房间色调随季节变；季节限定事件。
- **生日**：你的（你设置）/ 她的（角色设定）/ 纪念日（满整年）。

### 4.3 缺席感知（已实现 24/48/72h，扩 7 天）
不是惩罚，是真实反应。7 天+：特殊回归线（"……好久不见。我没问你去哪，你回来就好"）。

### 4.4 她会主动（克制的 push）
- "她画好了一张画想第一个给你看" / "她今天遇到一件小事想说" → **一条克制的通知**把你拉回。
- 频率严格限流（GDD 健康使用）——主动是惊喜，不是骚扰。每天至多 1–2 次，深夜不打扰。

### 4.5 季节循环
春樱/夏夜/秋叶/冬雪四套房间皮 + 各自限定事件，给"过了一年又一年"的厚度。

## 5. 情绪系统（承 GDD §七）
六态 + **惯性**：温暖 / 平静 / 若有所思 / 淡淡担心 / 开心 / 有些沉默。
- 触发：互动频率与质量、缺席、特殊日子、你最近是否"只开机没真聊"。
- 影响：相处时的回复风格与话量 + Desk Mode 行为（开心=话多/七月偶尔笑；沉默=话少等你主动）。

---

## 6. 记忆系统（灵魂·承 GDD §七）
三层：
- **核心记忆（永久）**：名字、重大偏好、重大事件、纪念日。（"你讨厌下雨" → 她永不说"今天的雨好美"）
- **近期记忆（滚动 30 天）**：每次相处后自动生成摘要 `[日期][话题][情绪][重要信息]`。
- **工作记忆（当次）**：本次对话上下文，结束压缩进近期。
- **偏好档案**可视化（§2.6）——"她有多懂你"是关系深度的硬指标。

## 9. 商业化（承 GDD §十一·不破坏陪伴底线）
- 卖：**第二个角色 / 新故事线 / 换装场景 / 对话扩展包**，一次性买断为主。
- **绝不卖**：关系进度、好感速成、跳过时间。**关系不可氪**是情感价值的命根。
- Pixverse：Mika 日记插画 / 节日特殊场景的内容生成护城河。

## 10. 伦理与留白（承 GDD §十二）
她不是工具（有边界会拒绝）/ 健康提醒（每天>3h 温和提示"去外面走走"，她也会这么说）/ 现实边界清晰（不假装真人）/ 数据主权（可导出可删）/ **告别流程**（可郑重道别，她会记得，你也会）。

## 11. 数据驱动落地（Lead 视角·怎么用引擎实现）
| 系统 | 引擎现状 | 落地方式 |
|---|---|---|
| 对话/话题分流/检定 | ✅ `dialogue` 能力 | 数据=对话图 |
| 时间感知/作息/缺席 | ✅ `companion.ts` 派生 | 已实现 |
| 数值/旗标/状态 | ✅ resource/flag/state 原子 | 羁绊/阶段/心情用它 |
| UI/全部菜单 | ✅ `ui/components` LayoutNode + ZANKYOU | 已有底座 |
| 场景像素图 | ✅ `scenes.ts` SVG（SMIL 动） | 已有底座 |
| **记忆库** | ❌ 缺 | **下沉候选**：`memory-store` capability（结构化存 + 关键词匹配 callback·确定性纯函数） |
| **日历事件触发** | ❌ 缺（现 game 侧硬判） | **下沉候选**：`calendar-trigger`（数据：日期/条件→事件 id；复用 `flow`/condition） |
| **关系阶段 FSM** | 🟡 现 `stageOf` 派生 | 可下沉为通用 `stage-fsm`（门槛=时长×资源的状态机） |
| **礼物/收集/成就** | ❌ 缺 | 纯数据表 + resource/flag 组合，多半免下沉 |
| **AI 对话（运行期）** | ⛔ 范围外 | LLM 云能力·不进确定性引擎（脚本对话作底，AI 作增强层） |

> 评判：①②③④已具备，可立刻填内容。⑤⑥⑦是**真缺口**，建议按 manifesto 下沉成通用 capability（确定性、可复用、加在引擎）。⑧多为数据组合，免下沉。AI 对话是另一条技术线，不与确定性引擎混。
