# game108《拳律 Rule of Three》· 横版对局屏 UI 设计委托

> 给设计方的**单张屏**委托稿。读完这份就够动手，不必读别的文档。
> 目标产物：**横版对局屏**的视觉设定（构图 / 层级 / 状态 / 配色），可交付为设计稿或标注图。

## 0. 一句话玩法（决定了整个画面该长什么样）

**石头剪刀布，但你蓄力时对手看得见。**

每回合分三段：**T1 蓄力（3 秒·公开）→ T2 出招（3 秒·隐藏·同时提交）→ T3 对决（2 秒·亮拳）**，然后结算 1 秒。

- 蓄力：点一只手 +1 层（最多 3 层）。**这个动作是公开的**——你往哪只手存力，对手当场看见。
- 出招：出任意一只手，**不必是刚蓄的那只**（这是诈唬的载体）。
- 判定：**克制关系定胜负**（石>剪>布>石）；**蓄力只决定赢了打多少**（10 / 20 / 30 / 40）。
- 出过的手清零，**没出的原样保留**——所以满蓄一手挂在那儿，是一句持续的威胁。
- 双方各 100 血。满蓄一击 = 四成血。

**设计上最要紧的一句**：这游戏的**唯一支柱**是「对手往哪只手存力，你看得见」。
六条蓄力槽（双方各三）不是 HUD 装饰，**是玩家全程盯着做决策的那份信息**。

### 核心比例（**这是本委托最硬的约束**）

| 元素 | 占画布 | 说明 |
|---|---|---|
| **两只手 + 手臂** | **合计约 45–55% 面积** | **绝对主体**。手臂从左右边缘延伸进来、切出画面外，不画肩膀不画人 |
| 单只手（手掌部分） | 宽 **20–24%** · 高 **40–50%** | 巨大。手掌中心约在 y=42% |
| 左手水平范围 | x **0% → 46%** | 手臂根部贴左边缘 |
| 右手水平范围 | x **54% → 100%** | 手臂根部贴右边缘 |
| 中线区 | x **46–54%** | 两手之间的**空隙**，判定与结果打在这儿 |
| 顶栏 | y **0–9%** | 极简，只放身份与分 |
| 底栏 | y **74–100%** | 选招 + 蓄力槽 + 烟雾 |

**手是主体，其余全部退到边缘**——这一条推翻了我们现有的竖版实现（现在是 UI 占主体、手是两个小图标，正好反了）。

## 2. 逐区要素（要素与按键已定稿，**不要增删**，只重排与美化）

### ① 顶栏（y 0–9%）

| 元素 | 位置 | 内容 | 备注 |
|---|---|---|---|
| 你的身份牌 | 左 x 0–14% | 「你」 | 与左手同色系 |
| 你的血量 | 左 x 14–30% | 血条 + 数字（0–100） | 数字要大、要能一眼读 |
| 回合与相位 | 中 x 38–62% | 「第 N 回合」+ 相位名 + **倒计时环** | 相位名四选一：蓄力 / 出招 / 对决 / 结算 |
| 对手血量 | 右 x 70–86% | 血条 + 数字 | 与右手同色系 |
| 对手身份牌 | 右 x 86–100% | 对手名（五名对手之一） | |
| 设置齿轮 | 右上角 x≈97% y≈12% | | 小、不抢戏 |

**倒计时环**：最后三分之一必须转成警示色——玩家要知道「还剩多久必须出手」。

### ② 中线区（x 46–54%）

平时空着（就是两手之间的缝）。三种时刻会用到：

- **T3 亮拳**：判定结果打在这里（谁克谁的关系可以用一个瞬时符号表达）。
- **结果横幅**：`你赢了这回合 -40` / `你被打中 -20` / `平局 · 双方都不掉血`。
  **伤害数字的视觉重量必须跟数值挂钩**——40 和 10 不能长得一样（40 是四成血，是全场最大的事件）。
- **规则石板**（可以放中线区，也可以另寻位置）：印当前判定表「石 › 剪 › 布 › 石」。
  它**会被道具当场改写**（比如整环反转），改写时要有"凿裂重刻"的表现。

### ③ 两只手（主体）

- **左手 = 你，右手 = 对手。左右位置固定，永不互换。**
- 双方用**明确可分的肤色/色系**区分（参考构图用了浅肤色 vs 橙肤色）——
  **玩家必须零思考就知道哪只是自己的**（我们上一版栽在这里：两只手没有任何区分标识）。
- 需要 **3 种手型 × 2 个色系 = 6 张**：石（握拳）/ 布（张开）/ 剪（V 字）。
- 未出招时显示**待机手型**（握拳待机即可），出招瞬间切换成实际手型。

### ④ 蓄力槽区（底栏·**本作独有·参考图里没有·这是设计难点**）

双方**各三条**槽（对应石 / 布 / 剪），**共六条，全程可见**。

- 每条槽：手型图标 + 0–3 层的进度表现 + 读数。
- **对手那三条要比我方三条更重**——它是玩家做决策的依据。
- **蓄满（3/3）必须是一眼可见的事件**：不是数字从 2 变 3，是整条槽的状态变了（换色 / 高亮 / 有标记）。
- 建议在对手槽附近留一句**威胁提示**的位置：「他攒满了一手 · 被打中要掉四成血」。

> 布局自由：可以左右分置（你的槽在左下、他的在右上），也可以上下分置。
> **唯一硬要求：对手的三条槽在视觉权重上不能弱于我方的。**

### ⑤ 选招三卡（底栏左·参考构图放左下角）

三张卡 = 石 / 布 / 剪，**同一组键在不同时区含义不同**：

| 时区 | 键的含义 | 键面副标 |
|---|---|---|
| T1 蓄力 | 点它 = 给这只手 +1 层 | 「蓄力 → 20」（点完这一层后能打多少） |
| T2 出招 | 点它 = 出这只手 | 「打 30」（现在出它能打多少） |
| T3/T4 | 不可点 | 灰 |

- **槽已满 3 层时，该键在 T1 禁用**（点不动、不产生效果）。
- 三张卡需要**明显的选中/已提交态**——玩家点完到揭晓有 2 秒空窗，这段必须看得出「我提交的是哪只手」。

### ⑥ 烟雾键（底栏右）

「💨 烟雾 ×2」。花一次，把**自己三条槽对对手遮住 2 回合**（自己照常蓄）。
用完 / 生效中 = 禁用态。生效中要有明确的「正在遮蔽」表现。

### ⑦ 终局面板（覆盖态）

胜或负时出现：结果 + 「打了 N 回合 · 剩 M 血」+ **再来一局** 按钮。
**此时对局键收起**——上一版这里是死路（键还亮着但点了没用），必须避免。

## 3. 四个时区的画面状态（一屏四态·请分别出图或标注差异）

| 时区 | 3 秒 | 画面重点 |
|---|---|---|
| **T1 蓄力** | 双方蓄力槽实时跳动；两只手**待机**（握拳）；选招卡是「蓄力键」 | 玩家在读对手的槽 |
| **T2 出招** | 槽不再变；两只手**开始摇拳**（见 §4）；选招卡是「出招键」；提交后有确认态 | 紧张·隐藏·同时提交 |
| **T3 对决** | 两只手**同时展开成实际手型**并向中线推进；判定与伤害打在中线 | **全场最大的事件** |
| **T4 结算** | 出过的手清零（槽掉回 0）；血条变化落定 | 收束 |

## 4. 动画要求（**这是这次重构的核心诉求**）

正常的猜拳，出招是有**过程**的——不是瞬间切图。

1. **伸入**：手从左右边缘**伸出来展开**，一个横向推进的过程（不是淡入、不是弹出）。
2. **摇拳**（T2，出招之前）：手**上下晃动**，且带**旋转性的放缩晃动**——
   就是现实里「一、二、三」那三下的节奏感。这是这个玩法的**节奏本体**，不是装饰。
3. **出招**：摇到位后，手**展开成实际手型**并定格。

请在稿子里标注：摇拳的**幅度**（上下位移 / 旋转角度 / 缩放范围）与**节拍**（几次、每次多久）。

> **实现侧现状（供设计方知情，不影响你出稿）**：我们的 UI 是数据驱动的闭集控件，
> 现有动画词表里**有**「上下浮动」「缩放脉冲」「自旋」「入场平移」，
> **没有**「循环的旋转+缩放摆动」，且一个元素只能挂一条动画。
> 摇拳这条已作为引擎缺口提单（`REQ-108-UI-02`）。**请照设计需要出稿，实现侧去补件。**

## 5. 实现侧约束（**请在这个范围内设计，超出的部分我们做不出来**）

我们的 UI 是**纯数据的闭集控件**（不是自由 HTML/CSS），设计稿最终要能映射到这些件：

**可用**：面板（可带异形轮廓：胶囊/六边/菱形/盾徽/绶带/箭头/标签/切角）、按钮（四种风格 + 异形 + 贴图皮 + 副标 + 图标）、
文字（语义色 11 档 + 描边 + 发光 + 22 款艺术字体，**含 4 款中文艺术字**）、进度条（横条 / **环形**）、
徽章、标签、图片、粒子（纸屑/金币/星爆/微光）、头像、立绘槽、连线、锚定浮层。

**面填充**：语义令牌（panel/raised/sunken/jade/gold/ok/warn/danger/ink/透明）或预设配色
（jade-sheen / gold-sheen / ink-deep / steel / blood / frost / ember / void），也可指定贴图。

**请避免**：自由绘制的矢量装饰、逐像素的特殊排版、需要自定义着色器的效果。
**手的美术**：请按「可替换的贴图资产」设计（6 张手型图 + 摇拳中间帧），不要设计成必须由代码绘制的图形。

## 6. 美术风格

- 现有主题是**暗色金属 + 钢蓝细纹 + 熔岩橙点睛**（暗底、金色点缀），中文标题用毛笔行楷。
- 参考构图那款是**明亮卡通 + 城市球场背景**。两种方向都可以，**请你判断哪种更配「心理博弈」这个内核**并给理由。
- 背景：需要一个能衬托双手的场景（参考构图用了球场 + 城市天际线）。背景**不能抢**手的注意力。
- **五名对手**将来各有形象（复读机 / 莽夫 / 戏子 / 赌徒 / 拳律大师），
  本次只需保证右手的**色系可替换**，不必出五套。
