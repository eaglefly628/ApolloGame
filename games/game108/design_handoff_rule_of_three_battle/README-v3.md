# Handoff: 拳律 Rule of Three — 横版对局屏 **v3 增量交付**

这份是对 `ui-v3-change-brief.md` 的答复。**上一版（v1）的 README 仍然有效**——构图、配色、字号阶梯、圆角、描边、投影、手的几何、T2 摇拳幅度、手部贴图规格全部未动，不在这里重复。本文件只写**变了什么、新增了什么、以及三条判断题的答案**。

节奏已按 v3 改：**T1 2.5s 硬倒计时**（一回合每手仅 +1 层）· **T2 5s 免费 + 每秒 −1 罚**（软超时，不强制推进）· **T3 1.5s** · **T4 无自动兜底，玩家点「下一轮」才推进**。v1 README 里「一局 6–10 回合 ≈ 60–90 秒」那条作废。

画布仍是 **1920×1080**，坐标沿用绝对 px 口径。

## 二、① T1 中央通道放大态

**不是全屏。** 三卡 **380×520**，间距 **56**，整排 1252 宽居中 → 左边 x=**334**，顶 y=**214**，底 y=734。

- 上界让给对手蓄力条（其底边 180）再留 34px 呼吸；
- 下界离底栏 800 还剩 66px；
- 左右各留 334px，两只手待机拳的外缘仍露出约 84px；
- **判定表（x883–1037）提到通道之上**（z-index 6 > 通道的 5），全程可读——玩家正在选手，这块正是告诉他什么克什么的唯一读数，不能被牌压住；
- 提示条「选一手蓄力 · 每回合只能加一层」在 y **110–153**，避开判定表顶边（174），右缘 1181 也避开对手蓄力条左缘（1188）。

**底栏原位处理：虚影。** 同尺寸 5px 虚线描边、背景 `rgba(255,246,226,.10)`、中间一行 15px 的「已升起」。整个 T1a/T1b/T1c 三拍都保持虚影——牌正好落回虚影的位置。这样底栏高度不塌，玩家也知道牌是从哪儿飞上去的。

## 三、② 升起 / 注水 / 粒子 / 回落

### 升起是**形变**，不是缩放

直接补间 `left / top / width / height`，从底栏原位（**186×252 @ x20/218/416, y814**）长到大位（**380×520 @ x334/770/1206, y214**）。

```
duration 380ms · cubic-bezier(.16, 1.3, .36, 1) · 三张错开 0 / 55 / 110ms
```

**不要用 `transform: scale()`。** 描边 7px、圆角 24px、条头高度必须在全程保持原值不被拉伸——四个角同构，牌是长大的，不是被放大的。

### 注水

**水色就用这只手自己的牌色**：石 `#2F7FD0` / 布 `#31A83F` / 剪 `#C8214F`，顶部 85% 不透明往下到实色。**不是金色**——水、粒子、落点光晕三处同色，一眼看得出这股力属于哪只手。

水位 **620ms**，分四段，看得出一记「咣」：

```
0%   → 0
62%  → 76%     快灌
80%  → 108%    拍到顶（过冲）
92%  → 96%     回落
100% → 100%    落定
```

水面是**两条错频的椭圆脊**叠加，单条只会像呼吸：

| | 高 | 颜色 | 动作 | 周期 |
|---|---|---|---|---|
| 主脊 | 20px | 牌色 80% | scaleY 1 ↔ .5，左右荡 ±3% | 900ms |
| 副脊 | 16px | 白 50% | scaleY .6 ↔ 1.15，**反向**荡 ±4% | 1250ms |

整杯水挂 **slosh**：以杯底为轴 ±1.6° 摇（1300ms）——**卡片本身不动，只有水在晃**。
另有 **3 颗气泡**（16 / 11 / 20px，白 60–75%）从底往上窜 210px，周期 1.5 / 1.8 / 2.1s 错开发。

### T1c 分两段：**先粒子，后回落**

**① 粒子（600ms）** — 只有**被选中的那一张**发，另两张不发。

- 起手一圈**爆环**：100px 圆、26px 描边取牌色，0.5s 内涨到 2.6 倍并收边到 2px；
- 随后 **14 颗**射出，直径 12–30 六档，芯白 → 牌色 → 牌色 75% 径向渐变，外挂 26px 同色光晕 + 5px 白描边；
- 轨迹：先向上窜 90px 再俯冲，飞行 **600ms**，每颗错开 36ms；
- 落点是它**该去的那一格**蓄力槽（石 x842 / 布 x1145 / 剪 x1447，y940），一记 200×130 的同色落地光晕。

> **这套 CSS 粒子只是形态与节奏的稿。** 真机建议直接换引擎粒子器——发射数 14、锥角 30°、初速带随机 ±15%、重力回落、加拖尾。CSS 这版拿不出真正的拖尾与随机散布。接口仍是 `layout.flyTo{ to:'slot-rock', ms:600, arc:.35 }`。

**② 回落** — 粒子落定后三张牌**各自飞回底栏原位**，不是飞进槽里（槽已经由粒子加满了）。

用**和升起完全同一套节奏**，只是几何反着走：

```
duration 380ms · cubic-bezier(.16, 1.3, .36, 1) · 错开 0 / 55 / 110ms
```

牌全程盖在底栏之上（z-index 5），不会从底栏下方穿过去。

## 四、③ T2 罚血读秒态

免费 5s 走完 → 倒计时环**不再倒数**（转为满圈红、停转，只当色块用），画面**正中央**升起欠账牌：

- 620 宽，墨边 7px，暗红面 `rgba(122,26,18,.94)`，圆角 32，投影 `0 12px 0 rgba(0,0,0,.45)`；
- 第一行：一枚每秒跳一下的「−1」印章（64px 圆，`#FF5A45`，`steps(1,end)` 1s）+ **42px** 主句「超时了 · 每思考 1 秒罚 1 滴血」；
- 分隔线（4px，白 22%）下：**132px** 的累计欠数，`#FFD0C6`，`text-shadow: 0 7px 0 #3F2B1E, 0 0 44px rgba(255,90,69,.7)`；
- 底行 22px 小字「出手即停 · 这不是他打的」。

**放正中是有意的**：这一拍两只手在摇、六条槽不用读，正中是唯一没人抢的地方，玩家一眼就懂自己在被罚。

**与战果掉血区分得开** —— 罚血是**血条左端渗出的小红滴**（−1，24px，从血条下沿落 46px，0.9s，三滴错开 0 / 300 / 600ms），**不走中央横幅、不放大字号、不震屏、不触发胜负判定**。战果掉血才有横幅 + 大字 + 震屏。文案钉死「超时」「罚」，不写「受伤」。

## 五、④ 结算演出的幅度与节拍

| 项 | 规格 |
|---|---|
| **伤害数字跳数** | 0 → 终值，**460ms** ease-out，步进 24 帧；字号仍 `56 + dmg × 2.1`，跳数期间字号同步从 .82 倍长到 1 倍 |
| **血槽双段条** | 底层滞后条**停 140ms** 再用 **420ms** ease-in-out 追上；色 `#FFD45E`（我方）/ `#FFB3A6`（对方） |
| **震屏三档** | 掉 10 → ±6px / 180ms；20–30 → ±14px / 260ms；40 → ±26px / 380ms。各配红色 inset 光晕 .16 / .26 / .38，跑 2 个来回 |
| **蓄力回撤** | 出过的手清零时，格子**逐个褪色** 520ms，从满格往回、每格延迟 90ms，不是瞬间归零 |

## 六、⑤「下一轮」

结算屏由玩家点它才推进（**不设自动兜底**）。

居中 x **960**，y **706–790**（底栏之上 10px），**320×84**，奶油面 `#FFF6E2` + 墨边 6px + 金色底影 `0 9px 0 #C9932A`，字 40px。

**与终局「再来一局」的区别**：那颗是**金面、44px、460×96**；这颗是**奶油面、更小**。同族不同重，不会认错。

## 七、⑥ 对手 = 传入的角色卡

**画像槽 34×34 → 76×76**（顶栏 97 内上下各留 10px 气）。名字与画像来自卡片，无图退化成名字首字。原型里用「林知夏」作占位。

**判断：不另开立绘位。** 对局屏四拍里注意力全在六条槽上，立绘会抢注意力，而且顶栏 97px 是硬约束、往下挂又会压到对手蓄力条（y110 起）。真正该放大画像的是 **T4 结算**与**二选一屏**——那两处玩家是停着的。

**判断：心情上屏。** 名字下一枚 18px 小签（阴晴不定 / 执拗 / 上头 / 玩心 / 精明），`rgba(255,246,226,.14)` 底 + 2px 白 30% 边 + 999 圆角。它直接解释对手为什么这样打——没有它，AI 的打法在玩家眼里就是随机。

## 八、⑦ 英文版正式排版

英文一律 **Fredoka**（600 / 700），中文 **ZCOOL KuaiLe**。两套字号阶梯：**英文取中文的 0.72×，下限 15px**。英文额外给 `letter-spacing: .04–.08em`。

三处溢出的正式解——**加宽标签列，不动内容列**：

| 位置 | 中文 | 英文 |
|---|---|---|
| 我的蓄力标签列 | 46px 宽，27px 字，竖排 | **92px 宽**，20px 字，横排两行 `MY / CHARGE` |
| 对手蓄力标签列 | 44px 宽，19px 字 | **62px 宽**，15px 字，两行 `FOE / CHARGE` |
| 卡副标 | 蓄力 → 30 / 已满 · 点不动 / 打 30 | `CHARGE → 30` / `FULL · locked` / `HIT 30` / `Locked this round`，16px |
| 烟雾副标 | 27px 名 + 14px 副 | 20px 名 + **13px 两行**副，`line-height 1.3`，左右各留 10px |

止血那版是反过来的（压内容列），会把 `n/3` 读数挤掉——**不要沿用**。

对照截图：`screens_v3/EN-T1a-cards-risen.png`、`screens_v3/EN-T2-overtime-penalty.png`。

## 九、⑧ 设置菜单定稿

620 宽，卡通语言不变：`linear-gradient(180deg,#FFF6E2,#F4E2C4)` 面 + 9px 墨边 + 28 圆角 + `0 20px 0 rgba(0,0,0,.35)` 投影，`pop .26s` 入场。

- 四行 **62px 高**：背景音乐 / 音效 / 角色配音 / 语言，标签 30px；

- **关闭键降为奶油面** 220×60——菜单里没有第二颗主键。
