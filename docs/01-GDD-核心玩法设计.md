## 1. 产品一句话定位

> "一边把海边餐厅重新经营起来，一边在合并小游戏里放松解压，一边追一部狗血又上头的海港连续剧。"

三个钩子叠在一起：

| 钩子 | 作用 | 对应系统 |
|---|---|---|
| **合并爽感** | 即时正反馈、解压、心流 | 合并板（核心玩法） |
| **经营/装修** | 中期目标感、审美表达、收集 | 星星 → 场景装修 Meta |
| **追剧欲** | 长期留存、情感投入、社交谈资 | 视觉小说剧情章节 |

- 平台：移动端，**竖屏 9:16**。
- 目标用户：25–45 岁休闲玩家，女性向偏多，喜欢剧情/情感/悬疑。
- 网络：单机为主 + 云存档 + 活动联网。

## 2. 核心循环 Core Loop

三层循环嵌套，是这类游戏的骨架：

### 2.1 微循环（合并板内，秒级～分钟级）

```
点击生成器 → 消耗体力 → 产出低级物品（带气泡）
   → 点开气泡 → 拖动两个相同物品合并 → 生成高一级物品
   → 用目标物品交付订单 → 获得金币 / 能量 / 星星
   → （物品不够就继续点生成器 / 合并）
```

心流来源：**"缺一个高级物品 → 我知道再合几步就能拿到" 的确定性推进**。

### 2.2 中循环（一次游玩 session，分钟级～十分钟级）

```
体力充足 → 连续完成多个订单 → 攒够星星
   → 花星星完成"剧情任务/装修"（如：修好吧台、打扫后厨）
   → 解锁新场景 / 新生成器 / 新订单
   → 体力耗尽 → 离开（等待恢复 / 看广告 / 充值）
```

session 目标：**"把手头体力花完，推进一到两个装修节点"**。

### 2.3 宏循环（长期，天级～周级）

```
完成一批装修任务 → 触发一段剧情演出（视觉小说）
   → 剧情埋新悬念/新冲突 → 解锁下一"天/章节"
   → 新章节带来新场景、新角色、新订单、新活动
```

宏循环目标：**追剧**。剧情按"天（Day）/章节"推进，节奏像电视剧，每段留钩子。

> 三层循环的黏合剂 = **星星**。合并板产出订单 → 订单产出星星 → 星星消费到剧情/装修 → 装修解锁更多订单来源。缺任何一环，循环断裂。

## 3. 核心玩法：合并板 Merge Board（P0，最高优先级）

### 3.1 棋盘 Board

- 网格：**7 列 × 9 行 = 63 格**（可调；早期可先给 7×7 再随进度扩容）。
- 每格容纳 1 个物品。
- 生成器**常驻**在棋盘上，占格，通常玩家会把它们靠边摆放，给中间留合并空间。
- 棋盘空间是核心约束：**格子会满**，逼玩家做取舍（合并/出售/收纳）。

### 3.2 合并规则 Merge-2

- **两个同种同级**物品拖到一起 → 合并为**高一级**同链物品，原两个消失。
- 采用 **merge-2**（合 2 个），是本品类主流手感（对标 Gossip Harbor / Travel Town）。
  - > 规则参数化：合并所需数量 `mergeCount` 默认 = 2，后续可为特定链配置为 3。
- 达到该链**最高级**的物品无法再合，通常是**订单目标物**或可高价出售。

### 3.3 生成器 Generators（产出源）

物品的唯一来源。分三类：

| 类型 | 行为 | 举例 | 备注 |
|---|---|---|---|
| **点击型生成器** | 点一下消耗体力，产出 1 个随机低级物品 | 食材袋、工具箱、渔获箱 | 主力产出，绝大多数体力花在这 |
| **生成器链** | 生成器本身也是一条可合并的链，越高级产出越好/一次产出更多 | Lv1 菜篮 → Lv5 冷藏柜 | 让"升级产出源"成为中期目标 |
| **免体力生成器** | 有内置"电量/产能条"，自然恢复，不吃体力 | 果树（对标 Orange Tree） | 中后期解锁，稀缺珍贵 |

生成器关键参数：

- `energyCost`：单次点击消耗体力（如 1）。
- `dropTable`：产出概率表（如 Lv1 60% / Lv2 30% / Lv3 10%）。
- `capacity` / `cooldown`：免体力生成器的产能上限与恢复速率。
- `outputBubble`：产出物是否带气泡锁（见 3.5）。

### 3.4 物品链 Item Chains（示例）

每条链 5～9 级不等，等级越高价值越高、越接近订单目标。餐厅主题示例：

**① 食材链（生鲜 → 料理）**
`Lv1 番茄 → Lv2 洗净番茄 → Lv3 切片 → Lv4 番茄酱 → Lv5 意面 → Lv6 招牌意面`

**② 渔获链（Harrison 供货线）**
`Lv1 小鱼 → Lv2 鲜鱼 → Lv3 处理好的鱼 → Lv4 鱼柳 → Lv5 香煎鱼 → Lv6 主厨鱼料理`

**③ 工具/维修链（Sam 维修线）**
`Lv1 螺丝 → Lv2 扳手 → Lv3 工具包 → Lv4 电钻 → Lv5 维修套装`

**④ 能量链（功能物品）**
`Lv1 咖啡豆 → Lv2 咖啡 → Lv3 提神咖啡（点击返还能量）`

**⑤ 货币链**
`Lv1 铜币袋 → … → Lv5 金库（点击/出售给大额金币）`

> 一条链的价值曲线建议**指数/超线性**：高级物品价值远大于把等量低级物品分别卖出，鼓励"往高合"。

### 3.5 气泡锁 Bubbles

- 新产出的物品被"气泡"包住，**点击才能使用/合并**。
- 点破气泡通常免费或极低成本；作用是制造"逐个揭开"的小惊喜节奏 + 防止误触。
- 可作为付费/广告点：一键清屏所有气泡。

### 3.6 物品操作汇总

| 操作 | 手势 | 结果 |
|---|---|---|
| 合并 | 拖 A 到同种同级 B 上 | 生成高一级物品 |
| 使用生成器 | 点击生成器 | 消耗体力，产出物品 |
| 交付订单 | 拖物品到订单气泡 / 点交付 | 满足需求，得奖励 |
| 出售 | 长按 → 卖出 | 换金币，清空间 |
| 点破气泡 | 点击气泡物品 | 解锁该物品 |
| 收纳（可选） | 拖入背包格 | 暂存物品，腾空间（付费扩容点） |

## 4. 体力系统 Energy（P0）

体力是**节流阀**，决定单次 session 时长与回流频率——是留存与付费的核心闸门。

- **黄色能量（主玩法体力）**
  - 上限：**100**（软上限；靠奖励/充值可临时超过 100）。
  - 恢复：**每 2 分钟 +1**（满 100 即停）。→ 空到满约需 200 分钟 ≈ 3.3 小时。
  - 消耗：点击点击型生成器（每次约 1）。
  - 获取：自然恢复、订单奖励、剧情奖励、看激励广告（小额）、能量物品、充值。
- **粉色能量（活动/探索专用）**（P2 再做）
  - 只用于限时活动/探索小地图，与主体力分离，便于活动配额独立调控。

设计意图：

- 100 体力 ≈ 一次能打 5～10 分钟，制造"每天回来几次"的节奏。
- 体力墙不能太硬（劝退）也不能太软（无付费动机）——**MVP 先用上面这组数，上线后按 session 长度和留存调**。

## 5. 订单 / 任务系统 Orders & Tasks（P0～P1）

玩家产出物品的**消耗出口**，也是奖励发放口。两种形态：

### 5.1 角色气泡订单（板上/侧栏，P0）

- 表现：角色头像 + 一个"我想要 X 物品"的需求气泡。
- 交付：把对应物品拖过去 / 点交付。
- 奖励：金币、能量，有时是**星星**或剧情道具。
- 特点：随时刷新、可跳过，是稳定的金币/能量水龙头。

### 5.2 剧情任务（顶部任务栏，P1）

- 表现：一句剧情化目标，如"打扫后厨的狼藉""和 Yuka 谈谈""修好破损的吧台"。
- 消耗：**星星**或指定高级物品。
- 完成：推进"当天（Day）"的任务清单 → 触发装修 + 剧情演出。
- 结构：每个"Day"是一组任务清单（3～6 条），全清 → 进入下一天。

> 星星是"进度货币"：订单/合并产出星星 → 星星买剧情任务 → 剧情任务解锁新内容。**务必让玩家清楚"我离下一段剧情还差几颗星"。**

## 6. 剧情 & 装修 Meta 系统（P1，本品差异化核心）

Gossip Harbor 卖座的关键**不是合并本身**（合并玩法同质化严重），而是**剧情把合并"包装"成了追剧**。复刻时这块必须做扎实。

### 6.1 剧情演出（视觉小说式）

- 表现：**角色立绘（含表情差分）+ 背景 CG + 对话框 + 说话人名条**，全屏演出。
- 触发：完成某个装修/任务节点后自动播放。
- 节奏：**每段短（30 秒～2 分钟）、每段留钩子**（悬疑/冲突/情感反转），像电视剧分集。
- 可选：关键节点给**二选一对话选项**（弱分支，主要给代入感，不做重分叉，控制成本）。

### 6.2 装修 / 场景修复 Meta

- 玩家用**星星**完成场景中的修复/装修节点（破损吧台 → 修好 → 选风格）。
- **玩家可选外观**（多套风格皮肤），可回头改——增强表达欲与收集欲。
- 每完成一片区域 → 解锁新剧情、新场景、新生成器/订单来源。
- 场景由小到大：单个餐厅 → 整条海港街 → 小岛。

### 6.3 章节 / 天 Chapter/Day 推进

- 剧情按"天/章节"线性推进，配合每周更新的新章节做长期 Live-ops。
- 追剧式钩子 = 长期留存主引擎。

## 7. 经济系统与数值锚点 Economy

### 7.1 货币与资源

| 资源 | 类型 | 主要来源 | 主要消耗 |
|---|---|---|---|
| **金币 Coins** | 软货币 | 出售物品、完成订单 | 剧情进度、部分装修、购买物品/道具 |
| **宝石 Gems** | 硬货币 | 充值、少量任务/活动赠送 | 买体力、加速、扩容、跳过、稀有礼包 |
| **黄色能量 Energy** | 节流资源 | 恢复/奖励/广告/充值 | 点击生成器 |
| **星星 Stars** | 进度货币 | 完成订单/关键合并 | 剧情任务 / 装修节点 |

### 7.2 数值锚点（MVP 初始值，均为占位，待灰度调优）

| 项 | 初始值 | 说明 |
|---|---|---|
| 体力上限 | 100 | 软上限 |
| 体力恢复 | 1 / 2min | 空→满 ≈ 3.3h |
| 生成器单次消耗 | 1 能量 | 点击型 |
| 生成器产出概率 | Lv1 60% / Lv2 30% / Lv3 10% | 各链可覆写 |
| 一条链层数 | 5～7 级 | 越长越"肝" |
| 物品价值曲线 | 每级 ×2.2 左右 | 鼓励往高合 |
| 单个订单奖励 | 金币 20～200 / 星星 1～3 | 按目标物等级给 |
| 新手前 3 天 | 明显放宽体力/降低目标 | 保 D1/D3 留存 |

> **强约束**：所有数值走**配置表（CSV/JSON）**，禁止硬编码。上线后靠数据（session 时长、体力墙触发率、订单完成率、付费转化）持续调参。

## 8. 商业化 Monetization（P2）

对标品收入极高，靠的是**体力墙 + 剧情钩子 + 礼包**的组合，而非广告。

- **内购**
  - 体力包 / 宝石包（最高频）。
  - 首充礼包、成长基金、周卡/月卡、赛季通行证（Pass）。
  - 限时剧情/活动礼包（借剧情高潮点冲动消费）。
  - 去广告、背包扩容、生成器扩容。
- **激励广告**：只给**小额**奖励（少量体力/金币），定位为"卡关时帮一把"，不喧宾夺主。
- **付费点位**：体力耗尽处、订单差一个物品处、剧情高潮处、限时活动结算处。

## 12. 美术风格方向（给设计师的总纲，细节见文档 02）

- 整体：**温暖、治愈、生活化**的海港小镇质感；轻插画/半写实 2.5D。
- 色调：暖阳橙 + 海水蓝的互补，明快但不刺眼，长时间看不累。
- 物品：**辨识度第一**——同链不同级一眼看出"更高级/更精致"；圆润、有小高光、无强描边或细描边统一。
- 角色：立绘半身，多表情差分，服化道体现身份与情感。
- UI：圆角、柔和阴影、糖果感按钮；信息层级清晰，主按钮醒目。
- 情绪板关键词：`cozy / seaside / warm sunlight / soap-opera drama / cute food`。
