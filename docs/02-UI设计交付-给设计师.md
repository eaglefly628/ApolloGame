> 用途：本文档是**出设计图（UI Mockup / 界面视觉稿）的直接依据**。
> 阅读对象：claude designer（视觉/UI 设计）。
> 配套：玩法逻辑见《01-GDD-核心玩法设计.md》。
> 交付目标：先出 **P0 主玩法界面**的高保真稿，再出 P1 剧情/装修界面。

---

## A. 设计总原则（先读）

1. **平台/画布**：移动端竖屏，主设计稿 **1080 × 1920（9:16）**，安全区上下各留 ~120px（刘海/手势条）。
2. **风格关键词**：`cozy / 海港治愈 / 暖阳 / 轻插画 2.5D / 糖果感 UI / 追剧情感`。
3. **色板（建议，可微调）**：
   - 主色 暖阳橙 `#FF9A3C`；辅色 海水蓝 `#3EC5E8`；点缀 珊瑚粉 `#FF6F91`。
   - 中性 奶白 `#FFF7EC`（背景）、深褐 `#4A3B2A`（文字）。
   - 功能色：能量黄 `#FFC43D`、星星金 `#FFD34E`、金币金 `#F4B740`、宝石紫 `#8A5CF6`。
4. **字体**：圆润无衬线中文字体（如思源黑体 Rounded 风格）；数字用略带弧度的展示体，突出数值。
5. **控件语言**：大圆角（16–28px）、柔和投影、按钮有轻微立体/高光；主 CTA 用主色实心大按钮。
6. **图标/物品**：统一光源（左上打光）、圆润造型、细统一描边或无描边；**同一链条从低到高要有清晰的"变精致/变复杂/变亮"的视觉递进**。
7. **可读性**：长时间游玩不累眼，避免高饱和大面积堆叠；重要数值（体力/星星/金币）永远在 HUD 固定位。
8. 每屏都请给 **default / 空态 / 满态 / 弹窗叠加** 关键状态（能给几个给几个）。

## C. 逐屏详细需求

### S1. 合并主界面 Merge Board（★最高优先，先出这张）

**布局（从上到下）**：

```
┌──────────────────────────────────────┐
│ [头像+等级]  [★星星] [🪙金币] [💎宝石]  │  ← S4 顶部 HUD
│              [⚡体力 34/100  ⏱2:00]     │
├──────────────────────────────────────┤
│  当前 Day / 剧情任务进度条（可点开 S5）   │  ← 任务提示条
├──────────────────────────────────────┤
│                                        │
│        ▨ ▨ ▨ ▨ ▨ ▨ ▨                   │
│        ▨ 🍅 🐟 ▨ ▨ 🔧 ▨                 │
│        ▨ ▨ 🧺 ▨ ▨ ▨ ▨                  │  ← 合并棋盘 7×9 网格
│        ▨ ▨ ▨ ⚙️ ▨ ▨ ▨                  │     生成器沿边、物品居中
│        [生成器] ▨ ▨ ▨ [生成器]           │     部分格带"气泡锁"
│        ▨ ▨ ▨ ▨ ▨ ▨ ▨                   │
│                                        │
├──────────────────────────────────────┤
│  订单角色栏（横向滑动，2–4 个角色气泡）    │  ← S3 订单
│  [👩需求🍝] [🧔需求🐟] [👵需求☕] ...      │
├──────────────────────────────────────┤
│ [菜单] [任务] [商店] [活动]  ← 底部导航    │
└──────────────────────────────────────┘
```

**要点**：
- 棋盘格子为**圆角方格**，空格有淡淡内阴影/纹理（木质餐桌/操作台质感）。
- 物品居中带柔和落影，选中/拖动时放大 + 高光。
- **气泡锁**物品：物品被半透明泡泡包裹，泡泡上有高光反光。
- 生成器视觉上明显区别于普通物品（更大、有"可点击"呼吸光/角标）。
- 合并瞬间要有**特效位**（星星迸发/光圈），请预留特效层示意。
- 空棋盘（新手）与满棋盘（提示"没空间了"）两种状态各出一版。

**交互态**：物品 default / 选中 / 拖动中 / 可合并高亮目标格 / 气泡锁 / 生成器可用 / 生成器冷却（免体力生成器电量条）。

---

### S2. 生成器与物品状态规范

请出一套**规范图（spec sheet）**，而非单屏：

- **生成器三形态**：点击型（食材袋/工具箱/渔获箱）、生成器链（Lv1→Lv5 逐级升级外观）、免体力果树型（带电量/产能环）。
- 生成器点击反馈：按下缩放 + 产出物"弹出"动效关键帧示意。
- **物品链视觉递进演示**：任选 1 条链（如食材链 6 级）画出 Lv1→Lv6，展示"越高级越精致/越亮/装饰越多"的递进法则，作为全链条美术基准。
- 物品尺寸/网格适配规范：所有物品统一画布尺寸、统一光源、统一落影。

---

### S3. 订单 / 交付面板

- **角色气泡订单卡**：左侧角色小头像（圆形），右侧需求物品图标 + 数量 + 奖励预览（金币/星星/能量小图标）。
- 一个"可交付"高亮态（发光/加边框）vs "缺物品"灰态。
- 交付成功动效：物品飞入 + 奖励飞出到 HUD 对应资源位。
- 面板形态：底部横向卡片滑动条（主界面内嵌），点单卡可展开详情弹窗。

---

### S4. 顶部 HUD & 资源条（全局通用组件）

- 左：玩家头像 + 等级徽章 + 经验小环。
- 右：**星星 / 金币 / 宝石** 三个资源胶囊（图标+数值+“＋”号可跳商店）。
- **体力条**：黄色能量图标 + `当前/上限` + 下一次恢复倒计时；点击弹出体力购买/看广告。
- 请保证 HUD 在所有界面**位置一致、可复用**（做成组件）。

---

### S5. 剧情任务栏（Day 任务清单）

- 顶部：`第 X 天` 标题 + 整体进度条。
- 任务列表：每条 = 图标 + 一句剧情化描述（"打扫后厨""修好吧台"）+ 花费（★星星数 / 指定物品）+ 完成勾选态。
- 完成一条：勾选动效 + 星星扣减飞出。
- 全部完成：出现醒目的"进入剧情"CTA 大按钮，引导到 S6。

---

### S6. 视觉小说剧情演出界面（本品情感核心，务必高质量）

**布局**：
```
┌──────────────────────────────────────┐
│                                        │
│          [背景 CG：海港/餐厅]           │
│                                        │
│     [角色立绘-半身，含表情差分]          │
│                                        │
│  ┌──────────────────────────────────┐  │
│  │ 说话人名条：林夏                   │  │
│  │ 对话正文……（打字机逐字）           │  │
│  │                          ▼ 继续    │  │
│  └──────────────────────────────────┘  │
│  [（可选）二选一对话选项按钮×2]          │
│  [跳过] [自动] [历史]                    │
└──────────────────────────────────────┘
```
- 立绘：至少给 **1 位主角（林夏）+ 3～4 种表情差分**（平静/惊讶/难过/生气/微笑）作为基准资产。
- 背景 CG：给 2 张基准（白天海港街 / 餐厅内景）。
- 对话框：半透明毛玻璃 + 圆角，名条用主色胶囊；字体清晰、行距舒适。
- 情绪表达是卖点 → 立绘表情与打光要"到位、有戏"。

---

### S7. 场景 / 装修界面

- 展示一片"待修复/待装修"的场景（如破旧吧台区）。
- 每个装修点：一个"＋/锤子"图标热点，点击弹出"花 ★N 星修复/装修"确认。
- **风格选择**：同一装修点提供 2～3 套风格皮肤缩略（如"温馨木质 / 现代简约 / 复古海洋"），可预览可切换。
- 修复前 vs 修复后对比图各出一版（体现"变好看了"的成就感）。

---

### S8. 主菜单 / 世界地图

- 一张手绘感的**云汐湾海港地图**：餐厅、码头、集市、灯塔等地标。
- 已解锁地标高亮可点，未解锁为剪影/上锁。
- 顶部 HUD 复用；地标上可挂"有新剧情/新订单"红点提示。

---

### S9. 商店 / 礼包 / 体力购买弹窗（P2）

- 体力购买弹窗：当前体力状态 + 购买档位（宝石换体力）+ 看广告免费领小额。
- 礼包卡：图标堆叠展示内含物 + 原价划线 + 现价 + "限时"倒计时。
- 分页：体力 / 宝石 / 礼包 / 通行证。
- 风格醒目但不欺骗性诱导（合规）。

---

### S10. 新手引导首屏

- 极简：一个生成器 + 一句手把手提示（手指点击引导）+ 高亮遮罩。
- 第一步只教"点生成器 → 拖动合并 → 交付第一个订单"三连，最短路径给到第一次正反馈。

## E. 交付格式建议

- 每屏：**高保真静态稿**（标注色值/字号/间距）+ 关键交互态。
- 组件：抽出**可复用 UI Kit**（按钮/HUD/弹窗/图标规范）。
- 物品/生成器：**spec sheet**（统一画布、光源、递进规则）。
- 命名规范：`S01_MergeBoard_default`、`item_food_lv3`、`gen_toolbox_pressed` 等，便于程序切图接入。
- 若能给一版**深色/夜晚场景变体**更佳（剧情夜戏用），非必须。
