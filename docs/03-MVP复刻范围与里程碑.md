# MVP 复刻范围与里程碑

> 目标：用最小成本先跑通"合并 → 订单 → 追剧"的核心闭环，再逐层加厚。
> 配套：《01-GDD-核心玩法设计.md》《02-UI设计交付-给设计师.md》。

---

## 1. 优先级总览

| 阶段 | 名称 | 目标 | 判定"完成"的标准 |
|---|---|---|---|
| **P0** | 可玩内核 | 合并玩法能自洽循环 | 玩家能：点生成器→合并→交订单→拿金币，体力耗尽会停 |
| **P1** | 追剧闭环 | 剧情驱动进度成立 | 玩家能：攒星星→做剧情任务→看剧情演出→解锁新内容 |
| **P2** | 商业化/长线 | 可上线运营 | 有内购/礼包/体力购买/活动/云存档 |

---

## 2. P0 — 可玩内核（Must Have）

**系统**
- [ ] 合并棋盘（7×7 起，网格、拖拽、merge-2 合并、出售、气泡锁）
- [ ] 生成器（≥3 个点击型，dropTable 配置，消耗体力）
- [ ] 体力系统（上限 100，2min/点恢复，倒计时）
- [ ] 角色气泡订单（交付换金币/能量）
- [ ] 金币货币 + 物品出售
- [ ] HUD（体力/金币/星星占位）
- [ ] 新手引导三连（点→合→交）
- [ ] 配置表驱动（物品链/生成器/订单/数值全走 JSON/CSV）
- [ ] 本地存档

**内容量**：3 条物品链（食材/渔获/工具，各 5–6 级）+ 3 个生成器 + 5 个订单角色头像。

**验收**：新玩家 3 分钟内完成第一个订单；体力耗尽有明确反馈；合并/交付手感顺滑有正反馈。

---

## 3. P1 — 追剧闭环（差异化核心）

**系统**
- [ ] 星星货币（订单/合并产出）
- [ ] 剧情任务栏（Day 清单结构，星星/物品消耗）
- [ ] 视觉小说演出（立绘+表情差分+对话框+打字机+跳过/自动）
- [ ] 装修/场景修复 Meta（花星星修复 + 风格选择）
- [ ] 章节/Day 推进（线性解锁新场景/生成器/订单）
- [ ] 世界地图/场景切换

**内容量**：第一章剧情（≈1 个 Day 完整流程可打通）+ 女主立绘（4 表情）+ 2 张背景 CG + 1 个装修场景（修复前后）。

**验收**：玩家完成一个 Day 的任务后能看到一段有钩子的剧情演出，并解锁下一批可玩内容——"追剧感"成立。

---

## 4. P2 — 商业化与长线

- [ ] 宝石硬货币 + 内购点位
- [ ] 体力购买 / 背包·生成器扩容
- [ ] 礼包 / 首充 / 周月卡 / 通行证
- [ ] 激励广告（小额奖励）
- [ ] 限时合并活动（独立小棋盘 + 粉色能量）
- [ ] 云存档 + 账号系统
- [ ] 埋点与数值后台（session 时长、体力墙触发、订单完成率、付费转化）

---

## 5. 技术选型建议（供程序参考，非强制）

- **引擎**：Unity（品类主流、2.5D/特效/热更成熟）或 Cocos Creator（H5/小游戏友好）。若先做 Web 可玩 Demo，可用 Phaser / 纯 Canvas。
- **数据**：本地存档（P0）→ 云存档（P2）；所有玩法数值走**配置表**，支持热更/AB。
- **架构**：棋盘/物品/生成器/订单做成**数据驱动 + 事件总线**，方便持续加链条与活动。
- **首里程碑建议**：先做一个**灰盒可玩 Demo**（无美术，色块+文字）验证合并手感与体力节奏，再套 claude designer 的视觉稿。

---

## 6. 里程碑排期（示意）

| 里程碑 | 内容 | 交付物 |
|---|---|---|
| **M0** 灰盒 Demo | P0 合并+生成器+体力+订单，纯色块 | 可玩性验证 |
| **M1** 视觉原型 | 套用 designer S1–S4/S10 视觉稿 | 可评审美术原型 |
| **M2** 追剧闭环 | P1 剧情+星星+装修，第一章打通 | 首个完整体验切片（vertical slice）|
| **M3** 商业化接入 | P2 内购/礼包/活动/云存档 | 可小范围灰度 |
| **M4** 上线打磨 | 数值调优、留存/付费 A/B、Live-ops 排期 | 上线版本 |

---

## 7. 风险与注意

- **IP 风险**：角色/剧情/美术必须原创换皮（见 GDD 第 11 节），只复刻机制。
- **同质化风险**：合并玩法差异小，**差异化押在剧情质量与美术调性**，P1 剧情别偷工。
- **数值风险**：体力墙软硬需灰度调；新手前 3 天务必放宽，保 D1/D3。
- **内容产能风险**：剧情/物品链是"无底洞"，需建立可持续的**内容流水线**（配置表 + 美术规范 + 文案模板）。
