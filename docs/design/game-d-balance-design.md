> **用途**：把《骰途》的**可玩内容 + 数值平衡**设定出来，并配一个**模拟程序**（`scripts/game-d-balance-sim.mjs`）跑数据验证。owner 2026-06-29「这是个大策划案，好好想」。

## 1. 五行元素系统（5 属性·相克五环）

5 元素 = **五行**：🟡金 / 🟢木 / 🔵水 / 🔴火 / 🟤土。颜色即元素（骰面染色）。

**相克五环（destruction cycle·A 克 B）**：`金→木→土→水→火→金`
> 金克木 · 木克土 · 土克水 · 水克火 · 火克金。

每个元素：**克 1 个、被 1 个克、对另 2 个中性**。对某敌：
| 攻击元素 vs 敌人元素 | 系数（模拟调后） |
|---|---|
| 克制（你克它） | **×2.2**（克制·super effective） |
| 被克（它克你） | **×0.3**（吃瘪·加重·逼你别堆单色硬刚弱点） |
| 同元素 / 中性 | ×1.0 |

> 干净 5 环：对任一敌人，5 色里恰好 1 色 ×2、1 色 ×0.5、3 色 ×1 → **"选对颜色"是核心决策**。

## 2. 伤害公式（小丑牌式：加法地板 × 乘法涌现）

一次攻击 = 玩家投入的一组骰子。**主元素** = 投入里数量最多的颜色（并列玩家选；模拟器选最克敌的）。

```
最终伤害 = round( 点数和  ×  元素组合倍率(mult)  ×  克制系数  ×  特殊修正 )
            └ 加法地板    └ 同主元素越多越大     └ ×2/×1/×0.5  └ 功能骰/buff
```

- **点数和**：投入所有骰的点数相加（小丑牌"筹码"地板·永远有）。
- **元素组合倍率 mult**（按主元素骰数 m·模拟调后压平·别让堆单色暴力碾压克制系统）：
  | m（同主元素骰数） | 1 | 2 | 3 | 4 | 5 | 6+ |
  |---|---|---|---|---|---|---|
  | mult | 1.0 | 1.4 | 1.8 | 2.2 | 2.6 | 3.0 |
- **克制系数**：§1（×2 / ×1 / ×0.5）。
- **特殊修正**：功能骰 / buff（如 +平加、×额外 mult、暴击）。

> 例：投 `火4 火5 火3`（3 火）打金系敌人（火克金）→ (4+5+3) × 2.2 × 2.0 = **52.8 → 53**。
> 同样三颗打水系敌人（水克火）→ 12 × 2.2 × 0.5 = 13。**选对色差 4 倍。** 这就是"加法 vs 乘法"的天壤之别。

## 4. 房间 / 关卡结构 + 奖励

### 4.1 一座塔 = 多层；一层 = 3 间（2 试炼 + 1 守关者）
- **run 长度**：默认 **4 层 × 3 间 = 12 间**（含 4 个 BOSS）；登顶=胜（可调）。
- **房间类型**：⚔ 普通战斗 · ☠ 精英 · 🛒 商店 · ❓ 事件 · 💎 宝箱 · 👑 BOSS(层末)。

### 4.2 奖励（过关三选一·哈迪斯式）
- 每清一间 **3 选 1**（从加权池抽 3 张不重复）。
- **奖励池（按权重）**：
  | 奖励 | 权重 | 内容 |
  |---|---|---|
  | 加骰 | 35% | 从骰目录抽一颗（按稀有度·入库） |
  | 升级骰 | 20% | 一颗骰升级（d6→d8 点数 +、或加一面元素） |
  | buff(命运祝福) | 20% | 见 GDD §7（加值/组合强化/重掷/协作/滚雪球） |
  | 道具(消耗) | 12% | 重掷石/+N 符文/染色/护盾药 |
  | 删骰/合骰 | 8% | 移除垃圾骰 / 两颗合一（精炼骰库） |
  | 货币 | 5% | 命运碎片（商店用） |
- **稀有度权重**（加骰/buff 内部）：普通 60% / 稀有 30% / 史诗 10%（精英·BOSS 后池更好）。
- **BOSS 奖励**：3 选 1（史诗池）+ 回 1 心 + 命运碎片。

## 5. 敌人 / BOSS + 难度曲线

### 5.1 敌人模型
- **HP** + **元素**（定弱点/抗性·§1） + **本回合威胁**（没打过 → 扣队伍 1 心 / 诅咒骰 / 加甲）。
- **HP 曲线（普通敌）**：第 f 间 `HP = round(BASE × growth^(f-1)) × modeFactor`
  - 初值 **BASE=22**，**growth=1.18**（模拟调后·原 1.28 是难度墙），精英 ×1.6。
- **BOSS（层末·带 5 属性）**：`HP = 普通 × 1.9`（模拟调后·原 2.6 团灭）；**多元素**——BOSS **每回合轮换当前元素**（弱点漂移·单人每 2 回合、双人每回合），逼玩家骰库带多色 / 百搭 / 导能。威胁更重。

### 5.2 队伍生命（心）
- **单人**：5 心。**双人**：7 心（共享·模拟调后·原 3/4 太脆）。心见底 → run 结束（带回命运碎片）。每过 BOSS 回 1 心。

## 6. ⭐ 单人 vs 双人（完全不同的两条曲线）

> owner 强调：单人关和双人关**完全不一样**。核心差异：双人 = **两套骰库合并掷** → 骰子更多、能同时覆盖"克制色 + 被克规避" + 协作 combo → **能力更强**，故敌人也更强、威胁更狠，但**容错也更高**（互救/共享心）。

| 维度 | 单人 | 双人 |
|---|---|---|
| 骰库 | 1 套（起手 5 朴骰） | 2 套（各起手 4·合掷=8） |
| 敌人 HP `modeFactor` | **×1.0** | **×1.9**（非 ×2·留协作红利空间） |
| BOSS 元素轮换 | 每 2 回合 | **每回合**（更逼多色） |
| 心 | 5 | 7（共享·同生死） |
| 威胁 | 扣 1 心 | 扣 1 心 + 偶尔点名一名玩家 |
| 协作 | — | 合并 combo（跨两人凑同色/同点）+ 连珠骰 + 互救道具 |
| 难度曲线目标胜率 | 新手 ~35% / 老手 ~60% | 同档但**靠配合达成**（单飞更难） |

- **难度曲线（两条·模拟器分别跑）**：敌人强度随层指数升（growth^f），玩家 build 随奖励线性+组合涌现升 → **追逐曲线**：前期苟、中期 build 成型滚雪球、BOSS 检验。双人曲线整体上移（更强敌）但方差更低（两人兜底）。
- **平衡判据**（模拟器输出）：① 单人 / 双人**每层存活率**落在目标带；② 没有"一色通吃"（各 build 原型胜率不应差太多）；③ BOSS 是明显尖峰但非劝退墙；④ 选对颜色 vs 选错颜色的伤害差体现策略价值。

## 7. 模拟程序（`scripts/game-d-balance-sim.mjs`）

**目的**：把上面数值跑成数据，验证难度曲线 + 平衡，回调数字。

- **实现**：纯 node（无引擎依赖·独立建模本文公式）。种子 PRNG（可复现）。
- **模型**：骰库 → 每回合掷 → 贪心选最优攻击（最大化"点数和×mult×克制"·会选克制色）→ 砸敌血 → 威胁扣心 → 过关按奖励策略加骰/buff → 跨层直到登顶或心尽。
- **跑**：单人 + 双人各 Monte Carlo N=2000 run。
- **输出**：① 每层存活率（两模式）② 整体登顶率 ③ 平均死在第几间 ④ build 原型对比（纯色流/双色流/重骰流/混合）⑤ 选对色 vs 随机色的伤害差。
- **用法**：`node scripts/game-d-balance-sim.mjs [--runs=2000] [--floors=4]`。
- **迭代**：看输出 → 调 §2/§5/§6 的数（mult 档、BASE/growth、modeFactor）→ 重跑，直到曲线达标。

> 数字是活的：本文 §2/§5/§6 的常量与模拟器顶部常量**一一对应**，一处调两处同步。

## 8. 模拟发现与当前平衡快照（2026-06-29·跑 3000 run/格）

> 模拟器跑出来的，比纸上推演靠谱。两轮调参，记录如下（数值仍非终态·需更多轮 + 真人实玩）。

**模拟器三次抓 bug（这就是它的价值）**：
1. **初版 = 难度墙**：growth 1.28 + boss×2.6 + 3 心、每存活回合扣 1 心 → 几乎全队灭在第 2 层（登顶 ~0.8%）。→ 调：growth 1.18、boss×1.9、心 5/7。
2. **二版 = 纯色流碾压**：元素组合 mult（5 同色 ×4-5）太猛，把克制系统（×2/×0.5）淹没 → 无脑堆单色 97% 登顶、"选对色"变得无所谓。→ 调：mult 压平（5 同色 ×2.6）+ 被克加重（×0.3）。
3. **当前快照（单人/双人 · 登顶%）**：
   | build | 单人登顶 | 双人登顶 | 评 |
   |---|---|---|---|
   | 纯色流 | 50% | 18%(BOSS 漂移惩罚) | 高 ceiling·高风险（对了爽·撞克制/漂移就崩） |
   | 混合流 | 37% | 6.5% | 稳健适应路（多色兜克制） |
   | 双色流 | 1% | 0% | 偏弱·待 buff（或本就该混搭非纯打） |
   | 重骰流 | 0% | 0% | 纯无元素=陷阱（应作补充·非独立流） |
   - **选对色 vs 随机色 = 3.5× 伤害** → 属性克制的策略价值坐实。

**仍待调（下几轮 + 实玩）**：① 双色/重骰可玩性（或确立"纯单一型=陷阱·鼓励混搭"的设计取向）；② 双人在模拟里偏难——**因模拟器尚未建模协作红利**（连珠骰/互救/跨人凑色），双人真实强度被低估，需补模型或实玩校；③ 各 build 拉近到目标带（稳健路 ~40-55%·极限路高方差）；④ 引入功能骰（重掷/百搭/导能）后重跑。

> **数值是活的**：`scripts/game-d-balance-sim.mjs` 顶部常量 = 本文 §1/§2/§5/§6 数值，一处调两处同步。改完 `node scripts/game-d-balance-sim.mjs` 即看新曲线。
