## 连通与出图约束

相邻门口保留同一门框、楼梯方向与光色边缘；主厅→晶球厅由暖木过渡到珍珠蓝，晶球厅→回忆廊过渡到纸本玫瑰，回忆廊→阁楼/窗厅分别转灰李紫/奶蓝；主厅→星牌室→茶水间转苔绿/鼠尾草；主厅→玩具间转杏橘；主厅→月庭→星砂铺转夜蓝绿/蜂蜜黄。每图至少 25–40% 的可见面积由本房间特征材质或光色控制，整体保留暖色温的局部光源。
