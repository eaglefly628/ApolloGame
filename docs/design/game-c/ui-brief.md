## 1. 屏幕分区（俯视 3D 视口打底 + UI 浮层）

```
┌─────────────────────────────────────────────────────────────┐
│ [盲注牌 25/50·手数]        [底池 POT]           [菜单⚙][🔊] │  顶带
│                                                             │
│          (P3·三姨太)     (P2·二姨太)                        │
│   (P4·四姨太)   ╔══════════════════╗   (P1·大姨太)          │
│                 ║   3D 牌桌俯视     ║                        │
│                 ║  公共牌×5  底池筹码║                        │
│   (P5·五姨太)   ╚══════════════════╝                        │
│                                                             │
│ [主角:头像·姓名·筹码·衣物徽章]   [底牌×2·牌型提示]  [行动条] │  底带
└─────────────────────────────────────────────────────────────┘
```

- **3D 视口**：全屏打底（俯视固定相机）。牌桌居中偏上 8%，给底带 UI 留呼吸。
- **座位环**：主角 P0 固定正南（底中）；对手 P1~P5 顺时针 东南→东北→北→西北→西南 环桌（默认大~五姨太对位 P1~P5，§11-l 定稿可换）。
- **UI 浮层**：全部 LayoutNode；点击写世界一律 action 信号入队（UI 铁律）。

## 2. 3D 场景规格（盒庭线现货组件）

| 件 | 组件 | 规格 |
|---|---|---|
| 相机 | `Camera3D` | **固定斜俯视 pitch≈46°（Cloud Design 定稿·manual §5.1）**·不切换；投影形态（透视/ortho）P3D 接线时定；取景框住桌+六凳+溢出 10% 地板 |
| 牌桌 | `Mesh3D` box(圆角矮柱)+`Material3D` | 椭圆感长桌 2.4×1.6 单位·呢绒绿桌面（后补贴图槽）·木色包边 |
| 凳子 | `Mesh3D` ×6 | 圆柱矮凳环桌·空位（出局后）凳面变暗 |
| 房间 | `Mesh3D` 地板+四墙 + `Light3D` | 暖顶灯聚在桌面·墙角暗（氛围）·`Sky3D` 关 |
| 公共牌 | `Mesh3D` 薄片 ×5 + `Decal3D` 牌面 | 桌心横排·未发=暗面·发牌滑弧+翻转（render-only 驱动） |
| 底池筹码 | `RigidBody3D`(cylinder) 堆 | 桌心偏北；下注时从座位前抛入（`Impulse3D`）·收池推给赢家 |
| 座位下注区 | 各座位前小片区域 | 本轮下注筹码落此·进街时扫入底池 |
| 按钮标记 | `Mesh3D` 小圆牌 | D 钮随手轮转 |
| 桌边铭牌 | （不用 3D 字）UI 浮层锚定 | 见 §3 座位卡 |

## 3. UI 元素清单（→ LayoutNode 控件 → 信号）

| 元素 | 控件 | 内容/状态 | 写世界信号 |
|---|---|---|---|
| 座位卡 ×6（浮于各凳位旁） | Panel(小)+Image(头像)+Label(姓名/筹码)+Label(状态徽章)+**衣物徽章 👗×n** | 状态：等待/思考中(倒计时环=Gauge)/已弃/全下/出局(置灰)；行动气泡（上一动作 CHECK/RAISE 50…）短显 | 点卡→`seat_view`(带座位号)→开衣柜面板 |
| 主角位（底带左） | 同座位卡放大版 | 头像=角色卡带入·衣物徽章同款 | 同上（看自己衣柜） |
| 底牌区（底带中） | Panel+Image ×2+Label(牌型提示) | 只主角可见；牌型提示=当前最优成牌名（如"两对"） | 无（只读） |
| 行动条（底带右） | Button ×3（弃牌/过牌·跟注/加注）+Slider(加注量)+Button 快捷（1/2池·2/3池·满池·全下） | 非行动轮=隐藏；跟注钮带金额；不足=显示全下 | `act_fold`/`act_check_call`/`act_raise`(带量) |
| 行动倒计时 | Gauge(环/条·嵌座位卡) | 当前行动者座位卡上走秒 | 超时→自动弃/过（sim 规则） |
| 顶带左：盲注牌 | Panel+Label | "盲注 25/50 · 第 N 手"（现金局恒定） | 无 |
| 顶带中：底池 | Label(大字) | POT 总额（多边池时分行列各池） | 无 |
| 顶带右：菜单/声音 | Button ×2 | 设置（难度显示）·静音切换 | `menu_open`/`sound_toggle` |
| **衣柜面板**（点座位卡弹出） | Panel 覆盖层两栏：**左=立绘区**（Image 分层合成·按已穿图层实时叠·owner 拍板逐件图层方案）+右=衣柜列表[每件一行：Image 图标+Label 件名+Label 面值+状态]+Button(关闭) | **自己**：在穿件行尾带「换筹码」Button；已当行置灰+立绘对应层消失；**对手**：列表只读（件名+面值可见·owner 拍板）·立绘同步其着装状态；立绘未产出前左栏=头像大图回退 | 自己行→`pawn_item`(带件 id)→craft-recipe 成交；`panel_close` |
| 摊牌横幅 | Panel+Label(赢家+牌型)+Image(亮 5 张成牌) | 摊牌时短显·同时 3D 收池演出 | 无（自动淡出） |
| 终局屏 | Panel 全屏：胜(五姨太全出局)/败(主角剥光) + 战绩 | 按钮：再来一局/回大厅 | `restart`/`exit` |

## 4. 关键流程时序（演出+音效挂点）

| 时刻 | 3D/特效 | UI | 音 |
|---|---|---|---|
| 开手 | 发牌滑弧（荷官位→各座）·D 钮轮转 | 座位卡状态刷新 | 洗牌+发牌沙沙 |
| 行动轮 | 当前座位凳前微光（`Glow3D`） | 该座位卡倒计时环走·行动条现身（主角轮） | 滴答（低量） |
| 下注/跟注 | 筹码 `Impulse3D` 抛入座位下注区（物理落桌） | 行动气泡+筹码数刷新 | 筹码碰撞 |
| 进街（翻/转/河） | 各下注区筹码扫入底池·公共牌翻转 | POT 刷新 | 翻牌啪 |
| 全下 | 筹码全堆推前（大把物理） | ALL-IN 徽章+`LayoutNode.fx` flash | 重筹码+提示音 |
| **典当** | 一小堆新筹码从座位上方落入该家筹码区（物理） | 衣柜行置灰·衣物徽章 -1·座位卡筹码+面值（fx pop） | 布料窸窣+筹码 |
| 摊牌 | 赢家聚光（`Glow3D`/`Post3D` 微光）·收池推移 | 摊牌横幅·亮成牌 5 张 | 胜利短奏 |
| 出局 | 该凳变暗·座位卡置灰 | 席位状态=出局 | 低音收 |
