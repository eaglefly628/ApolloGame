## 0. 一句话定位

> **单人 vs 五名行为树 AI 的六人桌德州扑克**：俯视固定 3D 牌房里，筹码真的会"哗啦"落在桌面上；
> AI 的强弱不靠作弊发牌，而靠"读你牌的准不准"——难度越高，它对你手牌范围的估计误差越小；简单档它根本不许读。

参照物：Prominence Poker / Poker Night 的"有房间感的单机德州"，减去剧情，加上可调"读牌"难度核。

## 1. 设计支柱

1. **规则零发挥**：打法与标准德州完全一致（owner 拍板）。正确性是底线——下注圈、边池、比牌 kicker 一处都不能错，全部测试钉死。
2. **可触摸的牌房**：俯视 3D 房间（牌桌+六凳）+ 筹码物理落桌。质感来自"筹码是真东西"，不来自视角炫技（相机固定不切）。
3. **诚实的难度**：AI 不偷看发牌堆、不改概率；难度=信息优势（对敌方手牌强度区间的读取误差 %）。可调、可关（简单档纯策略 AI）。
4. **你就是主角**：姓名+头像由外部角色卡带入（立绘字段预留），你的座位铭牌/结算都以你的身份呈现。

## 2. 核心循环

```
【一局 SNG（提案，待 owner 定）】
  落座（角色卡带入身份）→ 盲注按级别表爬升 → 手手对局 → 淘汰离桌 → 决出冠军 / 主角出局
      └─【一手牌 HAND 循环】（心跳单元）
           发底牌 → 翻前下注圈 → 翻牌(3) → 下注圈 → 转牌 → 下注圈 → 河牌 → 下注圈
           → 摊牌比大小（7 选 5 最优）/ 全弃直接收池 → 筹码物理推给赢家 → 按钮轮转 → ↺
```

## 3. 规则面（全部摆成数据，逐条对照标准德州）

| 规则块 | 内容（数据表） | 备注 |
|---|---|---|
| 桌面结构 | 6 座位、按钮位、小盲/大盲轮转表 | 缺人（淘汰）时盲注轮转遵标准死按钮规则 |
| 盲注结构 | SNG 级别表（如 25/50 起，N 手或 N 分钟一升）；现金局=恒定盲注（模式开关） | **待 owner 定局型**（§11-a） |
| 下注动作 | fold / check / call / bet / raise / all-in；min-raise=上一加注增量；不足 min-raise 的 all-in 不重开行动 | 标准规则，无发挥 |
| 边池 | 多人 all-in 逐层切池；每池独立比牌 | 正确性关键，测试点名 |
| 摊牌 | 7 选 5 最优牌型；同型比 kicker；平分池，奇数筹码给位置靠前者；弃牌可 muck | 正确性关键 |
| 发牌 | 种子 PRNG 洗牌；烧牌可作数据开关（不影响公平，仪式感用） | 确定性、可回放 |
| 起始筹码 | 提案 1500（=30BB@25/50），数据可调 | §11-b |

## 4. AI 设计（行为树 + 读牌误差）

- **决策骨架 = 行为树（数据）**：节点输入只有四类——①自身手牌强度（equity 估算）②位置（前/后位）③底池赔率 ④对手行动史（本手加注次数等）。输出=动作+加注尺度（尺度表=数据：1/2 池、2/3 池、全池、all-in）。
- **读牌 oracle（难度核）**：AI 对"对方当前手牌强度"拿到一个**区间估计**：`真实强度 ± 误差%`（误差由难度表配置，owner 可后调）。误差收敛=难度上升。**简单档 oracle 关闭**——AI 只按自身牌力+赔率打（正常策略 AI）。噪声用种子 PRNG，同局可复现。
- **性格模板（数据表）**：紧凶 / 松凶 / 岩石 / 跟注站 / 诈唬狂——每模板一组参数（进池率、激进度、诈唬频率、oracle 权重）。五名对手从模板池配置。
- **不作弊承诺**：AI 永不读发牌堆、永不知道未发的公共牌；oracle 只提供"对手成牌强度"的带噪估计。

## 5. 3D 牌房与筹码物理（表现层）

- **房间**：俯视角固定相机（不切换、不旋转）。布局=牌桌居中 + 六把凳子环绕 + 地板/墙（盒庭 3D 线现成组件拼）。
- **筹码**：3D 圆柱堆按面额分色。下注/收池时筹码**抛掷落桌，刚体物理表现**（弹跳、散落、堆叠）。
  **纪律**：物理只管好看——筹码**数量**永远是 sim 内确定性资源，物理落点不回写游戏状态（render-only，不碰确定性/回放）。
- **牌**：公共牌在桌面 3D 平铺翻开；自己的底牌另有 UI 大图（俯视角下看清花色）。
- 特效：发牌滑弧、翻牌翻转、底池推移、胜者聚光；声音：洗牌/发牌/筹码碰撞/翻牌/allin/胜利（全走现有音频线，声音=数据）。

## 9. 实现顺序（逻辑先行 · 八阶段流程板管进度）

- **M1 逻辑核**（headless）：洗发牌→下注圈→边池→摊牌判定，全规则测试钉死（含边池/分池/kicker 边角）。
- **M2 AI**：行为树+oracle+性格表，AI 对 AI 万手模拟验合理性（胜率分布、非退化策略）。
- **M3 3D 牌房**：房间+筹码物理+发牌演出（render-only）。
- **M4 UI 接线**：素坯→cross design 稿落位。
- **M5 打磨**：特效/声音/难度调参。
- 每阶段一个会话、过流程板门（`game-production.md`），不一口气跑穿。

## 10. 确定性声明

随机源=引擎种子 PRNG（洗牌、AI 噪声、oracle 噪声全部走它，游戏层禁裸 Math.random）；
单人游戏，无 lockstep 需求，但保持全 sim 确定性（回放/测试/bench 复现）。筹码物理与特效=render-only 旁路，不入 hash。
