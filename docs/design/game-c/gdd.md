## 0. 一句话定位

> **单人 vs 五名行为树 AI 的六人桌德州扑克**：2D 俯视大牌桌上（正式赛椭圆桌），下注时筹码真的是 3D 物理"哗啦"抛进池里（桌边围栏挡住不滚出）；
> AI 的强弱不靠作弊发牌，而靠"读你牌的准不准"——难度越高，它对你手牌范围的估计误差越小；简单档它根本不许读。

参照物：Prominence Poker / Poker Night 的"有房间感的单机德州"，减去剧情，加上可调"读牌"难度核。

## 1. 设计支柱

1. **规则零发挥**：打法与标准德州完全一致（owner 拍板）。正确性是底线——下注圈、边池、比牌 kicker 一处都不能错，全部测试钉死。
2. **可触摸的牌桌**：2D 俯视大牌桌（正式赛椭圆·**无椅子**·桌边 3D 围栏）+ 筹码 3D 物理抛入池。质感来自"筹码是真东西·扔进去弹跳散落"，不来自视角炫技（相机固定陡俯视不切不转）。
3. **诚实的难度**：AI 不偷看发牌堆、不改概率；难度=信息优势（对敌方手牌强度区间的读取误差 %）。可调、可关（简单档纯策略 AI）。
4. **你就是主角**：姓名+头像由外部角色卡带入（立绘字段预留），你的座位铭牌/结算都以你的身份呈现。

## 2. 核心循环

```
【一局（现金局·owner 拍板）】
  落座（角色卡带入身份·六人各带预设筹码+衣柜）→ 恒定盲注手手对局
  → 筹码尽则典当衣物续命 → 衣物也尽且缴不起盲注=剥光出局
  → 终局：主角出局（败）或五位姨太全部出局（胜）
      └─【一手牌 HAND 循环】（心跳单元）
           发底牌 → 翻前下注圈 → 翻牌(3) → 下注圈 → 转牌 → 下注圈 → 河牌 → 下注圈
           → 摊牌比大小（7 选 5 最优）/ 全弃直接收池 → 筹码物理推给赢家 → 按钮轮转 → ↺
```

节奏旋钮（现金局无盲注爬升压力，节奏靠这三个数据调）：盲注/起始筹码比 · 衣物总面值 · AI 典当阈值。

## 3.5 衣物筹码——典当机制（owner 2026-07-17 追加）

> 每位牌手（主角 + 五位姨太对手）随身一套**衣物清单**（如：上衣/裙子/袜子/手套/耳环/内衣……每件一个筹码价值）。
> 筹码告急时，点自己身上的一件衣物 → **原子换成筹码**入自己筹码栈。衣物点完+筹码归零=真正出局。

- **经济语义**：衣物=带面值的可典当资产。典当走现成 `craft-recipe`（信号→原子扣衣物+加筹码），**每件衣物一条配方=纯数据**，零新代码。
- **胜负弧线（owner 拍板）**：淘汰条件=「筹码=0 且无衣可当（下一手盲注缴不起）」→ **剥光才出局**；终局=主角败或五姨太全出局。
- **信息面（owner 拍板）**：点开任一座位卡看**具体件名+面值**（"她只剩内衣了"的压迫感 + 可精算对手续命能力）。
- **AI 典当策略**：行为树动作叶——筹码低于压力线（默认 <3BB）时典当最低值衣物；性格影响典当阈值（岩石型早当保守打，诈唬狂拖到 all-in 才当）。
- **衣物表（数据·面值待调平衡）**：耳环 100 · 手套 150 · 袜子 200 · 上衣 500 · 裙子 500 · 内衣 1000（总 2450）；**典当顺序自由点选**（owner 拍板·点哪件当哪件）。
- **表现口径（owner 2026-07-17 终版·修订第三批之 9）**：**立绘换装=挂起需求**（requests.md `REQ-C-立绘换装`·owner「先记需求外面再做」·拉起前置=分级口径/成年人设明示/层规格 spec）；**本期口径=头像不随典当变化**（衣柜清单置灰+件数徽章）。内容口径=自玩/内部体验。美术走**双风格锚**（人物线 `sakura-nijigen`·场景线 `vegas-victoriana`·REQ-C-ART 拍板包+修订①），台账建行底稿=`art-script.md`。

## 4. AI 设计（行为树 + 读牌误差）

- **决策骨架 = 行为树（数据）**：节点输入只有四类——①自身手牌强度（equity 估算）②位置（前/后位）③底池赔率 ④对手行动史（本手加注次数等）。输出=动作+加注尺度（尺度表=数据：1/2 池、2/3 池、全池、all-in）。
- **读牌 oracle（难度核）**：AI 对"对方当前手牌强度"拿到一个**区间估计**：`真实强度 ± 误差%`（误差由难度表配置，owner 可后调）。误差收敛=难度上升。**简单档 oracle 关闭**——AI 只按自身牌力+赔率打（正常策略 AI）。噪声用种子 PRNG，同局可复现。
- **性格模板（数据表）**：紧凶 / 松凶 / 岩石 / 跟注站 / 诈唬狂——每模板一组参数（进池率、激进度、诈唬频率、oracle 权重）。五名对手从模板池配置。
- **不作弊承诺**：AI 永不读发牌堆、永不知道未发的公共牌；oracle 只提供"对手成牌强度"的带噪估计。

## 5. 牌桌表现层（owner 2026-07-18 定稿·2D 视角 + 3D 物理筹码·实现见 `build3d.ts`/`chip3d.ts`/`hud.ts`）

> **owner 2026-07-18 三次拍板改版**（GD-C 验收按本节·勿按旧「斜俯视 3D 牌房 + 六凳」核）：
> ① 弃斜俯视 3D 牌房、弃圆桌；② **2D 俯视视角**（陡俯视相机≈64°·桌面看着是平的 2D 平面）；
> ③ 大**椭圆跑道桌**（正式比赛桌尺寸·占屏中央大半）；④ **不要椅子**（无凳）；⑤ 筹码仍是**真 3D 物理**。

- **牌桌（scene 层 3D·陡俯视=2D 观感）**：椭圆跑道呢面（绒绿）+ 桌基（木）。桌面上沿=筹码落面（静态碰撞体）。**无椅子**。
- **围栏（**隐形**物理墙·owner 2026-07-18「可见木栏太奇怪·改看不见的碰撞」）**：沿桌缘一圈静态 box 墙（`rail-*`·mass0·
  `Visibility:false` **不渲染**·physics.ts「围栏/地台」静态体）——墙面朝心·抛入的筹码撞（看不见的）栏反弹、**不滚出台**；渲染上桌面干净无栏。
- **筹码（3D 物理圆柱·主玩法手感）**：下注时从下注者座位前朝底池**抛掷**——**速度+力量随机**（cannon-es 刚体·弹跳/散落/堆叠·
  围栏内落定）。按面额分色（金/红/黑/绿）。**每座位筹码堆（owner 2026-07-18·六席各一堆）**：各家在**自己那侧桌缘内侧**一摞
  （主角靠自己南桌边近点·五位姨太各堆靠各自桌边·`setStack(seat)`）·**赢得越多摞越高**·封顶防穿天（静态无物理·不被抛入筹码撞倒）。
  **纪律**：物理只管好看——筹码**数量**永远是 sim 内确定性资源，物理落点/翻滚不回写游戏状态（render-only·专属种子·不碰确定性/回放）。
- **HUD（overlayHost 层 2D LayoutNode·透明区透出 3D 桌）**：座位卡（六席环桌·主角带 D 庄家标）+ 公共牌浮层（桌心）+
  底池数（顶带 POT）+ 行动条 + 摊牌屏 + 衣柜。UI 铁律=纯 LayoutNode 闭集控件·零手写 DOM。
- **摊牌屏（owner 2026-07-18 重设计·防 5~6 人 freeze）**：全屏模态。**定高卡**（不随人数增高）三段——
  ① 顶=**公共牌板**（5 张·金边突出·「看公共牌」）；② 中=**各家最优五张组合依次排开**（一行一家·左名+牌型、中最优 5 张牌、
  右分池；赢家金边+🏆 高亮·可**滚动**，人多也不撑破卡）；③ 底=**确认键钉底常驻**（「确认·继续下一手」·**永远在视口内可点**）。
  盖牌收池（无摊）行显「盖牌收池·无摊」。**旧版病根**：列高随人数长、按钮掉出 720 视口按不到=freeze——今按钮脱离滚动区钉底根治。
- **牌**：公共牌 = 桌心 2D 浮层牌面（陡俯视看清花色·真贴图 S6）；主角底牌 = 底部大图。
- 特效：筹码抛掷落桌物理（已接）；发牌/翻牌/胜者聚光=后续；声音：洗牌/发牌/筹码碰撞/翻牌/allin/胜利（走音频线·声音=数据）。
- **验收对账口径（供 GD-C 写验收剧本/浏览器目击）**：进桌 = 见大椭圆桌 + 无椅 + 桌面干净（围栏隐形）；下注 = 见 3D 筹码从座位飞入池心
  （随机散落·被隐形栏挡在台内不外溢）；**六席各有筹码堆靠自己桌缘**（主角堆更靠南边·赢家堆变高）；相机固定陡俯视不切不转；
  **摊牌（尤其 5~6 人）= 见公共牌板在顶 + 各家最优五张依次排开（可滚动）+「确认」键始终在视口内可点（不再 freeze）**。

## 10. 确定性声明
