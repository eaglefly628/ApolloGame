## 2. 一句话定位

**你是深渊之主，面对的是一整群不断涌入的 game-103 幸存者。**
他们各自独立成长（同一套武器/被动/进化/三选一），成长到「讨伐级」就会转头来拆你的深渊之心。
你的资源有限，每隔十几秒就要重做一次分诊：**割掉哪个、拖住哪个、收割哪个** ——
而英雄等级越高，杀他的赏金越厚。于是这不是清剿，是**牧养**。

## 3. ⭐ 乐趣在哪（owner 追问「这个游戏的乐趣所在」·GD 回答）

三层，由内到外：

### 第一层 · 分诊（Triage）——本作的主玩法
不是"打赢一场仗"，而是**在一堆同时生长的指数曲线里，决定砍哪一条**。
- 场上 6–8 个英雄，每个都是一条独立的成长曲线；你的收入是线性的。
- 最弱的那个杀起来最便宜，但他现在也最不构成威胁、赏金最薄；
- 已经养肥的那个赏金最厚，但也最难杀，而且再放任二十秒他就会来拆你的核心。
- **没有正确答案，只有当下最优。** 这个判断每十几秒重做一次——这是乐趣的发动机。

### 第二层 · 喂养的方向性（你决定谁变强）
怪物阵亡掉经验宝石，这是必然的税；但**税交给谁是你能选的**。
- 交战点设在谁附近，谁就吃到宝石；
- 「回收」残血怪 = 这笔税不交（宝石根本不掉）；
- 「食晶蛭」抢在英雄之前吞掉地上的宝石；
- 甚至可以**故意喂肥一个跑得慢、好收割的**，让他替你压制别人的成长空间。

这一层把「经验反噬」从惩罚变成了**工具**——是本作最有深度的地方。

### 第三层 · 收割时机（反向雪球）
英雄死时会把身上一部分成长**洒在地上**。
- 杀在你的地盘 → 食晶蛭吞掉，净赚；
- 杀在人堆里 → 你亲手把旁边那个喂成了下一个麻烦。

**所以"什么时候杀、在哪里杀"比"能不能杀"更重要。** 这正是 owner 说的"资源和时间"。

> 一句话概括乐趣：**你在牧养一群正在长大、并且想吃掉你的猎物。**
> 全杀光=没有赏金来源，饿死；放着不管=被讨伐波推平。玩的是那条中间的窄线。

## 4. GD 架构评判（该不该做 · 怎么做才对）

按宪法尺子逐条过：

| 判据 | 结论 |
|---|---|
| **能用现有 capability 表达？** | ✅ **极强命中**。本作 ≈ game-103 的**输入端对调**：英雄从 `input-capture` 驱动改为 `t2-behavior-tree` 驱动；刷怪从 `t2-spawn-director` 波表改为玩家实时指令。核心模拟层（移动/索敌/开火/命中/死亡/被动聚合/DoT/三选一）**与 game-103 完全共用**。详见 `capability-plan.md` §2 的角色对调表。 |
| **是否虚胖数据（表+游戏层自写解释器）？** | ⚠ 风险点=**新增的经济层**（痛苦汲取/赏金/回收/腐化领地）。已逐条映射到 `atoms/resource` + `t2-effect-apply` + `atoms/destroy` + `t2-group-count`，见 plan §3；**开工前必须过审**。 |
| **最弱 LLM 能否产出一样的数据？** | ✅ 内容层（怪物谱系/经济表/腐化层级/波次）= 纯 JSON。 |
| **"能出复杂的东西"（owner 价值序第一要素）** | ✅ 强命中。同一套模拟跑两个视角（103 正位 / 107 逆位）= 引擎复用度的最好证明。 |
| **该不该做（YAGNI 检查）** | ✅ 该做。**边际成本极低**（复用 103 已建的 `draft-offer`/`spawn-director`/全部 tier2-3），边际价值高（一套资产两个游戏、且互为对方的 AI 陪练）。 |

**评判结论：接受立项**，但有三条前置条件：

1. **capability-plan 必须先过 Lead 审**（焦点=经济层四件事的能力归属），过审前零游戏层代码。
2. **必须先解决 §5 的头号设计风险**（收割窗口），否则玩法只有前 3 分钟成立。
3. 一切随机走种子 PRNG，**禁裸 Math.random**（randomness.md 红线）。

## 5. 头号风险：收割窗口（**未解决 · 阻塞项**）

模拟器（`scripts/game107-balance-sim.mjs`）已经把结构验证到位，但也**证伪了一半的经济假设**：

- ✅ 已验证：龟缩必输、无差别进攻必输、只割最弱必输、只打最强必输，**分诊策略显著最优**（数据见 `balance-design.md` §5）。
- ❌ **未验证**：「养肥再收割」目前**做不到**。英雄一旦到 Lv5+（4–5 把武器、带进化），玩家侧现有的线性成长（裂隙收入 + 腐化科技 ×1.66）打不动他。
  模拟中策略 F（专等 Lv5+ 再收割）**一个都没杀掉**。

> **这意味着：赏金随等级暴涨的设计目前是一张无法兑现的支票。** 若不修，玩家的最优解会退化成"全在低级割掉"，牧养的乐趣（§3 第一层）不成立。

**GD 建议的修向（交 owner/Lead 裁）**：加一条**深渊科技树**——用「养分」（击杀赏金）买**永久**强化（怪物属性/新词条/裂隙能力），
让玩家侧也具备指数成长的可能。当前模拟里的 `techPerTier` 只是这条线的最粗占位。**S3 定稿前必须补齐并重跑模拟。**
