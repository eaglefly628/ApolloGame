## 0. 需求（owner 2026-06-28）
烘焙管线要**轻量、稳定、高效**。这三个词是硬约束，直接否决一部分做法。
- **轻量** = 我们自己的代码薄、依赖少；不背 GPU 路径追踪器、不背巨型二进制。
- **稳定** = **可复现**（同输入→同字节·能 review/缓存/回归），不吃显卡驱动差异。
- **高效** = 运行时成本≈0（只采样烘好的图/顶点色）；烘焙在**离线**、不在热路径。

## 1. 用尺子筛三条路
| 做法 | 轻量 | 稳定 | 高效 | 裁决 |
|---|---|---|---|---|
| 自研 GPU 路径追踪烘焙（three-gpu-pathtracer / SwiftShader 烘） | ❌ 代码重 | ❌ 跨驱动/软 GL 飘·难复现 | ❌ 软 GL 烘极慢 | **⛔ 回驳**（直接违反三条要求） |
| Blender 无头 Cycles（`blender --background bake.py`） | 🟡 脚本薄·Blender 二进制大 | ✅ 成熟高质量 | ✅ 运行时 0 | 🟡 高质量逃生口·重依赖 |
| **确定性 CPU AO 烘**（three `Raycaster` 半球采样·固定序列） | ✅ 纯 JS·零新重依赖 | ✅ 定序列→字节可复现 | ✅ 小静态场景秒级·运行时 0 | ✅ **推荐核心** |

## 2. 推荐设计：确定性 CPU「AO/遮蔽」烘焙作核心
低多边形卡通盒庭（Captain Toad 风）的「高级感」90% 来自**环境遮蔽(AO) + 软接触影 + 柔和天光**，不是全局光路径追踪 → **不需要重型 GI**，一个确定性 CPU AO 烘即可，天然满足轻量/稳定/高效。

- **烘什么**：`Raycaster` 对每顶点/每 lightmap 像素半球采样算遮蔽率（缝隙暗、开阔亮）+ 可选天空方向软天光。**固定低差异采样序列（无 `Math.random`）→ 输出字节可复现**（进回归）。
- **烘到哪**：
  - **顶点色 AO（首选·最轻）**：低模顶点够密时直接烘进顶点色，**完全不需 UV 展开**（省掉整条 xatlas 依赖）→ 最轻最稳。
  - **lightmap 贴图**（要细节时）：需 UV2 展开（`xatlas-wasm`）烘进一张小图。重一档·按需。
- **运行时消费**：`Model3D` 加 `vertexColors:true` 或 `lightMapKey` → 渲染器应用。运行时≈采样一张图。
- **离线产出**：固定资产字节，**不进 hash / 不碰 lockstep**（同任何 sprite）。

## 3. 数据契约（数据驱动·宣言对齐）
```
bake-manifest（数据·声明烘哪个蓝图/哪些灯静态/采样数/输出 key）
  → 薄烘焙脚本（scripts/bake-ao.mjs）
  → 烘好的资产（keyed·顶点色/lightmap）
  → 运行时 Model3D 消费（lightMapKey / vertexColors）
```
「最弱的 LLM 也能填这份 manifest」→ 过尺子，是数据接口不是自由代码。

## 4. 与动态日夜的关系：混合光照
烘**静态**部分（地台/方块/道具间固定 AO + 软接触影），**动态日夜太阳 + 角色保持实时**。
`Light3D` 加 `mode:'baked'|'realtime'` 给烘焙脚本读：baked 进烘焙、realtime 运行时算。静态省成本、动态保灵活。

## 5. 落地分期（每期都薄·可单独验收·待启）
1. **运行时消费先行**（最小·解锁一切）：`Model3D` 加 `lightMapKey` + `vertexColors` → 渲染器应用。不管谁烘的（Blender 或脚本）都能上屏。
2. **确定性 CPU AO 烘脚本**（`scripts/bake-ao.mjs`·顶点色版·零 UV 依赖）：核心轻量烘焙器·出回归。
3. （按需）lightmap 版（+xatlas UV2）；（按需）Blender 无头高质量档。

## 6. 回驳记录
- **⛔ 自研 GPU 路径追踪烘焙器**：违 owner「轻量/稳定/高效」三条（重、跨驱动飘、软 GL 慢）。不做。
- **🟡 Blender 无头 Cycles**：作高质量逃生口·不进轻量核心（重依赖·离线偶发用）。

## 7. 与数据驱动宣言的关系
烘焙=离线产资产；运行时只消费。全程顺现有 asset-key 管线，three 不泄进资产层，确定性零风险。
唯一的运行时改动（分期①的 `Model3D.lightMapKey/vertexColors`）是 render-only 字段（不进 hash）。
