# Game 113 · V4 策划对齐草案：第二爱好

> 状态：**S1 已获 owner 签核**（2026-09-30）。非游戏应用流程原型先行；游戏能力 S2 暂缓。本稿记录最新口述；与 v1–v3.2 冲突时以本稿为准，旧稿仅供追溯。
>
> 正式名称：**《雅趣・第二人生》**。它表达「人生的第二爱好」，不再使用「博古斋」。

## 项目愿景与定位

- **目标受众**：全球中老年群体、退休人士、自由职业者，以及重视小众文化的高净值兴趣爱好者。
- **核心愿景**：做一个现代银发族的精神桃花源。让用户以可承担的门槛，进入现实中因财力、精力或机会不足而未曾涉足的小众兴趣。
- **产品调性**：慢节奏、有尊严、文化感强。拒绝「打怪升级」「充值变强」和炫富式竞争；奖励的是技艺精进、知识获取、用心收藏与高质量的社交认同。

**设计裁决**：若一个功能只会催用户花钱、制造焦虑或展示财富，而不能帮助他发现兴趣、增长见识、照料收藏或获得真诚交流，就不应进入《雅趣・第二人生》。

## 一句话

面向中老年人的第二兴趣生活社区：从现实中有合法流通市场、能分品相的爱好中发现新门类，学习、收藏、展示、交流；在一个**封闭的游戏内市场**里买入、养护和交易虚拟藏品，并以轻度游戏获得成长材料。

它不是古玩 App，也不是炒股 App。它的气质应是：见多识广、温和有趣、愿意把生活重新玩起来。

## 三条核心循环

```text
发现兴趣 → 看细节、学知识 → 考级 / 完成成长 → 获得游戏内货币
      ↑                                              ↓
同好分享 ← 上传真藏、交流、掌眼 ← 收藏 / 养护 ← 市集买入、细看入仓
                                         ↑
                                  三消「擦擦亮」产出保养品
```

1. **兴趣循环**：每日从用户尚未入坑的门类里挑一项「今日推荐」，带用户不断开新坑。
2. **收藏循环**：市集买入虚拟藏品 → 待鉴 → 找门道 / 找瑕疵 → 入仓 → 养护升品级 → 在游戏内市场卖出或长期收藏。
3. **社交循环**：晒自己的真藏、进入兴趣圈、请教和掌眼、串门看别人的仓库。社交不是后置功能，而是首版产品体验的一部分。

## 藏品与分类准入

一门爱好只有同时满足以下条件才进入产品：

- 有合法、真实且持续存在的市场渠道；
- 物件可被品相或规格分级；
- 可找到可授权的实拍资料或由用户上传；
- 不涉及禁止或高风险的野生动物、濒危材料、管制物品交易。

首发展示以红酒、雪茄、机械表、文玩核桃、木工 / 榫卯、老爷车为主。前台按兴趣与体验分类；流通渠道、价位带、流动性属于市集筛选与后台准入，不应成为用户理解爱好的负担。

## 游戏内货币与行情

- 货币只在产品内使用，用来买卖**虚拟藏品**与游戏服务；不提现、不兑换实物、不做玩家间转账。
- 获得方式可包括：学习和考级、首次读懂知识、审核通过的优质真藏投稿、主动观看广告，以及待确认的充值。
- 真藏上传的奖励应基于内容通过审核、信息完整度与社区贡献，不按物件的现实估价自动发钱，避免造假和操纵激励。
- 行情按爱好细分板块日更，呈现为低频、克制的游戏内指数；界面固定标明「游戏内行情，仅供娱乐，不构成任何购买或投资建议」。
- 不用「升值保值」作为对外承诺。玩家拥有的是游戏中的收藏价值与成长乐趣，不是投资收益。

> 充值如进入首版，需单独完成上线地区、发行资质、虚拟货币、支付、未成年人保护、消费提示和日志留存的合规评审；它不应与随机抽取、现实收益或回收承诺绑定。

## 信息架构（App）

底部五项固定为：

```text
首页       发现       市集       仓库       同好
每日推荐   全部爱好   行情与在售  我的收藏   圈子与串门
```

- 顶栏头像进入「我」：证书、学识、货币明细、设置。
- 「擦擦亮」不单占一级导航，作为仓库的养护入口；这能为社交保留一个一级位置。
- 首页的主角是「今日推荐」而非仓库：每天推荐一个尚未关注的兴趣，配一个低门槛的「先看看」入口。

## 首屏：首页应该回答什么

1. **今天有什么值得认识？** —— 一张编辑感很强的「今日推荐」大卡，来自未入坑门类。
2. **今天有什么新鲜事？** —— 新上架、轻微行情变化、同好动态三条克制摘要。
3. **我下一步能做什么？** —— 继续待鉴、去市集看看、回应同好请教；只突出一个主行动。

网页版与 App 共用内容模型。网页用宽屏编辑式三栏呈现「今日推荐 / 市集温度 / 同好新鲜事」；App 将同一内容压缩成纵向卡片流，不做两个彼此割裂的产品。

## 视觉方向

从「粗糙 loft 仓库」升级为 **当代收藏杂志 + 私人藏品室**：

- 真实藏品照片是视觉中心；
- 大面积米白、深墨或暖灰，黄铜与酒红只作小面积提示；
- 标题使用克制衬线，正文和数字使用高可读无衬线；
- 行情是安静日线和文字说明，不是证券交易台；
- 材质只出现在边缘细节，不用仿古画框、密集木纹或过度中式装饰；
- 所有交互保留适老标准：大字、大按钮、高对比、明确文字状态。

## 页面出图与预审顺序

1. **首页**：App 版与 Web 版同时出，先定整体气质、今日推荐和信息密度。
2. **市集**：行情板块 → 在售藏品 → 买入确认。
3. **仓库与藏品详情**：待鉴区、档案、品相、养护和卖出。
4. **同好**：兴趣圈、晒真藏、掌眼、串门。
5. **游戏化**：细看找门道、知识卡、擦擦亮三消、养护结算。
6. **成长与账户**：考级、证书、货币获得、设置。

每一页先出静态视觉稿给 owner 预审；只在视觉语言和信息层级通过后，再扩展状态稿和交互实现。

## 实现方式裁决（owner 2026-09-30）

113 继续走 Apollo 的 S1–S8 生产流程并复用可用的空间/资产，但按产品形态划清边界：

| 部分 | 实现原则 |
|---|---|
| 非游戏 App/Web 页面 | 允许 113 独立 UI 代码与响应式布局，不强制用 Apollo LayoutNode 闭集；优先复用现有设计资源和数据结构。 |
| 游戏化玩法 | 细看、三消、知识/奖励等优先接 Apollo 已有 capability/组件；不能表达的能力先在 S2 实查并摆 A/B。 |
| 跨用户社交、用户上传、审核、广告和日更行情 | 属于外壳/服务端接口，不能误称为已有 Apollo 能力；原型可用明确标注的演示数据。 |

此为 **game113 专项授权**，不是全库规则修改。流程签核、测试与用户预审仍按阶段进行；静态图册本身不算可运行产品。
