# UI 设计需求单 · 雅趣：第二人生（game113）· 给 Claude Design · v3

生成时间：2026-09-28（v3，替换 v2；v1「博古斋」、v2「社交为主」均作废）· 起草：GD/PE-113
依据：[`concept-source.md`](./concept-source.md)（owner 原话）· [`brief.md`](./brief.md)（立项卡）· [`gameplay.md`](./gameplay.md)（**游戏元素与经济循环，本版主依据**）· [`hobby-catalog.md`](./hobby-catalog.md)（爱好图谱）· [`collectible-spec.md`](./collectible-spec.md)（数据规范）

**一句话**：老顽童的百宝仓库。从上百门真能买到的小众爱好里挑着入坑，点开真实照片找门道、学知识、考级挣「雅钱」；在市集用雅钱买藏品，看它跟着真实行情涨跌；用自己的藏品玩三消，消出保养品，把藏品养得更好、更值钱。

**平台**：手机竖屏。**画框 390×844（逻辑点）**，顶部安全区 47、底部 34；核心内容在 **360×640（9:16）** 内也必须完整可用。

## ⓪ 给设计师的五句话（最重要）

1. **这不是古玩 App，也不是炒股 App。** 是「有钱有闲的老顽童」的爱好大集合：红酒、雪茄、文玩核桃、机械表、老爷车、锦鲤、黑胶……气质是**好玩、见多识广、有点小得意**。
2. **照片是主角，而且是真实照片。** UI 不要挡照片，不要把照片包进复杂画框。
3. **它是一个游戏。** 有货币、有买卖、有考试、有三消。但节奏是**慢的**：没有倒计时、没有体力焦虑、没有红点轰炸。
4. **钱只用「雅钱」表示。** 行情、走势图要有，但**不要做成证券 App 的刺激感**：没有闪烁跳动的数字，没有「立即抢购」，周线而非分时线。
5. **用户是 55–75 岁的人。** 大字、大按钮、高对比、少手势。「年轻人觉得精致但老人看不清」的设计都算错。

## ① 硬约束（适老 · 每屏必守）

| 项 | 要求 |
|---|---|
| 字号 | 正文 ≥ 18pt；辅助说明 ≥ 15pt；标题 ≥ 24pt；**价格、余额等关键数字 ≥ 28pt** |
| 大字模式 | 全局字号 ×1.25；**S1、S4、S7、S14 各出一版大字模式** |
| 点击热区 | ≥ 56×56pt；相邻可点元素间距 ≥ 12pt；**三消棋子 ≥ 48pt**（7×7 棋盘在 390 宽内成立） |
| 对比度 | 正文 ≥ 7:1，大字 ≥ 4.5:1；状态不只靠颜色（加文字或图形） |
| 手势 | 只用：**单击 · 双指缩放 · 单指拖动**（三消的拖拽交换属于单指拖动；同时支持「点两下交换」）。缩放同时提供「＋ / － / 复位」按钮 |
| 主操作 | 每屏最多一个实心主按钮 |
| 文案 | 完整中文短句；图标一律配文字 |
| 返回 | 二级页左上角固定「‹ 返回」 |
| 节奏 | 不用倒计时、不用红点轰炸、不用「限时抢购」 |
| **涨跌颜色** | 按中国习惯**涨红跌绿**，且**必须同时有 ▲▼ 箭头和「涨 / 跌」文字**；涨跌红要与主按钮的砖红区分开（见 ⑥ 调色板） |
| **免责常驻** | 凡出现行情、走势、价格的页面，底部固定一行小字：「游戏内行情，仅供娱乐，不构成任何购买或投资建议。」 |

## ④ 逐屏规格

> 「控件」列是工程接线时映射的 ZeroCraft LayoutNode 闭集控件（Panel / Label / Button / Image / Card / Tabs / Modal / Drawer / VirtualList / ProgressBar / Badge / Tag / Avatar / Rating / Toggle / Slider / Segmented / Particles / LevelPath 等）。设计师照常画视觉，**不要发明闭集之外的交互形态**；拿不准就标注出来。
> 「play-field」= 引擎渲染的画面（照片、缩放、门道点、三消棋盘），画出观感即可。
> 「**走势图**」目前**不在**控件闭集里，请照常设计，工程侧会补这个控件（见文末备注）。

### 全局 · 顶栏与雅钱

- 顶栏右侧：方孔铜钱图标 + 余额（≥ 28pt，千分位），点开进雅钱明细。
- **雅钱入账动效**：金色小铜钱从来源处飞进顶栏余额，余额数字滚动（约 0.8 秒）。考级通过、卖出、首次读懂知识卡时出现。
- 雅钱图标：黄铜色方孔圆钱，简洁，16pt / 24pt / 48pt 三个尺寸。

### S5 · 知识卡

从下方升起的抽屉（Drawer），半屏，可上拉到 85%。
内容：类别标签（门道 / 鉴别 / 典故 / 行话）· 标题 · 正文（≥ 18pt，行距 1.6）· 可选真实局部照片 · 可选小考（2–3 个大按钮）· 奖励行「学识 +3 · ◎ +5（首次读懂）」· 来源「官方审校：××」· 主按钮「记住了」。
动作：`card.close` · `card.done` · `quiz.answer`。
语气：老伙计聊天。例：「阴皮多是脱青皮时处理不当留下的，一般盘不掉。挑核桃要翻过来掉过去看一圈。」

### S6 · 正式入仓

约 2 秒：照片缩小飞进仓库对应分区的格子，挂上黄铜吊牌（名字 + 品级 + 入仓日期），显示「正式入仓！核桃匣 4/12」。学识升级时额外一行「称号升级：懂行 → 行家」。按钮：「看看它」（`item.detail`，主）/ 「继续逛」（`collect.done`）。
风格：小得意、好玩，木箱盖合上的弹性 + 少量金色火花（Particles）。不要「恭喜获得」、彩带、金币雨。

```

│ │ [核][表][车][核][茶][表][核]   │ │  7×7 棋盘（play-field）
│ │ [茶][核][表][车][车][核][表]   │ │  每个棋子 = 你仓库里某件藏品的
```

| 元素 | 控件 | 动作 |
|---|---|---|

## ⑥ 风格锚 + 品味槽

**【老顽童的百宝仓库】**

- 关键词：`私人仓库 / loft · 杂而有序 · 砖墙铁架木箱 · 皮革与黄铜 · 手写吊牌 · 暖光 · 见多识广 · 有点得意的幽默感`
- **不是**：古玩店、博古架、新中式茶室、宫廷风、仿古画框；**也不是**证券 App、糖果消消乐。
- 中文提示词：有品位的私人仓库兼收藏室：裸露红砖墙，黑铁货架，旧木箱与皮革箱，黄铜吊牌与手写标签，酒窖木架、雪茄柜、表柜各占一角，温暖的工业吊灯光，杂而有序，见多识广的老绅士的游乐场，真实照片质感，无文字，无水印
- 英文提示词：tasteful private warehouse and collector's loft: exposed red brick walls, black iron shelving, vintage wooden crates and leather trunks, brass tags and handwritten labels, a wine rack, a cigar humidor and a watch cabinet each in its own corner, warm industrial pendant lighting, eclectic yet orderly, a worldly old gentleman's playground, photographic realism, no text, no watermark
- 调色板：

| 角色 | 色值 | 用途 |
|---|---|---|
| 仓库深灰 | `#22201E` | 细看页、三消棋盘背景 |
| 牛皮纸 | `#EFE4D0` | 卡片、面板底 |
| 旧砖红 | `#8C3B2E` | 唯一主按钮 |
| 皮革棕 | `#5A3A26` | 分区标题、导航底 |
| 黄铜 | `#B8924A` | 描边、吊牌、雅钱、证书、进度 |
| 墨字 | `#231F1B` | 牛皮纸上的正文（≥ 7:1） |
| **涨 · 朱红** | `#C8321E` | 行情上涨（配 ▲ 和「涨」字）；比主按钮更亮更正，避免与砖红混淆 |
