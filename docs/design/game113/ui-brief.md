# UI 设计需求单 · 雅趣：第二人生（game113）· 给 Claude Design · v2

生成时间：2026-09-28（v2，按 owner 修正重写；v1「博古斋」方向废弃）· 起草：GD/PE-113
依据：[`concept-source.md`](./concept-source.md)（owner 原文 + 修正口述）· [`brief.md`](./brief.md)（立项卡 v2）· [`hobby-catalog.md`](./hobby-catalog.md)（爱好全表）

**一句话**：老顽童的百宝仓库。从上百门小众爱好里挑感兴趣的入坑，每门爱好是一套**真实物件**的收藏；点开细看、找到门道，学识就涨；再把仓库晒给同好看。

**平台**：手机竖屏。**画框 390×844（逻辑点）**，顶部安全区 47、底部 34；核心内容在 **360×640（9:16）** 内也必须完整可用。

---

## ⓪ 给设计师的四句话（最重要）

1. **这不是古玩 App。** 是「有钱有闲的老顽童」的**爱好大集合**：红酒、雪茄、威士忌、机械表、普洱、老爷车、钓鱼、鸣虫……什么都有。气质是**好玩、见多识广、有点小得意**，不是庄重肃穆。
2. **照片是主角，而且是真实照片。** 每件藏品都是真实物件的高清实拍。UI 不要挡住照片，也不要把照片包进复杂的仿古画框。
3. **它是一个社区。** 同好之间晒藏品、点赞、串门、请教，是和「收藏」同等重要的一半。
4. **用户是 55–75 岁的人。** 大字、大按钮、高对比、少手势。任何「年轻人觉得精致但老人看不清」的设计都算错。

## ① 硬约束（适老 · 每屏必守）

| 项 | 要求 |
|---|---|
| 字号 | 正文 ≥ 18pt；辅助说明 ≥ 15pt；标题 ≥ 24pt；关键数字 ≥ 28pt |
| 大字模式 | 设置里一键把全局字号 ×1.25；**S1、S2、S4 各出一版大字模式**，证明不溢出、不截断 |
| 点击热区 | ≥ 56×56pt；相邻可点元素间距 ≥ 12pt |
| 对比度 | 正文 ≥ 7:1，大字 ≥ 4.5:1；状态不只靠颜色区分（加文字或图形） |
| 手势 | 只用三种：**单击 · 双指缩放 · 单指拖动**。不用长按、左滑、双击；缩放同时提供「＋ / － / 复位」按钮 |
| 主操作 | 每屏最多一个实心主按钮 |
| 文案 | 完整中文短句（「把它收进仓库」而非「收藏 ▶」）；图标一律配文字 |
| 返回 | 二级页左上角固定「‹ 返回」文字按钮 |
| 节奏 | 不用红点轰炸、不用倒计时 |

## ④ 逐屏规格

> 「控件」列是工程接线时要映射的 ZeroCraft LayoutNode 闭集控件（Panel / Label / Button / Image / Card / Tabs / Modal / Drawer / VirtualList / ProgressBar / Badge / Tag / Avatar / Rating / Toggle / Slider / Segmented / Particles 等）。设计师照常画视觉，**不要发明闭集之外的交互形态**（例如 3D 旋转货架、翻页书）；拿不准就标注出来。
> 「play-field」= 引擎渲染的画面（照片、缩放、门道点），不是 UI 控件，画出观感即可。

### S2 · 我的仓库

老顽童的私人仓库：**不是博古架**，是一间杂而有序的大仓库，每门爱好占一个区——酒窖一格、雪茄柜一格、表柜一格……

```

│  [照片][照片][照片][照片] ›      │     横向一排藏品缩略（真实照片、方形）

│                              │
│ ▌雪茄柜 · 雪茄  学识 Lv1「入门」 │
│  [照片][照片][空][空] ›          │
│                              │
│ ▌表柜 · 机械表 …                │
│                              │
│ ▌我的真藏（自己拍的）            │  ← 用户上传的真实藏品单独一区
│  [照片][照片] [＋ 晒一件我的]     │
```

|---|---|---|---|
| 标题 | Label + Button | 总件数、「晒一晒」（生成仓库长图分享） | `warehouse.share` |

### S4 · 细看（★核心 · 请最先出）

```
┌──────────────────────────────┐
│ ‹ 返回      拉菲古堡 1996       │  顶部半透明条，3 秒无操作淡出
│                              │
│      （全屏真实照片：酒瓶）       │  ← play-field：双指放大、单指拖动
│           ◌                  │  ← 门道点：默认隐藏；放大到附近
│      ◌          ◌             │     才以「呼吸光圈」浮现
│                              │
│  ┌────────────────┐           │
│  │ 门道 2/5 · 学识 +6 │           │  ← 发现进度
│  └────────────────┘           │
│ [－] [复位] [＋]    [ 收进仓库 ] │  ← 找齐前按钮为禁用态「还差 3 处门道」
└──────────────────────────────┘
```

| 元素 | 控件 | 内容 / 状态 | 动作 |
|---|---|---|---|
| 照片 | play-field | 真实照片，1× → 8×；局部可以切换更高清的特写照片 | 手势 |
| 门道点 | play-field（圆形热区 + 光圈） | 隐藏 / 浮现（呼吸光圈）/ 已读（小对勾） | `spot.open`（带门道点 id） |
| 缩放按钮 | Button ×3 | 放大 / 缩小 / 复位 | `zoom.in` / `zoom.out` / `zoom.reset` |
| 进度 | Badge + Label | 「门道 2/5 · 学识 +6」 | — |
| 找不到？ | Button（文字链） | 「给点提示」：让最近的一个门道点闪一下 | `spot.hint` |
| 收进仓库 | Button（主） | 未找齐 = 禁用 + 「还差 N 处门道」；找齐 = 可点 | `item.collect` |
| 同好评论 | Button（小，右上） | 「32 条同好说」→ 抽屉里是这件藏品下的评论和请教 | `item.comments` |

**需出状态**：整件 1× · 放大 3×（门道点浮现）· 放大 8×（特写：如酒标上的 Grand Cru Classé 字样、瓶口封签）· 全部找齐 · 大字模式。
**示例藏品**：请用**一瓶波尔多红酒**做主稿，另出一版**一支古巴雪茄**（门道点：茄标、茄衣颜色、茄帽）。
**观感**：背景近黑暖灰，照片居中「发光」；参考高端腕表官网的细节放大页。

### S5 · 知识卡

从下方升起的抽屉（Drawer），占屏高 55%，可上拉到 85%；照片在上方仍可见。

| 元素 | 控件 | 内容 / 状态 | 动作 |
|---|---|---|---|
| 容器 | Drawer + 显式「收起」按钮 | 半屏 / 展开 | `card.close` |
| 类别 | Tag | 门道 / 鉴别 / 典故 / 行话 | — |
| 标题 + 正文 | Label | 例：「瓶肩的酒液高度」——老酒看酒液降到哪儿，就知道保存得好不好…… 正文 ≥ 18pt，行距 1.6 | — |
| 配图 | Image | 真实局部照片或对比图（好 / 差），各带文字说明 | — |
| 小考（可选） | Button ×2–3 | 未答 / 答对（「行啊老哥」）/ 答错（给解释，不扣分） | `quiz.answer`（带选项序号） |
| 学识奖励 | Label | 「红酒学识 +3」，淡入，不弹窗 | — |
| 来源 | Label（小） | 「官方审校：×× 侍酒师」或「藏家自述：老王」 | — |
| 主按钮 | Button | 记住了 | `card.done` |

**文案语气**：老顽童之间聊天的口吻，懂行但不端着。例：「这瓶的门道在瓶肩——酒液降到这儿，说明它在谁家柜子里躺得不太舒服。」

### S6 · 收进仓库（收藏时刻）

短演出，约 2 秒：照片缩小，飞进一个仓库木箱或货架格子，贴上黄铜吊牌（藏品名 + 收藏日期），然后显示：

- 「收下了！红酒馆藏 10/12」
- 学识升级时额外一行：「红酒称号升级：懂行 → **行家**」
- 两个按钮：「晒给同好看」（`item.post`，主）、「继续逛」（`collect.done`）

**风格**：有点小得意、好玩，可以有轻微的木箱盖合上的弹性动画和少量金色火花（Particles）。**不要**「恭喜获得」、彩带、金币雨这类手游腔。

### S8 · 串门（P1）

别人的仓库，版式同 S2，顶部换成对方的名片：头像、昵称、「玩过 N 门」、最高称号、「关注 / 已是老伙计」按钮（`friend.follow`）。点对方的藏品进入 S4（在别人的藏品上找门道一样涨学识）。

### S9 · 晒我的真藏（P1）

三步，每步一屏，大按钮：

1. **拍或选照片**（`mine.photo`）——提示「光线亮一点，东西摆正」。
2. **点出门道**：在照片上点一下放一个门道点，为每个点写一句话（可语音输入）（`mine.spot_add` / `mine.spot_voice`）。至少 1 个点。
3. **归到哪门爱好 + 一句讲究**，然后「晒出去」（`mine.publish`）。

说明文字：「这是你的真东西，门道由你来讲，同好会看到『藏家自述』标签。」

### S10 · 我（P1）

- 名片：头像、昵称、**「玩过 N 门」**（老顽童的最大荣誉）。
- 各门学识列表：爱好名 + 等级条 + 称号。
- 称号墙：每门一枚「吊牌」，像行李牌一样挂着，未获得的是空钩子。
- 入口：老伙计、我的动态、设置。
