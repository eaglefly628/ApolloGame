# UI 设计需求单 · 雅趣：第二人生（game113）· 给 Claude Design

生成时间：2026-09-27 · 起草：GD/PE-113 · 依据：[`concept-source.md`](./concept-source.md)（owner 原文）+ [`brief.md`](./brief.md)（立项卡）

**一句话玩法**：在私人书房里凑近看、每天养，把生核桃盘出包浆、把残盏金缮复原；署名的藏品拿去雅集展出、以物易物，换来圈内声望。

**平台**：手机竖屏。**画框 390×844（逻辑点）**，顶部安全区 47、底部 34。所有屏的核心内容在 **360×640（9:16）** 内也必须完整可用（适配窄长和宽短两类机型）。

---

## ⓪ 给设计师的三句话（最重要）

1. **图是主角，UI 是展签。** 本作的核心资产是实拍级高清藏品图。UI 像博物馆的展签和展柜：安静、克制、退后，绝不遮住藏品。
2. **用户是 55–75 岁的人。** 大字、大按钮、高对比、少手势。任何一处「年轻人觉得精致但老人看不清」的设计都算错。
3. **慢和体面。** 没有红点轰炸、倒计时逼迫、闪烁促销。奖励时刻（包浆蜕变、盖印署名）要庄重，像「落款」，不要像「中奖」。

## ① 硬约束（适老·每屏必守）

| 项 | 要求 |
|---|---|
| 字号 | 正文 ≥ 18pt；次要说明 ≥ 15pt（仅限辅助信息）；标题 ≥ 24pt；关键数字 ≥ 28pt |
| 大字模式 | 设置里一键把全局字号 ×1.25，**每屏都要出一版大字模式缩略**，证明不溢出、不截断 |
| 点击热区 | ≥ 56×56pt；相邻可点元素间距 ≥ 12pt |
| 对比度 | 正文 ≥ 7:1，大字 ≥ 4.5:1；不单靠颜色区分状态（加文字或图形） |
| 手势 | 只用三种：**单击 · 双指缩放 · 单指拖动**。不设长按、左滑删除、双击等隐藏手势；缩放必须同时提供「＋ / － / 复位」按钮 |
| 主操作 | 每屏最多一个主按钮（实心），其余为次按钮（描边）或文字链 |
| 文案 | 完整中文短句（「今天给它盘一盘」而非「盘玩 ▶」）；图标一律配文字 |
| 返回 | 每个二级页左上角固定「‹ 返回」文字按钮，位置全局一致 |
| 节奏 | 不用倒计时数字制造焦虑，改用「约明早可再养护」这类自然语言 |

- **底部导航**四项：书房 / 图鉴 / 集市 / 雅集。「我的」放在顶栏头像。

- **精力**用 5 颗「墨点」或一炷香表示，不显示数字倒计时；点开 = S14 说明。

## ④ 逐屏规格

> 「控件」列写的是工程接线时要映射的 ZeroCraft LayoutNode 闭集控件（Panel / Label / Button / Image / Card / Tabs / Modal / Drawer / VirtualList / ProgressBar / Badge / Tag / Avatar / Rating / Toggle / Slider / Segmented / Particles 等）。设计师照常画视觉，**不要发明闭集之外的交互形态**（例如翻页书卷、3D 旋转展柜）。拿不准就标注出来，由我们来判断。
> 「play-field」表示那一块是引擎渲染的画面（高清藏品图、缩放、热点），不是 UI 控件，设计稿画出观感即可。

| 元素 | 控件 | 内容 / 状态 | 动作 |
|---|---|---|---|
| 顶栏头像 | Avatar + Label | 玩家名、当前头衔 | `nav.profile` |
| 精力 | Panel + Image ×5 | 满 / 部分 / 空三态 | `energy.info` |

| 博古架 | play-field 背景（木格）+ Card 网格 | 每格：藏品图、名牌、状态标签（生涩 / 渐入 / 包浆 / 极品）；空格 = 虚线框 +「添一件」 | 点藏品 `item.open`；点空格 `nav.codex` |
| 底部导航 | Tabs | 四项 | `nav.study` / `nav.codex` / `nav.market` / `nav.salon` |

**需出状态**：默认 · 新手空书房（只有 1 件、其余空格）· 书架满 · 大字模式。

### S2 · 把玩台（★核心·请最先出）

```
┌──────────────────────────────┐
│ ‹ 返回        狮子头核桃 · 包浆中 │  顶部半透明条，可自动隐去
│                              │
│                              │
│      （全屏高清实拍藏品图）      │  ← play-field：双指缩放、单指拖动
│         ◌        ◌            │  ← 热点：默认隐藏；放大到对应区域后
│              ◌                │     以「呼吸微光圈」浮现，点开 = S3
│                              │
│  ┌──────────────┐             │
│  │ 已发现 3/7 处 │             │  ← 热点发现进度
│  └──────────────┘             │
│ [－] [复位] [＋]   [对比] [养护] │  底部工具栏，大按钮
└──────────────────────────────┘
```

| 元素 | 控件 | 内容 / 状态 | 动作 |
|---|---|---|---|
| 藏品图 | play-field | 高清图；缩放 1× → 8×；放大到约 4× 以上时，特定区域切换为**微距特写图**（淡入） | 手势，无 action |
| 热点 | play-field（圆形热区 + 微光圈） | 未发现（缩放不足时不显示）· 可见（呼吸光圈）· 已读（小印章 ✓） | `hotspot.open`（带热点 id） |
| 缩放按钮 | Button ×3 | 放大 / 缩小 / 复位 | `zoom.in` / `zoom.out` / `zoom.reset` |
| 发现进度 | Badge / Label | 「已发现 3/7 处」 | — |
| 前后对比 | Button | 打开后图上出现一条竖向分割线，左侧为初始状态、右侧为当前状态，可拖动 | `compare.toggle` |
| 去养护 | Button（主） | 今日已养护时变为「明早再来」（禁用态） | `care.open` |
| 顶部标题条 | Panel + Label | 名称、状态；无操作 3 秒后淡出，点图任意处唤回 | `nav.back` |

**需出状态**：1×（整件）· 放大 3×（热点浮现）· 放大 8×（微距特写，如核桃纹路里的包浆、建盏兔毫）· 对比模式 · 全部热点已读。
**观感参考**：博物馆数字藏品页、高端腕表官网的细节放大页。背景用近黑暖灰，让藏品「发光」。

### S5 · 蜕变与落款（奖励时刻）

整屏演出，分三拍：

1. **蜕变**：旧状态图缓慢淡出（约 2 秒），新状态图显现，背景的暖光轻微亮起。文字：「三个月的光阴，它终于温润了。」
2. **落款**：画面下方出现一方印章，玩家点击「落款」，朱红印泥盖在藏品卡的一角，伴随纸面轻压的质感。
3. **入册**：生成一张藏品证书卡（即 S6 的缩略版），附两个按钮：「放回博古架」「分享给老朋友」。

| 元素 | 控件 | 动作 |
|---|---|---|
| 前后状态图 | play-field（透明度渐变） | — |
| 旁白 | Label（大字，逐句淡入） | — |
| 落款按钮 | Button（主·印章造型） | `seal.stamp` |
| 金粉 / 墨晕粒子 | Particles（克制，少量） | — |
| 放回博古架 | Button（主） | `seal.done` |
| 分享 | Button（次） | `item.share` |

**风格要求**：庄重，像书画落款；**禁止**彩带、金币雨、「恭喜获得」字样。

### S8 · 领域图鉴（P1）

- 顶部 Tabs：文玩杂项 / 硬核手作 / 高阶品鉴 / 精密器械 / 活体微观。
- 每个领域一张大 Card：领域代表图、名称、我的「鉴赏力 Lv / 熟练度 Lv」、已收藏件数；未开放领域显示「敬请期待」（灰，但仍然好看）。
- 点击进入领域页：该领域可获得的初级藏品列表（Card 网格）+ 「启蒙课」入口（一组知识卡）。
- 动作：`codex.tab` · `codex.domain` · `codex.acquire`（带藏品 id）· `codex.lesson`。

### S9 · 集市·以物易物（P1）

- 帖子列表（VirtualList），每帖：「我出 [藏品卡] ⇄ 我想要 [描述或藏品卡]」+ 发帖人名、头衔 + 「看看」按钮。
- 顶部「发一帖」主按钮 → 发帖流程三步：选我的藏品 → 写想换什么（候选标签 + 一句话）→ 确认。
- 出价页：选择用哪件藏品去换，附一句留言；**没有金币输入框**。
- 动作：`market.post` · `market.view` · `market.offer` · `market.accept` · `market.decline`。

### S10 · 雅集·博览会（P1）

- 本期主题横幅（如「秋·核桃雅集」）+ 我的展位（最多 3 件）+ 他人展位列表。
- 他人展位：藏品大图、藏家、一句题跋、「赏」（点赞）按钮（点后变成「已赏」+ 数字）。
- 同好俱乐部入口：俱乐部卡片（鸣虫协会、威士忌品鉴会……）→ 问答列表。
- 动作：`salon.exhibit` · `salon.like` · `salon.view` · `club.open` · `club.answer`。

### S11 · 我的·声望与头衔（P1）

- 声望（大数字）+ 当前头衔 + 下一头衔条件。
- 各领域鉴赏力 / 熟练度一览（横条）。
- 徒弟与师承、展出记录、成就印章墙。
- 动作：`profile.title` · `profile.apprentice`。

### S12 · 求助：掌眼 / 代工（P2）

- 两个入口大卡：「请人掌眼（鉴真伪）」「请人代工（修复）」。
- 悬赏帖：选藏品 + 描述 + 酬谢（精力点或藏品）。
- 专家列表：头像、头衔、擅长领域、好评印章数。
- 「求助老专家」可以用激励视频代替酬谢，按钮文案须如实写「看一段广告，请老专家看一眼」。
- 动作：`help.appraise` · `help.commission` · `help.pick_expert` · `help.ad`。

### S13 · 首次进入（P2）

- 邀请码输入（大号数字键盘，6 位，每格 ≥ 48pt）→ 「这是你的书房」三步引导（放大看 → 点热点 → 做一次养护）。
- 动作：`invite.submit` · `onboard.next` · `onboard.skip`。

### S14 · 精力说明 / 会员（P2）

- 精力规则一句话 +「明早 6 点恢复满」。
- 会员权益列表（书房装潢、离线管家、展位特效）。**不得出现**「加速包浆」「立即完成」类权益。
- 关闭按钮醒目，不设「再想想」这类诱导文案。
- 动作：`energy.close` · `vip.view` · `vip.subscribe`。

## ⑦ 输出契约（固定模板·不可删改）
