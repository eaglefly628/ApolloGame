## 0. 出发点

现在的「看细节 → 读知识卡 → 收进仓库」更像一本好看的图鉴，还不够像游戏。缺的是三样东西：

1. **知识没有用处**：学了「阴皮」，除了学识 +4，什么都没变。
2. **没有判断和风险**：没有「我觉得是 A，结果是 B」的时刻，也就没有惊喜和得意。
3. **没有明天再来的理由**。

**原则**：所有游戏元素只能从「每门爱好都已有的数据」长出来：真实照片、门道点、知识卡、品相维度、品级、雅钱、规格字段。**每个游戏元素 = 一个通用动作 × 全部爱好**。加一门爱好，所有玩法自动可玩，不写代码。

## 1. 候选游戏元素

| # | 元素 | 玩起来是什么样 | 吃哪些现有数据 | 要补的数据 | 推荐 |
|---|---|---|---|---|---|
| ① | **寻门道**（已有） | 放大照片，找到隐藏的门道点，读知识卡 | 门道点、知识卡 | 无 | ✅ 保留，作为「学」 |
| ② | **估品** | 给一件没见过的藏品按品相维度打分（配对？瑕疵？包浆？），然后揭晓官方品级，看你眼力准不准 | 品相维度、品级、照片 | 无 | ⭐ 核心 |
| ③ | **捡漏**（淘货摊） | 每天几个 NPC 摊主摆出几件东西、标着雅钱价。你凭眼力判断哪件标低了，买下来带回去细看，揭晓真实品级：捡到漏了，身价大涨；打眼了，亏一点 | 品级、雅钱、照片 | 摊主名单、摊位规则（全局一张表） | ⭐ 核心 |
| ④ | **天天鉴宝**（关卡） | 像电视上的鉴宝节目：每关 5 件跨爱好的藏品，逐件估品，按眼力打星，一关一关往后走 | 同 ② | 关卡表（由规则自动生成） | ⭐ 核心 |
| ⑤ | **老伙计上门** | NPC 老伙计拿着东西来找你：「帮我看看这对核桃」。你估品，他按你说的去卖或收，过几天回来告诉你结果，谢你或怪你 | 同 ② | NPC 名单（性格、台词、偏好的爱好） | ✅ 推荐（社交的单机替身） |
| ⑥ | **比一比** | 两件同门藏品并排，猜哪件品级高 | 品级 | 无 | ✅ 轻量小游戏 |
| ⑦ | **凑套系** | 集齐「波尔多五大名庄」「四大名核」这类套系，有额外奖励 | 藏品 | 每门爱好 0–3 个套系 | ✅ 推荐 |
| ⑧ | 仓库陈列 | 自己摆柜子、挂吊牌 | —— | 陈列物件 | ⏸ 以后 |
| ⑨ | 养（时间变化） | 盘核桃、醇化雪茄 | —— | 多状态照片 | ⏸ 以后（预留模块） |

## 2. 推荐的 v1 核心循环：眼力飞轮

```
        学（寻门道 ①）
        读懂了「阴皮」「液位」「号码匹配」……
              │
              ▼  学过的门道，在估品时变成提示
        估（估品 ② / 天天鉴宝 ④ / 老伙计上门 ⑤）
        估得准 → 眼力涨、赚雅钱
              │
              ▼
        淘（捡漏 ③）
        用雅钱在摊上买，眼力好才捡得到漏
              │
              ▼
        藏（仓库 + 凑套系 ⑦）
        买回来的东西要找齐门道才算真正收进仓库 → 又回到「学」
```

**关键设计：让知识变成力量。**
- 估品时，你**学过的门道**会在对应维度旁出现提示。例如学过「阴皮」后，估核桃瑕疵时会提醒「注意右边那颗侧面」。
- 没学过的，只能凭感觉。
- 所以「读知识卡」不再只是涨个数字，而是**让你下一次估得更准、捡漏更稳**。这是把图鉴变成游戏的那一步。

**明天再来的理由**：摊位每天换货，天天鉴宝每天一关，老伙计隔几天回来报结果。全部来自已有藏品库，按日期作为种子洗牌，**不需要额外内容**。

## 3. 与已定规则的衔接

| 已定规则 | 衔接方式 |
|---|---|
| 「看懂一件才收一件」 | 捡漏买到的东西先进仓库的「**待鉴区**」，找齐门道才算正式收藏、计入身价。规则保留，捡漏只是多了一个来源 |
| 雅钱不可消费（为防社交诈骗而定） | 🟡 **需要 owner 确认**：单机模式下，雅钱可以在 **NPC 摊位**上花，但依旧**不能充值、提现、转账、玩家之间交易**。没有外部流通，就没有诈骗和合规问题 |
| 不做赌博 | 捡漏**不是盲盒**：东西明摆着、价格明标着，隐藏的只有「官方品级」，靠眼力判断，是技能不是运气。不卖抽奖、不卖开箱 |
| 适老 | 估品和鉴宝**没有倒计时**；打眼只亏游戏内雅钱，而且有「今日保底」，不会亏到没法玩 |
| 真实图片 | 所有玩法都用真实照片，不需要额外美术 |

## 4. 数据增量（都很小，都是全局表或每门几行）

| 数据 | 放哪 | 例子 |
|---|---|---|
| NPC 名单 | 全局一张表 | `{ id: "lao-zhang", name: "老张", persona: "嘴硬心软的退休钳工", likes: ["walnut", "classic-car"], lines: {...} }` |
| 摊位规则 | 全局一张表 | 每天几个摊、每摊几件、标价 = 雅钱 × 随机系数（0.5–1.6，种子决定）、保底规则 |
| 套系 | 每门爱好 0–3 条 | `{ id: "five-firsts", name: "五大名庄", items: [...], xp: 30 }` |
| 门道 → 估品提示 | 每个门道模板一句 | 在已有 `spotTypes` 上加 `appraiseHint`（学过才显示） |
| 眼力档位 | 全局 | 估品命中几个维度给几颗星 |

全部可以由现有的 AI 量产流程产出，校验器扩几条规则即可。
