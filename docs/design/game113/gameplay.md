# Game 113 · 游戏元素与经济循环 v2

> owner 2026-09-28：社交往后放，先做好产品本身；要好好考虑怎么把游戏元素引入进去。随后 owner 给出四条主线（原话存 `concept-source.md`）：
> 1. 有一个系统内的**私有虚拟货币**，用于收藏品的流通和购买；
> 2. 一个**价格系统**：每样东西的价格跟着网上真实行情变化，有**走势图**，买入后能看到它的走势；
> 3. **知识能换货币**：懂得越多、通过这一门的**考试**就能得到货币；
> 4. 需要一个**玩法**：点开大图找细节、**找不同 / 找瑕疵**，或者用自己的藏品玩**三消 / 连连看**，消出**保养品**。
>
> 本页把四条接成一个循环，并逐条给出评判与落地方式。状态：🟡 待 owner 确认 §7 几个问题后出 S2 能力计划，开工 v1。

## 0. 总原则（不变）

每个玩法 = **一个通用动作 × 全部爱好**，只吃每门爱好已有的数据（真实照片、门道点、知识卡、品相维度、品级、雅钱）。加一门爱好，所有玩法自动可玩，不写代码。

## 1. 总循环

```
      ┌──────────── 学 ─────────────┐
      │ 细看大图：找门道 / 找瑕疵 / 找不同 │
      │ 读知识卡 → 学识涨               │
      └──────────────┬──────────────┘
                     ▼
      ┌──────────── 考 ─────────────┐
      │ 这门爱好的考级（初 / 中 / 高）     │  知识 → 雅钱（owner 第 3 条）
      │ 通过 → 雅钱 + 证书称号            │
      └──────────────┬──────────────┘
                     ▼
      ┌──────────── 买 ─────────────┐
      │ 市集：按行情价用雅钱买藏品         │  私有货币流通（owner 第 1 条）
      │ 买回先进「待鉴区」，找齐门道才入仓   │
      └──────────────┬──────────────┘
                     ▼
      ┌──────────── 养 ─────────────┐
      │ 三消「擦擦亮」：用自己藏品的图消除   │  玩法（owner 第 4 条）
      │ → 产出保养品（核桃刷、麂皮布、保湿包…）│
      │ → 用在藏品上，提升包浆 / 成色 → 品级升 │
      └──────────────┬──────────────┘
                     ▼
      ┌──────────── 看行情 ───────────┐
      │ 每件藏品的雅钱价跟真实行情走        │  价格系统 + 走势图（owner 第 2 条）
      │ 持有的东西显示买入价、现价、走势图    │
      │ 想卖就按行情价卖回市集             │
      └──────────────┬──────────────┘
                     └──▶ 雅钱再去买、去考、去学……
```

**为什么这个循环成立**：学 → 考 → 挣钱，是「知识变现」；买 → 养 → 升品级 → 值更多钱，是「亲手养出来的价值」；看行情，是「持有的乐趣」。三条路都回到雅钱，雅钱又回到买更多藏品、开更多爱好。**鼓励学习就体现在：学得越多，考得越高，挣得越多，看得越准。**

## 2. 雅钱：私有货币（owner 第 1 条）

| 项 | 设计 |
|---|---|
| 来源（入口） | 考级奖励（主要）· 首次读懂一张知识卡（少量）· 新手礼 · 卖出藏品 |
| 去处（出口） | 市集买藏品 · 卖出手续费（例如 5%，防止来回倒买倒卖刷钱）· 开新爱好馆的「入坑礼包」（可选） |
| 保养品 | 只从三消产出，**不能用雅钱买**（保证「养」必须亲手玩出来） |
| 硬规则（🟡 建议定死） | **不能提现、不能玩家之间转账**；是否能用人民币购买雅钱见 §7 问题 3 |

**与之前定的冲突已解决**：之前为防社交诈骗定了「雅钱不可消费」，owner 现在明确雅钱要用于流通和购买，改为：**可以在系统市集里买卖，但不能提现、不能玩家之间转账**。诈骗和合规风险主要来自这两条，守住就行。

## 3. 价格系统与走势图（owner 第 2 条）

### 3.1 评判

- 方向对：真实行情让藏品有「活的价值」，走势图是很强的持有乐趣。
- 但「**实时到网上抓对应的东西**」有两处要改：
  1. **不能按单件抓**：玩家手里那对核桃在网上找不到一模一样的，单件没有价格。要按「**行情板块**」算，例如「文玩核桃 · 狮子头 · 精品」。一个板块里有很多同类挂价，取中位数才稳定。
  2. **不能爬虫抓，也不用实时**：爬淘宝、咸鱼违反平台协议，国内已有判例（见 `ai-pipeline.md` §2.5）。收藏品行情本来就是按周、按月变的，**周更足够**，还能避免走势图变成分钟级的「炒股」刺激。

### 3.2 做法

```
藏品现价（雅钱）= 该品级的基准雅钱（grading.values） × 所属板块的行情指数

行情指数：以开馆那周 = 1.00；之后每周更新一次
          数据来源（按优先级）：
            ① 有授权的开放接口 / 公开指数（如葡萄酒有 Liv-ex 这类行业指数，电商有联盟开放接口）
            ② 拍卖行公开成交结果
            ③ 运营 + AI 辅助：每周人工抽样公开挂价、取中位数（只取一个数，不搬运页面内容）
          压缩：指数周涨跌幅封顶（例如 ±10%），避免真实市场的异常波动直接砸到玩家
```

- **走势图**：每个板块一条周线；持有的藏品显示「买入价 · 现价 · 盈亏 · 走势图」，买入那一周在图上打点。
- 板块划分数据：每门爱好的 `market.segments`（按品级，或按品种 + 品级）。
- 每周的指数是一份**数据文件**，由外壳作为输入交给游戏逻辑，游戏逻辑本身仍然确定、可重放。
- **界面固定提示**：「游戏内行情，仅供娱乐，不构成任何购买或投资建议。」面向中老年，这句必须常驻。

## 4. 知识换货币：考级（owner 第 3 条）

| 项 | 设计 |
|---|---|
| 题库 | 每门爱好的知识卡小考题（`quiz`）自动组卷；AI 量产流程已经在出题，只需把每张卡的出题比例提高 |
| 考级 | 每门三级：**初级**（学识到「懂行」可报考）· **中级**（「行家」）· **高级**（最高称号）。每级 10 题，答对 8 题通过 |
| 奖励 | 通过给雅钱（初 < 中 < 高）+ 一张「证书」（该爱好的称号，挂在名片上） |
| 防刷 | 每级奖励只发一次；没通过第二天才能再考；题目从题库随机抽（种子决定，可重放） |
| 适老 | 不计时；答错立刻给解释；题目配真实照片 |

## 5. 玩法（owner 第 4 条）

### 5.1 找门道 · 找瑕疵 · 找不同：同一个玩法的三种数据

三者都是「在真实照片上找到对的地方点下去」，**用同一个解释器**，区别只在数据：

| 模式 | 数据 | 状态 |
|---|---|---|
| 找门道 | 门道点（已有） | ✅ 已有 |
| 找瑕疵 | 门道点里 `kind: authenticity` 的那些（阴皮、锈、霉斑、冲线）单独成关：「这件有 3 处毛病，找出来」 | ✅ 现有数据即可，只加一个出题方式 |
| 找不同 | 两张**真实照片**并排：真品与仿品、同一件东西养护前后、原厂件与复刻件。在第二张图上标出不同之处 | 🟡 需要成对照片（数据结构早已预留 `compare` 图片角色）。**不做 P 图造假的「不同」**，保持真实照片原则 |

### 5.2 三消「擦擦亮」：推荐三消，不推荐连连看

| | 三消 | 连连看 |
|---|---|---|
| 引擎 | ✅ **现成**：`t3-match3-board`（交换、连锁、特殊块、格层、按颜色**产出材料**）+ `t2-match3-drag-swap`（竖屏拖拽） | ❌ 没有，要新做一个「两格之间不超过两个拐弯的连线」规则 |
| 老人熟悉度 | 很高（开心消消乐） | 很高 |
| 结论 | ✅ **推荐**：零引擎开发 | 以后如需要再作为通用能力下沉 |

**玩法设计**：

- **棋子 = 你仓库里藏品的真实照片缩略图**（owner：「把你所有藏品消一消」）。每种颜色对应一门你入坑的爱好。
- **消除产出保养品**：消核桃的块 → 核桃刷；消雪茄 → 保湿包；消手表 → 擦表布……按爱好自动对应（每门爱好在数据里定义 1–3 种保养品）。
- **保养品用在藏品上**：提升藏品某个「可养」的品相维度一档（核桃的包浆从「生核」到「初上色」，相机的成色……）。品相维度升了，**品级按规则重算**，雅钱价跟着涨。
- 每件藏品每天最多养一次，养到头就封顶。这让「包浆靠时间养」的味道保留下来，但不用真的等几个月。
- 不计时关卡、无体力惩罚；每天有免费局数，适老。

### 5.3 估品、天天鉴宝、捡漏、老伙计上门（v1 方案里的其他元素）

保留在菜单里，排到 v1.1：它们都复用品相维度，数据已经齐了，和上面的循环也兼容（捡漏 = 市集里某件标价低于行情）。

## 6. 数据与引擎影响（S2 会逐条实查）

| 需要 | 数据增量 | 引擎 |
|---|---|---|
| 雅钱余额 | —— | `f1-resource` ✅ |
| 市集买卖 | 全局手续费率 | `t2-craft-recipe`（扣雅钱 → 得藏品）✅ |
| 行情指数 + 走势图 | `market.segments` + 每周指数数据文件 | ⚠ 每周数据作为外壳输入（与「每天」同一个缺口）· ⚠ **UI 没有走势图控件**（缺口，报 PUI） |
| 考级 | 每门三级的门槛与奖励（全局默认 + 可覆盖） | `t3-dialogue` 可做选择题；组卷抽题用种子随机 ✅ |
| 三消擦擦亮 | 每门爱好的保养品 1–3 种 | `t3-match3-board` + `t2-match3-drag-swap` ✅ |
| 保养提升品相 | 字段标 `careable: true` | ⚠ 品级要从「编辑手填」改为「按品相维度规则计算」（校验器里现成的估算规则转正）；可能需要一个通用的「阈值表」能力，顺带也解决学识称号 |
| 每天一次 / 每周行情 | —— | ⚠ 游戏逻辑不读真实时钟，要由外壳传入「今天是第几天」，**这个缺口绕不开**，S2 摆 A/B |
| 找不同 | 成对的真实照片 | 同找门道解释器 ✅ |
| 双指缩放 | —— | ⚠ 已知缺口 |

1. **v1 范围**，我建议：找门道 / 找瑕疵 + 考级换雅钱 + 市集买卖 + 行情走势（周更）+ 三消擦擦亮 + 养护升品级。找不同、估品、捡漏、天天鉴宝、老伙计放 v1.1。
2. **三消还是连连看**：我推荐三消（引擎现成，零开发）。
3. **雅钱能不能用人民币买？**
   - 不能（🟡 我推荐）：雅钱只能靠学、考、养、卖挣。「知识换钱」的设定最纯粹，也彻底避开「充值 + 行情涨跌 = 类赌博」的风险。VIP 只卖外观和便利。
   - 能：多一条收入，但「花真钱买虚拟币、再看它涨跌」对中老年用户有投机诱导的风险，上架审核也会更严。**无论哪种，都坚持不能提现、不能玩家间转账。**
4. **行情数据来源**：先用「每周运营 + AI 辅助人工抽样取中位数」，有授权接口的品类（如葡萄酒指数）再逐步接入。同意吗？
