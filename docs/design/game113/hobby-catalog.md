# Game 113 · 全球小众爱好全景图谱（v2 · 按 owner 五大类归档）

> **分类轴（🟢 owner 2026-09-28 定）**：按玩家在其中**投入的核心资源**（时间、技艺、财力、审美）划分大类。
> 本表 = 爱好广场（首页）的全部入口：每一项爱好 = 一套收藏；入坑后在「我的仓库」里占一个区，里面是这门爱好的**真实物件照片**。
> 机读版：[`data/categories.json`](./data/categories.json)（大类定义与基础字段）。每门爱好的数据格式见 [`collectible-spec.md`](./collectible-spec.md)。

## 五大类总览

| # | 大类（id） | 核心资源 | 乐趣在哪 | 未来通用玩法模块（首期都不开） |
|---|---|---|---|---|
| 一 | 岁月沉淀与高阶消耗（`aging`） | 时间 | 时间的复利 + 环境参数控制，最后品鉴风味 | `care` 养：时间 + 温湿度 → 状态变化 |
| 二 | 精密机械与岁月修复（`mechanics`） | 技艺 | 极客精神与秩序感：拆解、清洁、重构 | `process` 工序：按步骤拆、洗、修、装 |
| 三 | 极致手作与器物延龄（`craft`） | 技艺 | 手艺与残缺美：让物件获得第二次生命 | `process` 工序（与二共用） |
| 四 | 微观生态与活体繁育（`living`） | 时间 | 扮演造物主：长周期选育、搭生态 | `breed` 繁育：血统、性状、生态参数 |
| 五 | 视听玄学与异类收藏（`sensory`） | 审美 | 感官辨识力 + 对历史碎片的极致追求 | `grade` 品相评级：版别、品相打分 |
| 六 | 身手与博弈（`pursuits`）· **🟡 待 owner 定** | 财力 + 体力 | 五大类装不下的：高尔夫、钓鱼、马术、帆船、围棋、桥牌…… | 暂无 |

**关键发现**：owner 的五大类恰好对应**四个通用玩法模块**（养 / 工序 / 繁育 / 评级）。所以以后要给某门爱好加深玩法时，不需要为它单独设计，**同一大类下的爱好共用同一个模块**，只填各自的参数数据。首期所有爱好只做「看细节 + 收藏」。

- 知识卡禁写健康功效（「普洱降三高」「红酒软化血管」之类），校验器会拦。
