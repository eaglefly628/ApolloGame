# Game 113 · 小众爱好全表（仓库货架清单 v1）

> owner 2026-09-28：「先把人类这种小众爱好都列出来」。本表 = **爱好广场（首页）的全部入口**：每一项爱好 = 一套收藏；玩家入坑后，它在「我的仓库」里占一个区，里面是这门爱好的**真实物件实拍图**。
> 玩法对所有爱好**通用**（看图 → 找点 → 涨学识和鉴赏力，见 `brief.md` §3），所以加一门爱好 = 加一份数据（照片 + 热点 + 知识文案），**不需要为它单独设计玩法**。

| 标记 | 含义 |
|---|---|
| ⭐ | 爱好广场首屏推荐位（owner 点名红酒、雪茄 + 我补的同调性几项） |
| 🕰 | 「会随时间变化」的爱好，**后续可选**开通用的「养」（陈放 / 包浆 / 醇化 / 生长）。**首期不做**，首期所有爱好都只有「收藏 + 看细节学知识」 |
| 📷 | 实拍图来源难度：**易** = 博物馆开放图库 / 公有领域大量可用 · **中** = 需要合作藏家或商家授权 · **难** = 需要自己实拍或专门拍摄 |
| ⚠ | 合规敏感，首期不做或需另议（濒危材料、赌博、狩猎、烟酒广告法等） |

## 首屏建议（爱好广场第一眼的推荐位）

owner 点名红酒、雪茄。我按「老顽童 + 有钱 + 一眼就懂」补齐成**六个区**：

| 区 | 爱好 | 为什么放首屏 |
|---|---|---|
| 酒窖 | 红酒（波尔多） | owner 点名；酒标就是天然的「找点」题 |
| 雪茄房 | 古巴雪茄 | owner 点名；雪茄柜、湿度计很有画面感 |
| 威士忌吧台 | 单一麦芽威士忌 | 与红酒、雪茄同属「杯中物」，老登三件套 |
| 表柜 | 机械表 | 放大看机芯游丝，最能体现「凑近看」的惊艳 |
| 茶仓 | 普洱茶 | 中国用户最有共鸣，茶饼陈化最直观 |
| 车库 | 老爷车 | 仓库的「大件」，视觉冲击最强 |

其余爱好按十五大类排在推荐位下方，全部可以直接点进去看、一键「入坑」。
