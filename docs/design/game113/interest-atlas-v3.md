# 《雅趣：第二人生》兴趣图谱 v3 · 从好奇到具体物件

这是一份可继续生长的**策展候选目录**，不是“世界上所有爱好已经收齐”，也不是已核验的商品库。目标是让玩家从一个陌生的方向进入，看到可学习、可讨论、可收藏的具体物件；价格、真实性和真实市场流通性必须另行核验。App 当前在「发现 → 兴趣图谱」展示 [机读目录](../../../games/game113/atlas.ts)，只有六门原有爱好馆开放操作，其余为“策展中”。

## 先定边界

- 一个“爱好”要有可独立建档的**实体物件**：例如斗蟋蟀文化可从蟋蟀罐、葫芦虫具切入；单纯活动、下注和服务本身不算藏品。
- “淘宝上有人卖”只能作为发现线索，不等于合法、长期稳定流通、真品可鉴或适合产品上线。每个候选分支正式开馆前应核验产地与品牌资料、品相标准、实际交易场景、所在地合规、图片授权。
- 系统内买卖始终是虚拟藏品与不可提现的雅钱；不暗示现实增值、保值或投资回报。真实上传与实物核验是另一条未来流程。
- 目录分成**大类 → 分支 → 物件候选**。真正的藏品还需**品牌 / 系列 / 正式型号 / 版本 / 实物档案**，不能把一个俗称当成唯一商品。
- 图片来源必须显式标记：本轮两张新图均为 **AI 生成氛围图**，不是任何真实藏品的证据。具体型号、刻字、瑕疵、年份、封签和品相，必须由授权的实物照片与资料承载。

## 看得见的纵深：五个样本

### 腕表

路径：**制表地区 / 传统 → 品牌 → 系列 → 正式参考编号 → 表盘、表圈、机芯、年份、品相**。例如瑞士 → Rolex → Submariner Date → 126610LN 或 126610LV。玩家俗称“黑水鬼”“绿水鬼”并不是 Rolex 的正式型号：官方资料显示 [126610LN 为黑色陶瓷表圈与黑表盘](https://www.rolex.com/en-us/watches/submariner/m126610ln-0001)，[126610LV 为绿色陶瓷表圈与黑表盘](https://www.rolex.com/en-us/watches/submariner/m126610lv-0002)。后续如加入旧款、特殊盘面或昵称，应逐参考编号另建记录，不把多个年代的“绿水鬼”混为一件。图像与真伪判断要回到实物。

同一套维度还可以扩展到 Omega Speedmaster、Seiko Prospex、德国制表、国产机械表；“产地”是筛选轴，不是对价值的排序。

### 雪茄

路径：**产区 → 品牌 → 系列 / 商品名 → 茄型与尺寸 → 盒装、封签与年份**。示例：古巴 → Montecristo → Edmundo / Petit Edmundo；古巴 → Partagás → Serie D No. 4 / Serie P No. 2。这些名称来自品牌官方目录；Habanos 亦将不同形状尺寸称为 *vitolas*，并区分工厂名称与市场名称。[Montecristo 官方品牌页](https://www.habanos.com/en/the-habanos-brands-academia/montecristo-brand/)、[Partagás 官方品牌页](https://www.habanos.com/en/the-habanos-brands-academia/partagas-brand/)、[Habanos 茄型说明](https://www.habanos.com/en/principal-shapes-sizes/)。

在 App 中这是成人限定的历史、工艺与器物知识候选。雪茄盒、保湿盒、剪刀可成为不同的收藏分支；不以烟草消费作每日推荐，也不在年龄与地区规则审查前接真实售卖。

### 摄影与摄像器材

路径：**胶片 / 数码 / 即时成像 → 旁轴 / 单反 / 中画幅 / 无反 / 摄录 → 品牌与卡口 → 机身或镜头型号 → 功能、光学和维护状态**。镜头又可按卡口、焦段、最大光圈、代际分类；配套品可独立做测光表、闪光灯、取景器、三脚架、摄影包。二手影像平台 MPB 的实际目录同时列出[相机、镜头和配件](https://www.mpb.com/en-us/shop)，可作为“市场确实有这一层级”的例子；但不能据此推断每个型号都有充足流动性。

### 斗蟋蟀文化

“斗”可以是文化入口，但首批内容落在**蟋蟀罐、葫芦虫具、鸣虫盒、图鉴、民俗记录**，可按材质、制式、工坊、年代、修复状态整理。不设计赌斗、押注、活体交易或竞技驱动的动物伤害。若以后真的纳入活体内容，要另做物种、福利、地域规则和平台政策审查。

### 香水与奢侈美妆

香水瓶型、旅行装、复古粉盒、口红外壳、限量礼盒与联名包装都可作为**设计器物**收藏。应分开记录“容器及包装”和“内部化妆品”；过期内容物不能被描述为可使用。不要把品牌、限定、贵价直接等同于有收藏价值；优先讲设计、工艺、保存和来源。

## 下一次添加新方向的方法

1. 用一句话定义吸引人的兴趣问题：“我为什么想认识它？”
2. 列出至少三种可建档的实体物件；若只有服务或体验，先放在社区话题而非藏品目录。
3. 记录分类轴：例如摄影需要介质、机身结构、卡口；腕表需要品牌、系列、参考编号；美妆需要容器与内容物状态。
4. 做准入核验：真实市场、合法来源、品相标准、图像授权、年龄或地域限制、敏感材料。未完成则保持“策展中”。
5. 在 `games/game113/atlas.ts` 的对应大类中追加稳定 `id`、名称、候选物件及必要备注；只有完成内容与图片审核后，才把它接到真正的爱好馆和虚拟市集。
