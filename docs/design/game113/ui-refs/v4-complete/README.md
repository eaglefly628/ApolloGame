## 用户路径

```text
首次选择兴趣 → 首页「今日推荐」→ 发现 / 爱好馆 → 市集
                                               ↓       ↓
同好 ← 仓库 ← 正式入仓 ← 细看 + 知识卡 ← 待鉴区 ← 买入
  ↑       ↓                                      ↑
  └─分享 / 掌眼 / 串门                  考级 / 学习 → 雅钱
          ↓
     擦擦亮三消 → 保养品 → 养护 → 品相成长
```

## 全局规则

- 一级导航：**首页 / 发现 / 市集 / 仓库 / 同好**；头像入口承载个人档案、证书、雅钱明细与设置。
- “今日推荐”永远优先于买卖；它从用户尚未入坑的爱好里提供一个低门槛新入口。
- 雅钱只用于游戏内虚拟收藏与服务；不可提现、不可转赠；广告仅由用户主动观看。
- 市集与行情均为游戏内收藏信息，常驻“仅供娱乐，不构成任何购买或投资建议”。
- 三消为步数制、无倒计时；保养品只服务于藏品养护与学习成就，不出售焦虑。
- 所有正文、按钮和状态均按适老标准设计：清晰文字、大点击区、高对比、无隐藏手势。
