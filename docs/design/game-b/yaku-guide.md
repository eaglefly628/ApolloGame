# 《雀宴》日式立直麻将 · 番数说明书

> **面向**：给大家看的规则说明（非开发 spec）。**口径**：**全日式立直麻将 · 天凤标准**（owner 2026-07-20 拍板「支持全日式麻将」）。
> **准确性**：机读真相 = `games/game-b/core/yaku.ts`（役/番）+ `fu-score.ts`（符/点）；本文数字与之同步（2026-07-20·连风 4 符订正后）。若代码与本文冲突以代码为准并回填本文。
> **牌**：万(m)/筒(p)/索(s) 各 1–9 + 字牌（東南西北 + 白發中）。赤5（赤ドラ）各一张。

---

## 一、和牌总则（先懂这几条）

| 规则 | 说明 |
|---|---|
| **1 番縛り** | 一手至少要有 **1 个役** 才能和牌；只有宝牌（ドラ）不算役、不能和。 |
| **番（han/翻）** | 役的价值累加，决定点数档位。宝牌/赤/里也计入番、但**本身不成役**。 |
| **符（fu）** | 手牌「形状」的细分计价（刻子/杠/雀头/听牌形/自摸…），配合番算点。 |
| **门前清 vs 副露** | 没鸣牌（吃/碰/明杠）=门前清，能吃门清限定役（立直/平和/门前自摸/一盃口/七対…）；一旦鸣牌这些役消失，且部分役 **喰い下がり**（降 1 番）。 |
| **食断あり** | 副露后仍可成 **断幺九**（本作采「食断あり」·天凤/雀魂通行）。 |

## 四、宝牌（ドラ · 加番不成役）

| 种类 | 说明 |
|---|---|
| 表ドラ | 宝牌指示牌的下一张，每张 +1 番。 |
| 裏ドラ | **立直和牌**才翻，里指示牌的下一张，每张 +1 番。 |
| 赤ドラ | 赤 5（各花色一张），每张 +1 番。 |

## 五、符计算（形状计价）

**符 = 底符 + 门前清荣和 + 面子符 + 雀头符 + 听牌形 + 自摸**，最后**个位切上**（22→30）。

| 项 | 符 |
|---|---|
| 底符 | 20 |
| 门前清 · 荣和 | +10（**副露荣和无此加符**） |
| 自摸 | +2（平和自摸例外·见下） |
| 明刻 中张 / 幺九字 | 2 / 4 |
| 暗刻 中张 / 幺九字 | 4 / 8 |
| 明杠 中张 / 幺九字 | 8 / 16 |
| 暗杠 中张 / 幺九字 | 16 / 32 |
| 雀头 · 三元/场风/自风 | +2 |
| 雀头 · **连风（自风==场风·ダブ東等）** | **+4**（场风 2 + 自风 2·**全日式**·天凤/雀魂/竞技一致） |
| 听牌形 · 边张/嵌张/单骑 | +2（两面/双碰 0） |

**特例**：
- **七対子** = 固定 **25 符**（不加不进位）。
- **平和自摸** = 恒 **20 符**（抑制自摸 +2）。
- **喰い平和形荣和**（副露纯顺形、算下来 20 符）= 升 **30 符**。

## 六、点数计算

**基本点 = 符 × 2^(2 + 番)**；四家支付按下表倍率、**百位切上**。

| 番数（或基本点） | 档位 | 基本点 |
|---|---|---|
| 满足下方任一 → 未到满贯 | 普通 | 符×2^(2+番) |
| 3–4 番高符 / 5 番 | **满貫** | 2000 |
| 6–7 番 | **跳満** | 3000 |
| 8–10 番 | **倍満** | 4000 |
| 11–12 番 | **三倍満** | 6000 |
| 13 番以上（数え役满）/ 役满 | **役満** | 8000（×倍数） |

**支付倍率**：闲家荣和 = 基本点 ×4；庄家荣和 ×6；闲家自摸 = 庄付 ×2 + 闲各付 ×1；庄家自摸 = 各家付 ×2。

> **无切上满贯**（天凤/雀魂段位战一致）：30 符 4 番 = 7700/11600（**不**升满贯）；40 符 4 番 = 满贯。

**常见速查**（子 荣和 / 自摸）：

| 番 符 | 子 · 荣和 | 子 · 自摸（闲各付 / 庄付） |
|---|---|---|
| 1 番 40 符 | 1300 | 400 / 700 |
| 2 番 40 符 | 2600 | 700 / 1300 |
| 3 番 40 符 | 5200 | 1300 / 2600 |
| 4 番 30 符 | 7700 | 2000 / 3900 |
| 満貫 | 8000 | 2000 / 4000 |
| 跳満 | 12000 | 3000 / 6000 |
| 倍満 | 16000 | 4000 / 8000 |
| 役満 | 32000 | 8000 / 16000 |
