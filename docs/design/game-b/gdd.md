## 一、一句话

俯视 3D 和风雀庄陪打局：外部角色卡带着主角与金钱入局，与三位姨太打一圈东风战日麻，被直击者当场脱一件（轻演出），终局把金钱与衣着状态带回局外。

## 二、体验支柱

1. **陪打氛围**——女性向二次元和风夜宴：三位性格分明的姨太、日语语音、和室夜灯，一圈 10~20 分钟的"陪你打牌"体验，不是竞技麻将客户端。
2. **正经日麻**——规则完整可信（役/符/振听/连庄），骰子和牌都真在 3D 桌上；懂麻将的玩家挑不出毛病。
3. **轻脱衣刺激**——直击=当场脱一件的即时张力；表现克制（图标+演出条起步），色气靠文案、语音、镜头，不靠像素。
4. **局外联动件**——本游戏是大系统里的一张"牌桌"：角色、金钱、衣着状态从外面来、回外面去。

## 三、核心循环

```
局外传入（角色卡+金钱+seed）
  → 开局演出（入席·掷骰定亲）
  → 东风战 东1→东4（庄家和牌/听牌连庄·本场棒累积）
      每局：摸打/鸣牌/立直 → 和了或流局 → 点数结算
      ★直击脱衣：放铳者 或 被自摸的三家 → 各脱一件（演出条+语音+图标熄灭）
      ★击飞：任一家点数<0 → 整圈立即终局（⚙ 日麻惯例·config 可关）
  → 终局结算（顺位·点数=金钱 1:1·衣着状态汇总）
  → 带出局外（SessionOut：金钱增减+每人剩余衣物+顺位）
```

- ⚙ 被自摸时"三家各脱一件"火力较猛，备选=仅支付最多的一家脱；默认取**三家各脱**（直击制字面语义），数值表可切。
- ⚙ 衣物件数默认每人 **5 件**（和装：簪/打挂/帯/襦袢/足袋——件名美术阶段可改）；脱光后再被直击=只扣分不再脱（不做出局，牌局照打）。
- ⚙ 主角**对称适用**脱衣规则（玩家被直击同样脱·紧张感来源）；做成 config `strip.symmetric`（默认 true），局外传入可覆盖。

## 五、AI（⚖ owner 定调：行为树+作弊读牌·不做真 AI）

- **结构**：行为树=**纯数据节点表**（selector/sequence/condition/action 闭集字段），解释器为固定确定性代码（游戏层 TS 起步·下沉债）；人设=BT 参数包，难度=信息面+犯错率，两轴独立。
- **难度三档**（⚙ 档名暂定 简单/普通/困难——owner 原话"简单、容易和困难"，档名可改）：

| 档 | 信息面（作弊面） | 犯错注入（种子 PRNG） |
|---|---|---|
| 简单 | 只读自家手牌+公开信息 | 15% 概率选次优打 |
| 普通 | + 牌山剩余概率精算（计数术） | 5% |
| 困难 | + ⚖ 可读对手手牌结构/听牌状态、全剩余牌概率 | 0% |

- **三姨太人设牌风**（BT 参数·⚙ 名字为工作名·台词由文案表出）：
  - **大姨太·绫**——端庄冷艳；防守权重高、门清偏好、立直慎重。
  - **二姨太·莉世**——好胜泼辣；鸣牌率高、速攻、对人直击欲强。
  - **三姨太·小夜**——天真烂漫；高波动、梦大役、危险打法。
- ⚖ 后续可能参考外部麻将 AI 代码：只参考思路，落地必须回到 BT 数据+确定性解释器；外部代码先过许可证审查。

## 七、脱衣系统（⚖ 直击制·轻表示起步→换装跟进）

- **触发**：放铳者脱 1 件；被自摸=三家各脱 1 件（⚙ 见 §三）；立直棒/罚符等非直击失点**不**触发。
- **v1 轻表示**：席位卡 5 件衣物图标逐件熄灭 + 脱衣演出条（镜头推近该席→立绘浮层滑入→台词字幕+语音+樱瓣粒子——全用既有 EffectKind/timeline，无新演出系统）。
- **v2 换装跟进**：立绘 3 档（整齐/微乱/最终档点到为止）；美术线就绪后逐角色替换；角色卡格式已预留多档立绘数组，无档位卡=永远用单张立绘（优雅降级）。
- **状态外带**：每人剩余衣物件数/档位随 SessionOut 带出（⚖ 局外纹身图系统消费，局内不管局外如何呈现）。

## 十、音频

- SFX/BGM=既有合成音频线（SynthAudioPort/SynthMusicPort·数据表）——和风音色（三味线拨/太鼓/风铃近似音色表）。
- **语音=两档制（⚖ owner 2026-07-17：音源包暂无，先用语音合成发声）**：
  - **即时档 TTS**：浏览器 speechSynthesis（ja-JP 音色）朗读 voice-manifest 的日文台词——零资产零 key 立刻出声；系统无日语音色时降级为合成提示音+字幕。
  - **采样档**：将来真人/AI 配音 wav 到位后按 `voice-pack-spec.md` 灌入，同一事件键表无缝替换（TTS 朗读文本=将来的录音台本，一表两用）。
  - 引擎缺口=**语音输出端口**（两档同接口·表现层旁路·headless 静默 no-op），见 capability-plan §2.5-a。
- ⚙ 语言组合默认：界面/字幕中文·语音日语。

## 十二、确定性声明

- 随机源：唯一 seed 入局（SessionIn.seed·缺省时钟种子入参化）→ 洗牌/掷骰/AI 决策/犯错注入全走引擎种子 PRNG；**游戏层禁裸 Math.random（审计红线）**。
- 语音/镜头/粒子=表现层，不进 sim；同 seed 同操作序列 → 牌局逐步可复现（walkthrough vitest 依据）。
- 不做双人同步/lockstep（单机陪打）。
