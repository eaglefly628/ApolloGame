> GD-B 2026-07-17 出（owner 点名交付物）。**消费方**：PE-B（场景装配/装载）、P3D（若需新 render-only 组件）、PUI（缺控件裁决）、美术平台（资产位对台账）。

> 一切数值=**可调默认值**（写进游戏 config，不是硬编码）；坐标系口径：桌面中心=原点，+Z 朝玩家（南），+Y 朝上，单位=桌面半宽归一（桌面=2×2）。
> 铁律复诵：3D 物走引擎 render-only 组件（Mesh3D/Model3D/Camera3D/Light3D/Vfx3D）；UI 走 LayoutNode 闭集；人物**无 3D 模型**——头像/立绘=2D 浮层。

## 一、场景总构（和室雀庄·夜）

```
            ┌─────────── 和室背景（障子门·格窗·灯笼·庭院月色远景板）───────────┐
            │   [北席·对面姨太]  头像+点数条（UI 浮层）                        │
            │        ╔═══════════════════╗                                    │
            │  [西席] ║   3D 麻将桌 2×2    ║ [东席]        ← 3D 世界层         │
            │  姨太   ║  牌山/牌河/骰/点棒  ║  姨太                             │
            │        ╚═══════════════════╝                                    │
            │   [南席·玩家] 3D 手牌 13-14 枚立面朝镜头                          │
            │   ────────── UI 层：行动按钮排 · 字幕条 · 场况角标 ──────────      │
            └──────────────────────────────────────────────────────────────┘
```

- **层级**：① 3D 世界（桌+牌+骰+点棒+背景件）② 2D 立绘浮层（演出时滑入）③ LayoutNode UI 层（HUD/面板）。三层各自独立，UI 绝不进 3D。
- **氛围**：夜·暖。樱色/绯色主导（对齐 sakura-otome 主题与女性向二次元锚），桌呢=绯红或樱粉（⚙ 非传统绿呢·美术定稿）。

## 二、3D 布局规格

### 桌与静物

| 物 | 位置/尺寸（归一单位） | 资产形态 |
|---|---|---|
| 麻将桌 | 中心原点·桌面 2×2·桌高 0.55 | Model3D（木质和桌·圆角方桌）或 Mesh3D box 占位 |
| 桌呢 | 桌面内区 1.8×1.8 | 材质数据（贴图槽·台账行） |
| 座垫 ×4 | 四边中点外 0.55·尺寸 0.5×0.5 | Model3D/Mesh3D 扁圆 |
| 牌 136 枚 | 牌尺寸 0.072×0.096×0.052（宽×高×厚·近似真实比例） | Model3D 单模+**实例化渲染**（引擎已有 3D 实例化能力）·牌面=图集 UV |
| 牌山 | 四边各 17 墩×2 层·距边 0.62 | 实例阵列（位置=纯计算布局） |
| 牌河 | 每席桌心侧 6×3 行起·间距 0.08 | 实例阵列·立直牌横置 |
| 自家手牌 | 南边距边 0.15·13-14 枚立起面向镜头·选中牌上浮 0.03 | 实例+选中位移 |
| 副露区 | 各席右手角 | 实例阵列 |
| 骰 ×2 | 桌心右上 0.3 偏移·尺寸 0.06³ | Model3D·掷骰=timeline 演出（结果由种子 PRNG 先定·动画只是回放） |
| 点棒托 ×4 | 各席右手边缘 | Mesh3D 扁盒+点棒计数走 UI |
| 供托（立直棒/本场棒） | 桌心 | 实例 |
| 背景件 | 障子门板 ×2（北后方）·灯笼 ×2（东西上方）·月窗板（远景） | Mesh3D 贴图板（2.5D 舞台布景即可·不做真房间） |

### 镜头（Camera3D·机位=数据表）

| 机位 | 参数（默认） | 触发 |
|---|---|---|
| 主机位 | 位 (0, 3.2, 2.6)·看向 (0, 0, 0.3)·俯角 ~55°·FOV 40 | 常态（看全桌+自家手牌立面） |
| 立直推近 | 向该席平移+拉近 25%·0.6s 缓动 | 任一家立直宣言 |
| 和牌俯冲 | 快速推向和牌席牌河·0.8s | 荣和/自摸宣言 |
| 脱衣特写 | 推近该席 35%+背景微暗（此时立绘浮层滑入） | 直击脱衣演出 |
| 掷骰特写 | 俯视桌心 (0, 2.2, 0.6)·跟骰 1.2s | 开局定亲/开杠翻宝牌可复用 |

- 机位切换=数据（目标位/时长/缓动字段闭集），禁游戏层手写相机代码；若现有 Camera3D 缺"机位表+缓动切换"语义 → 提单下沉，绝不自造。

### 光照（Light3D）

- 主光：暖白顶光（桌面上方 (0,4,0)·强 1.0·樱米色 #FFF2E0 近似——终值走主题令牌）。
- 补光：琥珀侧光（东西灯笼位·强 0.35·营造夜宴暖晕）。
- 演出光：脱衣特写时全局调暗 30%+该席聚光（数据开关）。

## 三、2D 立绘浮层（人物无 3D 模型）

| 元素 | 规格 | 说明 |
|---|---|---|
| 席位头像 | 方图·UI 层席位卡内（见 §四） | 常驻·来自角色卡/内置卡 |
| 立绘 | 竖构图半身~七分身·真 alpha PNG·屏高 ~85% | 演出时从该席对应侧滑入（东→右侧入·西→左侧入·北→右侧入·南/主角→左侧入），0.4s 缓动 |
| 立绘触发闭集 | 开局问候/立直/和牌/放铳懊恼/脱衣演出/终局 | 与语音事件表同键（voice-pack-spec） |
| 换装档 | v2：同角色多档立绘按 clothing 档位替换 | 单张卡=优雅降级不换 |

## 四、UI 层布局（LayoutNode·sakura-otome 主题·横屏 16:9）

```
┌────────────────────────────────────────────────────────┐
│ [场况角标·左上]         [北席位卡·顶中]        [设置·右上] │
│  东1局·2本场·供托2·余70                                  │
│ [西席位卡·左中]        （3D 桌透视区）        [东席位卡·右中] │
│                                                        │
│              [字幕条·底部上方·语音同步]                   │
│ [自席位卡·左下]  [行动按钮排·底中：吃碰杠立直和跳过]  [🀄]  │
└────────────────────────────────────────────────────────┘
```

| 件 | 内容 | LayoutNode 落法 |
|---|---|---|
| 席位卡 ×4 | 头像+名字+风位（東南西北）+点数+**衣物图标列 5 件**（轻表示·逐件熄灭）+立直标 | Panel+既有控件组合；衣物图标=图标行（现有 icon/emoji 控件·件图标走台账资产） |
| 场况角标 | 局数/本场/供托/余牌数/宝牌指示牌缩略 | Panel |
| 行动按钮排 | 吃/碰/杠/立直/荣和/自摸/跳过——仅合法时亮起·**全部=action 信号入队** | Button 排（异形按钮 8 形可选樱瓣形） |
| 字幕条 | 语音台词中文字幕 | Label（艺术字库 18 款内选和风字体） |
| 结算面板 | 役种逐行+符番+点数移动动画+本局脱衣汇总 | 全屏 Panel/Modal |
| 开局/终局面板 | 席位与带入金确认 / 顺位·金钱增减·衣着汇总·带出确认 | Modal |

- **红线**：写世界只走 action 信号入队；缺控件（如"点数移动飞点动画"若现有件不覆盖）→ requests.md 报 PUI，绝不手写 DOM/CSS。交付前 `/check-ui` 全过。
