> 算法复核过：标准形=「最低未消耗牌必为面子起点」贪心+回溯（完备）·顺子 `i%9<=6` 防跨花色·七对/国士计数判定完整·听牌枚举排除已握 4 枚。门禁 tsc0 + vitest(game-b) 47 绿。
