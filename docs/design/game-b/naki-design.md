## 1. 数据模型（`core/meld.ts` 新 + `game-state.ts` 扩）
```ts
export type MeldKind = 'chi' | 'pon' | 'minkan' | 'ankan' | 'kakan';
export interface Meld {
  kind: MeldKind;
  tiles: number[];     // 组成牌码（chi/pon=3·kan=4·含赤5）·升序
  from: number;        // 供牌者 seat（ankan=自己·kakan=原碰的供牌者）
  called: number;      // 被鸣的那张牌码（摆放/朝向·加杠=补的第4张）
}
```
- `RoundState.melds: Meld[][]`（四家副露·含暗杠）。
- `hands[seat]` = **暗手**（不含副露牌·升序）·每鸣一次缩 3（杠缩 3 暗手 + 岭上补 1 摸）。
- **不变式**：`hands[s].length + 3*melds[s](非杠) + 4*melds[s](杠?按3计手数) + (drawn?1:0)` → 手数恒 13/14（杠额外摸补）。以「暗手需再凑 `4 - melds.length` 面子 + 雀头」为准绳。

## 2. 鸣牌合法性（纯函数 `core/calls.ts`·对某弃牌/自家手）
- **吃**：仅**下家对上家**弃牌 c·本家暗手含 {c-2,c-1}|{c-1,c+1}|{c+1,c+2}（同花色·数牌）→ 三种搭子候选。**喰い替え禁**（R-2：鸣成的顺子不得立刻打出同筋/同牌）。
- **碰**：任意家·本家暗手 ≥2 张 == c。
- **大明杠**：任意家·本家暗手 3 张 == c。
- **暗杠**：自家回合·暗手(含 drawn) 4 张同牌·**立直后仅不变听可暗杠**。
- **加杠**：自家回合·已有 c 的**碰**·摸到第 4 张 → 升杠·**可被抢杠**（R-6：暗杠不可抢·国士例外 v1 不做）。

## 3. 优先级（一张弃牌多家争鸣）
**荣和 > 碰/大明杠 > 吃**。多家荣=双响制（gdd）。同时有人碰、有人吃 → 碰赢（吃只下家、碰任意家）。

## 4. 流程改动（call window·`game-state.ts`）
弃牌后**不立即轮转**，开「鸣牌窗口」：
1. 收集四家对该弃牌的 {可荣, 可碰, 可大明杠, 可吃}。
2. **玩家**：HUD 亮按钮（荣/碰/杠/吃/过）等点击（吃多搭子→选一）。**AI**：按倾向决策（v1 简版启发·种子 PRNG）。
3. 结算优先级：有人荣→settleWin(ron)；否则有人碰/大明杠→该家鸣（成 actor·**不摸**·碰后打牌 / 杠后岭上摸再打）；否则有人吃→该家吃打；否则**下家摸**（原流程）。
4. actor 跳到鸣家；一发/门清态按鸣牌破坏。

## 5. 杠专项
- 岭上摸：王牌尾摸 1·活山尾 1 张补进王牌（**王牌恒 14**·岭上耗尽口径）；岭上和=自摸+岭上开花(R-5 符+2)。
- 新宝牌：**暗杠即翻·明杠打牌后翻**（R-3）。
- 抢杠：加杠被荣 → 杠不成立·杠者放铳（暗杠不可抢·国士例外 v1 不做 R-6）。
- 四杠散了（4 杠不同家）v1：记债（罕见·先不做途中流局·照续）。
- **P3b 已实现债（2026-07-18·占位分下无玩法差别·P6 结账）**：①R-3「明杠打后翻」精确时序→当前即翻（占位分无差）；
  ②立直后暗杠 v1 **整体禁**（未做「不变听」判定·安全子集）；③岭上开花/抢杠役接线=P6（当前杠只走机制+占位分）；
  ④被抢的加杠残留 kakan 副露（本局已终·仅结算面板 cosmetic）。守恒 136 / 王牌恒 14 / 门清不回退 已测钉死。
