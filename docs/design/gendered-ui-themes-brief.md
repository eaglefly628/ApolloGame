# 两套性别向游戏 UI 主题 · 设计简报（给 Claude designer）

> 2026-06-10 · 性质:**设计简报**,委托 designer 出**设计稿**。不改任何逻辑(UI=纯表现层)。
> 产出物:**两套完整游戏 UI 主题包**——「偏女性向」+「偏男性向」,各覆盖全部标准组件。

---

## 0. 重要:沿用现有主题系统,别另起炉灶

Apollo 已有成熟的主题包体系,**两套新主题必须按它的格式产出**:
- **契约**:`src/ui/themes/theme.types.ts` —— `ThemeTokens`(色板/排版/形状/特效)+ `ThemeComponentConfig`(各组件参数)+ `GameTheme`。
- **每套主题的结构**(参照 `src/ui/themes/sakura-otome/`):`spec.md`(风格定位 + 色板表 + 生成 prompt)+ `tokens.css`(CSS 变量)+ `components/*.css`。
- **20 个标准组件**(固定清单,两套都要全覆盖):`health-bar` 血条 / `button` 按钮 / `panel` 面板窗口 / `dialog` 对话框 / `menu` 菜单 / `notification` 通知横幅 / `progress-bar` 进度条 / `tooltip` 悬浮提示 / `label` 文字标签 / `icon-badge` 图标徽章 / `inventory` 背包物品栏 / `skill-slot` 技能槽 / `mini-map` 小地图框 / `avatar-frame` 头像框 / `name-plate` 名牌称号 / `choice-option` 选项按钮 / `tab-bar` 标签栏 / `slider` 滑块 / `modal` 模态弹窗 / `toast` 轻提示。

> **和已有主题的关系(designer 须知)**:已有 8 套(cyberpunk / sci-fi-hologram / fantasy-medieval / ink-wash / glassmorphism / minimal-dark / pixel-retro / **sakura-otome**)。其中 **sakura-otome 已是一套乙女(偏女性)主题**。本次要的两套是**旗舰级、商业品质**的性别向代表作——可把 sakura 当女性向的参考基线,但新女性向要做出**更高完成度 / 不同子风味**;男性向则是现有里没有的明确定位(cyberpunk/sci-fi 偏科幻而非"男性向游戏 UI"通感)。

## 1. 通用要求(两套都遵守)

### 1.1 交互态(延续上一份 brief 的重点,必做)
每个可交互组件都要给**完整状态 + 精确动效处方**:`default / hover / press(active) / focus-visible / disabled / loading / selected`。
- **hover**:抬升 / 缩放 / 亮度 / 阴影 / 发光的具体值 + 时长缓动。
- **press**:点击瞬间反馈(下沉/缩小 scale≈.96 / 高光闪 / 可选涟漪)+ 回弹。
- **focus-visible**:键盘聚焦环(主题 accent 描边 + 柔光),鼠标点击不触发。
- `ThemeComponentConfig.button` 已预留 `hoverScale/activeScale`——把这套交互显式定义出来。

### 1.2 动效语言
进出场、列表交错、数值跳动(血条/分数/金币)、强调脉冲;给时长/缓动档;`prefers-reduced-motion` 降级。

### 1.3 可达性 & 工程约束
- 对比度达标(尤其暗底低饱和、亮底浅色);点击热区 ≥ 视觉尺寸;键盘可达。
- 组件 UI **浮在 canvas 游戏画面之上**:处理好 z 层、`pointer-events`、半透明背板/毛玻璃与画面的关系。
- 主题切换走 **CSS 变量**(tokens.css):同一套组件结构,换 token = 换皮。

### 1.4 每套交付物
1. `spec.md`:风格定位 + 视觉关键词 + **完整色板表**(token→色值→用途)+ 排版/形状/特效规范 + Claude 生成 prompt。
2. **20 组件设计稿**:每组件的视觉 + 全交互态 + 关键动效。建议附**整屏参考 mock**(见 §4 锚定到 Apollo 真实游戏)。
3. `tokens.css` 草案(CSS 变量)便于落地。

## 2. 「偏女性向」主题(代号建议:**Aurora / 霞** 或沿用乙女系)

### 2.1 气质定位
柔美 · 温暖 · 梦幻 · 精致 · 治愈。让玩家觉得"被温柔包裹、赏心悦目、有少女心/高级感"。覆盖品类:乙游/恋爱养成、换装、三消、生活模拟、社交养成。

### 2.2 视觉语言
- **色彩**:暖白/浅粉/奶油底;主色取**樱粉 / 蜜桃 / 丁香紫 / 薄荷**等高明度低饱和;点睛用**玫瑰金/珠光**。可做柔和渐变(135° 双色)。整体明亮、通透。(参考 sakura 的 `#fff5f9 / #e8618c / #4a3040` 一脉,但做出新风味,如"奶油茶+丁香紫"或"蜜桃+玫瑰金"。)
- **形状**:**大圆角**(12–20px)、圆润、无硬边;边用浅色细线或干脆无边靠柔光阴影。
- **材质/装饰**:柔光扩散阴影、花瓣/丝带/星屑/爱心点缀(克制,角落或分隔处)、珠光高光、磨砂玻璃。
- **排版**:圆体/手写体混排(标题可手写花体,正文圆润 sans);字距舒朗。
- **微交互**:hover 柔光扩散 + 轻微放大;press 软回弹;好感/收藏类用心跳/星屑脉冲;数值上升用甜美跳动。**手感关键词:软、弹、亮。**
- **避免**:尖锐切角、冷硬金属、高对比黑红、暴力字体。

### 2.3 几个组件的特别处理
- `dialog` 对话框:立绘对侧、缎带名牌、打字机、选项大而圆润 hover 柔光。
- `avatar-frame` 头像框:花环/丝带边、柔光描边、好感等级用色环。
- `choice-option`:大圆角胶囊、hover 柔光扩散 + 浅色填充。
- `health-bar/progress-bar`:圆头、渐变填充、柔光、变化时甜美跳动。

## 3. 「偏男性向」主题(代号建议:**Vanguard / 锋** 或 **Tactical**)

### 3.1 气质定位
硬朗 · 力量 · 锐利 · 高科技/暗黑 · 竞技。让玩家觉得"强大、酷、信息高效、有压迫感与掌控感"。覆盖品类:ARPG/动作、射击、自走棋/策略、卡牌对战、硬核竞技。

### 3.2 视觉语言(可给两个子方向供选,或合一)
- **子方向 A · 暗黑金属/硬核**:近黑底 + 钢灰/暗铜/血红;切角(clip-path 斜切)、铆钉/装甲/纹理金属、磨损质感;字体冷峻(无衬线粗体或军用等宽)。
- **子方向 B · 赛博 HUD/电竞**:深空蓝黑 + 霓虹青/电光橙/警示黄;发光描边、扫描线、网格、棱角面板、数据流动效。
- **共性**:**高对比、低圆角(2–6px)或切角、棱角分明**;信息密度高、HUD 感强;边框用**发光线/双线/角标**而非柔影。
- **材质/装饰**:金属/玻璃/碳纤维纹理、能量光带、警示条纹、棱形/六边形几何。
- **排版**:粗壮无衬线或科技等宽;字距偏紧、可全大写小标签;数字用 tabular/等宽(读数稳)。
- **微交互**:hover 发光描边 + 轻微亮起/位移;press 锐利下沉 + 高光闪(像按下机械键);选中用边角点亮/能量脉冲;数值变化用刚性快跳 + 命中闪。**手感关键词:锐、亮、力。**
- **避免**:柔粉、花瓣、过度圆润、低对比"奶油感"。

### 3.3 几个组件的特别处理
- `skill-slot` 技能槽:六边形/切角框、冷却扫描遮罩、就绪时边角点亮、按下锐闪。
- `mini-map` 小地图框:棱角边 + 角标 + 网格底。
- `health-bar`:分段/刻度、硬边、掉血时红闪 + 抖动;`progress-bar` 带斜纹流动。
- `inventory/icon-badge`:稀有度发光边(参考 game-e 商店稀有度光晕)、品质角标。
- `modal/notification`:切角面板 + 顶部能量光带 + 入场锐利滑入。

## 4. 锚定到 Apollo 真实游戏(让 mock 有的放矢)
- **偏女性向** → 对应 **Game B(乙游 VN)**、**Game C(缝纫换装三消)**。参考 mock 建议出:① VN 对话+选项+好感面板 ② 三消/换装的背包+按钮+进度。
- **偏男性向** → 对应 **Game D(暗黑 ARPG)**、**Game E(小丑牌 roguelike)**、**Game F(自走棋三国)**。参考 mock 建议出:① ARPG 战斗 HUD(血条/技能槽/小地图)② 卡牌商店(稀有度卡 + 购买/重摇,可参考 game-e 现有商店)③ 自走棋备战(棋子卡/羁绊/金币 HUD)。

## 5. 明确不做
- 不改游戏/引擎逻辑、不碰确定性模拟、不动 canvas 内的游戏美术资产。
- 不偏离 20 组件标准清单与 `theme.types.ts` 契约(要能直接落进主题系统)。
- 性别向是**审美取向不是限制**——做"偏"不做"刻板":女性向也要高级不幼稚,男性向也要精致不糙。

## 6. 风格锚点(给 designer 定调)
- **偏女性向**:任天堂《动森》/ 乙游 / 现代治愈手游那种**明亮柔美、圆润精致、微光甜美**;一点高级感避免廉价。
- **偏男性向**:《暗黑破坏神》/《命运 2》HUD / 电竞 OSD / Apex 那种**暗色高对比、棱角金属/霓虹、信息高效、按下有"机械感"反馈**。
