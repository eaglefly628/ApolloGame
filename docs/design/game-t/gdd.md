竖屏三消（糖果传奇-like），水墨意象棋盘：交换墨珠连三消除，卷轴/朱印/太极丸特殊棋子与连锁，洗墨（果冻）/破瓷（障碍）多目标 30 关闯关。

## 三、目标类型与关型（首发 30 关分布框架·逐关表=GD 产出）

- **关型闭集**：`score`（分数）/ `collect`（集齐 N 枚某色墨珠）/ `jelly`（洗净全部墨渍）/ `blocker`（破尽冰纹瓷）/ `mixed`（组合目标）。
- **30 关节奏**（每型引入关=教学关·低压）：1-5 纯分数教学（四色·宽步数）→ 6-10 收集+第五色 → 11-15 墨渍（洗墨）→ 16-20 冰纹瓷 → 21-25 砚石地形+混合目标 → 26-30 高压混合（六色·紧步数·双目标·30=全机制汇演）。
- 特殊棋子教学埋在关卡里：4 连必现局（关 3）、L/T 局（关 7）、5 连局（关 12）——用摆盘（初始 cells 布局）保证可教学，不写教程代码。

## 四、难度与经济（照抄糖果传奇框架·数值 GD 用 balance-sim 调）

- **步数**：每关 15-40 步；目标步数裕度=sim 平均所需步 ×1.4（教学段）递减至 ×1.1（26-30）。
- **计分**：单珠消除 60 分；连锁每级 ×1.5；特殊棋子引爆按波及格计分；收笔=剩步 ×1000。
- **三星**：1 星=达成目标过关；2/3 星=分数阈值（GD 按 sim 分布 P50/P85 定标）。
- **通关率目标带**（sim 验证·确定性 bot × 200 seeds/关）：教学段 ≥90%，中段 70-85%，后段 55-70%；果冻/障碍引入关允许 spike 但 ≥50%。
- **道具经济**：镇纸/洗砚由关卡三星奖励发放（无内购无体力）；每关限用各 1。

## 五、屏向与 UI

- **竖屏**（棋盘 7×9 建议·GD 可按关微调 cols∈[6,8] rows∈[8,10]）；布局：顶=目标+步数 HUD，中=棋盘，底=道具条。
- UI 全 LayoutNode：选关=`LevelPath` 水墨长卷；结算=Modal+`Particles`(confetti)+星级；飘分=`floatUp`；收集飞行=`flyTo`；主题直接用 **apollo-toon**（换皮下拉已有）。
- 消除表现：墨晕爆点（Particles/既有 fx 令牌）；卷轴引爆=行列拖尾（styleset fx 台账件）。

## 六、美术需求稿（台账雏形·真台账=推导脚本产出·风格锚引 apollo-toon 不手抄）

- 棋子：6 珠基础 + 6×横轴 + 6×立轴 + 6×朱印 + 太极丸 + 锦鲤(三期) ≈ **26 件**（128×128 透明）。
- 格层：墨渍 ×2 层、冰纹瓷 ×3 态、砚石 ×1 ≈ **6 件**。
- 场景：局内竖屏背景（水墨远山·可先吃 styleset 背景板）、长卷选关背景、菜单背景 ≈ **3 件**。
- 特效帧集：墨晕爆点/钤印/太极流转 ≈ **3 件**（styleset fx 的 sparkle/confetti 可复用）。
- UI 件：**零新增**——按钮/面板/图标全吃 styleset apollo-toon。
- 音：SynthAudio 合成为主（`docs/playbooks/audio.md` 首选路）；采样等 audio adapter 单落地后再议。
