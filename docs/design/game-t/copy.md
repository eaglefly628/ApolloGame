## 一、世界观 · 一句

少年武者「小墨」自山下拜师，执一根木棍、一条汗巾，沿水墨长卷逐章拜会五形师父（虎·鹤·蛇·豹·龙），
以三消为「运墨」，在山门到山巅的修行路上淬炼五形拳意，终至山巅出师。
