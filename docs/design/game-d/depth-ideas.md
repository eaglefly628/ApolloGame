# Game D《骰途》· 深度创意池（让"扔骰子"更复杂好玩 · 10 点子）

> owner 2026-06-29：第一层战斗（凑骰满足要求）只是地板，要更复杂。本文 = 10 个加深度的创意，
> 每个挂一个**游戏设计理念 + 参照游戏**，供 owner 挑选/组合。**正交是关键**——几个系统相乘才出复杂度（非堆砌）。

## 设计哲学锚（为什么这些能加深度·非乱加）
- **心流(Flow·Csikszentmihalyi)**：清晰目标 + 即时反馈 + 挑战≈技巧。复杂度要落在"挑战曲线"里，不是噪音。
- **有意思的决策(Sid Meier)**：好玩 = 一连串两难抉择。每个点子都要制造"选 A 还是 B"的纠结。
- **正交系统 → 涌现**：N 个独立系统给 N² 种互动（BotW 化学引擎）。深度来自相乘，不是相加。
- **玩家自调难度**：押注/契约让玩家把自己卡进心流通道（哈迪斯惩罚契约）。

## 10 个点子（按"深度落在哪层"分组）

### A. 每回合战术层（让单场战斗更耐玩）
1. **骰子操纵 · 拨/翻/进位**（参照 Dicey Dungeons / Astrea）：道具/buff 能**改一颗骰的点数**（+1、翻面=7-x、整列同色 +1）。把"听天由命"变"我能掰一掰"——运气 + 操控的张力，心流里的掌控感。
2. **押注 · 步步高**（参照 Can't Stop / Quacks of Quedlinburg 爆桶）：满足要求后可**继续掷**博取额外奖励（多抽骰/货币），但掷出"凶面/超界"就**爆掉全没**。每回合一个 push-your-luck 心跳。
3. **空间骰盘**（参照 Sagrada / Dice Throne）：战场是格子，掷出的骰要**摆到盘上**，相邻/连线有加成（同色相邻互增、一条线凑牌型）。在点数之上叠一层**位置谜题**。

### B. 涌现/连锁层（少数系统相乘）
4. **元素连锁反应**（参照 BotW 化学 / 2048 合并）：骰面在盘上**触发反应**——火骰点燃相邻木骰(变火)、水浇灭…一次摆放引发**级联**。"我把这颗放这会怎样"的涌现爽点（呼应你最早爱的元素组合）。
5. **牌型进化树**（参照 Balatro 小丑顺序 / 麻将番种）：牌型可**升级/自创**（顺子→同色顺→五行顺；解锁"镜像""五行齐"等自定义番），且**结算有顺序**（先加后乘），顺序本身是决策。

### C. 构筑/经济层（跨场积累）
6. **骰面雕刻**（参照 Dice Forge / Inscryption）：不只是"获得骰"，而是**改单颗骰的某一面**（把一颗的"2"刻成"百搭"或"+火"或"7"）。每颗骰是**可雕刻的画布**，组合爆炸、归属感强。
7. **骰子合成/升阶 + 瘦库**（参照 Dice Forge / Threes / 杀戮尖塔删牌）：两颗合成更强一颗（火 d6+火 d6→火 d8/孪生骰）；**删骰/净化**对抗敌人塞给你的**诅咒骰**。"宽而杂" vs "瘦而精"的构筑两难。
8. **蓄力/节奏骰**（参照 杀戮尖塔能量 / 炉石法力曲线）：部分强骰**用完要蓄 N 回合**才能再用。把决策从"这一手"拉长到"跨回合的节奏调度"。

### D. 局/元层（每局不同 + "再来一局"）
9. **命运牌 · 全局规则变体**（参照 杀戮尖塔进阶 / Balatro 底注 / roguelike 每日变异）：每层抽一张**命运牌**弯曲全局规则（本层：所有对子翻倍 / 掷 6 爆裂连掷 / 五行相生改相克）。每局玩法不重样，逼出新策略。
10. **契约/赌约 · 玩家自调难度**（参照 哈迪斯惩罚契约 / Cultist Simulator）：战前可接**契约**（敌血翻倍但奖励稀有）或敌人**下赌约**（"一掷满足→跳过+大奖；失败→额外伤害"）。把难度旋钮交给玩家，正好把人卡进心流通道。

### （备选·协作专属）
- **共鸣套牌**（参照 Quarriors / 麻将凑番）：跨回合**收集套**（凑齐五行齐→解锁超必杀）；双人时共鸣条**两人共享**——长线目标 + 协作。

## 怎么用（别全塞·选 2~3 根正交主轴）
- 选一个**战术层**(1/2/3) + 一个**构筑层**(6/7/8) + 一个**元层**(9/10)，三根正交轴相乘 = 足够深，又不糊。
- 每加一个先问：**它制造了新的"有意思的决策"吗？还是只是更多数字？**（后者砍掉）。
- 想更系统地挖：可跑 deep-research 把"骰子 roguelike / 心流 / 牌组构筑"的设计文献扒一遍，出带引用的综述。
