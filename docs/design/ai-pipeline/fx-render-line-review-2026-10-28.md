## 二、特效线：能用，但表现力是「圆点粒子」级，撑不起风格化特效

已有：3D 粒子 `Vfx3D`（持续发射、寿命、点 / 锥 / 球发射、重力、阻尼、吸引点、尺寸与颜色随寿命、加法 / 透明混合）、`Glow3D` 加性辉光、`Trail3D` 拖尾、`Billboard3D` 广告牌、溶解、辉光后处理、闪白、震屏；UI 层 `Particles`（纸屑 / 金币 / 星光）；2D `VisualEffect` 闭集。

实查要点：`Vfx3D` 渲染为池化的 `THREE.Points`（`src/renderer/three/vfx.ts`），**粒子只有圆点**，没有贴图；**只能持续发射，没有一次性爆发**；发射形状只有点 / 锥 / 球；没有噪声或风。也没有可复用的特效库，每个游戏手写参数。

对照要做的效果：

| 效果 | 需要 | 现状 |
|---|---|---|
| 擦火柴的火星迸出、拾取闪光、落地尘土 | 一次性爆发 | ❌ 只能用渲染绑定把发射率临时拉高再降，粗糙 |
| 火苗形状、烟团、雪花形状 | 贴图粒子 / 序列帧 | ❌ 只有圆点 |
| KayKit / 任天堂式低多边形特效（方块碎片、星形、菱形火花） | 网格粒子（每颗粒子是一个小低多边形） | ❌ |
| 整条街下雪、一片区域落叶 | 盒 / 面区域发射 | ❌ 只能用球近似 |
| 雪随风飘、火苗摇曳 | 噪声 / 风场 | ❌ |

### 缺口 V · 特效线升级（V1–V5，render-only，P3D 域）

- **A**：`Vfx3D` 增加五项可选字段，全部向后兼容（不写则行为不变）：V1 爆发（`burst{count, trigger}`，trigger 变化即发一次，同震屏的触发方式）；V2 贴图与序列帧（`texture`、`flipbook{cols,rows,fps}`）；V3 网格粒子（`mesh: 图元形状或模型部件`，实例化绘制）；V4 盒 / 面发射（`shape:'box'|'plane'` + 尺寸）；V5 噪声 / 风（`noise{strength,freq}`、`wind{x,y,z}`）。之后由 Codex 用这些字段做一份 **KayKit 风格特效库**（营火、火柴、雪、火星、尘土、拾取、魔法等，纯数据预设 + 预览），像动画库一样可匹配、可复用。
- **B**：不升级，用现有圆点粒子 + 辉光 + 绑定凑合；game628 的火与雪、KayKit 风格的特效都会显得廉价。
- **Lead 推荐 A**，顺序 V1 → V2 → V4 → V5 → V3（前四项改动小、收益最直接；V3 依赖 R1 的实例化思路，放最后）。
