## 范围与版本 1

1. 母版不可覆盖。新优化 id、derivedFrom、source/output SHA、recipe/version、原/保留帧数、实际字节、误差最坏骨/时刻/时间集均落证据。现有减帧对照组不可冒充 None 母版；完整源目录与对照库分开。
2. 新资源 spec 可选 `encoding: 'sparse-linear-v1'`。缺省原有严格校验不变，未知编码拒收；schema → AssetManager → ModelPool → M3/离线工具传播完整。
3. 稀疏 GLB 所有轨共用 frame-grid 子集，起止必留，仅 LINEAR，旋转按原生 quaternion 插值，不对 Euler 分量盲插。解码前检查端点/严格递增/原 frame-grid/有限归一值/类型/共享时间与展开预算（不高于既有 1600 万分量预算）；一次展开后仍走现有完整稠密验证与 M1。
4. 确定性区间细分：试减后比较原生世界空间全骨位置、旋转及速度，超预算插回最坏位置附近原帧，tie 取最早。速度与方向变化通过重建误差决定保帧，而非仅用瞬时速度大小。设置最大间距/迭代/样本预算；无收益或质量不达标不冒称成功。
5. 脚/脚趾/手采用更严格预算；显式接触窗优先，落脚/抬脚边界及相邻帧保护。自动推断只标候选，不当已知地面。验证接触窗内的漂移、角度与单边速度，避免中心差分抵消。
6. 质量比较同时覆盖原网格、半帧点、接触加密点和准确终点，既比较标准 sparse 直接播放，也比较引擎实际解码后播放。报告是有限验证点实测，不是连续时间数学上界，不保证修正母版本身错误。
7. 默认质量参数需在闭集 recipe 中记录：全骨位置/转角/速度预算，末端更严预算、maxGapFrames、显式 contacts（bone/start/end）。单位为米、弧度、秒；不通过时不放宽预算凑压缩率。
