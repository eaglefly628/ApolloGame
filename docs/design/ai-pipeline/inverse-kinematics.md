# E4 解析双骨 IK 与 lookAt

分段锁8e225687d（2026-10-21），依赖E2独立复查dd0374031、E3独立复查34199bb4f。沿owner已裁A的路线图E4下沉通用render-only数据解释器。已实查 registry/3D手册、AnimGraph3D、Anim3D/Pivot3D/Attach3D：它们能播放/合成/挂接，不能将双骨链末端约束到目标；本段不改游戏或反写模拟，不启动Blender。

## 数据闭集

`IK3D{chains:[{kind:"two-bone",root,mid,end,target:{entity,bone?,offset:[x,y,z]},pole?:[x,y,z],weight}],lookAt?:{bone,target,weight}}`。chains必填、0..16；无chain时须有lookAt。字段未知、空/超256字符串、非有限三元组、重复root/mid/end、坏kind均拒收；type在裸蓝图可省。载体必须有有效Model3D，动态目标可以尚未生成。

weight常量为有限0..1；参数驱动使用闭集 `{param:<同实体AnimGraph3D.params别名>,fade:<0..60秒>}`。该对象是路线图“E2参数驱动weight”的机读接线：数值clamp到0..1，Flag布尔映射0/1，State字符串不做隐式数值转换。装载时引用须存在且声明源为speed/flag；运行缺失/无效源有效权重0并一次诊断，不猜未定义开关。参数值沿E2原读取，不写图的状态，不要求图动画正在播。

常量即时生效；只有参数绑定带线性渐变包络，初始有效权重0，目标改变从当前权重重新淡入；fade0立即。未定义自由表达式/映射脚本。pole为世界坐标参考点；target.offset是目标骨骼或目标实体的局部米制偏移。字符串均引用实体真实id与实际唯一THREE.Bone名。

## 固定执行语义

- 每帧先恢复上一帧IK私有改动，再由原生动画采样当前姿态；E3挂接解析目标位置；IK先lookAt、再按chains数组顺序求解，最后E3重算挂件/拾取/相机。读取每条链目标前刷新挂件，允许前一条链移动持壶手、后一条链对准新壶把；不遍历到无限收敛，不将动画回写sim。
- 双骨采用纯函数解析位置解，root/mid/end必须依次祖先相连且链上是正的均匀局部缩放（可有静态中间骨），在root.parent坐标系求解，保留共同祖先/模型的非均匀世界变换。不能将世界矩阵TRS近似当精确解；不支持的局部剪切/非均匀骨尺度明确拒收，而非谎称1cm。
- 只改本实例root/mid局部四元数，不移动骨骼位置/缩放、不动共享模板或其它角色。pole未给时先用当前动画弯曲平面，退化时用稳定有界参考平面；不可达时取可达域最近点，最远处伸直、不翻折。零长度/坏层级/歧义骨骼/非有限矩阵一次WARN并跳过。
- weight1时可达目标末端误差须<1cm；weight0完全不干预当帧动画（不正规化/重算其四元数）。中间weight以原动画→求解姿态四元数slerp。被移除、模型换代、资产驱逐或目标失效时恢复当帧原动画，不把上帧IK姿势累计成新输入。
- lookAt沿目标骨骼局部+Z朝向目标点，在父坐标系使用原生四元数方向旋转并按同一weight混合；lookAt先行、后列的手臂链具有最终端点优先级。缺目标/缺骨/同点不造NaN、不默默看原点。
- 目标指定bone须有当前实际Model3D实例且骨骼唯一；不指定bone可用实际可绘对象矩阵，也可用无绘制实体的Transform3D作为点锚。Attach3D目标若因父不可用而隐藏，不能退回其被替代的base位置。目标不得依赖当前求解链自己的后代（自追逐），其他同实体骨骼可以作为目标。
- 世界只读，IK3D入NON_DETERMINISTIC。旧AnimState3D/E2语义保留；无IK路径保持兼容。静止求解不永久强制重绘，权重渐变/目标变化/最后一次恢复仍刷新画面与阴影；缓存按当前实体、实例代际与有界chain数收敛。拒收/降级console分级且不逐帧刷屏。
