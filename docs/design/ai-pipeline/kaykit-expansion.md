# KayKit 风格补全能力评估（不用 Tripo 类 AI 建模）（2026-10-28·⚖ 待 owner 判 A/B）

> **owner 裁（2026-10-28）**：风格锚定为 **KayKit**。问题：**不用 Tripo 之类 AI 建模**，我们能不能按 KayKit 风格补全物件，组成世界与基本元素？
> 口径：逐项对现有代码实查。

## 一、结论

**能补大部分，但要补 4 个工具（全在 `scripts/`，不动引擎运行时）。** 补不了的是「全新的有机造型」（新动物、全新外形的角色）：不用 AI 建模就只能靠人工建模或买 KayKit 的扩展包。

不用 AI 时，补全的三种手段按效率排：

1. **拼装改件**（最高效）：用 KayKit 已有部件组合出新物件（摊位 = 箱子 + 木板 + 布篷；城门 = 墙段 + 拱 + 旗），配合缩放、旋转、镜像。
2. **换色变体**：KayKit 所有物件共用一张渐变色图，颜色就是 UV 落在色图上的位置；把 UV 挪到别的色块就是一个新配色，风格天然一致。
3. **Blender 参数化生成**：仓库自有的生成脚本按风格规范出简单几何物件（栅栏、台阶、桥、路牌、平台变体），再按色图上色。

## 三、缺口与 A/B（Lead 推荐，owner 裁）

### KayKit 补全线（K1–K4，🟢 工具链，只碰 `scripts/` 与 Blender 作业）

- **A · 补齐 4 个工具**：
  - **K1** `world-kit ingest`：KayKit 包 → 统一 GLB 与目录（分类、标签、占地格、碰撞代理、色块、许可），CC0 进仓库，分批控制体积；
  - **K2** Blender 新作业 `kitbash`：输入部件清单（来源件 + 位移 / 旋转 / 缩放 / 镜像），烘焙成一个新 GLB，进目录并记来源；
  - **K3** Blender 新作业 `atlas-conform`：①换色：按「色块 → 色块」映射表改 UV；②校正：任意网格颜色吸附到最近色块、统一平涂、面数与尺度检查；
  - **K4** Blender 新作业 `generate`：只运行仓库内登记过的生成脚本（闭集、参数校验），产物必过 K3。
  - 代价约等于 M2 + M6；全部离线，运行时零改动；与动画库同一套目录、预览、盲审。
- **B · 只用 KayKit 原样物件**，缺的靠人工在 Blender 里手做。零工具代码，但每个新物件都要人做、风格靠人把关，AI 无法批量补全。
- **Lead 推荐 A**，顺序 K5 数据 → K1 → K3 → K2 → K4。

### 附带一处引擎缺口（暂不推荐做）

- **运行时 3D 多部件模板**：让 `prefab` 展开时也按生成点偏移 `Transform3D`（含 z 与朝向）。碰定序与快照，属 🔴。**Lead 推荐暂缓**：K2 离线烘焙成单个模型已能覆盖「同一个组合件到处摆」；等真有「运行时动态生成组合件」的玩法再开。

## 四、补不了的部分怎么办

- 全新外形的动物、角色、复杂有机物：人工建模，或购买 KayKit 扩展版（各包 EXTRA 版约 5 美元起，**许可是否同为 CC0 需逐包核对**），或日后在 K3 校正之后再考虑 AI 建模。
- KayKit 角色接动画库：补一张 KayKit 骨骼 → `apollo-humanoid-v1` 改名表（随 K1 一起做），之后直接用 2445 个动作。
