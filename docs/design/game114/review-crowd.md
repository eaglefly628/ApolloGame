## Explicit static-collision boundary

ORCA constrains neighbors, not static geometry. Static blocking uses the existing discrete overlap/collision solver, which has no swept collision guarantee. Empirical full-composition repro: moving circle at `(0,0)`, radius `.05`, actual/preferred velocity `(0,2)`, maxSpeed `2`; stationary neighbor at `(0,1)`, radius `.05`; vertical static box center `x=.099498743710662`, width `.01`, height `20`. ORCA chooses `(.198997487421324,1.98)` and the mover crosses the wall in one tick without endpoint overlap. The original vertical preference does not cross the wall. This is a reproduced limitation, not a safety test passing.

Owner-authorized scope does not include continuous collision detection. Demo applicability is restricted to speed `.025–.05` world units/tick, cell size `.5`, and static blockers at least `.5` thick, so this whole-wall one-step traversal is excluded. Normal-speed full collision composition was tested separately and stops at the wall. This does not establish a general guarantee for arbitrary speeds, thin geometry, crowd packing, or zero-overlap behavior.
