# ENG-02 independent review — 2026-10-09

Status: accepted after independent reproduction and verification of the fixes below. Reproductions live in `src/skills/tier2/navigation-grid.review.test.ts`; production files were not modified by the reviewer. No remaining blocking finding within the agreed navigation scope.

## Empirical findings

1. **Fixed:** periodic grid replan prevented slow units leaving their initial cell. Cell size `1`, start `(10.5,-2.5)`, goal `(14.5,-2.5)`, speed `.005`, repath period `30`: after `500` ticks, originally observed x=`10.600000000000016`. Replanning now excludes the already occupied start cell; the slow-agent test passes.
2. **Fixed:** explicit malformed graph `{nodes:null,edges:[]}` threw while reading `.length`, before validation. A further independent case found that missing derived `grid.blocked`/`grid.cost` arrays were accepted by the optional-input-grid validator and subsequently threw. Both shapes now reject/stop, with passing tests.
3. **Fixed:** existing greedy flow direction disagreed with source-cell weighted integration. Grid `3×2`, costs `[10,1,1,1,1,1]`, goal `(2.5,1.5)`: integration optimum from cell 0 is `114`; greedy diagonal first step produced `150`. Opt-in `costAware` extraction now satisfies the same cost equation, generated profiles enable it, and legacy flow behavior is preserved. Independent core/flow rerun: `69/69` tests pass. The independent profile test consumes the actual generated FlowField.
4. **Fixed:** trusting `grid.bakeKey` as adjacency-cache identity introduced hidden state. After ticking once and replacing derived graph edges with `[]`, a warm cache produced x=`10.7`, reachable=true; clearing the cache produced x=`10.6`, reachable=false from otherwise identical world inputs. Pathfinding now keys adjacency and path invalidation on a canonical serialization of all navigation-relevant graph fields. For performance it compares actual scalar/array values with an independent snapshot before reusing that key, once per graph per tick. It does not trust object identity or `bakeKey` as proof of unchanged contents. Independent cache-clear equivalence now passes.
