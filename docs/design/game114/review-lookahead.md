# PathFollow 路线方向优先复查（2026-10-09）

结论：可选 `lookAhead` 由 `PathFollow` 在当前线段前方生成期望速度，交给原 ORCA 求局部避让；未配置时保持原直奔航点行为。源码、实现测试和复查由不同执行者完成。本地未提交、推送。

依据：[RVO2 使用文档](https://gamma-web.iacs.umd.edu/RVO2/documentation/2.0/using.html)将每拍期望速度交给外部导航生成；[版本说明](https://gamma-web.iacs.umd.edu/RVO2/documentation/2.0/whatsnew.html)明确 ORCA 不包含全局路线规划或车体朝向。本修订只改善方向意图，不改动 ORCA 约束纯函数。

复查人独立复跑 path-follow + conveyor 共29项，通过；形状守卫仅存量 WARN。复查发现非闭环路线在中间航点横向偏离后可能越过航点而不切换，已修为除末点外也按航点横截面推进。独立复现由红转绿；在隔离副本将 `(pf.loop || i < len - 1)` 撤回 `pf.loop` 且先断言锚点命中，该用例重新转红。隔离场景另测：非闭环末点停靠、`onEnd` 只发一次、带 `queueId/minGap` 的间距和双跑快照一致，4项均通过。生产文件未被复查撤修操作改动。

压力演示按最终七牛一车与两条交错路线跑1200步：大车与牛碰撞圆没有穿透，全部单位远目标连续低速0步，大车完成两次端点切换；`lookAhead:6` 通过，而同场景 `lookAhead:4` 曾出现最长120步等待。数值是场景实测，不能外推成任意密度保证。既有队列 `pathProgress` 仍按到航点的欧氏距离计进度；偏离路线很远时不等于沿线投影进度，本修订未改变该既有定义。
