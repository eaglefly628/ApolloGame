## ENG-01：通用 ORCA 避让

目标：NavAgent/A* 和 FlowAgent 均可用闭集组件配置参与同一避让计算；复用现有 ORCA 纯函数，不复制算法。主程决定组件及系统接口。必须冻结旧 FlowAgent.orca/separation 的默认行为，不得让旧世界轨迹改变；不得双重执行 ORCA。

语义：先生成期望速度，避让读取稳定的同拍邻居快照，再一次性写输出速度，最后移动；邻居选择和同距排序确定；速度及 timeHorizon 用引擎 tick 口径。跨目标/体型单位相互可见。无目标、定身、到达和无路停止不应被避让意外驱动。非法数据及无解降级记录 opt-in DebugTrace，每系统每拍最多3条。ORCA 不承诺零碰撞；硬碰撞仍复用已有求解器。

验收：A* 两队迎面、A* 与流场混合、同位分离、不同半径、终点拥挤、定身/无目标、无解/非法参数、插入序颠倒、重复运行、快照恢复；整条组合零定序环告警；旧 ORCA/分离用例不变。独立复查必须撤修验红并断言锚点命中。

## ENG-02：共享 Grid based 导航数据

目标：同一份静态障碍/地形定义可供 A* 与流场消费；按不同 agentRadius 生成通行配置，单位显式选择其配置。复用 gridFromBounds/rasterizeBlocked/bakeNavGraph 和流场核，主程定义兼容接口。

数据需覆盖：地面 XZ（导航 x/y 映射 X/Z）、原点、格边长、行列、blocked 行主序、地形代价、目标、配置 id、净空半径。注意已有 NavMesh 的 minX/minZ 为格中心、FlowField 的 origin 为格边界，必须显式换算，禁半格偏移。相同数据输出 A* 图与流场障碍掩码须一致，斜向防穿角；路/草地代价需保持两种路线可比较的定义。

保留旧 NavMesh/无配置选择 NavAgent 的默认行为。障碍变化触发更新，目标变化不应重烘静态几何。失效输入、目标不可达时停止并留痕，禁沿直线穿墙兜底。

验收：同一地图 A* 与流场绕障、网格边界/半格对齐、牛可过而龟不可过的窄路、斜角夹墙、障碍更新、配置选择/切换、无路目标、旧接口回归、确定性/恢复。
