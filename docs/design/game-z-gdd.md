## 0. 一句话定位

> **一个"所有战斗都用掷骰子解决"的双人合作 Roguelike。** 两人各带一套骰子，一间间小房间往前闯，每场战斗 = 一次掷骰挑战；过关后像《哈迪斯》那样三选一拿 buff/技能；骰子凑不够就掏宝物和消耗品救场；打穿一层拿局外永久解锁，全灭就从头再来。**支持双人（主打）也支持单人。**

它把我们多轮共创的所有零件焊在了一起：
- **骰子 + 随机命中的惊喜**（你最初的核）
- **双人非对称合作**（两套骰池/buff，战斗里凑组合、互救）
- **Roguelike**（程序化房间 + 局外成长 → 结构性根治"内容枯竭 / 一次性冲动"）
- **哈迪斯式 build**（每关选 buff → 组合爆炸 ×N）
- **极简美术**（数字骰 + 贴图体素房间 + UI；战斗是抽象的，不吃美术）

## 1. 设计支柱（为什么好玩 · 情感核心）

1. **"赌一把"的心跳**：掷骰那两秒的悬念 + 翻盘的 clutch 时刻。随机给惊喜，重掷/道具给掌控——**握着运气，不是被运气摆布**。
2. **滚雪球的成长爽**：开局弱小、骰子平平；几个 buff 叠起来后，一把掷出毁天灭地的连锁——**从苟活到无双的曲线**。
3. **共渡难关的羁绊**（双人核心）：你差一个点数，我从骰池里补；你的组合不够，我掏消耗品救。**同生共死、一起拍桌、一起翻盘**。
4. **永远有"下一局"**：每局房间、buff、敌人、骰运都不同；局外解锁让每局起点都更强一点——**Roguelike 天生的复玩引擎**。

## 2. 双层核心循环

```
【局外 META 循环】（跨局 · 永久）
  开一局 → 闯关 →（胜/败）→ 带回永久货币 → 解锁新骰子/新buff/新角色 → 下一局更强 → ↺

  └─【局内 RUN 循环】（一局之内）
       进入房间 → 看敌人挑战 →【骰斗】→ 胜 → 三选一拿 buff → 选下一个房间 → … → Boss → 通层
                                      └ 败到队伍生命见底 → 本局结束

            └─【骰斗 BATTLE 循环】（一场战斗之内 · 见 §3）
                 掷骰 → 组合算伤害 → buff 加成 → 够了？胜 ： 掏道具补 → 还不够？敌人威胁、扣血、再来一轮
```

三层嵌套：**骰斗**给即时心跳，**一局**给成长弧线，**局外**给长期动力。

## 3. 骰斗（核心战斗机制 · 详细）

> 这是整个游戏的心脏。设计目标：**掷骰的惊喜 + 组合的策略 + 双人的协作 + 翻盘的 clutch**，四样齐全。

### 3.1 敌人 = 挑战条件 + 威胁
每个敌人有两个数据：
- **护甲值 / HP**：你这场要凑出的伤害总量（如 `18`）。也可以是**特殊挑战**（"凑出一个对子""总和为偶数""至少三颗 ≥4"——给敌人差异化）。
- **威胁（threat）**：你这一轮没打过，它就发动的惩罚（如 `-1 队伍生命`、`诅咒你一颗骰下回合 -2`、`自身护甲 +3` 越拖越难）。**威胁制造"快打完"的压力**。

### 3.2 骰池（玩家的"牌组"）
- 每名玩家有一套**骰池**：开局如 `3 颗标准 d6`。
- 局内可成长：**加骰**（多一颗）、**升级骰**（d6→d8→d10）、**特制骰**（改面：把 1 改成 7、全偶数骰、保底骰…）、**金骰**（伤害 ×2）。
- 骰池就是你的 build 载体，和 buff 一起定义这局的打法。

### 3.3 一轮骰斗的结算
1. **掷**：两名玩家把各自骰池一股脑掷进房间（3D 骰子在贴图体素房间里翻滚·juicy·render-only）。
2. **组合算基础伤害**：基础 = 骰子点数之和。但**牌型加成**（借 Balatro/扑克心智）让你想凑特定形状：
   - 对子 ×2、三条 ×3、四条 ×4
   - 顺子（3,4,5）+ 大额
   - 全同点（豹子）→ jackpot
   - → **"想凑形状"这件事制造了 build 空间**（buff 去强化某种形状）。
3. **buff 变换**：被动 buff 改写这次结算（"每颗 6 额外 +4""对子改 ×3""奇数无视护甲""+2 给每颗骰"…）。
4. **够了吗？** 伤害 ≥ 敌人 HP → **胜**。不够 → 进 3.4。
5. （可选机制）剩余轮数 / 蓄力：某些敌人限轮数，逼你高效。

### 3.4 不够时 → 掏道具救场（你亲口设计的那一步）
合并掷骰还差一点打不过时，玩家**消耗手里的宝物/消耗品**去改这次结果：
- `+3 符文`：给总伤害 +3
- `重掷石`：重掷任意几颗骰
- `点数置换`：把一颗骰设成任意值
- `复制`：复制队友最高的一颗骰
- `孤注`：本轮伤害 ×2，但失败则额外扣血
→ **这是"差一点点 → 掏出王牌 → 险胜"的 clutch 高潮**，是单场战斗的情绪顶点。

### 3.5 败的代价
- 全队共享**队伍生命（❤ 心）**（如开局 3 心，借哈迪斯）。敌人威胁扣心；某些机制扣心。
- **心见底 → 本局结束 → 回到局外**（Roguelike 死亡）。带回这局攒的永久货币。

### 3.6 一场骰斗走一遍（样例）
> 敌人：石巨人，HP 20，威胁"每轮存活 → 护甲 +2"（越拖越难）。

- **第1轮**：A 掷 `4,4,2`，B 掷 `5,3,1`。合并 6 颗 → 看组合：两个 4 = 对子，sum=19，对子 ×... 还差 1 点（19<20）。
- A 的 buff「炽炎」：每颗 6 +4 —— 可惜没 6。
- **掏道具**：B 用 `+3 符文` → 22 ≥ 20。**险胜！**"就差一点，幸好留了符文！"
- 若不掏：石巨人存活，护甲 +2 → 下轮要 22，更难，且可能扣心。

## 4. 双人合作（A+B 的协作 · 你亲口描述的流程）

### 4.1 合作怎么发生（你描述的 → 机制化）
- 两人**各有独立骰池 + 独立 buff + 独立道具** → **非对称 build**（你点"对子流"，我点"大数流"）。
- 战斗中**合并成一个共享攻击**：A 先掷、亮出结果，看**差什么**；B 据此决定从自己骰池里**掷几颗、怎么补**（凑缺的点数/形状）。
- 合并仍不满足 → 两人**各掏道具互救**（"你重掷，我 +3"）。
- → **组合往往要两人各出一面**（"我有俩 4，你有 4 吗？凑三条！"）——这就是"必须一起"的硬约束。

### 4.2 协作型 buff（专为双人设计）
- 「共鸣」：两名玩家掷出相同点数 → 全队 +10
- 「传递」：可把自己一颗骰送给队友用
- 「掩护」：队友扣心时，你可代受
- → 双人 build 不只是 1+1，是**互相成全**。

### 4.3 单人模式
- 单人 = 一名玩家操作**一套更大的骰池**（或同时操作双池），同一套系统单飞。
- 设计上**先做单人把核心做爽（M1），再加双人（M2）**——降风险（双人是核心系统的叠加，不是另一套）。

## 5. 成长系统

### 5.1 局内（一局之内 · 死亡清空）
| 维度 | 怎么长 | 类比 |
|---|---|---|
| **骰池** | 加骰 / 升级骰 / 特制骰 | 牌组构筑 |
| **buff / 技能** | 每过一关三选一（哈迪斯 boon） | Hades 祝福 |
| **宝物（被动）** | 商店买 / 宝箱 / 事件 | 圣遗物 |
| **消耗品** | 同上 | 药水 |
| **货币** | 战斗/事件掉落 | 金币 |

### 5.2 局外（META · 永久持久化）
- 每局带回**永久货币** → 解锁：
  - **新骰子类型**（进随机池）
  - **新 buff**（进三选一池）
  - **新消耗品/宝物**
  - **新角色/职业**（不同起始骰池 + buff 倾向 → 不同 build 路线）
  - **永久小加成**（起始多 1 颗骰、起始 +1 心…）
- → **"再来一局"的长期引擎**，也是根治"一次性冲动"的结构。

## 6. 地牢结构（Roguelike 地图）

- **一层（Act）= 一串房间，以 Boss 收尾**；多层逐渐升级（更强敌人/更高门槛/新机制）。
- **分支路径**（Slay the Spire 式）：每步在 2-3 个房间里选一个走 → 风险/收益抉择。
- **房间类型**：
  | 图标 | 类型 | 内容 |
  |---|---|---|
  | ⚔️ | 普通骰斗 | 标准敌人 |
  | ☠️ | 精英骰斗 | 更难 + 更好奖励（稀有 buff/宝物） |
  | 🛒 | 商店 | 花货币买骰/buff/道具 |
  | ❓ | 事件 | 随机抉择（风险换收益·叙事调味） |
  | 💎 | 宝箱/休整 | 拿道具 / 回心 / 升级骰 |
  | 👹 | Boss | 关底·特殊挑战机制·通层奖励 |
- **程序化**：房间序列 + 类型 + 敌人编成由**种子 PRNG** 生成（确定性·双人同步·可回放）。

## 7. Buff / 技能系统（哈迪斯式 boon · = 这游戏的 build 深度）

> 这是 build 的核心，也是引擎 game-e「小丑」系统的直接对应（Effect 修饰器）。

**类别 + 样例：**
- **加值类**：「炽炎」每颗 6 +4；「厚重」+2 给每颗骰
- **组合强化类**：「孪生」对子 ×3；「序列大师」顺子额外 +15；「豹子手」全同点伤害再翻倍
- **重掷操控类**：「博弈」每回合可重掷 1 次；「执着」可锁定骰子只重掷其余
- **协作类（co-op）**：「共鸣」同点 +10；「传递」送骰给队友
- **滚雪球类**：「贪婪」每杀一敌本局永久 +1 全骰伤害；「血契」每受伤一次 +5 伤害
- **转化类**：「点石成金」把最低骰变成最高骰；「奇偶」奇数无视护甲 / 偶数加心

**Build 原型**（玩家追求的方向）：对子流 / 大数流 / 重掷流 / 滚雪球流 / 协作同点流 …… 每局抓到不同 buff → 不同 build → **每局玩法不重样**。

---

## 8. 宝物 & 消耗品（救场 + 持有）

- **消耗品（一次性）**：重掷石、+3 符文、点数置换器、复制器、护盾药水、孤注 —— **专治"差一点点"**（§3.4 的 clutch）。
- **宝物（被动持有）**：常驻小加成 / 提供每局可用主动技 —— 像圣遗物，定义这局底子。
- 设计意图：**消耗品制造单场战斗的情绪峰值**（留着关键一掏）；宝物制造一局的策略底盘。

## 9. 心流 / 体验流程设计（你要的"新流体验"）

### 9.1 单场骰斗的心流（秒级 dopamine 链）
**掷（悬念）→ 看组合（运气揭晓）→ buff 加成（成长感）→ 差一点（紧张）→ 掏道具翻盘（紧张→宣泄）→ 击杀（爽）→ 三选一拿新 buff（变强预期）**。每一环都有明确的情绪点，环环相扣。

### 9.2 一局的弧线（分钟级）
**苟活开局**（骰子弱、如履薄冰）→ **build 起步**（攒到关键 buff）→ **滚雪球**（连锁越打越猛）→ **Boss 高潮**（检验你的 build）→ **通层/全灭**。失败也"差一点就赢"，勾着你"再来一局"。

### 9.3 新手流程（零文字教学 · 渐进解锁）
- **第 1 房**：只有"掷 + 求和打过去" → 学会掷骰。
- **第 2 房**：敌人 HP 高一点，逼你发现"凑对子能 ×2" → 学会组合。
- **第 3 房**：给一个消耗品，敌人正好差一点 → 学会道具救场。
- **首个 boon 三选一**：学会"选 buff = 定 build"。
- **首个精英 / 双人首战**：逼出协作（凑共享组合、互救）。
- → **用关卡节奏教学，不靠文字**（任天堂式）。

### 9.4 难度曲线
敌人 HP/威胁逐层递增，但**玩家 build 成长更快**（滚雪球快感）；Boss 是阶段性"考试"。**难度来自'你的 build 够不够强'，不是手指操作**——对双人/休闲友好。

### 9.5 双人社交体验
一起赌重掷、关键互救、build 互吹、险胜击掌、全灭一起捶桌 —— **协作与共情就是复玩的社交胶水**。本地同屏即可点燃。

## 10. 美术与呈现（极简 · 符合"不重美术"）

- **房间** = 小体素场景（**精美贴图体素**·§见美术铁律）；**敌人** = 体素怪物，**Boss/少量精英可用 glTF 模型**做 showcase（证明我们有导入能力·小黄鸭已验证）。
- **战斗呈现** = 3D 数字骰在房间里翻滚（juicy·render-only） + **`LayoutNode` UI**（骰池/组合/伤害/HP/buff/道具/地图）。
- **美术总量极小**：数字骰点 + 一套贴图体素 + UI。丰富度靠**贴图 + 数据**（敌人/buff/道具全是数据 + 图标），不靠建模 → **绕开高面数模型困局**。

## 11. ⭐ 架构与能力映射（CLAUDE.md 核心规则 #2 · 本文最关键一节）

> 尺子：能现有能力重组 → 摆数据（回驳新需求）；真缺口 → 下沉/报主程。**诚实分清"我能做的"和"要主程的"。**

### 11.1 回驳栏：game-e 已证明这个品类能用现成能力 + 数据搭

| 本作需要 | 现成能力（证据） | 判定 |
|---|---|---|
| buff 修饰伤害（哈迪斯 boon） | `Effect` 修饰器 + `order`（game-e 小丑链：+/×有序结算） | ✅ 摆数据 |
| 组合→伤害结算 | `EventWhen`+`Effect`+`ConditionExpr`（game-e 计分管道） | ✅ 摆数据 |
| 敌人 HP / 挑战 / 胜负 | `Resource` + `ConditionExpr`（game-e：round_score≥blind_target） | ✅ 摆数据 |
| 消耗品/宝物 | `Effect` + `CraftRecipe`（消耗触发） | ✅ 摆数据 |
| 房间/层推进 / 回合 | `GameFlow` 状态机（game-f 多关推进） | ✅ 摆数据 |
| 货币 / 心 / 计数 | `Resource` / `Flag` / `GroupCount` | ✅ 摆数据 |
| 骰子随机 | 种子 `chance`/PRNG（game-e 概率小丑·**确定性·双人同步·可回放**） | ✅ 摆数据 |
| 商店 / 事件抉择 | `Clickable`→信号→`Effect`/`CraftRecipe` | ✅ 摆数据 |

**含义**：本作主体玩法**大量可由现成能力 + 数据蓝图表达**——game-e 几乎是现成模板。这正是数据驱动宣言要的。

### 11.2 真缺口栏：要验证 / 可能报主程的

1. **骰子作为一等数据**：用什么表达"掷 N 颗 d6、得点数集合"？可能 `Resource`+`chance` 重组即可，也可能值得一个轻量 `Dice` 组件/能力。**待验证**。
2. **局外 META 持久化（存档）**：跨局保存永久解锁。**引擎是否有存档/持久层？这是真问题，报主程。** Roguelike 的命根。
3. **地牢程序化生成**：房间序列 + 分支 + 敌人编成。可能 `GameFlow` + PRNG 选表即可（game-f 已有"按 stage_idx 查编成表"先例），也可能要个 map-gen helper。**待验证**。
4. **双人输入 / 帧同步**：本地同屏双人 = 输入胶水（轻）；联机 = `net/` lockstep 地基（引擎已为此而生，但要联机基建·后期）。

### 11.3 ⚠️ 域边界（必须对 owner 讲清楚）
- **本作主体是 sim / 玩法系统**（骰斗、buff、meta、map-gen）——按契约 §0.1，sim/能力/装配是 **🔒 主程域**，不是我的 3D 渲染线域。
- **我（P3D）天然能做的**：① 整个**数据蓝图**（实体+组件+能力接线·game-z 我独占·纯数据 AI 可写）；② **3D/体素渲染**（房间、贴图体素、3D 骰子翻滚表现·我的域）；③ HUD/UI 的 `LayoutNode` 数据。
- **要主程的**：任何**新 sim 能力**（存档持久层 / 骰组件 / map-gen / 新结算算子）。
- **结论**：这游戏比"3D 盒庭"更吃主程域能力。**请 owner 裁定协作方式**——是"主程主导 sim 系统 + 我做渲染/蓝图"，还是像之前授权碰撞/资产那样**授权我跨界落部分 sim**。新能力一律走 `requests.md` 评审。

## 12. MVP 分期路线（全程 tsc+vitest+build 全绿才推）

- **M0 · 验缺口（先做·阻塞）**：核验 §11.2 四项（骰表达 / 存档 / map-gen / 双人输入）；评估 game-e 模板可直接复用多少。**这步决定哪些是摆数据、哪些要报主程。**
- **M1 · 单人垂直切片（证明核心爽）**：1 层、3 种房间（普通/精英/Boss）、骰斗核心循环、~8 个 buff、~5 个消耗品、1 个 Boss。**目标：单人能从头打到 Boss，循环成立、好玩。**
