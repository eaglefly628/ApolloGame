# game102 · 核心重定义：颜色调度（真 Pixel Flow · 3D 转面立方）

> **状态**：设计稿·待 owner 拍板（2026-07-28）。定后写实现 spec / 改原型。
> **一句话**：*转面立方 + 稀缺颜料调度*——你用**有限的彩色颜料**去清立方各面的同色格，颜料不够清所有东西，必须**分配 + 规划转化链**；清对能返还颜料续航，清错/耗尽/超时就输。爽感=一划一片倾倒破碎，策略=稀缺下的分配与路由。

## 0. 为什么重定义（诊断）

前面几版一直在调「怎么开火」（狂点→自动→点射→拖动扫射），每种都「丧失意义」——根子不在输入，在**决策太薄**：

- 清同色格**不是决策**：面上什么色就清什么色、清光，没有"该不该清"的取舍。
- **无积累/无后果**：早先做的事不改变后面什么最优，每面各自独立地清。
- 揭示宝石是被动副产物，不是你去争取的目标。

→ 爽感和策略必须从**盘面逼你做的决策**里长出来，不是从输入方式里挤。

## 1. 核心重定义：颜料调度

**唯一稀缺资源 = 颜料（pigment）**。你不是有无限子弹的炮，你是有**有限彩色颜料**的倾倒器。

- 每种颜色一格**储备**（如 红×N / 蓝×N …）。清一个同色格 = 消耗 1 该色颜料。
- 立方各面是**需求**：面上散布各色目标格，转面限时露出。你**清不完所有**——颜料不够。
- **决策来源**（这才是灵魂）：
  1. **分配**：这面红最多但你红料快空了——先清红换料，还是省红去别面？
  2. **路由/转化**：某些格清掉会**返还别色颜料**（清蓝格产红料）。你**规划转化链**让自己不断料：用富余色开路，换出稀缺色，续航去清高价值格。
  3. **优先级**：功能格/宝石/高分格值得优先花料抢；空放（异色反弹）=浪费料。
- **爽感来源**：拖动一划=沿路径一片倾倒破碎；转化返还=连锁续航的畅快；破坏率达标=通关烟花。
- **失败**：颜料全线耗尽（且没达标）/ 全局限时到 / 破坏率不足。**过关 = 破坏率 ≥ 阈值**。

> 这就是 Pixel Flow 的魂做成真核心：**稀缺彩色资源的分配与路由**，而不是"匹配颜色清格子"。

## 2. 循环（一局）

1. 立方自动转面（每面几秒）→ 露出这面的彩色目标格 + 功能格 + 转化格。
2. 顶部显示**每色颜料储备条**（稀缺可见）。
3. 你**拖动倾倒**当前色（或直接拖不同色？见 §6 待定）清同色格 → 耗料；异色→反弹浪费。
4. 清到**转化格**→ 返还别色颜料（HUD 对应色条跳动）→ 你据此规划下一步倒哪色。
5. 面转走 → 下一面。破坏率达标即通关烟花；颜料耗尽/超时未达标即输。

## 3. 决策深度的升级阶梯（= 关卡 = 数据行扩展）

- **L1 教学**：单色·料充足·转化明显（学"清X返Y"）。
- **L2 稀缺**：料变紧·必须取舍先清哪面哪色。
- **L3 转化链**：目标格要求"先攒够某色再清一片"·转化率吃紧·规划链条。
- **L4 混色（真 Pixel Pour）**：二级色格（紫/橙）要**同时耗两源色**（红+蓝→紫）→ 颜色第一次有配方深度。
- **L5 刁难**：锁格（先清某"钥匙色"解锁一片）、装甲格（耗 2 料）、变色格（每转面换色）。
- **L6**：提速 + 多色 + 缩料。

每关 = 从"颜料配额表 + 转化表 + cell 类型表"挑几行开启 + 调数值。

## 4. 复用现有原型（不推翻外壳）

保留：**3D 转面立方**、五色体素、**拖动扫射输入**（现在有意义了：倾倒稀缺料）、功能格贴图、破坏率过关、埋藏宝石=额外达成、选关菜单、3D 炮台（→ 语义变"颜料倾倒器"）、碎片物理、通关烟花。

## 5. 新增系统（这次真正要加的）

| 系统 | 内容 | 数据/解释器 |
|---|---|---|
| **颜料储备** | 每色一格数值 + HUD 条 | 数据（初始配额表）；消耗/返还在破坏结算里记账 |
| **转化格** | cell 带 `yield:{color,amount}`·清掉返还 | 数据行（cell 类型表新增 kind='convert'）+ 现有 breakVox 结算加一笔 |
| **混色格（L4+）** | 二级色格 require 两源色各 X | 数据（配方表 red+blue→purple）+ 结算判定 |
| **锁/装甲/变色（L5+）** | cell flags | 数据行 + 结算分支 |

> **数据驱动落点**：颜料配额 / 转化率 / 配方 / cell 类型全是**数据表**（对齐 manifesto）。原型阶段手写解释器验证手感；定型后下沉为 `cellEffects` / `pigmentLedger` 数据表 + 通用解释器（最弱 LLM 也能配新关）。

## 5.5 转化格怎么让玩家秒懂（可读性·关键）

问题：玩家怎么一眼知道"什么色能换什么色"？**答案：别让玩家背表，让每个转化格自解释。**

- **双色图标**：转化格身上同时穿两色——**外圈 = 要花的色**（倒这个才清得掉）、**中心核 = 返还的色**（清掉给你这个）。例：蓝格中间嵌红水滴 = 「倒蓝→换红」。配小箭头/水滴形强化方向。
- **零记忆**：规则写在格子上，不在脑子/说明表里。走现有功能格 emissiveMap 同管线（多一类双色图标）。
- **颜料条联动**：倒下去时被扣色条↓、返还色条跳一下发光 → 看着条动就确认换到了什么。
- **可学**：转化关系**固定不随机**（配得上自解释图标）；一关只 1-2 组转化；L1 转化格放大 + 一次性气泡提示，之后撤。
