# game102 · 特殊炮道具 spec（GD 出 2026-07-24 · owner 拍板：彩虹/连锁/激光三选）

> 依据：owner 2026-07-24「加彩虹炮（百搭）+ 连锁炮 + 激光炮（手动触发）三门作特殊道具·追加在备选炮之后·可强制激活」。
> 规则真相=`gdd.md`；接线遵 Lead 裁①（**先组合表达·撞墙才回 `requests.md` 报缺口·绝不游戏层自写编排**）。

## 0. 通用规则（三门共有）

- **定位**：特殊炮 = **稀有一次性道具**，不常驻补给；「强制激活」后**追加显示在补给区常规色炮之后**的「特殊炮区」（独立槽·稀有色边 + 数量 Badge）。
- **交互差异**：彩虹/连锁 = 同常规炮（点一下→上传送带→到位自动喷）；**激光 = 手动触发**（见 §3）。
- **消耗**：用一发扣一个（数量 Badge 显示）；本局用完即从特殊炮区隐去。
- **强制激活来源**（`activation` 数据·可配置·LiveOps 调）：
  | 来源 | 首发建议 | 说明 |
  |---|---|---|
  | 连击里程碑 | ✅ 开 | combo 达阈（如 x8/x15）奖 1 发 |
  | 关卡预置 | ✅ 开 | 某些关卡数据自带 N 发（教学/救场关）|
  | 激励广告 | ✅ 开 | 看广告领 1 发（保早期留存·不早付费墙）|
  | 内购/礼包 | ⏳ 后置 | Lv.20 后开 |
  | 每日免费 | ⏳ 后置 | 登录送 |
  | 调试强制授予 | ✅（authoring）| `grant(cannonType, n)` 供 balance-sim/QA 强制激活 |
- **平衡**：三门都**限量 + 弹药少**（万能/范围/直线威力大，靠稀缺维持策略），数值见各节·全 config。

## 1. 彩虹炮 🌈（百搭 · 纯数据）

- **行为**：到发射位后**无视同色过滤**，自动连喷、命中**任意存活像素块**（每发命中当前可达的任意色格·可优先"剩余最多色"以最大化清除）。
- **交互**：同常规炮（一指·护核）。
- **数值**：`ammo=12`（比常规 20 少·因万能）；限量默认每局上限 2 发。
- **能力接线（组合·无下沉）**：色炮加 `matchAny:true` 标 → `launch`/`hitbox`/`group-count` 目标筛选跳过同色判定，改「任意存活 BoardCell」。**PE 可直接组合表达。**

## 2. 连锁炮 🔗（跳弹传播 · ⚠ 可能下沉）

- **行为**：命中一格消除后，**向相邻同色格跳弹连锁**（4-邻接 flood 扩散），一次清一整片**连通同色区**。
- **交互**：同常规炮（一指）。
- **数值**：`ammo=3`（每发触发一次连锁）；限量默认每局 1-2 发。连锁上限（防一发清全屏）`chainMax=20` 格·可配。
- **能力接线（先试组合·撞墙报缺口）**：
  - **先试**：命中 → `effect-apply` → 对相邻同色 BoardCell 递归/队列触发消除（`event-when` 级联 + 邻接查询）。
  - **⚠ 预判缺口**：4-邻接**连通区 flood 传播**很可能现有能力表达不了（`group-count` 是全局按色计数·非"连通区"；无邻接 flood 解释器）。**PE 实证撞墙 → 回 `docs/design/game102/requests.md` 报缺口**：候选下沉 `flood-clear`（确定性·邻接连通消除·可复用于任何"连锁/连通消"玩法）。**在裁决前不游戏层自写 flood 散逻辑。**

## 3. 激光炮 ⚡（手动触发 · ⚠ 手动瞄准态可能下沉）

- **行为**：**不自动发**。玩家对局中**手动激活**：点特殊炮区的激光道具 → **进入瞄准态**（高亮可选行/列）→ 点选一行或一列 → **发射激光**，清掉该行/列的**同色**像素块（首发默认同色·护核；"任意色"作更强付费变体后置）。
- **交互（新增·仅此道具）**：`点道具 → aim 态 → 选行/列 → 触发`。区别于一指自动核心——**这是本作唯一手动瞄准交互**，owner 明确要「运营中手动触发」。
- **数值**：`charges=1`（一次一发·限量）；`axis` 可配（row|col|both）；目标色 = 瞄准线上"剩余最多的同色"或玩家二次点选的色（首发取"最多色"·省一步）。
- **能力接线（先试组合·撞墙报缺口）**：
  - **先试**：道具 `clickable` → 发 `aim:laser` action 置瞄准 Flag → 行/列热区 `clickable` → 发 `fire:laser:{axis,index}` action → `effect-apply` 清该行列同色 BoardCell。
  - **⚠ 预判缺口**：**手动瞄准态（aim mode）+ 行列热区选择**的输入编排，现有 `clickable`+action+Flag **可能拼得出但较重**；PE/PUI 会审——撞墙 → 回 `requests.md` 报缺口（候选：一个通用「aim-target 瞄准选择」输入能力）。**UI 侧的瞄准高亮/行列热区** = PUI（LayoutNode overlay 或 render 高亮·会审归属）。

## 4. UI 放置（补给区增量 · 报 PUI）

- 补给区常规色炮之后**追加「特殊炮区」**：每门一个槽·稀有色边 + 数量 Badge（`Badge`）·可点（彩虹/连锁=发射·激光=进瞄准态）。
- 激光瞄准态的**行/列高亮 overlay + 热区**：PUI/PE 会审归属（LayoutNode overlay vs render 层）。
- 基准更新：`ui-layout-spec.html` 补给区加特殊炮区 → 增量工单 **REQ-G102-UI-2** 派 PUI。

## 5. 数值总表（首发基线·全 config）

| 炮 | 触发 | 弹药/次数 | 每局上限 | 作用 | 稀有 | 接线 |
|---|---|---|---|---|---|---|
| 彩虹 🌈 | 自动 | ammo 12 | 2 | 命中任意色 | 稀有 | 组合·无下沉 |

## 6. 验收剧本（GD 补 · 见 `acceptance/06~08`）

- `06-rainbow-any-color`：彩虹炮命中异色格（remain.<其它色> 下降）。
- `07-chain-flood`：连锁炮一发清整片连通同色（remain 该色连通区归零·非连通同色不受影响）。
- `08-laser-line-manual`：手动 aim→选列→清该列同色（该列同色归零·他列不动）。

## 7. 边界与红线

- 三门皆**数据+现有能力**优先；连锁/激光撞墙走 `requests.md` 报缺口（Lead 裁·spec 亲笔·Opus 施工），**在此之前不游戏层自写 flood/aim 散逻辑**。
- 强制激活/掉率/数值全走 config（LiveOps 可调）；随机走种子 PRNG（禁裸 random）。
- play-field 行为=PE render 层；特殊炮区 UI=PUI；跨域走 requests.md。
