## 0. 一句话定义

**带容量限制的动态颜色匹配 + 队列调度谜题**：把"发射器"按正确的**颜色 / 顺序 / 时机**投上环绕像素画的传送带，让它们绕行时消掉暴露的同色像素，在有限的传送带容量 + 5 个等待槽内做流量调度，清空整幅画即胜、资源死锁即负。**核心是动态流量管理（Traffic Management），不是手速、也不是静态消除。**

## 1. 底层操作循环

```
点击部署 → 传送带流动 → 自动索敌消除同色 → 缓冲区回收 → （再调度）
```

## 2. 元素定义

| 元素 | 说明 |
|---|---|
| **中央像素画** | 由多种颜色方块（体素格）构成的图案。每格有颜色 + 1 点 hp。清空全部 = 胜利。 |
| **发射器（射击器/炮台/打蛋器）** | 带**一种颜色** + 头顶**弹药数字**。部署后进入传送带绕行，**自动**击破**与自身同色**的暴露像素格。图标 = 圆角方体 + 顶部两根竖柱 + 面上动态弹数（实机为带色动物/打蛋器模型）。 |
| **传送带轨道** | 环绕像素画一周的跑道（圆角矩形·有向·持续移动）。发射器从**弹簧口（左下~7点）出发**，绕行一圈。**有严格容量上限**（见 §4）。 |
| **等待槽（缓冲区）×5** | 屏幕底部 5 个缓存槽，存放"绕完一圈但弹药未耗尽"的返回发射器。点击槽中发射器 → 重新推入传送带。 |
| **待发弹库（池）** | 等待槽下方的待部署发射器队列。**每关的队列内容 + 顺序 = 关卡设计**（有意安排·非随机）。取走一个 → 后面依次前推补位。 |

## 3. 消除 + 弹药系统

- **颜色匹配**：发射器**只能消除与自身同色**的像素格（异色不误伤）。
- **过位剥离（次序依赖）**：发射器绕行时，只打**当前所经这条边、外沿暴露的**同色格——从**外向里**一层层啃。像素层叠/包裹排列，内层被外层挡住时打不到，必须先清外层暴露内层。
- **弹药 = 可消同色数上限**（头顶数字）。**每消除一格 −1**。
- **弹药归零 → 发射器物理退场**（消失·不占等待槽）。
- **选错色 / 该边无暴露同色**：绕一圈打不到任何同色 → 弹药不减、满弹返回等待槽。

## 4. 空间与调度模型（核心难点）

- **传送带容量上限**：轨道上**同时容纳的发射器数量有严格上限**。**投放数量 / 顺序错误 → 轨道拥堵**。
- **等待槽回收**：发射器绕完一圈**仍有弹药**（如同色被别色包围、这一圈没打到）→ **退出传送带、落入一个空等待槽**；玩家**择机再点它 → 重新送回传送带**。
- **优先级调度**：玩家在**有限缓冲（5 槽）+ 有限管道（传送带容量）**内，对不同颜色的处理进程排优先级。
- **资源验算**：实时权衡"可用发射器剩余弹药总量 vs 目标同色格数"。**过量 / 错序投放 → 无效发射器占满传送带 + 等待槽 → 拥堵死锁**。

## 5. 状态判定

- **胜利（Win）**：中央所有像素格被清空。
- **失败（Fail = 资源死锁 / Deadlock）**：**传送带达到容量上限 且 5 个等待槽全部填满**。此刻既无正在输出的发射器、也无法部署新的 → 判负。

## 6. ⭐ 核心经济：弹药守恒

- **全部发射器的弹药之和 == 像素画全部体素格数**（出的子弹总数 == 要消的格子总数·**精确相等·零冗余**）。
- ⇒ 必须让**每一发都打在暴露的同色格上**（不空过、不带弹堵槽），且**按外→内暴露顺序 + 对应色**投放，才能清完全盘且不触发死锁。**这是谜题内核**：确定性资源调度（守恒进 hash·可复算·天然契合确定性引擎）。

## 7. 操作（输入）

- **部署**：点击待发弹库 / 等待槽中的发射器 → 送上传送带（从弹簧口入场）。取走后队列前推补位。
- **回收再部署**：点击等待槽中的返回发射器 → 重新推入传送带。
- （无拖拽、无手动瞄准——发射器**自动**索敌开火。）

## 8. 关卡设计约束（authoring）

1. **Σ(发射器弹药) == Σ(像素格数)**（守恒·出题即校验）。
2. 像素图分**层叠/包裹**结构 → 隐含**外→内**的正确清除序。
3. **待发弹库的内容 + 顺序**是关卡的核心难度旋钮（有意编排的出场序）。
4. 每关分段推进 `x/5`（实机左下角）。
5. 画内可嵌 🔑钥匙 / 🔒锁块等目标/解锁件（关型变体）。

## 9. 引擎实现映射（现状 → 缺口·详见 core-experience-v2 §3）

## 附录 A · ⚠ 研究稿中的「连线解谜」= 另一款游戏（**不属于 game102·不实现**）

owner 提供的研究稿末段描述了一套**《Flow Free》式「拖拽连接同色端点、填满网格」的连线解谜**（`M×N 网格 / CellType Endpoint·Path / Connections 4-bit 位掩码 / OnPointerDown-Drag-Up 拖拽 / SequenceIndex 回溯·截断 / 端点连通判定 / 16 图集管道渲染`）。
