## 0. 设计目标

1. **易上手**：一指点击，自动瞄准，零文字教学。
2. **难精通**：容量 + 队列 + 连击三层隐藏深度。
3. **上头**：每次消除都有强反馈（粒子 + 震屏 + 音效 + 数字飘字）。
4. **可运营**：为关卡、经济、变现、赛季预留扩展位。

**一句话体验**：*「把颜色倒进对的地方，看它啪地一下消失。」*

## 1. 核心循环（Core Loop）

```
        ┌─────────────────────────────────────────┐
        │                                           │
        ▼                                           │
  观察棋盘颜色 → 点击补给区取色炮 → 色炮跳上传送带 → 抵达发射位
        ▲                                           │
        │                                           ▼
   清空棋盘/进入下一关 ◄── 同色消除(爽!) ◄── 向中央同色方块开火
        │                                           │
        │              弹药打光 → 滑入待命槽(5) ─────┘
        │                     │
        └──── 再次点击 → 跳回传送带补一轮火 ◄────────┘
```

**微循环（秒级）**：点击 → 取色 → 上带 → 开火 → 消除反馈。
**中循环（局级）**：清空一屏方块 → 结算连击/得分 → 下一波 / 通关。
**宏循环（日级）**：通关得金币 → 抽皮肤/升道具 → 每日任务 → 回归。

## 2. 核心构件规则

### 2.1 传送带 Conveyor
- 一条移动带（截图为**左侧竖向**滑轨），承载「色炮」到达发射位。
- **容量上限**：`CONVEYOR_CAP = 5`（可配置·截图 HUD 显示「5/5」）。满则新色炮需等待前方消耗。
- 到达发射位的色炮**自动向中央同色像素块开火**，无需选目标。

### 2.2 色炮 Cannon（原作皮=兔子；我们原创换皮，见 §9）
- 属性：`{ color, ammo }`。默认 `AMMO_PER_CANNON = 20`（**实机校准**·截图单位肚子标「20」）——单位是**连喷一长串**同色弹，而非点射。
- 只攻击与自身颜色相同的中央像素块。
- 弹药打光后**滑入待命槽**，等待玩家再次点击复用（复用即重新装满弹药）。

### 2.3 中央像素画棋盘 Pixel Picture Board（核心内容模型）
- 棋盘=**一整幅像素画**（截图为鲸鱼/海豚·蓝白青海洋色），由带颜色的像素块拼成；每块有 `hp`（承受几发同色弹）。
- 被同色弹打到 `hp` 归零即消失；**清空全部像素块 = 通关**。清除过程中画面即是这幅画（themed art）。
- **一张像素图 = 一关数据**——这是低成本可批产的内容引擎（关卡=位图+调色板+特殊件坐标），也是收集/图鉴动机的来源。

### 2.4 特殊件：金钥匙 & 宝箱门（**关型变体·非通用核心**）

> **定位澄清（owner 2026-07-24）**：金钥匙/宝箱门源自实机单张「Whale Level」——它是**一种「关卡目标变体」（关型之一）**，**不是每一关都有的通用核心**。
> 通用核心 = 点击→色炮上传送带→自动喷同色→**清一整幅像素画**。钥匙/门作为可选关型丰富目标层，不做强制核心（MVP 可后置）。

- **金钥匙 Key**：棋盘上散布若干把（截图约 8 把）。作为**收集目标件**——清到/收集钥匙推进关卡目标（如开启宝箱门）。数据=像素坐标 + `key` 标记。
- **宝箱门 / 目标计量 Door**：棋盘中央一扇带计数（截图「100」）的宝箱双开门——作为**关卡目标/奖励计量**（集满钥匙或清够进度→开门发奖）。数据=位置 + 目标值 + 奖励。
- 二者均为**数据摆放**（坐标+类型+目标值），由现有能力解释（见 capability-plan §2/§3），不写游戏层散逻辑。

> **⭐ 解谜层（owner 2026-07-23 点明·核心深度所在）**：钥匙不是「随便清就能拿」——它嵌在像素画里，
> 玩家要**选对颜色、按对顺序**把「通往钥匙的像素」打掉、命中钥匙；集齐钥匙 → 门才开 → 过关。
> 这带来三重决策：① **颜色取舍**（先打哪色能露出钥匙周边）；② **顺序/路径**（别把垫脚色浪费掉、别堵死通路）；
> ③ **弹药预算**（每炮 20 发·容量 5·配合待命槽择机齐射）。→ 关卡设计=**把钥匙藏在需要「正确解法」才能打到的位置**，
> 而非均匀铺色。这是本作从「爽快消除」升级为「像素解谜」的关键，也是关卡可设计性/图鉴收集的来源。

### 2.5 待命槽 Waiting Slots
- **5 个**固定槽位（`SLOTS = 5`·截图底部 5 空槽已确认）。
- 打光的色炮进入槽位；点击槽位让其**跳回传送带**并**重新装满弹药**补一轮火。
- 用于**堆叠、排序、择机齐射**——策略层核心。

### 2.6 连击与突破上限（技巧天花板）
- 连续快速消除累积 **Combo**，Combo 提升得分倍率。
- 手速够快时可**临时突破容量上限**，把在带+待命单位堆到 **10 个**（`BURST_CAP = 10`），实现「齐射救场」。
- 突破状态有短暂时间窗，逼迫玩家做手速决策。

## 3. 数值表（首版基线，均可配置）

| 参数 | 键名 | 基线值 | 说明 |
|---|---|---|---|
| 颜色种类 | `COLOR_COUNT` | 4（截图本关）→ 6（后期）| 越多越难 |
| 传送带容量 | `CONVEYOR_CAP` | 5（实机「5/5」）| 满则等待 |
| 待命槽数 | `SLOTS` | 5（实机确认）| 策略层 |
| 每炮弹药 | `AMMO_PER_CANNON` | **20**（实机「20」）| 连喷一长串·命中同色 -1 |
| 连击突破上限 | `BURST_CAP` | 10 | 手速奖励 |
| 像素块血量 | `CUBE_HP` | 1（普通）/ 2-3（硬块）| 需多发 |
| 传送带速度 | `BELT_SPEED` | 90 px/s | 随关卡加速 |
| 连击窗口 | `COMBO_WINDOW` | 1.5s | 内消除续连击 |
| 单次消除得分 | `SCORE_CLEAR` | 10 × combo | — |
| 关卡钥匙数 | `KEYS_PER_LEVEL` | 0-8（截图 8）| 收集目标件 |
| 宝箱门目标值 | `DOOR_TARGET` | 100（截图）| 目标/奖励计量 |
| 关卡步数/时限 | `LEVEL_LIMIT` | 步数或倒计时 | 二选一 |

### 3.1 难度曲线（Lv.1-20 示意）
| 关段 | 颜色数 | 方块数 | 带速 | 引入机制 |
|---|---|---|---|---|
| 1-3 | 3 | 8-12 | 1.0x | 教学：点击→消除 |
| 4-7 | 4 | 12-18 | 1.1x | 待命槽排序 |
| 8-12 | 4-5 | 18-26 | 1.2x | 硬块(hp2)、连击 |
| 13-17 | 5 | 26-34 | 1.3x | 隐藏图案层 |
| 18-20 | 6 | 34-42 | 1.4x | 突破齐射救场关 |

**Fail 点设计**：18-20 关刻意制造「差一点就死局」的场面 → 触发续命 offer（见 §6）。

## 4. 失败与胜利条件

- **胜利**：清空全部中央像素块（基础目标）；含特殊件的关卡另可要求**集齐金钥匙 / 开启宝箱门（达 `DOOR_TARGET`）**。
- **失败**：
  - 步数/时限用尽仍有方块；或
  - 传送带 + 待命槽全满且无可消除颜色（死锁）。
- 失败进入结算：可看激励广告复活 / 续命 offer / 重来。

### 5.2 视觉风格
- **明快卡通像素风**：饱和高对比色、圆角像素方块、Q 版色炮。
- 颜色语义清晰（色盲友好：颜色 + 形状/图标双编码）。
- 字体：像素/圆润游戏字体（如 Press Start 2P / Fredoka）。

### 5.3 反馈（Juice）清单（必做）
- 消除：**真3D 物理碎片迸溅 → 落到下方平台弹跳/堆叠**（owner 2026-07-24 拍板 B·雕刻碎片感·spec `fx-3d-debris.md`·P3D 域·render-only 不影响 sim）+ 缩放弹出 + 得分飘字。
- 连击：屏幕边缘光晕 + Combo x N 大字 + 升调音效。
- 突破上限：全屏色带闪光 + 慢动作瞬间。
- 上带/入槽：Q 弹缓动（ease-back）。
- 失败：轻微灰屏 + 震动。

## 6. 商业化框架（按关分层，保护早期留存）

| 触发点 | 形式 | 设计意图 |
|---|---|---|
| Lv.10 | 激励视频 → 双倍金币 | 培养看广告习惯 |
| Lv.20 | 内购：移除强制广告 | 转化首充 |
| 失败点 | $6.99 fail offer（续命/免损生命）| 高付费意愿点变现 |
| 结算 | 激励视频复活 | 广告库存变现 |
| 商店 | 皮肤 / 主题 / 道具礼包 | 长期 ARPU |

**原则**：早期（1-9 关）零打扰，先让玩家爱上手感。
