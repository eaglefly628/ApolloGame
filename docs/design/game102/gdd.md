# 《色流工坊 / Pixel Pour》核心玩法设定文档（GDD）

> 代号：Pixel Pour ｜ 版本：v1.0 ｜ 日期：2026-07-23
> 品类：混合休闲益智 ｜ 平台：移动端竖屏 ｜ 参考：Pixel Flow (Loom Games / Scopely)
> 本文定义**核心玩法复刻**所需的规则、数值、界面与商业化框架。

---

## 0. 设计目标

1. **易上手**：一指点击，自动瞄准，零文字教学。
2. **难精通**：容量 + 队列 + 连击三层隐藏深度。
3. **上头**：每次消除都有强反馈（粒子 + 震屏 + 音效 + 数字飘字）。
4. **可运营**：为关卡、经济、变现、赛季预留扩展位。

**一句话体验**：*「把颜色倒进对的地方，看它啪地一下消失。」*

---

## 1. 核心循环（Core Loop）

```
        ┌─────────────────────────────────────────┐
        │                                           │
        ▼                                           │
  观察棋盘颜色 → 点击补给区取色炮 → 色炮跳上传送带 → 抵达发射位
        ▲                                           │
        │                                           ▼
   清空棋盘/进入下一关 ◄── 同色消除(爽!) ◄── 向中央同色方块开火
        │                                           │
        │              弹药打光 → 滑入待命槽(5) ─────┘
        │                     │
        └──── 再次点击 → 跳回传送带补一轮火 ◄────────┘
```

**微循环（秒级）**：点击 → 取色 → 上带 → 开火 → 消除反馈。
**中循环（局级）**：清空一屏方块 → 结算连击/得分 → 下一波 / 通关。
**宏循环（日级）**：通关得金币 → 抽皮肤/升道具 → 每日任务 → 回归。

## 2. 核心构件规则

### 2.1 传送带 Conveyor
- 一条从右向左（或下往上）移动的带子，承载「色炮」到达发射位。
- **容量上限**：`CONVEYOR_CAP = 6`（可配置）。超过则新色炮无法上带，需等待前方消耗。
- 到达发射位的色炮**自动向中央同色方块开火**，无需选目标。

### 2.2 色炮 Cannon（对应 Pixel Flow 的「小猪」）
- 属性：`{ color, ammo }`。默认 `AMMO_PER_CANNON = 3` 发。
- 只攻击与自身颜色相同的中央方块。
- 弹药打光后**滑入待命槽**，等待玩家再次点击复用。

### 2.3 中央像素方块 Pixel Cubes
- 一组带颜色的方块（可排成图案）。每个方块有 `hp`（承受几发同色弹）。
- 被同色弹打到 `hp` 归零即消失。清空全部方块 = 通关。
- 支持**分层/图案**：清空后露出隐藏图案（差异化钩子）。

### 2.4 待命槽 Waiting Slots
- **5 个**固定槽位（`SLOTS = 5`）。
- 打光的色炮进入槽位；点击槽位可让其**跳回传送带**补一轮火（重置弹药需消耗一次「补给」或直接复用，见 2.5）。
- 用于**堆叠、排序、择机齐射**——策略层核心。

### 2.5 连击与突破上限（技巧天花板）
- 连续快速消除累积 **Combo**，Combo 提升得分倍率。
- 手速够快时可**临时突破托盘上限**，把待命+在带单位堆到 **10 个**（`BURST_CAP = 10`），实现「齐射救场」。
- 突破状态有短暂时间窗，逼迫玩家做手速决策。

## 3. 数值表（首版基线，均可配置）

| 参数 | 键名 | 基线值 | 说明 |
|---|---|---|---|
| 颜色种类 | `COLOR_COUNT` | 4（新手）→ 6（后期）| 越多越难 |
| 传送带容量 | `CONVEYOR_CAP` | 6 | 超出需等待 |
| 待命槽数 | `SLOTS` | 5 | 策略层 |
| 每炮弹药 | `AMMO_PER_CANNON` | 3 | 命中同色方块 -1 |
| 连击突破上限 | `BURST_CAP` | 10 | 手速奖励 |
| 方块血量 | `CUBE_HP` | 1（普通）/ 2-3（硬块）| 需多发 |
| 传送带速度 | `BELT_SPEED` | 90 px/s | 随关卡加速 |
| 连击窗口 | `COMBO_WINDOW` | 1.5s | 内消除续连击 |
| 单次消除得分 | `SCORE_CLEAR` | 10 × combo | — |
| 关卡步数/时限 | `LEVEL_LIMIT` | 步数或倒计时 | 二选一 |

### 3.1 难度曲线（Lv.1-20 示意）
| 关段 | 颜色数 | 方块数 | 带速 | 引入机制 |
|---|---|---|---|---|
| 1-3 | 3 | 8-12 | 1.0x | 教学：点击→消除 |
| 4-7 | 4 | 12-18 | 1.1x | 待命槽排序 |
| 8-12 | 4-5 | 18-26 | 1.2x | 硬块(hp2)、连击 |
| 13-17 | 5 | 26-34 | 1.3x | 隐藏图案层 |
| 18-20 | 6 | 34-42 | 1.4x | 突破齐射救场关 |

**Fail 点设计**：18-20 关刻意制造「差一点就死局」的场面 → 触发续命 offer（见 §6）。

## 4. 失败与胜利条件

- **胜利**：清空全部中央方块（或达成关卡目标图案）。
- **失败**：
  - 步数/时限用尽仍有方块；或
  - 传送带 + 待命槽全满且无可消除颜色（死锁）。
- 失败进入结算：可看激励广告复活 / 续命 offer / 重来。

## 5. 界面与交互（UI / UX）

### 5.1 竖屏布局（自上而下）
```
┌──────────────────────────┐
│ [关卡] [得分]     [暂停]  │  顶部 HUD
├──────────────────────────┤
│                          │
│     中央像素方块阵         │  目标区（可拼图案）
│     ■ ■ ■ ■ ■            │
│     ■ ■ ■ ■ ■            │
│                          │
├──────────────────────────┤
│ ▶ [炮][炮][炮] ...  传送带 │  传送带（发射位在左端）
├──────────────────────────┤
│ 待命槽: [ ][ ][ ][ ][ ]   │  5 槽
├──────────────────────────┤
│ 补给区: 🔴 🟡 🔵 🟢       │  点击取色炮
└──────────────────────────┘
```

### 5.2 视觉风格
- **明快卡通像素风**：饱和高对比色、圆角像素方块、Q 版色炮。
- 颜色语义清晰（色盲友好：颜色 + 形状/图标双编码）。
- 字体：像素/圆润游戏字体（如 Press Start 2P / Fredoka）。

### 5.3 反馈（Juice）清单（必做）
- 消除：方块碎裂粒子 + 缩放弹出 + 得分飘字。
- 连击：屏幕边缘光晕 + Combo x N 大字 + 升调音效。
- 突破上限：全屏色带闪光 + 慢动作瞬间。
- 上带/入槽：Q 弹缓动（ease-back）。
- 失败：轻微灰屏 + 震动。

## 6. 商业化框架（按关分层，保护早期留存）

| 触发点 | 形式 | 设计意图 |
|---|---|---|
| Lv.10 | 激励视频 → 双倍金币 | 培养看广告习惯 |
| Lv.20 | 内购：移除强制广告 | 转化首充 |
| 失败点 | $6.99 fail offer（续命/免损生命）| 高付费意愿点变现 |
| 结算 | 激励视频复活 | 广告库存变现 |
| 商店 | 皮肤 / 主题 / 道具礼包 | 长期 ARPU |

**原则**：早期（1-9 关）零打扰，先让玩家爱上手感。

## 7. 元系统与 LiveOps（预留）

- **金币经济**：通关/看广告获取，用于皮肤、道具、续命。
- **道具**：炸弹（清一片）、彩虹炮（打任意色）、扩容（+1 待命槽/回合）。
- **每日任务 & 登录奖励**：拉回归。
- **皮肤/主题**：色炮外观、方块主题、背景。
- **赛季 / 排行榜 / 限时活动**：LiveOps 长线。

## 8. 技术与实现（MVP 范围）

**本次 MVP 复刻范围**（对应设计参考原型 `prototype.html`；正式落地形态与能力映射见 `capability-plan.md`）：
- ✅ 传送带 + 容量
- ✅ 色炮（颜色 + 弹药）+ 自动同色开火
- ✅ 中央方块阵 + 同色消除
- ✅ 5 待命槽 + 点击复用
- ✅ 连击计分 + 突破上限（堆到 10）
- ✅ 消除粒子 / 飘字 / 震屏反馈
- ✅ 通关 → 下一关，难度递增
- ⬜（后续）广告/内购、皮肤、每日任务、后端

**数值全部走配置常量**，便于调参与 A/B。
