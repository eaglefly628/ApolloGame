交接说明（给 PUI）

本稿 = GD 布局基准，非最终 UI 代码（GD 零代码 + UI 铁律）。请 PUI：

  1. 据本稿出 .dc.html 视觉稿（字体/渐变/纹样/配色以卡通像素风为基·「稿=1:1 复刻基准」铁律）。
  2. 四屏用 LayoutNode 纯数据实装；写世界=action 信号入队（handler 不塞自由逻辑/DOM）。
  3. 待命槽/补给的交互层归属（render+clickable vs LayoutNode）请 PUI/PE 会审定夺——本稿标为待定项。
  4. 若实装中发现缺控件/表达不了 → 走 requests.md 报 PUI，绝不手写逃生。
