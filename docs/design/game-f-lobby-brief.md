# Game F · 局外大厅 UI 简报(给 Cloud Design / 前端原型)

> 主策划 ｜ 2026-06-13 ｜ **派给 Cloud Design 做可点击原型**。
> 配套:玩法见 `docs/game-design/game-f-cards-and-decks.md`(卡牌哲学)、`game-f-deck-spec.md`(10 套牌组/卡面)、`game-f-economy-market.md`(经济/市场/天梯)、`game-f-coop-ui-brief.md`(局内合作 UI,姊妹篇)。

---

## 〇、定位 & 范围(先读)

- **这是「局外大厅」** —— 玩家进入一局攻岛**之前**待的地方:社交、组队、组牌、逛商城、看天梯。
- **纯前端原型,数据全假(mock)即可。** 它属**服务·账号层,与确定性引擎完全解耦**(引擎只在开局时收一份"牌组数据"输入)。本原型**不连引擎、不做真实联机/账本**——目标是把**信息架构 + 视觉基调 + 交互流**走查清楚,为后续真实接入打样。
- **交付** = 一个可点击走查的 Web 原型(React + 假数据),覆盖下列 7 屏 + 导航闭环。像素/古风美术可先用占位色块/emoji。

## 一、信息架构 / 导航

```
┌─ 顶栏(常驻):主公头像·称号 | 段位徽章 | 货币(金/卡券/钻) | 设置 ─┐
│                                                                      │
│   [大厅 Home] [组队 Party] [牌组 Decks] [收藏 Collection]            │
│   [商城/市场 Market] [天梯 Ladder]                                   │
│                                                                      │
│   右侧常驻好友栏(可收起)  +  右下角邀请/通知弹窗                    │
└──────────────────────────────────────────────────────────────────────┘
```

主 CTA(贯穿大厅)= **「渡海攻岛」**(快速匹配 / 邀好友组队)。

---

## 二、视觉基调

- **主题**:三国列强**渡海征日**。首页背景 = 一张**待征服的日本海岛地图**(战国城寨星布),三面有孙/刘/曹的登陆船队。史诗 + 古风。
- **风格**:像素三国 + 古风卷轴 UI 框(木质/绢帛/印章/水墨点缀);战国侧用日式元素(家纹/天守)做敌方氛围。
- **配色**:绢帛底(暖米)+ 水墨黑;势力色——**蜀=青绿 · 魏=靛蓝 · 吴=朱红 · 群=玄灰**;稀有度——白/绿/蓝/紫/橙(炉石同制式)。
- **氛围词**:大气、可收集的"图鉴欲"、社交热闹但不喧宾夺主(主角是"我的牌组 + 我的征程")。

## 三、逐屏设计

```
├──────────────────────────────────────────────┬─────────────────┤
│                                              │  好友(在线 5)   │
│        [ 日本海岛地图·背景大图 ]              │  🟢 张飞_关张  对战中│
│        战国城寨标记 + 三方登陆船队            │  🟢 周瑜       大厅 │
│                                              │  🟢 孔明       组队中│
│   ┌─────────────────────────────┐            │  ⚫ 司马懿     离线 │
│   │   ▶ 渡海攻岛(快速匹配)      │  ← 主CTA   │  ⚫ 吕布       离线 │
│   └─────────────────────────────┘            │  [+ 添加好友]    │
│   [ 邀好友组队 ]  [ 单人(AI补位) ]           │                 │
│                                              │  最近队友 ▸      │
```

### S2 · 组队房间(Party,3 人攻岛)
```
┌─ 战役:九州征伐 · 段位:黄金 · 终盘 Boss:???(轮换) ───────────┐
│                                                                  │
│   席1(房主/我)        席2                 席3                   │
│  ┌──────────┐       ┌──────────┐        ┌──────────┐            │
│  │ 🪖赵云    │       │  + 邀请   │        │ 🤖 AI     │            │
│  │ 势力:蜀  │       │  好友/匹配 │        │ 势力:曹  │            │
│  │ 牌组:虎豹│       │  /AI补位  │        │ (自动)   │            │
│  │ ✅已准备 │       │  (空席)   │        │           │            │
│  └──────────┘       └──────────┘        └──────────┘            │
│   选势力:[蜀][魏][吴]   选牌组:[虎豹铁骑 ▾]   [更换 ▸S4]        │
│                                                                  │
│   岛屿/难度:[九州 ▾]   规则:贡献度排名 → 岛主                  │
│                                                                  │
│   队内聊天 ▸                         [ 准备 ✅ ]  [ 开始(全员ready) ]│
└──────────────────────────────────────────────────────────────────┘
```
- **要点**:空席可「邀好友 / 快速匹配 / AI 补位」(用户:人不全用 AI 替换);每人**各选势力 + 各选牌组**(势力只是出生倾向,牌组才是身份);全员 ready 才能开始。

### S3 · 好友 & 社交(可做成 S1 右栏的展开页)
- 好友列表:在线状态(大厅/组队/对战/离线)、段位、当前牌组流派小标。
- 操作:邀请进房、私聊、查看主页/战绩、加好友(搜 ID/推荐/最近队友)。
- **假数据**:给 8–12 个假好友 + 状态即可。

```
┌─ 我的牌组(8) ──────────────────────[+ 新建牌组] [按 流派▾ 分类]─┐
│  分类标签:[全部][速攻][连携][控制][单核][经济][降将][刺客]…     │
│ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐              │
│ │ 虎豹铁骑 ⚔️   │ │ 桃园结义 🛡️  │ │ 白衣渡江 🗡️  │  …           │
│ │ 魏·速攻      │ │ 蜀·连携      │ │ 刺客·斩首    │              │
│ │ 钥匙:虎豹骑令│ │ 钥匙:桃园三义│ │ 钥匙:白衣    │              │
│ │ 完成度 5/5   │ │ 4/5(缺1)    │ │ 🔒需稀有卡   │              │
│ └──────────────┘ └──────────────┘ └──────────────┘              │
├──────────────── 牌组预览(点开某套)─────────────────────────────┤
│  虎豹铁骑 · 魏速攻 · 围绕[魏·骑兵连携]                            │
│  卡位:[虎豹骑令★][速攻令][募兵][铁骑突阵][星球·魏][空][空][空] │
```

- **要点**:牌组**分类**(按流派/势力/稀有度筛);牌组**预览**(5–8 卡位 + 钥匙牌 + 流派标签 + 克制提示);从 S5 收藏拖卡入位。

### S5 · 收藏(Collection)
```
┌─ 卡牌收藏 ─── 筛选:[势力▾][职业▾][稀有度▾][品质▾] 搜索:___ ─┐
│  ▣虎豹骑令 ▣桃园三义 ▣东南风 ▣八阵图 ▣白衣🔒 ▣招降令 …       │
│  (网格:每张显 缩略图 + 稀有度边框 + 拥有×N + 附魔角标)         │
├──────────────── 卡牌详情(点某张)──────────────────────────────┤
│  虎豹骑令 · 稀有(蓝) · 魏 · 拥有×3                              │
│  效果:每有 1 魏骑·全骑 +攻                                      │
│  附魔:[普通]→[多彩+30%]  星球:可叠「星球·魏」                  │
│  [附魔] [分解] [上架交易 ▸S6]                                    │
└──────────────────────────────────────────────────────────────────┘
```
- 排序/筛选 + 卡牌详情(效果/附魔/星球/拥有数)。未拥有显灰锁 🔒。

### S6 · 商城 & 交易市场(Market)
```
┌ [抽卡] [直购礼包] [交易市场] ──────── 货币:金1.2k 券30 钻88 ──┐
│ ◤抽卡◢ 「战国风云」卡池:10 连 / 单抽,展示概率公示              │
│ ◤直购◢ 新手流派包 / 月卡 / 外观                                 │
│ ◤交易市场◢                                                      │
│   搜索/筛选卡牌  ·  我的挂单(2) · 求购(1)                       │
│  ┌─卡名──────┬最低售价─┬求购价─┬成交均价─┬走势─┬操作──┐       │
│  │白衣       │ 💎120  │ 💎90  │ 💎105   │ ↗  │[购买]│       │
│  │虎豹骑令   │ 💎15   │ 💎10  │ 💎12    │ →  │[购买]│       │
│  └───────────┴────────┴───────┴─────────┴────┴──────┘       │
│   [挂单出售]  [发起求购]  [成交记录]                            │
└──────────────────────────────────────────────────────────────────┘
```
- **要点**:抽卡(概率公示)/ 直购 / **交易市场**(挂单/求购/行情/成交记录)。**标注:TCG 式封闭市场,非 crypto**(见 economy 章红线)。全假数据。

### S7 · 天梯(Ladder)
- 我的段位/LP/赛季进度;排行榜(好友榜/全服榜);战绩(近 N 局的名次/贡献/岛主次数);赛季奖励路线。
- **假数据**:造一个 Top 20 假榜 + 我的近 10 局记录。

## 四、全局组件 & 弹窗
- **顶栏**:头像/称号、段位、三种货币、设置。常驻。
- **好友邀请弹窗**:右下角 toast「周瑜 邀请你加入攻岛队伍 [接受][拒绝]」。
- **通知红点**:宝箱可领 / 商城上新 / 好友上线。
- **导航**:顶部 tab 或左侧栏皆可,Cloud Design 定;保证 7 屏互通、能走查闭环。

## 六、技术注记 & 验收
- **独立前端原型**(建议 React + 本地 mock JSON),**不连引擎、不做真实网络/账本**;像素美术用占位即可。
- **与确定性引擎解耦**:大厅只在"点开始攻岛"那一刻产出一份「出战牌组 + 势力 + 队伍配置」数据(未来交给引擎),原型阶段打印/console 即可。
- **验收**:S1–S7 七屏 + 全局组件做成**可点击走查**的闭环,信息架构与交互流清楚,视觉基调到位。**功能可假,流程要真。**

> 复诵:局外大厅 = 社交+组队+组牌+商城+天梯的"家";纯前端原型、假数据、与引擎解耦;主角是"我的牌组 + 我的征程"。覆盖 7 屏走查闭环即达标。
