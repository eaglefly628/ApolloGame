## 1. 伤害公式（加法地板 × 乘法涌现 · 对齐引擎 modifier-stack 应用序）

一次命中：

```
hit = weaponDmg
      × (1 + Σ damageAdd)      // 加法层：被动/局外「+X%伤害」求和（modifier op=add 段）
      × Π damageMul            // 乘法层：暴击/元素/特殊（op=mul 段·非交换·按 id 定序）
命中期望 = hit × (1 + critRate × (critDmg − 1))   // 暴击期望值（模拟用），实时=掷种子 PRNG 判暴
```

> 应用序固定 **add → mul**（引擎 `t2-modifier-stack` 铁律·乘性靠 order/id 定序·禁墙钟/Math.random）。**加法先地板、乘法后涌现**——堆「+伤害%」是线性稳健，凑「暴击/进化」是指数拔尖，两条 build 路线由此分野。

**武器有效冷却**：`effCd = baseCd × (1 − Σ cooldownReduction)`（下限 clamp 0.1s，防除零/无限射速）。

**单体 DPS**：`dps₁ = hit命中期望 × amount / effCd`。
**清屏吞吐**：`dpsₐ = dps₁ × min(pierce+1, 敌群密度)`（穿透/AoE 命中多目标的乘数·模拟按当前屏敌数估）。

## 3. 被动逐级 + 叠加数学（modifier-stack）

| 被动 | op | 每级 | 满级(5) | 叠加进哪层 |
|---|---|---|---|---|
| 锋刃手册 | add | +8%伤害 | +40% | (1+Σadd) |
| 疾风护符 | add | −6%冷却 | −30% | ΣcooldownReduction |
| 能量核心 | add | +10%范围 | +50% | areaMul（乘 dpsₐ 密度） |
| 重力符文 | add | +8%击退/范围 | +40% | 击退（软控·非伤害） |
| 棱镜 | add | +1投射物 | +4（4级封顶） | amount（线性乘 dps） |
| 生命护心 | mul | +15%生命/+0.2回复 | +75%HP | maxHp × Π |
| 疾行靴 | add | +8%移速 | +40% | moveSpeed |
| 磁石 | add | +25%拾取 | +125% | pickupRadius |

**叠加范例**（飞镖 lv5 + 锋刃手册 lv5 + 疾风护符 lv3）：
```
dmg 22 ×(1+0.40)=30.8 ; effCd 0.85×(1−0.18)=0.697 ; amount 2
dps₁ = 30.8×2/0.697 = 88.4   （裸 51.8 → +71%）
```
> **反例警戒（虚胖）**：棱镜 +投射物 与 疾风 −冷却 叠加是**乘性涌现**（88→更高），需模拟盯住别失控；封顶（棱镜 4 级、冷却下限 0.1s）是硬刹车。

## 7. ⭐ P/M 功率曲线验证（核心调优锚 · 手算样例，模拟细调）

设 **P**=玩家有效清屏 DPS，**M**=敌群血量涌入速率 `= 总spawnRate × 平均敌HP`。健康节奏：

| 时段 | 目标 P/M | 手算样例（飞镖 build） | 判定 |
|---|---|---|---|
| 0–1.5min | ≈0.8 | P≈16（Kunai lv2）/ M≈1.5×20=30 → **0.53** | ⚠ 偏紧·靠走位补（可接受·紧张感）；若挫败超预期→起手武器 +1 |
| 1.5–6min | 1.0–1.3 | P≈90（lv5+被动）/ M≈2.6×26≈68 → **1.32** | ✅ 压制但需走位 |
| 6–12min | 1.5–2.5 | P≈315×穿透吞吐（进化）/ M≈4.5×32≈144 → **≥2.2** | ✅ 进化后碾压 |
| 12–15min | 爆发 | 多进化 P 数千 / Boss 12000 → ~40s 清 | ✅ 达标线 |

> **调优铁律**：任何新武器/敌人/被动改动，必须重算这张表、标注推向哪。**破坏"0.8→1.3→2.2→爆发"节奏的一律回退。** M 的 spawnRate 是多刷怪源叠加（波表 §waves），模拟按实际同屏敌数算 dpsₐ 吞吐（穿透/AoE 乘数），比手算精确。

## 8. 掉落 / 局外经济

**掉落**：蓝/绿/金经验=1/5/20；回血 2%、磁铁 1%、炸弹 1%（种子化掷·`t2-dice-roll`）。
**金币**：~每 8 敌掉 1 金（+局外「金币加成」）。单局均产估 200–500 金。

**局外元进度成本**：`cost(lv) = costBase × costMul^lv`（边际递增）。
| 升级 | base | mul | 满级 | 累计成本(估) |
|---|---|---|---|---|
| 基础攻击 +2%/级 | 100 | 1.3 | 20 | ~40k |
| 基础生命 +5%/级 | 100 | 1.3 | 20 | ~40k |
| 复活 +1 | 2000 | 3.0 | 2 | 8k |

> **意图**：局外升级是**缓坡**（20+ 局才满攻/血）——保证「技术+build」仍是主导、局外只托底，不做数值碾压。复活稀有贵。

## 9. 模拟程序 spec（`scripts/game-103-balance-sim.mjs` · 待建）

> headless、种子化、零渲染——把上面数字跑 N 局验证曲线。**GD 分析工具**（不碰引擎/游戏 runtime）。

- **输入**：weapons/passives/enemies/waves/drops 数据表 + build 策略（focus 武器）+ 局外等级 + seed。
- **循环**：按 dt 步进 15min——刷怪(§4/waves)、玩家自动攻击算 dpsₐ、扣敌 HP、掉经验、升级三选一(策略选)、进化触发、Boss。
- **输出**（每 build×难度跑 ≥2000 局）：存活时长分布、通关率、进化落点时刻、各时段 P/M 实测、DPS 峰值、失衡红旗（某 build 通关率 >95% 或 <10%）。
- **回调闭环**：跑出的 P/M 若偏离 §7 目标带 → 调对应数据表数字 → 重跑，直到多 build 都落健康带。
