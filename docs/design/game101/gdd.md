# game101 ·《海港绯闻》核心玩法策划案 GDD (v1)

> 复刻对标 **Gossip Harbor: Merge & Story**（Microfun）。GD-101 · 2026-07-23。
> 口径：**整个游戏是数据**——本文所有数值/内容为 **config 默认值**，逻辑走现有能力（见 `capability-plan.md`），数据结构见 `config-schema.md`。
> 换皮规避 IP：机制复刻，角色/剧情/美术原创（§角色与世界观）。

## 1. 一句话

点生成器（耗体力）→ 合并物品（merge-2）→ 交付订单 → 得金币/星星 → 星星推进剧情与装修 → 解锁新内容 → 追剧式长线。

## 2. 体验支柱（设计北极星）

1. **合并爽感**：即时正反馈、确定性推进（"再合几步就能拿到目标物"）、解压心流。
2. **追剧欲**：剧情是体验主体不是附加——狗血、悬疑、反转，每段留钩子；这是本品与同质合并游戏的差异化命根，**M2 不许偷工**。
3. **经营表达**：装修可选风格、可回改，给审美表达与收集欲。
4. **零学习成本**：核心操作只有"点"和"拖"；深度藏在合并链与订单规划里。

## 3. 核心循环

```
        ┌──────────────── 宏循环：追剧（天/章节）────────────────┐
        │  [剧情章节/Day] ──解锁──► [新场景/生成器/订单]          │
        │        ▲触发剧情演出(dialogue)      │                  │
        │  [装修节点]◄─花星星─[星星]◄─订单奖励─┐                  │
        └──────────────────────────────────┐ │                  │
                     ┌── 微循环：合并（秒级心流）──┐│                │
                     │ 点生成器→耗体力→产出(带气泡) ││                │
                     │ →点破泡→拖动合并(merge-2)   ││                │
                     │ →交付订单→金币/星星/能量     │┘                │
                     └──────────▲───────────────┘                 │
                                │体力恢复(timer)/奖励                │
                            [体力系统]────────────────────────────┘
```

- **微循环**（`merge-rule`+`grid-drag-square`+`prefab-spawn`+`f1-resource`）：秒级心流。
- **中循环**（订单→星星→剧情任务/装修·`event-when`/`effect-apply`/`f2-flag`）：一次 session 目标。
- **宏循环**（`dialogue` 演出 + Day 推进）：追剧长留存。
- 黏合货币 = **星星**。

## 5. 内容表

### 5.1 物品链（示例 3 条·M1；完整默认值见 config-schema §2）

- **食材链**：番茄 → 洗净番茄 → 切片 → 番茄酱 → 意面 → 招牌意面（6 级）
- **渔获链**：小鱼 → 鲜鱼 → 处理好的鱼 → 鱼柳 → 香煎鱼 → 主厨鱼料理（6 级）
- **咖啡链**：咖啡豆 → 磨粉 → **浓缩咖啡** → **拿铁** → 招牌特调（5 级·owner 举例链）
- **工具链**：螺丝 → 扳手 → 工具包 → 电钻 → 维修套装（5 级）
- （M4 扩展）货币链（金库·高额出售）。

### 5.2 生成器（M1 点击型·耗体力·部分带冷却 CD）

| 生成器 | 产出链 | 耗体力 | CD | 备注 |
|---|---|---|---|---|
| 咖啡机 | 咖啡链 Lv1–2 | 1 | — | owner 举例·主力 |
| 冰箱 | 食材链 Lv1–3 | 1 | — | owner 举例·生鲜 |
| 渔获箱 | 渔获链 Lv1–3 | 1 | — | 周航供货线 |
| 工具箱 | 工具链 Lv1–2 | 1 | 8s | 维修线·产出后冷却（碎片化）|
| （M4）果树 | 免体力 | 0 | 产能条 | 免体力·产能自然恢复（G4）|

> 「生成器冷却 CD」= owner 特殊道具机制：部分生成器产出后需等待 CD 才能再点，促碎片化游玩（数据 `cooldownSec`·`timer-advance` 解释）。

### 5.3 订单（角色气泡·config-schema §5）

角色头像 + 需求物（目标链某级）→ 拖物交付 → **经验 + 金币 + 星星（+能量）**。可跳过刷新。经验累积升玩家等级。

### 5.4 剧情 Day 清单（config-schema §6）

每 Day = 3–6 条任务（"打扫后厨""修好吧台""和苏晴谈谈"），消耗星星/指定物 → 触发装修 + `dialogue` 演出 → 进入下一 Day。

### 5.5 装修节点（config-schema §7）

场景待修点：花星星做**装修/清洁/修复**动作 → 解锁 flag → 场景皮肤切换 + 推进一段主线剧情；破败建筑分多区域，同点提供 **3 选 1** 风格皮肤（个性化审美·可回改）。

## 6. 系统

- **体力**：黄色能量（主玩法）；上限 100、120s/点恢复；来源=恢复/订单/剧情奖励/（后续）广告·充值·能量物品；出口=生成器。（粉色能量=活动专用·Out of Scope）
- **泡泡（气泡锁·G3）**：新产出物被临时泡泡包住，**用金币购买打开**（合成产生的泡泡=官方金币回收/变现途径）；防误触 + "逐个揭开"节奏。
- **空间管理博弈**：格子有限是核心约束；生成器增多 + 高阶链拉长逼玩家整理规划；操作=合并/出售（换金币·腾格）/点生成器/买泡泡/交付；（后续）背包收纳扩容。
- **订单=顾客柜台（原作布局）**：顶部 3 顾客立绘，点的是**成品菜**（棋盘高阶物）；交付发**满意度😊+经验+金币+星星**；棋盘上可交单的成品标**绿✓**。
- **满意度系统（😊）**：交付累积满意度，满一格（如 7/12→12/12）触发活动/通行证奖励（原作顶部挂件）。
- **能量药水**：作为**可合并道具**存在于棋盘（点用返还体力），紫/蓝多级。
- **货币与资源**：**经验**（升等级）、**满意度😊**（活动进度）、金币（软·出售/订单/买泡泡出口）、星星（进度·订单/关键合并→剧情/装修）、体力（节流·可被能量药水补）、宝石（硬·Out of Scope）。

## 7. 呈现与 juice（`timeline`+`effect-apply`）

合并迸发（星星光圈）、交付飞行（物品飞入·奖励飞出到 HUD）、气泡破裂、生成器按下缩放 + 产出弹出、发奖入袋。均走 `JUICE_TIMELINES` 数据编排。

## 10. 确定性声明

见 `capability-plan.md` §5：随机走 `w1-random` 种子 PRNG（禁裸 Math.random）；merge 确定；实时体力恢复隔离在 timer 输入层；单机休闲、无 lockstep。
