## 0. 设计总原则

1. **风格关键词**：`cozy / 海港治愈 / 暖阳 / 轻插画 2.5D / 糖果感 UI / 追剧情感`。长时间游玩不累眼。
2. **色板（建议·可微调）**：主色 暖阳橙 `#FF9A3C`、辅色 海水蓝 `#3EC5E8`、点缀 珊瑚粉 `#FF6F91`；中性 奶白 `#FFF7EC`(底) / 深褐 `#4A3B2A`(字)；功能色 能量黄 `#FFC43D`、星星金 `#FFD34E`、金币金 `#F4B740`、宝石紫 `#8A5CF6`。
3. **控件语言**：大圆角（16–28px）、柔和投影、糖果感按钮；主 CTA 主色实心大按钮；信息层级清晰。
4. **物品/生成器**：统一左上光源、圆润、统一（或无）描边；**同链低→高一眼看出"更精致/更亮/装饰更多"的递进**。
5. **合并板 = play-field**（`grid-drag-square` 渲染层），**非 LayoutNode**；HUD/面板/菜单 = LayoutNode 浮层。
6. 每屏尽量给 default / 空态 / 满态 / 弹窗叠加 关键状态。

## 2. S1 · 合并主界面（★先出）

### 屏幕分区（play-field 打底 + UI 浮层）

```
┌────────────────────────────────────────┐
│ [头像·Lv]  [★星星][🪙金币][💎宝石]        │ 顶带 HUD (S4)
│            [⚡体力 34/100  ⏱1:58]         │
├────────────────────────────────────────┤
│ 第1天 · 剧情任务进度 ▓▓▓░░  [任务▸]       │ 任务提示条 (→S5)
├────────────────────────────────────────┤
│   ▨ ▨ ▨ ▨ ▨ ▨ ▨                          │
│   ▨ 🍅 🐟 ▨ ▨ 🔧 ▨      ← 合并棋盘 7×7    │ play-field
│   [食材袋] ▨ ▨ ▨ [渔获箱]  生成器沿边      │ (grid-drag-square)
│   ▨ ▨ ⭘🍅 ▨ ▨ ▨   ⭘=气泡锁               │
│   ▨ ▨ ▨ [工具箱] ▨ ▨ ▨                     │
├────────────────────────────────────────┤
│ [👩🍝][🧔🐟][👵☕][👨🔧]  订单栏(横滑) (S3) │
├────────────────────────────────────────┤
│ [菜单][任务][商店][活动]  底部导航          │
└────────────────────────────────────────┘
```

- **play-field**：圆角方格网格（木质操作台质感·淡内阴影）；生成器常驻边缘、明显区别于普通物品（更大·可点呼吸光·角标）；物品居中带落影，选中/拖动放大+高光；气泡锁物品裹半透明泡泡（带高光）。**合并瞬间预留特效层**（星星光圈）。空板(新手)/满板(提示"没空间了")各出一版。

## 11. 资源清单（供设计排产·对齐 config-schema sprite 命名）

- **物品**：食材链 ×6、渔获链 ×6、工具链 ×5（≈17 图标·`item_<chain>_<lvl>`）。
- **生成器**：食材袋/渔获箱/工具箱（各 default/按下/产出·`gen_*`）；（M4）果树含产能环。
- **功能物**：气泡锁蒙层、金币袋、星星、能量物、货币/资源小图标全套。
- **角色**：订单小头像 ×5（林夏/周航/老陈/苏晴/阿雅）；剧情立绘：林夏半身 +4 表情(P1 首要)。
- **场景/背景**：合并板操作台底纹、剧情 CG ×2、装修场景(修复前后)×1、世界地图 ×1。
- **UI Kit**：HUD 资源胶囊/体力条/按钮(主·次·文字)/订单卡/任务条/弹窗容器/导航/红点角标。
- **特效关键帧**：合并迸发/交付飞行/气泡破裂/星星金币获得（对齐 `juice.json`）。
