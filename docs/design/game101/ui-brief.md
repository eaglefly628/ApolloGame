## 0. 设计总原则

1. **风格关键词**：`cozy / 海港治愈 / 暖阳 / 轻插画 2.5D / 糖果感 UI / 追剧情感`。长时间游玩不累眼。
2. **色板（建议·可微调）**：主色 暖阳橙 `#FF9A3C`、辅色 海水蓝 `#3EC5E8`、点缀 珊瑚粉 `#FF6F91`；中性 奶白 `#FFF7EC`(底) / 深褐 `#4A3B2A`(字)；功能色 能量黄 `#FFC43D`、星星金 `#FFD34E`、金币金 `#F4B740`、宝石紫 `#8A5CF6`。
3. **控件语言**：大圆角（16–28px）、柔和投影、糖果感按钮；主 CTA 主色实心大按钮；信息层级清晰。
4. **物品/生成器**：统一左上光源、圆润、统一（或无）描边；**同链低→高一眼看出"更精致/更亮/装饰更多"的递进**。
5. **合并板 = play-field**（`grid-drag-square` 渲染层），**非 LayoutNode**；HUD/面板/菜单 = LayoutNode 浮层。
6. 每屏尽量给 default / 空态 / 满态 / 弹窗叠加 关键状态。

> **布局基准=原作真机（refs.md 拆解）**：① **订单在顶部**＝3 顾客立绘 + 奖励气泡（😊满意度/🪙/⭐/⬆经验）+ 柜台托盘上他点的成品菜；② 板 **7×9** 铺满下 ~70%；③ 生成器嵌**顶部行**（含**果树=免体力·⏱**）；④ 物块 badge：**🡇 粉箭头=生成器新产出**、**✓ 绿勾=可交当前订单**；⑤ **能量药水**=可合并道具（选中带青色角框）；⑥ 无底部导航条（菜单入口收进顶部 HUD·板铺到底）。

- **play-field**：圆角方格网格（暖操作台质感·淡内阴影）；生成器明显区别于普通物品（更大·⚡耗体力/⏱免体力角标·可点呼吸光）；物品居中带落影，选中/拖动放大+高光+青色角框；气泡物品裹半透明泡泡 + 金币价签。**合并瞬间预留特效层**（星星光圈）。空板(新手)/满板(提示"没空间了")各出一版。

## 4. S3 · 顾客柜台订单（顶部·原作布局·→ `drop-zone`+`event-when`+`effect-apply`）

| 元素 | 控件 | 内容/状态 | 写世界信号 |
|---|---|---|---|
| 顾客立绘位 ×3（顶部一排） | Panel+Image(**半身立绘**·表情差分) | 立绘=皮肤槽；可交付=绿框高亮 | 点顾客=`order_detail(id)` |
| 奖励气泡（立绘右上） | Panel+Label ×N(小图标) | **😊满意度 / 🪙金币 / ⭐星星 / ⬆经验**（不同顾客不同·含大额） | — |
| 柜台托盘（立绘下） | Panel+Image ×1–2(成品菜)+Label(×数量) | 他点的成品菜；集齐=托盘绿底+✓ | — |
| 交付 | play-field 拖成品到顾客 / 顾客上 Button | 拖 needItem(成品) 到该顾客 | `deliver_order(orderId)` |
| 交付成功 | Timeline fx | 成品飞向顾客 + 满意度/奖励飞出到 HUD（juice `deliver`）；满意度满→活动奖励 | — |
