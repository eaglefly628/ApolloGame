## 0. 设计总原则

1. **风格关键词**：`cozy / 海港治愈 / 暖阳 / 轻插画 2.5D / 糖果感 UI / 追剧情感`。长时间游玩不累眼。
2. **色板（建议·可微调）**：主色 暖阳橙 `#FF9A3C`、辅色 海水蓝 `#3EC5E8`、点缀 珊瑚粉 `#FF6F91`；中性 奶白 `#FFF7EC`(底) / 深褐 `#4A3B2A`(字)；功能色 能量黄 `#FFC43D`、星星金 `#FFD34E`、金币金 `#F4B740`、宝石紫 `#8A5CF6`。
3. **控件语言**：大圆角（16–28px）、柔和投影、糖果感按钮；主 CTA 主色实心大按钮；信息层级清晰。
4. **物品/生成器**：统一左上光源、圆润、统一（或无）描边；**同链低→高一眼看出"更精致/更亮/装饰更多"的递进**。
5. **合并板 = play-field**（`grid-drag-square` 渲染层），**非 LayoutNode**；HUD/面板/菜单 = LayoutNode 浮层。
6. 每屏尽量给 default / 空态 / 满态 / 弹窗叠加 关键状态。

### 0.1 UI 布局铁律（owner 2026-07-25 拍板·多轮返工的教训·所有屏必守）

> **核心：游戏 UI 要把「信息本身」放大填满，而不是拉大空容器让小内容飘在中间。** 手机小屏、拇指操作、追剧式休闲——信息必须**又大又醒目、一眼可读**，不留大片留白。

1. **信息最大化**：图标、数字、文字取「能放多大放多大」。资源值/关键数字用大字（xxl+ 或裸 px 40+），图标 48+；宁可少放几项、每项做大，不要一堆小元素。**留白是设计手段不是默认结果**——出现大片空白＝布局失败信号。
2. **内容填满容器·别拉空壳**：卡片/面板用 `flex:1` 撑高后，**里面的内容也要同比放大填满**（大圆牌图标 + 大字），不许小图标+小字飘在高卡中间上下留空。容器多大，内容就顶多大。
3. **固定尺寸·非内容自适应**：同类元素（资源胶囊/按钮/卡片）给**统一固定尺寸**（`flex:1` 等宽 或 显式 `width/height`），不要让每个元素各自按文字长短缩放成参差不齐的窄条/长条。按钮尤其——`Button` 无固有宽会缩成窄条，**用固定尺寸框 Panel 包**（`width/height` + `Panel.action`）。
4. **比例要匹配·别又高又窄/又长又扁**：横向条带（HUD/工具栏）就做**宽>高的扁横带**，别做成一列又高又窄的胶囊；纵向列表项做**宽>高的横卡**。宽高比明显失衡＝错。基准照**原作真机截图比例**（`refs.md`）+ owner 给的原图 size，不凭空定。
5. **元素不出框**：格子内的角标/数字（如沙格 💥N 解锁次数）必须**画在该格方框内**、不溢出到 grid 框外；尺寸收进容器。
6. **别跟缩放场景的绝对定位/`position:fixed` 硬碰**：`mountHost` 场景被 `transform:scale` 信箱化，`Modal`/绝对定位在其中会错位——整屏浮层优先用**整屏替换 Screen**（正常流）而非绝对坐标覆盖。

### 4.1 右侧动态异形限时菜单（owner 2026-07-24 记录·基准右端那条随时间变化的异形菜单）

- 顾客行**最右端**是一条**动态、异形（irregular）**的**限时菜单**：随时间刷新、形状不规则（不是标准矩形卡），带**倒计时**——过期即换单/消失。
- 落地映射：LayoutNode `Panel`(不规则观感靠 skin 皮肤槽·`bg`异形纹样) + `Label`(⏱倒计时·由 `e1-timer` 驱动) + `Badge`；倒计时数据来自引擎计时器组件，**不在游戏层写自由计时逻辑**。
- **✅ 功能部分已落地（2026-07-24）**：限时特惠订单（苏晴）= **金框(edge:'gold') + ⏱ 实时倒计时**（共享 `menu` Timer 循环驱动·e1-timer·不销毁）。动态限时菜单的「时间显示 + 动态」已具。
- **异型外形仍待 PUI**：`Panel`/`Card` 无 shape 枚举 → 引擎池 `REQ-UI-异型容器`（PUI·复用 ShapeToken 到 Panel）+ `REQ-101-07`。现用矩形金框顶着，本件落地即升级异型。**绝不手写 DOM/clip-path。**

### 4.2b 交付发奖飞行轨迹（✅ 已落地 2026-07-24·juice）

- 交付集齐发奖时，金币从顾客卡沿弧**飞进 HUD 钱包**——用基座 `layout.flyTo{to:'hud-coins',ms,arc}`（唯一飞行原语·**非自造**·render-only 不进 sim/hash）。宿主订阅金币增量→短暂注入 fly 节点→播完清（setTimeout=纯表现层清理）。
- 后续 juice（合成迸发 `Particles`/`popOut`、满意度、破泡）同走基座件（rendering-fx.md / ui.md juice 行），缺口才报 requests.md。

### 4.2 物件级倒计时时钟（owner 2026-07-24 记录·棋盘/托盘上单个食物物件带时钟）

- 部分食物**物件本身带一个倒计时时钟**（角标）：**时钟归零 → 该物件销毁**（如限时投放的鲜货/活动物）。
- 落地映射：物品实体挂 `e1-timer`（或 over-time 计数）→ 到期发信号 → `effect-apply` 触发 `DestroyRequest`；角标 = play-field badge(⏱剩余)。**纯引擎能力组合·游戏层零自由逻辑**；现有 timer/effect-apply 能覆盖，无需新能力（若覆盖不了再报 requests.md）。
