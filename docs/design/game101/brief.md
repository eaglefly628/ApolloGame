## 调研结论摘要（Gossip Harbor 核心设计）

> 来源：Deconstructor of Fun / Naavik / Udonis 行业拆解 + Fandom Player Guide + BlueStacks 能量指南 + Mobi.gg 角色剧情（2026-07 检索）。

### 它凭什么卖座

合并玩法在品类里**高度同质化**；Gossip Harbor 的差异化不在合并本身，而在**用一部"海港狗血连续剧"把合并包装成了追剧**——剧情是体验主体、不是附加。

### 三层核心循环

| 层 | 循环 | 黏合货币 |
|---|---|---|
| **微循环（心流·秒级）** | 点生成器→耗体力→产出物品（带气泡）→拖动同物合并（merge-2）→交付订单 | 体力 |
| **中循环（经营·分钟级）** | 订单产出**星星**→星星花在剧情任务/装修→解锁新场景/生成器/订单 | 星星 |
| **宏循环（追剧·天/周级）** | 装修节点触发**视觉小说剧情演出**→留钩子→解锁下一"天/章节" | 剧情进度 |

三层的黏合剂 = **星星**：合并→订单→星星→剧情/装修→更多订单来源。断任一环，循环崩。

### 关键系统与数字（对标品，作复刻锚点）

- **合并板**：约 7×N 网格；生成器常驻边缘、点击**消耗体力**产出随机低级物品；merge-2（两同物→高一级）。新产出物带**气泡锁**需点开。棋盘格子有限=核心约束。
- **体力**：黄色能量上限 **100**，**每 2 分钟回 1**（空→满 ≈ 3.3h）；来源=恢复/订单奖励/剧情/看广告(小额)/充值/能量物品；出口=点生成器。另有粉色能量专供活动。中后期有**免体力生成器**（Orange Tree）。
- **订单/任务**：① 角色气泡订单（角色头像+需求物→交付换金币/能量/星星）；② 剧情任务（"打扫后厨""和 X 谈话"，消耗星星/指定物）。结构=按"天(Day)"清单推进。
- **剧情/装修 Meta**：视觉小说式（立绘+背景+对话），追剧节奏、每段留钩子；花星星修复/装修场景，**玩家可选外观风格**、可回改；每片区域解锁新剧情+新内容。
- **剧情梗（对标）**：女主 Quinn 离婚回乡接手餐厅 → "食物中毒"疑云 → 有人蓄意破坏 → 查真相 + 情感/家族线。悬疑+情感+反转的电视剧结构。
- **商业化（本次不做，仅记）**：体力墙 + 剧情高潮点礼包 + 通行证；广告只给小额兜底。

## owner 追加·核心循环口径（2026-07-23·authoritative·压过上文对标描述）

> owner 二次细化的复刻口径，设计以此为准；GD-101 评判＝**全部接受**（均为品类核心循环的精确化，可数据表达、映射现有能力，无新增引擎缺口，仅 sharpen 已列 G3/G4）。

**一、核心基础循环**
1. **体力消耗与产出**：消耗体力点击**自动生成器**（如**咖啡机、冰箱**），随机获得低级合成素材。
2. **合成升级**：拖拽相同素材升级至指定阶数（如 **两个咖啡豆 → 浓缩咖啡 → 拿铁**）。
3. **订单交付**：棋盘生成高级物品满足顾客订单，完成后获取**经验、金币、剧情星星**。

**二、剧情与装扮系统（代入感 + 目标感）**
1. **碎片化叙事**：消耗**星星**解锁**装修/清洁/修复**动作，每个动作推进一段主线剧情（**纵火案真相 / 家族秘密 / 情感纠葛**）。
2. **多阶段装扮**：破败建筑分多区域，每次装修给 **3 选 1** 外观选项（个性化审美）。
3. **NPC 关系网**：核心悬疑主线 + 多名支线角色，经**对话框 + 过场动画**逐步解锁，保持悬念。

**三、关卡与棋盘经济设计**
1. **空间管理博弈**：网格棋盘；生成器增多 + 高阶链拉长 → 格子容量受限，考验整理与规划。
2. **特殊道具机制**：
   - **锁定 / 生成器冷却（CD）**：高级道具需特定条件解锁；或生成器产出后需等待冷却，促碎片化游玩。
   - **泡泡购买 / 出售**：合成产生的临时**泡泡可用金币直接购买（打开）**，是官方的**金币回收/变现途径**；物品可出售换金币。
