## 1. 定位与核心循环

- 定位：单机四人掼蛋（主角+3 AI）×二次元人设×**以「衣服」为筹码的服饰经济**（输盘脱衣·赢盘收藏对手行头）；成人向自玩（分级红线见 brief §3·A-006）。
- 核心循环：主菜单 → 选桌（难度×**对局档**）→ **盘循环**〔发牌 →（次盘起）**牌贡**/还贡 → 打牌（墩/圈轮转）→ 盘结算（**输队脱衣＝衣贡·转入赢家衣橱**·头游队升级）〕→ **run 终局**（我方过 A=通关结算 ／ 对方过 A=游戏结束）→ 离桌带出（**衣橱收藏持久存档**）。
> **两种「贡」勿混（owner 2026-07-20 术语）**：**牌贡**＝开局牌面进贡/还贡/抗贡（§2.3·规则层·G1~G4·不变）；**衣贡**＝盘末输队脱衣转赢家衣橱（§3·经济层·新）。二者独立并行、互不换算。

## 4. 衣服价值 / 对局档 / 衣橱收藏

### 4.1 衣服价值 / 等级（盛→简·5 档·越外越盛越值钱）

| 档序 | 语义（三姨太各套见 `characters.md`） | 价值分 | 等级 |
|---|---|---|---|
| 档1 | 最外·最盛（晚礼服/晚装档） | 5 | ★★★★★ |
| 档2 | 次盛（旗袍裙/套装档） | 4 | ★★★★ |
| 档3 | 常装（衬衫+裙/针织档） | 3 | ★★★ |
| 档4 | 简装（吊带/短裙档） | 2 | ★★ |
| 档5 | 底线（非裸露·内容红线 A-006） | 1 | ★ |

### 4.2 对局档（替代旧底注档·放大收藏价值）

| 档 | 价值倍率 | 说明 |
|---|---|---|
| 常局 | ×1 | 赢来衣服按基础价值收藏 |
| 贵局 | ×5 | 高价值局·衣服更值钱（镜像旧底注 500） |
| 顶局 | ×20 | 顶级局·收藏价值最高（镜像旧底注 2000） |

> **无「带入/荷包/破产扣钱」概念**——你带整套行头入座，输脱赢收。对局档只放大**收藏价值**（AI 难度另选·正交）。

### 4.3 衣橱（点开查看 · SC-7b 状态卡扩展）

- **生涯收藏册（持久存档）**：几套几件、各是**谁的**、什么档、价值多少、等级几星；集齐某姨太整套 5 档＝「**一套**」（收藏成就）。
- **本 run 战况**：各角色当前档位（已脱到第几档）、本 run 已脱/已收件数。
- 入口：点角色头像/衣橱按钮；控件走 **LayoutNode 网格清单**（缺库存/收藏控件报 PUI·见 `requests.md`·**不手写 DOM**）。
