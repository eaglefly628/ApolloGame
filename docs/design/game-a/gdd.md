## 1. 定位与核心循环

- 定位：单机四人掼蛋（主角+3 AI）×二次元人设×快局金钱/服饰罚；成人向自玩（分级红线见 brief §3·A-006）。
- 核心循环：主菜单 → 选桌（难度×底注·带入=底注×20）→ **盘循环**〔发牌 →（次盘起）进贡/还贡 → 打牌（墩/圈轮转）→ 盘结算（金钱±·输方服饰-1·头游队升级）〕→ **run 终局**（我方过 A=通关结算 ／ 对方过 A=游戏结束）→ 离桌带出。

## 3. 服饰罚（owner 追加 · brief §6.1 全文为准）

输方两人各-1 件（**所有人参与含主角**·四轮拍板）；5 档阶梯；底线档后转金钱罚加倍；run 开局回满；点头像看状态（SC-7b）。内容红线：全员成年·底线档非裸露·露骨不做（A-006）。

## 4. 经济（弱压力 · 三轮拍板）

| 项 | 值 |
|---|---|
| 初始资金 | 10,000（生涯钱包持久存档） |
| 底注档 | 100 / 500 / 2000；带入=底注×20；荷包不足按结余入座（无破产惩罚） |
| 盘结算 | 赢队每人 +底注×倍率（双上×3／一三×2／一四×1），输队对称扣 |
| 彩头 | 抗贡成功 +1 倍；天王炸终结本盘 +1 倍；单盘封顶 ×5 |
| 底线档后 | 该角色所在队输盘金钱罚 ×2（替代脱衣） |

## 5. AI（t2-behavior-tree 消费 · 全种子确定性）

| 档 | 记忆 | 特权 | 延迟 |

| L1 雏鸟 | 无 | — | 0.6~1.2s 拟人（性格微浮动·全档同） |
| L2 常客 | 大牌集（王/级牌/炸弹计数） | — | 〃 |

- 提示按钮=最小合法压牌（各难度一致）；玩家记牌器只统计明面已出牌。
