# Game A《掼蛋》· 场景布局 & UI 布局设计交接案（v1）

> 2026-07-17 · GD-A 出案 → 交接对象：PE-A（S3/S5 落地）、PUI（控件缺口裁决）、美术线（S6 台账）。
> **铁律对齐**：所有 UI=`src/ui/components` LayoutNode 纯数据（控件实名以 `catalog.ts` 闭集为准，本案只用闭集词汇）；handler 只入队 action 信号零逻辑；本案给的是**布局意图+控件词表+信号契约+美术槽位**，具体 LayoutNode 数据由 PE 在 S5 落地；表达不了 → `requests.md` 报 PUI，**绝不手写逃生**（存疑项已集中在 §7）。
> 风格总纲：**二次元向 · 原生自产**（owner 拍板零外部 IP）。基准横屏 16:9（建议 1280×720 逻辑分辨率，PE 定稿）。

## 1. 全局设计语言

- **色彩意向**（S6 风格锚定稿）：暖木牌桌 × 青瓷绿主色 × 朱砂红强调（级牌/警示）× 米金（金钱）；二次元高饱和+柔光渐变，避免写实赌场感——**茶馆棋牌室的轻松氛围**。
- 标题/大数字用 `Label.font` 艺术字（18 款 OFL 内嵌里选中式衬线感一款，S5 定）；正文用默认主题字。
- 控件皮全走**主题令牌**（三态填充，非裸 hex）；金钱一律 `Badge`+金币 icon；四家身份一律 `Avatar`+昵称 `Label`。
- 演出强度可在设置里降档（Toggle「简化特效」）——低端机与晕动友好。

| 中央出牌区 | `PlayingCard` 组（四家落位·最近一手）+`Tag`(墩型名：三带二/钢板/炸弹…)+`Float`(「过」) | 出牌流 | — |
| 局信息条 | `Panel` 内 `Label`+`Tag`：级牌(红桃级牌带流光标识)·双方级数·底注·盘数 | 对局状态 | — |

**牌桌演出点**（美术/特效时刻表·特效全部走引擎闭集，程序化优先）：

| 时刻 | 演出 | 强度 |
|---|---|---|
| 发牌 | 牌背瀑布流入四家 + 洗牌音 | 中 |
| 打出级牌/逢人配 | 牌面朱砂描边流光 | 低 |
| 炸弹(4-10张) | 屏震 + `Particles` 爆裂 + 墩型 Tag 弹跳 | 高 |
| 同花顺 | 横幅流光扫过出牌区 | 高 |
| 四大天王 | 全屏暗场 + 出牌者立绘/头像 cut-in + `Particles` | 最高 |
| 抗贡 | `Versus` 双王对撞 | 中 |
| 一家走科(出完) | 名次徽章(头游/二游…)落到其席位 | 低 |

### SC-4 盘结算

| 区块 | 控件 | 说明 |
|---|---|---|
| 名次榜 | `Table`（4 行：名次徽章+`Avatar`+昵称+本盘出完顺序） | 双上时整行金色高亮+`Particles` 金币雨 |
| 金钱收付 | 每行 `Badge`(±金额·底注×倍率明细 `Tooltip`) + 主角荷包大数字滚动 | 彩头(抗贡/天王炸)单列一行 |
| 级数推进 | `LevelPath`（2→A 双方两条轨·本盘 +N 推进动画） | 打A局特别标记 |
| 操作 | `Button`[下一盘][离桌结算] | `sig.round.next` / `sig.round.leave` |

### SC-5 通关结算（过 A）

- 全屏演出：主角立绘+队友人设卡并立、`Particles` 庆祝、艺术字「过 A」；
- 生涯统计 `Table`（总盘数/胜率/最大炸弹/净盈亏）+ 带出金钱大数字；
- `Button`[再来一局][回主菜单]（`sig.clear.restart` / `sig.clear.home`）。

### SC-6 设置（全局 Modal）

`Slider`(音乐/音效音量) + `Toggle`(简化特效/跳过演出) + `Button`[回主菜单(牌桌内·带确认 Modal·视为弃盘按末游结算)]。信号 `sig.settings.*`。

### SC-7 角色卡详情

`Image` 立绘全身大图 + `Label` 名字 + 扩展字段占位区（年龄/性格… `Label`+`Tag`，**外部角色卡标准发放后填充**）+ 战绩摘要 `Table` + 返回 `Button`。
