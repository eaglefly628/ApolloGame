## 1. 全局设计语言

- **色彩意向**（S6 风格锚定稿·世界观=**现代私宅**·owner 三轮拍板）：现代豪宅牌室——暖夜灯光 × 深胡桃/大理石 × 朱砂红强调（级牌/警示）× 米金（金钱），落地窗夜景点缀；二次元高饱和+柔光渐变，避免写实赌场感——**私宅夜局的松弛氛围**；立绘=现代时装（「姨太」称谓保留作设定趣味）。
- 标题/大数字用 `Label.font` 艺术字（18 款 OFL 内嵌里选中式衬线感一款，S5 定）；正文用默认主题字。
- 控件皮全走**主题令牌**（三态填充，非裸 hex）；金钱一律 `Badge`+金币 icon；四家身份一律 `Avatar`+昵称 `Label`。
- 演出强度可在设置里降档（Toggle「简化特效」）——低端机与晕动友好。

### SC-5 通关结算（过 A）/ 游戏结束

- 全屏演出：主角立绘+队友人设卡并立、`Particles` 庆祝、艺术字「过 A」；
- 生涯统计 `Table`（总盘数/胜率/最大炸弹/净盈亏）+ 带出金钱大数字；
- `Button`[再来一局][回主菜单]（`sig.clear.restart` / `sig.clear.home`）；
- **失败变体（对方先过 A·owner 二轮拍板「直接游戏结束」）**：同布局复用暗色调「游戏结束」——无庆祝粒子，统计照显、带出结余照算；数值目标=短周目内「对方过 A」为罕见事件（S4 balance-sim 钉）。

### SC-6 设置（全局 Modal）

`Slider`(音乐/音效音量) + `Toggle`(简化特效/跳过演出) + `Button`[回主菜单(牌桌内·带确认 Modal·视为弃盘按末游结算)]。信号 `sig.settings.*`。

### SC-7 角色卡详情

`Image` 立绘全身大图 + `Label` 名字 + 扩展字段占位区（年龄/性格… `Label`+`Tag`，**外部角色卡标准发放后填充**）+ 战绩摘要 `Table` + 返回 `Button`。

### SC-7b 角色状态卡（姨太 · 牌桌内 Modal · 服饰罚可视化）

`Modal` 内：`Image` 立绘（**随服饰阶梯 5 档切换**，底线装束为最终档不再变化）+ `Badge`「服饰 N/5」+ `ProgressBar`（run 内状态）+ 对战战绩 `Table` + 关闭按钮。规则语义见 brief §6.1；**内容红线**：全员成年、底线档非裸露（brief §3）。信号 `sig.table.inspect-char`。
**主角也参与服饰罚**（owner 四轮）：角色卡暂无状态立绘 → 主角状态卡先以**服饰计数+头像框状态**呈现，角色卡标准含立绘后补齐。人设与阶梯明细=`characters.md`。
