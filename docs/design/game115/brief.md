## 一句话

> 你不是卖火柴的小女孩——**你是她手里的火柴**。每擦亮一根，你就用自己短短几十秒的燃烧，为她点亮一个幻象。

宣传语（取自安徒生原文最后一句）：
> 「谁也不知道她曾经看到过多么美丽的东西。」——**除了火柴。**

## 为什么是它（立项依据·对标《The Little Prince: Across the Stars》）

| 成功条件 | 本作 |
|---|---|
| 全球知名·零解释成本 | 安徒生《卖火柴的小女孩》（1845），各语种课本级 |
| 公版可商用 | 安徒生 1875 年去世，全球公版；**只用原著**，不借任何影视/动画版设计 |
| 天然分章 | 原著就是「一根火柴 = 一个幻象」：火炉 → 烤鹅 → 圣诞树 → 奶奶 → 整把火柴 |
| 安静、留白、有情绪 | 雪夜、微光、孤独，与《小王子》调性同档 |
| 范围小 | 7 个场景、单一核心动词、15–25 分钟通关 |
| 零门槛分发 | 网页即玩（免费：序章 + 第一根火柴）→ Steam 完整版 |

## 核心体验（单一核心动词·每章只换数据）

物件不会走路，只能做三件事：

1. **燃烧（倒计时）**：每根火柴有一条火苗寿命（Resource 衰减）。火苗越弱，幻象越淡。
2. **照见（探索）**：幻象里藏着若干「美丽的东西」（热点）。火苗还亮着时点中它们，幻象才更完整，小女孩也更暖。
3. **护火（微动）**：寒风按时间线吹来，在提示窗口内护住火苗，否则火苗骤减。

火柴熄灭 = 本章结束（不是失败）。照见了多少，只决定结局里「她看到过的美丽东西」相册有多满。

## 调性红线

- 结局是死亡：**不渲染痛苦，不做煽情惩罚**；镜头留在光与微笑上，尊重原著的克制。
- 不加原著没有的反派、战斗或数值成长。
- 美术不借任何改编版造型（动画/电影），只从原著文本出发。
