# game103 ·《幸存者核心原型》核心玩法策划案（GDD）

> 版本 v0.1 · 2026-07-23 · 策划：game103
> 标杆：《Survivor.io（幸存者！.io）》《Vampire Survivors》
> 本文只覆盖**核心单局玩法**，商业化/社交/多角色养成见后续文档。

---

## 一、玩法综述

俯视角 2D 割草。玩家控制一名幸存者，在被无尽敌群包围的封闭场地中，靠**走位**躲避、靠**自动开火的武器**输出。击杀敌人掉落经验，攒够经验升级，升级时**三选一**强化武器或获得被动。当某把武器满级且携带对应被动，即触发**进化**，威力质变。目标是活满 **15 分钟**并击败最终 Boss。

**一句话循环**：走位躲怪 → 自动杀怪 → 捡经验 → 升级三选一 → 变强 → 面对更强的怪 →（重复）→ 进化 → 清屏 → 打 Boss → 结算。

---

## 二、核心循环（Core Loop）

```
       ┌───────────────────────────────────────────────┐
       │                                               │
       ▼                                               │
 [移动走位] ──> [武器自动攻击] ──> [击杀敌人] ──> [掉落经验宝石]
       ▲                                               │
       │                                               ▼
 [变强/进化] <── [三选一强化] <── [升级弹窗] <── [经验条满]
```

- **秒级循环**（0.1s）：移动 + 自动攻击 + 碰撞结算。
- **十秒级循环**（~10-30s）：升一级，做一次三选一决策。
- **分钟级循环**（1-15min）：波次推进、精英出现、凑进化、打 Boss。
- **局外循环**（跨局）：金币 → 局外永久升级 → 下一局起点更强（M4）。

## 三、操作与视角

| 项 | 设计 |
| --- | --- |
| 视角 | 俯视 2D，相机跟随玩家居中，轻微前瞻（朝移动方向偏移 ~40px） |
| 移动 | **单虚拟摇杆**（触屏左下）/ WASD / 方向键。8 向或全向皆可 |
| 攻击 | **全自动**，玩家不手动开火/瞄准 |
| 瞄准逻辑 | 见「四、武器系统」的目标选取规则 |
| 场地 | 封闭有边界（撞墙不出屏）或无限平铺地形；原型用**有界矩形 2400×2400** |
| 唯一深度操作 | 走位（拉扯怪群、卡地形、贪经验 vs 求生的取舍） |

> 设计信条：**只有"移动"一个操作**。停下=等死。所有策略深度在升级选择，不在操作。

## 四、武器系统

### 4.1 攻击自动化与目标选取

武器分两类，每类有独立的目标选取规则：

| 类型 | 攻击方式 | 目标选取 |
| --- | --- | --- |
| 近战（Melee） | 冷却好了自动挥/环绕/范围 | 以玩家为中心的区域/朝向 |
| 远程（Ranged） | 冷却好了自动射弹 | **最近敌人** / **随机敌人** / **朝移动反方向**（按武器定义） |

### 4.2 武器通用属性（可配置）

| 属性 | 说明 |
| --- | --- |
| `damage` | 单次伤害 |
| `cooldown` | 攻击间隔（秒） |
| `area` | 作用范围/弹体大小倍率 |
| `speed` | 弹速（远程） |
| `amount` | 单次投射物数量 |
| `duration` | 持续时间（持续型武器） |
| `pierce` | 穿透次数 |
| `knockback` | 击退 |
| `level` (1-5) | 每级提升上述部分属性；满级(5)+对应被动=可进化 |

### 4.3 首发武器清单（5 把，均可进化）

命名做原创化改写（避免直接照抄标杆 IP），保留机制原型：

| # | 武器 | 类型 | 机制原型 | 满级手感 |
| --- | --- | --- | --- | --- |
| W1 | **飞镖 Kunai** | 远程 | 向最近敌人连射直线飞镖，穿透 | 高频点杀，覆盖面窄 |
| W2 | **回旋镖 Boomerang** | 远程 | 抛出后返回，往返双段伤害 | 中距离清线 |
| W3 | **护盾环 Orbit** | 近战 | 数颗光球绕身旋转，触碰伤害 | 贴身保命 + 持续 |
| W4 | **冲击波 Shockwave** | 近战 | 周期性以自身为中心爆一圈 AoE | 解包围 |
| W5 | **激光 Laser** | 远程 | 蓄力后横扫一条直线，高伤穿透 | 高 DPS 直线秒杀 |

### 4.4 进化系统（核心爽点）

**进化条件（与标杆一致）**：`武器达到 5 级` **且** `携带指定被动（不要求被动满级）` → 下次开宝箱/满足瞬间自动进化为强化形态。

| 基础武器 | + 被动 | = 进化武器 | 进化收益 |
| --- | --- | --- | --- |
| 飞镖 Kunai | 锋刃手册（+攻击/暴击） | **万镖穿心** | 射速翻倍、必穿透、追踪 |
| 回旋镖 Boomerang | 疾风护符（+攻速） | **无限回环** | 常驻多枚环绕飞行 |
| 护盾环 Orbit | 能量核心（+范围） | **恒星轨道** | 光球数 +N、体积↑、附加灼烧 |
| 冲击波 Shockwave | 重力符文（+范围/击退） | **黑洞脉冲** | 吸附敌人后引爆 |
| 激光 Laser | 棱镜（+投射物数） | **死亡射线** | 多道激光扇形覆盖全屏 |

> 进化是"功率曲线的第二个台阶"。数值上：进化武器 DPS ≈ 满级基础武器的 **2.5–4×**，且附加质变机制（追踪/穿透/吸附/全屏）。

### 4.5 被动技能（Support / Passive，5 个首发）

被动不直接攻击，提供全局增益，且是进化钥匙：

| 被动 | 效果 | 作为进化钥匙 |
| --- | --- | --- |
| 锋刃手册 | 全武器伤害 +8%/级 | 飞镖 |
| 疾风护符 | 攻击冷却 -6%/级 | 回旋镖 |
| 能量核心 | 作用范围 +10%/级 | 护盾环 |
| 重力符文 | 击退/范围 +8%/级 | 冲击波 |
| 棱镜 | 投射物 +1（分级解锁） | 激光 |
| 生命护心（无进化用途） | 最大生命 +15%、回复 +0.2/s | — |
| 疾行靴（无进化用途） | 移速 +8%/级 | — |
| 磁石（无进化用途） | 拾取半径 +25%/级 | — |

> 三选一池 = 未满级武器升级 + 未满级被动升级 + （新武器/新被动，若槽位未满）。**武器槽 6 + 被动槽 6**（可配置）。槽满后不再出现新品，只出现已有项升级。

## 五、敌人与刷怪（Spawner）

### 5.1 敌人类型（首发）

| # | 敌人 | 行为 | HP | 速度 | 伤害 | 掉落 |
| --- | --- | --- | --- | --- | --- | --- |
| E1 | 蹒跚者 | 直线追玩家 | 低 | 慢 | 低 | 蓝经验 |
| E2 | 疾行者 | 快速追击 | 低 | 快 | 中 | 蓝经验 |
| E3 | 胖子 | 血厚、体型大、击退抗性 | 高 | 慢 | 中 | 绿经验 |
| E4 | 爆裂者 | 死亡时溅射/自爆 | 低 | 中 | 高(近身) | 蓝经验 |
| E5 | 精英（Elite） | 强化属性、周期出现 | 很高 | 中 | 高 | 宝箱/金经验 |
| E6 | Boss | 大血条、多阶段技能 | 极高 | 中 | 极高 | 通关判定 |

所有敌人**接触即伤**（碰撞持续伤害，带无敌帧 ~0.5s），无远程攻击（原型阶段），保持"被追着跑"的核心张力。

### 5.2 刷怪与难度曲线

- 时间驱动 + 波次表（见 `03-config-schema.md`）。**每 30 秒**难度台阶上升：刷新率↑、敌人 HP/伤害按时间系数增长。
- **难度系数**：`enemyHP = base × (1 + 0.08 × minute)`，`spawnRate = base × (1 + 0.12 × minute)`。
- **精英节点**：第 3/6/9/12 分钟各刷一波精英。
- **Boss 节点**：**第 15 分钟**刷最终 Boss，击杀=胜利；也可设计 10 分钟中 Boss。
- **围杀波（Swarm）**：每 ~90 秒一次密集大群（考验清屏/走位），是雪球检验点。

## 六、掉落与资源

| 掉落物 | 来源 | 作用 | 拾取 |
| --- | --- | --- | --- |
| 经验宝石（蓝/绿/金） | 击杀敌人 | 攒经验升级 | 进入拾取半径自动吸取 |
| 金币 | 少量敌人/破坏物 | 局外养成货币（M4） | 自动吸取 |
| 回血包 | 低概率掉落 | 即时回复生命 | 触碰生效 |
| 磁铁道具 | 精英/宝箱 | 立即吸全屏经验 | 触碰生效 |
| 炸弹道具 | 精英/宝箱 | 清屏 AoE | 触碰生效 |
| 宝箱 | 精英/Boss | 开出 1-5 次升级（含进化触发） | 触碰开启 |

**经验升级曲线**：`expToNext(level) = 5 + level × 10`（前期快、后期渐缓，可配置为分段）。

## 八、单局结构与胜负

| 阶段 | 时间 | 体验 |
| --- | --- | --- |
| 开局求生 | 0:00–1:30 | 武器弱、怪不多但威胁大，练走位 |
| 构筑成型 | 1:30–6:00 | 三选一凑流派，等第一件进化 |
| 滚雪球 | 6:00–12:00 | 进化到位，开始清屏，密集围杀波 |
| 决战 | 12:00–15:00 | 全屏怪 + Boss，检验 build 上限 |

- **胜利**：击杀 15 分钟 Boss（或活满 15:00）。
- **失败**：HP 归零。
- **结算**：存活时长、击杀数、最高等级、拾取金币、获得的进化 → 换算金币入局外账户。

## 九、局外元进度（Meta，M4 雏形）

单局赚金币 → 局外永久升级（每项多级，边际递增成本）：

| 局外升级 | 效果范围 |
| --- | --- |
| 基础攻击 | +2%/级 |
| 基础生命 | +5%/级 |
| 移速 | +1%/级 |
| 拾取半径 | +5%/级 |
| 初始金币加成 | +5%/级 |
| 复活次数 | +1（稀有） |

目的：给"失败也有收益"的正反馈，支撑长期重开动机。**原型阶段可仅留数据结构与结算入口，先不做完整商店 UI。**

## 十、数值总纲（DPS 功率曲线锚点）

设玩家 DPS 为 P，敌群总"血量涌入速率"为 M（HP/秒）。健康节奏满足：

- 0–1.5 min：`P ≈ 0.8×M`（略吃紧，需走位补足 → 紧张感）
- 1.5–6 min：`P ≈ 1.0–1.3×M`（基本压制，仍需走位）
- 6–12 min：`P ≈ 1.5–2.5×M`（进化后碾压，围杀波拉回平衡）
- 12–15 min：`P` 面对 Boss + 全屏怪，考验爆发上限

> 调优铁律：**任何新武器/敌人/被动，都要标注它把这条曲线推向哪。破坏"先紧张后碾压"节奏的改动一律回退。**

## 十一、原型里程碑拆解（对齐 M1–M5）

- **M1 灰盒**：玩家走位 + 1 武器自动攻击 + 1 种敌人刷怪 + 经验升级三选一（占位 UI）。验证「走位+自动攻击+升级」闭环手感。
- **M2 进化**：补齐 5 武器 5 被动 + 进化触发 + 槽位系统。验证「构筑差异化」。
- **M3 关卡**：波次表 + 4 敌人类型 + 精英 + Boss + 难度系数。验证 15 分钟节奏曲线。
- **M4 元进度**：金币结算 + 局外永久升级数据层。验证「失败有收益」。
- **M5 打磨**：受击反馈、命中特效、屏震、音效、数值平衡 pass、性能（对象池/空间网格）。

## 十二、风险与关注点

| 风险 | 缓解 |
| --- | --- |
| 实体过多导致卡顿（数百敌人×子弹） | 对象池 + 空间网格碰撞 + 屏外剔除 + 经验宝石合并 |
| 数值失衡（太强/太弱一路） | 全参数配置化 + 功率曲线锚点 + 快速迭代表 |
| 缺乏 build 多样性→重复感 | 保证进化组合互不重叠、流派清晰（穿透/环绕/AoE/全屏） |
| IP 侵权 | 武器/敌人命名原创化，仅复刻机制 |
