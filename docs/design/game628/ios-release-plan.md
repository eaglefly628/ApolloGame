## 2. 产品接入契约

1. 可玩入口先按能力计划与已裁方案实现，提供稳定 `mount(host)` / dispose，或通过真实 manifest 校验；不能创建空入口只为让打包通过。
2. 生成正式配置时使用 owner 所属 Bundle ID、已核实的版本 / buildNumber；不直接沿用示例 `dev.zerocraft.*`。密钥、签名身份和设备标识放本机 / 环境，不写入产品文档。
3. 首版按现有横屏设计验证 iPhone 与 iPad；原生生成器当前同时声明两类设备，故两类都需真实测试与截图。删减设备族必须单独改契约，不能只漏交 iPad 材料。
4. `resources` 逐项声明本作已登记资产并核离线请求；实际需要的 GLB、纹理、解码器、字体、字幕、音频和角色播放器均须随包。未声明资源或未授权素材阻断发行。
5. 本作以点击热点与护火为核心，不能照搬样板的拖动移动配置：样板 `runtime.touch` 需要 `Controllable`，本作未证明存在该玩家组件。点选仍走既有指针 / UI action 契约，环视由 GAP-628-05 裁决。
6. 按本作进度 / 相册设计选择存档编码和迁移；不要未经验证把全世界快照当作相册恢复。现有 SavePort / SaveSystem 可复用，具体消费路径需本作运行验证。
7. 正式媒体不得使用开发期 Mock 产物冒充真实角色、场景或表演；真实 Tripo / ARP / Mixamo 生产链未验仍如实记账。

没有提交一个 source 指向不存在路径的“正式产品配置”；这会绕开当前构建校验。资料草案 [app-store-draft.json](./app-store-draft.json) 与正式配置类型分开，缺失信息保留 null。
