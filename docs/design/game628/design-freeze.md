## 2. 风格令牌草案（待 owner 定）

| 令牌 | 值 | 用途 |
|---|---|---|
| 雪夜蓝 | `#1E2A44` | 现实层底色、UI 底 |
| 雪白 | `#E8EEF5` | 雪、正文字 |
| 火光橙 | `#FFB25A` | 火苗、热点微光、主按钮 |
| 余烬红 | `#C8553D` | 强调、火柴头 |
| 旧金 | `#E9C46A` | 幻象层高光、相册边框 |
| 字体 | 衬线手写感（中文宋体系 / 英文 serif） | 标题与引文；正文可用无衬线 |

UI 主题起手：`apolloOnyx`（深色）+ 本表覆盖，不自写皮（`capability-plan.md` §4.6）。

| 火苗 / 雪 / 星光 | **不出图**：引擎 `l7-vfx2d` 粒子 | — |

## 5. 审查（R1）

每章截火苗强 / 中 / 弱三帧，与该章关键图比对；UI 屏与 Claude Design 稿按同一把尺子比盒子。复查 agent ≠ 施工方。

## 6. 本作的执行顺序

1. owner 确认 GDD §9 四个问题 → GDD 升 v1.0
2. 定风格令牌（§2）
3. 第 1 波工具到位后：出 KA-02 → owner 定稿风格锚 → 出其余关键图与角色设定
4. 拆层单（D1）→ owner 确认
5. 跑 `ui-brief.mjs --game game628` 出 UI 需求单 → Claude Design 出稿 → 收稿
6. owner 签「设计定稿」→ 进 S3 骨架
