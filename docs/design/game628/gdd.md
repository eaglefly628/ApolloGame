## 1. 核心设定

- **玩家身份**：一根火柴，躺在小女孩的火柴盒里。不是小女孩，也不替她做决定。
- **玩家能做的只有三件事**：燃烧（被擦亮后持续倒计时）· 照见（在幻象里点中「美丽的东西」）· 护火（寒风来时护住火苗）。
- **不可改变的事**：原著结局。小女孩会在清晨被人发现。游戏不提供「救她」的分支——火柴能做的，是让她最后看到的东西更完整。
- **情感落点**：尾声相册。人们说「她想暖和一下」；只有火柴知道她看到过什么。

## 2. 核心循环（每根火柴一轮）

```
擦亮（火花）→ 幻象淡入 → 照见热点 / 护火 → 火苗衰减、幻象变淡 → 熄灭 → 章节卡 → 下一根
```

| 规则 | 首版数值 | 说明 |
|---|---|---|
| 火苗寿命 | 第 1–3 根各 40 秒；奶奶章 35 秒；终章整把 60 秒 | `flame` 资源，`t2-over-time` 每秒衰减 |
| 幻象变淡档 | 火苗 60% / 30% / 10% 三档 | 低于 10% 时热点仍可点，但画面接近全暗 |
| 寒风 | 第 1 根 1 次（教学）· 第 2 根 2 次 · 第 3 根 3 次 · 奶奶章 2 次（轻）· **终章无风** | 终章无风是叙事表达：世界终于安静了 |
| 风的预警 | 起风前 1 秒：雪粒变斜 + 风声渐起 | 预警是纯表现，判定只看时间线 |
| 护火窗口 | 1.5 秒 | 窗口内点击火苗即护住 |
| 风害 | 火苗 −30% 上限 | 不会一次吹灭；连吃两次才可能提前熄灭 |
| 热点数 | 第 1 根 4 · 第 2 根 5 · 第 3 根 6 · 流星 1 · 奶奶 4 · 终章 3，共 **23** | 对应相册 23 格 |
| 失败 | **无** | 火灭只是章节结束；没照见的东西相册里留空格 |
| 重玩 | 通关后解锁章节选择，可回去补相册 | 不重开整局 |

**不做**：一根火柴熄灭后再擦一根「补看」同一个幻象。每根火柴只对应一个幻象，这样范围最小，叙事也更干净。

## 6. 文本来源与版权

- 原著：安徒生 1845 年，公版。
- **译文不能直接用现代中文译本**（多数译本仍在版权期内）。中文由我们**从公版英文译本（H. P. Paull 1872 年译本）或丹麦文原文自行翻译改编**；英文可直接以 1872 年公版译本为底本改写。
- 文本全部数据化（`t3-dialogue` 节点 + `services/i18n` 字符串表），首发中 / 英。

## 7. 美术方向（详见 `design-freeze.md`）

- **3D 低多边形手作感**（owner 2026-10-22 定）；冷蓝雪夜与暖橙火光的强对比；大面积留白。每个幻象是一个可环视的小场景（diorama），火柴是镜头的视角锚点。
- 小女孩是 3D 角色（T-Pose 四视图 → Tripo 多视图建模 → Auto-Rig Pro 绑骨 → Mixamo 动作），镜头以**背影、侧影、手部特写**为主，不做正脸大特写——克制，也降低角色一致性风险。火柴挂在她手上（骨骼挂点），擦火柴时手对准火柴盒（IK）。
- 幻象层比现实层更饱和、更柔焦，火苗变弱时整体降饱和、向冷色回落。
