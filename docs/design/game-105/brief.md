## 1. 名字

《心跳叠叠乐》（Jenga of Hearts）

## 2. 一句话玩法

两人轮流从一座**真物理 54 块积木塔**里抽走一根，抽出来按积木颜色得「亲密度」并触发一张心动任务卡；
**塔塌在谁手里谁输**，输家按「自己抽过的颜色分值 + 撑到第几轮」结算惩罚。

## 3. 参考物

| 参照 | 借什么 |
|---|---|
| 实体叠叠乐 / Jenga | 核心张力：每抽一根都在动摇自己下一轮的处境 |
| 《Truth or Dare》类桌游 | 颜色→任务卡的分频道设计 |
| 引擎内先例 game-d `throw3d.ts` | 3D 物理定结果 + 落定读数的既有范式 |

## 4. 风格意向

- **受众**：情侣 / 约会同屏轮流玩（hot-seat 双人，非联机）
- **观感**：暖调暧昧夜色。UI house 主题起手取 `apolloBrocade`「锦霞」（暖白锦缎 + 金/胭脂波点 + 玫瑰点睛·手册标注适配「女性向」），非自写皮
- **3D 舞台**：一张桌 + 一座塔 + 双色打光，镜头绕塔。塔是唯一主体，UI 让位于塔
