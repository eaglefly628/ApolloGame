# M2.5 登记契约 · pending 清单 + provenance/license 硬字段

> **REQ-PA-工坊工位四件 ② 交付**（PA·PST 图纸补件）。M2.5 人审门已由 PST 落地（`scripts/ai-gen.mjs`）——本契约=**登记面单一真相**：字段名 / 必填 / 校验规则 / 示例。PST 照它实现、PA 照它审 diff。宪法约束：**AI 产物无自动入库**（唯一入 `index.json` 的门 = `reviewPending(approve)` 且 provenance 硬校验过）。

## 一、两级落点（game 给了=游戏本地；否则=共享货架）

| | 待审清单 | 待审文件 | 最终索引 | 最终文件 |
|---|---|---|---|---|
| 共享货架 | `assets/ai/pending.json` | `assets/ai/pending/<base>` | `assets/index.json` | `assets/ai/<adapter>/<slug>.<ext>` |
| 游戏本地 | `public/games/<g>/art/ai/pending.json` | `.../pending/<base>` | `public/games/<g>/art/index.json` | `.../ai/<adapter>/<slug>.<ext>` |

`base = <adapter>-<slug>.<ext>`·`slug = (id|prompt) 小写非字母数字压成 '-'·截 40`。**pending 文件绝不进 index.json**（宪法）。

## 二、pending.json 清单结构

```json
{ "version": 1, "pending": [ <pendingEntry>, … ] }   // pending 按 id 升序·同 id 覆盖（重生成删旧待审文件）
```

`pendingEntry` = 一条干净 index 条目 + 4 个**审门机制字段**（approve 时剥除，不进 index）：

| 机制字段 | 含义 |
|---|---|
| `previewPath` | 待审预览 URL（`/…/ai/pending/<base>`）——UI before/after 用 |
| `pendingFile` | 待审文件名 `<base>` |
| `finalRel` | approve 后最终相对落点 `ai/<adapter>/<slug>.<ext>` |
| `scope` | `shelf` 或 `game:<g>`（聚合列表分组用） |

## 三、index 条目结构（approve 后写入·登记面真相）

```json
{
  "id": "ai/<adapter>/<slug>",   "type": "texture|mesh",   "status": "filled",
  "description": "<prompt> · AI 生成(<adapter>[·mock])",
  "path": "<servedPath>",         "category": "ai-gen|mesh",
  "tags": ["ai-gen", "<adapter>", "…prompt 词≤6"],
  "license": "<厂商授权串>",       "source": "ai:<adapter>",
  "spec": { … },                  // texture: {format,width,height,usage}；mesh: {scale,genCollision}
  "provenance": { "generator": "<adapter>", "prompt": "…", "model": "…", "mock": false, "generatedAt": "YYYY-MM-DD" }
}
```

## 四、硬字段校验（`provenanceMissing`·缺一即拒绝登记）

登记门（approve）逐条查以下四项，**任一缺失→拒登记并回报缺失字段名**（宪法·§七约束2）：

| 硬字段 | 位置 | 规则 |
|---|---|---|
| `model` | `provenance.model` | 非空——具体生成模型名（如 `wanx2.1-t2i-turbo`·mock 记 `<adapter>-mock`） |
| `prompt` | `provenance.prompt` | 非空——原始提示词原文 |
| `date` | `provenance.generatedAt` | 非空——生成日期 `YYYY-MM-DD` |
| `license` | 条目 `license` | 非空——授权串（发行前 PA 复核最终授权） |

> `mock:true` 产物**允许**入库（占位真相·tags 带 `mock`），但四硬字段一样不得缺。

## 五、审核动作

- **approve**：硬校验过→拷贝待审文件进最终位+删待审→剥机制字段→upsert `index.json`（按 id 排序）→清待审项。失败态：provenance 缺字段 / 待审文件丢失 → 不登记、回错。
- **reject**：删待审文件+清待审项，`index.json` 零改动。
- 命令：`node scripts/ai-gen.mjs review <id> <approve|reject> [--game <g>]`；`pending [--game <g>]` 列待审。端点 `POST /api/assets/review`（唯一入 index 的门）。

## 六、示例待审条目（共享货架·texture）

```json
{
  "id": "ai/qwen/red-dragon-token", "type": "texture", "status": "filled",
  "description": "red dragon token flat icon · AI 生成(qwen)",
  "path": "ai/qwen/red-dragon-token.png", "category": "ai-gen",
  "tags": ["ai-gen","qwen","red","dragon","token","flat","icon"],
  "license": "Qwen/DashScope 万相 (按订阅授权)", "source": "ai:qwen",
  "spec": { "format": "png", "width": 1024, "height": 1024, "usage": "sprite" },
  "provenance": { "generator": "qwen", "prompt": "red dragon token flat icon", "model": "wanx2.1-t2i-turbo", "mock": false, "generatedAt": "2026-07-22" },
  "previewPath": "/assets/ai/pending/qwen-red-dragon-token.png",
  "pendingFile": "qwen-red-dragon-token.png", "finalRel": "ai/qwen/red-dragon-token.png", "scope": "shelf"
}
```

> **红线**：authoring-time 旁路·产物=固定数据·不碰 sim/hash。契约随 `ai-gen.mjs` 实现走——改字段先改这里再改码（登记面口径单一真相）。
