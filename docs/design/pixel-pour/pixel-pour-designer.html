玩法构件

🎡

传送带 Conveyor

承载色炮到发射位，容量上限 6；超出需等待。到达发射位自动向中央同色方块开火。

🔫

色炮 Cannon

属性 {color, ammo}，默认 3 发。只攻击自身颜色，无需手动选目标。

🧱

中央像素方块 Cubes

带颜色 + hp（普通 1 / 硬块 2-3）。同色打满即消。可排成隐藏像素图案做收集钩子。

🗄️

待命槽 ×5

打光弹药的色炮滑入槽位；点击跳回传送带补一轮火。堆叠 / 排序 / 择机齐射 = 策略层。

🔥

连击 & 突破上限

连续快速消除累积 Combo 提升倍率；手速够快临时突破托盘上限堆到 10，救回死局——技巧天花板。

🏁

胜负

胜：清空全部方块 / 拼成目标图案。负：步数或时限用尽仍有方块，或传送带+待命槽全满死锁。

界面布局 · 实机原型

顶部 HUD — 关卡 · 剩余方块 · 得分 · COMBO
目标区 — 中央像素方块阵（可拼图案）
传送带 — 发射位在左端 · 容量 6/突破 10
待命槽 — 5 格 · 点击复用装填
补给区 — 点击颜色发射色炮 · 角标=剩余同色数

竖屏自上而下；卡通像素风，颜色+形状双编码（色盲友好）。可玩原型见 prototype.html。

数据驱动落地（引擎口径）

依数据驱动宪法：规则摆成数据表，由现有引擎 capability 解释。核心构件映射（详见 capability-plan.md）：

待命槽 = tray · 传送带容量 = zone-occupancy · 发射 = launch + hitbox · 剩余同色统计 = group-count · 胜负链 = event-when + effect-apply + flow · 随机 = 种子 PRNG（禁裸 Math.random）· UI = LayoutNode 纯数据。 唯一待裁：传送带有序编排——先按组合表达装配，实证表达不了再下沉 conveyor-queue 通用能力（走 requests.md）。
