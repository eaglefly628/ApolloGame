## 这四件（已自做一版·请过目）

### ① T1：三张招式卡放大到**中央通道**（不是全屏）

- 玩家在放大的卡上点一张给那只手蓄力。
- **硬约束**：右上角对手蓄力条（x 1188–1808, y 110–180）与顶栏**必须全程可见**——
  T1 正是对手在存力那一拍，盖住它等于把这游戏的核心信息在最关键的时刻关掉。
- 可用空间 = 你们本来就留出来的那条中央通道（两手之间 + 手的上方，约 x 300–1620 / y 150–790）。
  两只手在 T1 是待机握拳，**可以**被卡片部分遮挡。
- 请给：放大后的三张卡尺寸、落点、间距、入场缓动；底栏原位在这一拍怎么处理（留空？虚影？）。
- **现状**：卡放大到 **340×460**，三张摆在 `x=390 / 790 / 1190`（间距 60）、`y=240–700`；
  由相位时钟插值（不是 CSS 关键帧）——进场 260ms `easeOutBack`，收场 320ms `easeInOut`，
  缩放量化到 0.1 档（不量化的话每帧一张新皮，整屏面板全量重建）。底栏原位**不留虚影**：
  卡是"从底栏长上去"的同一个元素，一路插值过去。顶栏与右上角对手条全程没被碰到。

### ② T1 的三段动画

1. **放大上去**：三张卡从底栏原位到中央通道；
2. **注水**：点中的那张**像水灌满一样、从下往上注色**（不是整块换色）——请给填充色、边界处理、时长；
3. **缩回 + 粒子注入**：倒计时结束缩回原位，从被选中的那张射出**高亮粒子**，飞进下方蓄力槽**对应的那一格**——
   请给弧度、颜色、密度、拖尾。
- **现状**：注水 = 卡面皮里烤的一层「从底往上灌到 level」+ 一条 4px 白水线，色 = 该手色条的 55% 透明版，
  从点下去那一刻起灌 450ms。粒子 = 3 粒 22px 圆点（该手色 + 白发光），用基座件
  `layout.flyTo{to:'cb-p1-<手>', ms:320, arc:90, delay:i*60}` 飞进对应那一格，只在收场那 320ms 出现。
  **没有拖尾**（闭集里没有，要拖尾得开单）。

### ③ T2：**罚血读秒态**

免费 5 秒走完后，界面要明确变成「你在被罚」：
- 倒计时环从"还剩多久"变成"你已经欠了多少"（形态请你们定）；
- 每秒 −1 要有**一秒一记**的节拍感，不是连续滑落；
- **必须与"被对手打中"区分得开**——罚血不是战果，不该触发胜负横幅。
- **现状**：环整圈转红、圈心从「N.N 秒」翻成「**-N**」（欠了几点）、圈下一行写「出手即停」，
  相位牌从「出招」换成「**拖延中**」；每秒一闪 180ms 的淡红纱（浓度 .16，只有挨打那一下的三分之一）。
  胜负横幅不触发。**血条会跟着一秒一格地掉**（2026-08-08 接线完成——早先那句「卡在引擎缺口」作废：
  举证经实查证伪，`t2-self-rule` 的 `whenGlobal` + `do` 本来就够用）。拖到血光会直接判负。

### ④ 结算演出加重 + T4 按钮

- **伤害数字跳数**（不是直接显示终值）；你们定的 `56 + dmg×2.1` 字号规则保留；
- **血槽双段条**：先掉的那段延迟追上来，让玩家看清这一波掉了多少；
- **红色震动**，**幅度随掉血量变化**——请给三档（10 / 20–30 / 40）的位移与时长；
- **蓄力回撤**：出过的手清零时演出式退回，不是瞬间归零；
- **「下一轮」按钮**：结算屏现在由它推进。注意它和终局屏的「再来一局」是两个键，风格该有关联但不能混淆。
- **现状**：
  · 伤害数字用 `Label.tween{from:0,to:N,ms:420}` 跳数，字号仍按你们的 `56 + dmg×2.1`；减号单独一枚
    Label（tween 接管的是数字本身，前缀塞不进去）。
  · 血槽双段条：`hpBar` 加了 `ghostPct`，先掉的那段用惨白留在原处，延迟 220ms、620ms 追平。
  · 红色震动：整块舞台按 `4 + dmg×0.35` px 抖（10→±7.5 / 20→±11 / 30→±14.5 / 40→±18），
    衰减正弦 480ms + 一层红纱（浓度随伤害，上限 .42）。**只有我挨打才红屏**（打中对手时红屏
    会让玩家以为自己被打了）。
  · 蓄力回撤：槽里的灯**一格一格灭**（每格 180ms，延迟 220ms 开始），不是瞬间归零。
  · 「下一轮」**占了三张招式卡的整条位置**（582×252 的糖果金键）——不是另找空地：
    中区那条带（y≈690–780）同时被结果横幅的尾巴和角色字幕占着，第一版摆那儿被「伤害落定」
    压掉大半、点击探针点上去打在横幅上、**世界零反应且不报错**（截图 `S4-play-2c-settle-gate.png`
    存的就是那一幕）。T4 的三张卡本来全是灰的「本回合不可点」，把这一拍唯一的动作摆到最显眼处
    既没叠层也是对的信息层级。终局屏那枚仍叫「再来一局」，DOM id 也故意不同名。
