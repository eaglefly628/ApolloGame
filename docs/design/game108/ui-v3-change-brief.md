## 请补的四件

### ① T1：三张招式卡放大到**中央通道**（不是全屏）

- 玩家在放大的卡上点一张给那只手蓄力。
- **硬约束**：右上角对手蓄力条（x 1188–1808, y 110–180）与顶栏**必须全程可见**——
  T1 正是对手在存力那一拍，盖住它等于把这游戏的核心信息在最关键的时刻关掉。
- 可用空间 = 你们本来就留出来的那条中央通道（两手之间 + 手的上方，约 x 300–1620 / y 150–790）。
  两只手在 T1 是待机握拳，**可以**被卡片部分遮挡。
- 请给：放大后的三张卡尺寸、落点、间距、入场缓动；底栏原位在这一拍怎么处理（留空？虚影？）。

### ② T1 的三段动画

1. **放大上去**：三张卡从底栏原位到中央通道；
2. **注水**：点中的那张**像水灌满一样、从下往上注色**（不是整块换色）——请给填充色、边界处理、时长；
3. **缩回 + 粒子注入**：倒计时结束缩回原位，从被选中的那张射出**高亮粒子**，飞进下方蓄力槽**对应的那一格**——
   请给弧度、颜色、密度、拖尾。

### ③ T2：**罚血读秒态**

免费 5 秒走完后，界面要明确变成「你在被罚」：
- 倒计时环从"还剩多久"变成"你已经欠了多少"（形态请你们定）；
- 每秒 −1 要有**一秒一记**的节拍感，不是连续滑落；
- **必须与"被对手打中"区分得开**——罚血不是战果，不该触发胜负横幅。

### ④ 结算演出加重 + T4 按钮

- **伤害数字跳数**（不是直接显示终值）；你们定的 `56 + dmg×2.1` 字号规则保留；
- **血槽双段条**：先掉的那段延迟追上来，让玩家看清这一波掉了多少；
- **红色震动**，**幅度随掉血量变化**——请给三档（10 / 20–30 / 40）的位移与时长；
- **蓄力回撤**：出过的手清零时演出式退回，不是瞬间归零；
- **「下一轮」按钮**：结算屏现在由它推进。注意它和终局屏的「再来一局」是两个键，风格该有关联但不能混淆。
