## 0. 品类定位（v2 改写·验收基准）

**超休闲的操作 × 轻 roguelite 的深度。**

- 操作面：一回合两次点击、三秒一决、一场 60-90 秒、零记忆、零算术。
- 深度面：公开信息下的二阶心理博弈 + 单局内的规则构筑。

> **验收铁律**：任何需要玩家**记住**（已出过什么）或**心算**（倍率、资源攒到几点）的设计，一律砍。
> 深度只许来自**看得见的状态互相咬**，不许来自记账能力。

## 1. 设计支柱

| 支柱 | 一句话 | 违反它的设计一律砍 |
|---|---|---|
| **读的是宣告，不是记忆** | 蓄力槽公开 = 玩家的意图被迫摆上台面，读它不需要记任何事 | 任何隐藏累积状态 |
| **规则会变** | 判定表本身是战利品，且在对局内就会变 | 把判定表写死成 3×3 的实现 |
| **一局一决断** | 每回合两次点击都必须有真取舍 | 存在恒定最优手 |

**目标体验**：60-90 秒里被人骗一次、骗回去一次，结束时想立刻再来一局。

## 2. 核心循环

```
爬塔选路 → 一场对局（6-10 回合三时区） → 胜 → 二选一遗物（凿改判定表） → 下一场 → Boss → 结算/图鉴
```

## 3. 对局结构：三时区

**【R-108-01】** 每回合固定四拍，**T1 与 T2 均为「同时提交」**——无先后手，信息对称：

| 时区 | 时长 | 双方做什么 | 信息状态 |
|---|---|---|---|
| **T1 蓄力时区** | 3 秒 | 各自点一手蓄力 | **同时提交 → 立即公开**（六条槽当场刷新） |
| **T2 出招时区** | 3 秒 | 各自点一手出招（**不必是刚蓄的那手**） | **同时提交 → 全程隐藏** |
| **T3 对决时区** | 2 秒 | 亮拳 → 克制判定 → 伤害演出 | 全公开 |
| **T4 结算** | 1 秒 | 出过的手清零 · 扣血 · 判胜负 | 全公开 |

**【R-108-02】** T1/T2 超时未选 → **随机顺延为「保持上一回合的选择」**（不罚玩家、不卡节奏、确定性由种子 PRNG 保证）。

**【R-108-03】** 台面常驻**六条蓄力槽**（我方三 + 对方三），任何时刻零操作可读。这是本作信息呈现的硬需求，不是 UI 偏好。

## 4. 六条核心规则

**【R-108-10】蓄力**：T1 往一手存 **+1**，**上限 3**；已满的手当回合不可再存（**逼分散**，不许一路死磕一手）。
**【R-108-11】出招**：T2 出任意一手，**不必是蓄过的那手**（这是诈唬的载体）。
**【R-108-12】判定**：克制关系定胜负（石 > 剪 > 布 > 石）。**蓄力不影响谁赢，只影响赢了打多少。**
**【R-108-13】伤害**：`10 × (1 + 该手当前蓄力)` → **10 / 20 / 30 / 40**。
**【R-108-14】消耗**：**出过的手蓄力清零**——不论胜、负、平。没出的手原样保留。
**【R-108-15】胜负**：双方血量 **100**，先归零者败。**平局双方不掉血，但双方出过的手都清零。**

## 5. 数值表（v2 首版）

| 项 | 值 | 设计理由 |
|---|---|---|
| 血量（双方一律） | **100** | **难度不靠血条**——Boss 也是 100，差异来自规则优势 |
| 蓄力上限 | 3 | 满蓄需攒 3 回合 → 一场只够兑现 1-2 次 = 大招的稀有度 |
| 伤害 | 10 / 20 / 30 / 40 | 一眼能算；满蓄一击 = 四成血；三次满蓄命中必死 |
| 一场时长 | 6-10 回合 ≈ 60-90 秒 | 一回合 ≈ 9 秒 |
| 时区秒数 | 3 / 3 / 2 / 1 | **咬死 3 秒**——给到 8 秒就变中核了 |
| 烟雾 | 每场 1 次 · 遮 2 回合 | 底牌，不是可循环资源 |
| 逆转碎片 | 血 ≤50 时落后方触发 · 每场 1 次 | 防一边倒 + 天然第二幕 |

## 6. 为什么这套规则不会退化（自洽性验算·勿删）

最大的怀疑：**玩家会不会永远「蓄满一手然后出它」**？那就可预测，游戏就死了。

因为【R-108-14】出过即清零，**满蓄被克 = 一次赔掉三回合**（没伤到人 + 三点力归零 + 还挨一下）。于是自然长出风险曲线：

| 出的手 | 赢了 | 输了 |
|---|---|---|
| 裸手（0 蓄） | 打 10（几乎没赚） | 几乎没赔 |
| 半蓄（2） | 打 30 | 赔 2 点力 |
| 满蓄（3） | 打 40（四成血） | **赔光三回合，还挨一下** |

**兑现越大，被读的代价越重** → 「什么时候兑现」成为每局最纠结的事。**规则自己锁住了，不需要额外惩罚项。**

## 7. 蓄力 = 资源 + 谎言（本作的心理引擎）

蓄力槽公开，所以往石头里存力 **等于当着对手的面说「我可能要出石头」**。而这句话可以是假的：

> 蓄三回合石头 → 出剪刀。代价是那三点力还压在槽里没兑现；收益是对手白防了三回合。

**这给「说谎」装上了看得见的成本**——纯猜拳永远做不到这件事。

**且它自带倒计时**：不出的手一直在涨，蓄满的手是一颗双方都看得见、越来越大的炸弹，**你不能永远不兑现**。所以每一轮都必须有人先眨眼。

## 8. 烟雾（三道锁）

**【R-108-20】** 每场限 **1 次**，遮蔽**自己**三条槽 **2 回合**。
**【R-108-21】** **「放烟雾」这个动作本身公开**——对手看得见你在放，只是看不见槽里发生了什么。**藏这件事本身就是信息。**
**【R-108-22】** 雾中蓄力照常累积，**出雾时全部曝光**——那两回合的紧张一路累到揭晓，**雾散是一场里最好看的一帧**。

## 9. 对手：表演型 AI（不是统计型）

**【R-108-30】** AI 出招 = **条件加权表**（规则自上而下首个命中生效，权重经世界种子 PRNG 抽取）。**AI 不打纳什均衡**——它有偏好、有破绽、会上当，这是单机乐趣的来源。
**【R-108-31】** **tell = 表演，不是数据**：出招前立绘做夸张预备动作（攥拳/手指抖/擦汗）。玩家读的是动画与表情，**不需要理解任何概率**。
**【R-108-32】** 五名对手 = 一条教学曲线，不是五个数值不同的怪：

| # | 对手 | 行为 | 破绽 | 教什么 |
|---|---|---|---|---|
| 1 | **复读机** | 倾向复用上一回合赢过的手 | 明显·必现 | 「对手是有规律的」（启蒙） |
| 2 | **莽夫** | 偏爱石头；蓄满必兑现 | 攥拳·高频 | 读表演 |
| 3 | **戏子** | **蓄一手、出另一手**（专职诈唬） | 假动作 | 「蓄力会说谎」 |
| 4 | **赌徒**（精英） | 血少时必押满蓄；先用烟雾 | 血低时破绽变多 | 烟雾与逆转 |
| 5 | **拳律大师**（Boss） | 自带改写过的判定表 + **蓄力上限 4** | 半真半假 | 总检 |

> 设计红线：AI 必须 **3-4 回合内可读**。读不出来的 AI = 随机数发生器 = 违反支柱一。
> **Boss 强在规则，不强在血条**（【R-108-15】双方一律 100）。

## 10. 凿改层（规则构筑）

**【R-108-40】** 石板 = 判定表的可视化，常驻台面中央；被改写时当场凿裂重刻。
**【R-108-41】** **局间**：每胜一场，二选一遗物（改判定表 / 改收益 / 改蓄力）。
**【R-108-42】** **局内逆转**：任一方血量首次 ≤50 时，**落后方**获得一次二选一石板碎片，当场生效（每场限 1 次）。
**【R-108-43】** **直觉存活期**：一轮之内「改克制关系」类最多 **2-3 件**生效，其余只改收益/蓄力——规则可以变，但不能一直变，否则玩家永远建立不起直觉。

## 11. 爬塔与局外

**【R-108-50】** 一轮 = 3 层 × (2 常规 + 1 精英) + Boss = **10 场 ≈ 12-15 分钟**；每胜一场二选一遗物；层间回复 30 血。
**【R-108-51】** v1 线性推进（`LevelPath` 只做进度展示）；**分叉选路留二期**。
**【R-108-52】** 局外：图鉴（对手 / 遗物 / 判定表变体）· **每日种子挑战**（同 seed 同塔·可回放·榜）· 解锁。
**【R-108-53】** **血量决定谁赢，分数决定排第几**：一场按「剩余血量 + 连胜 + 最大一击」折算分数，只用于榜与每日挑战，**不进对局内任何计算**。

## 12. 联机路线（分期·不进 v1）

**【R-108-60】** **v1 = 纯单机**。理由：表演型 AI 的破绽/性格/tell 是单机独有的乐趣，真人对手没有这些；PvP 成本 80% 不在同步，在账号/匹配/防作弊/运营。
**【R-108-61】** **v1.5 = 异步幽灵对战**（对手历史出招序列 + 种子回放）——确定性回放引擎已具备，**近乎零成本**拿到好友榜/复仇/社交钩子，零实时基建、零断线、零作弊面。
**【R-108-62】** **v2 = 真实时 PvP，走权威服务器 + 状态同步**，不走帧同步。
- 回合制 + 6 选 1 输入 → 帧同步的带宽优势为零，代价（确定性洁癖 / desync 排查）全付。
- **同时出招 + 帧同步 = 可作弊**：对端会先收到对方命令才被迫提交，作弊客户端可等看到对方再出。必须**承诺-揭示**或**权威服务器**。这是公平问题，帧同步天然解决不了。
