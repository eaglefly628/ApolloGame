## 1. 设计支柱

| 支柱 | 一句话 | 违反它的设计一律砍 |
|---|---|---|
| **读人 > 猜数** | 玩家赢是因为读懂了对手，不是因为运气好 | 任何让最优解回归「均匀随机」的改动 |
| **规则会变** | 判定表本身是战利品 | 把判定表写死成 3×3 的实现 |
| **一局一决断** | 每回合都有真实取舍，不许无脑出牌 | 存在恒定最优手 |

**目标体验**：一场 2-4 分钟的心理拉锯；结束时玩家能说出「我是怎么赢的」。

## 2. 核心循环

```
爬塔选路 → 单挑对局（多回合猜拳） → 胜 → 三选一遗物（可能凿改判定表） → 下一场 → Boss → 结算/图鉴
```

## 3. 对局规则（A 线核心）

### 3.1 判定表

**【R-108-01】** 判定表是数据，形态 = `{ throws[], beats{}, payoff{}, tie{} }`。默认三手：

```
throws: [rock, paper, scissors]
beats:  rock→scissors · paper→rock · scissors→paper
```

**【R-108-02】** 胜负结算：胜方按**己方所出手**的 `payoff.damage` 对败方造成伤害。

| 手 | 伤害 | 胜时附带 | 定位 |
|---|---|---|---|
| 石 rock | 6 | — | 钝重·高风险高回报 |
| 剪 scissors | 5 | +1 洞察点 | 资源手 |
| 布 paper | 4 | 抽 1 张 | 滚雪球·低伤 |

**【R-108-03】** 平局：双方各受 **1 点僵持伤**（`tie.selfDamage`）。存在理由 = 逼玩家做决定，禁止磨蹭。
**【R-108-04】** 胜时附带效果走闭集（`draw` / `gainInsight` / `heal` / `damageBonus`），遗物可增改。

### 3.2 手牌与信息

**【R-108-05】** 牌库 12 张（石 4 / 布 4 / 剪 4），手牌 5 张，出一张补一张（牌库非空时）。
**【R-108-06】** **双方弃牌区全程公开且持久**——这是本作演绎深度的唯一来源，任何时候不得隐藏。
**【R-108-07】** 牌库耗尽且手牌打空 → 弃牌区确定性洗回成新牌库（种子化洗牌），公开信息清零 = 节奏的一张一弛。

### 3.3 洞察点

**【R-108-08】** 上限 5，对局开始为 0。
- 花 **1 点** → 窥视对手手牌中的 1 张（种子化选取）。
- 花 **3 点** → 强制对手本回合重新出牌（重出后 tell 重新生成）。

### 3.4 血量与回合

**【R-108-09】** 玩家 30；小怪 24 / 精英 32 / Boss 45。任一方 HP ≤ 0 → 对局结束。
**【R-108-10】** 回合流程（固定七拍）：

```
① 抽补 → ② 双方选牌（AI 同回合锁定但不亮） → ③ tell 展示
→ ④ 加码阶段（仅精英/Boss） → ⑤ 亮牌 → ⑥ 判定表结算 → ⑦ 附带效果结算
```

## 4. 加码与弃权（B 线变奏）

**【R-108-11】** 加码**只在精英战与 Boss 战启用**（小怪战保持纯净，用于教学与节奏喘息）。
亮牌前双方各可押 0/1/2 枚拳票；本回合伤害 ×(1 + 双方押注总数)。
**【R-108-12】** **弃权**：亮牌前任一方可弃权 → 本回合不亮牌，**双方手牌均不消耗、不进弃牌区**（买的就是信息保护）。
弃权方受伤 = `2 × 本场已弃权次数`（第 1 次 2、第 2 次 4、第 3 次 6）——**递增即自限**，不设次数上限，天然防僵局。
**【R-108-13】** 拳票：每胜一回合 +1，上限 5，对局开始为 0，不跨对局保留。

> 设计意图：弃权把「我不知道」变成一个**要付钱的合法选项**。这是 B 线最值钱的一格，也是小怪战不该有的复杂度。

## 5. 读心层（对手 = 数据）

**【R-108-20】** AI 出招 = **条件加权表**：规则自上而下，**首个命中者生效**，按权重经世界种子 PRNG 抽取；无规则命中走 `fallback` 均匀权重。

```
policy: {
  rules: [ { when: <条件>, weights: {rock, paper, scissors} } ],
  fallback: { weights: {1,1,1} }
}
```

**【R-108-21】** tell（破绽）：每对手一个 `tellKind` + `tellRate`（种子概率门决定本回合是否泄露）：

| tellKind | 显示 | 含义 |
|---|---|---|
| `exclude` | 「不会是 X」 | X = 其本回合**未选**的一手（真情报） |
| `hint` | 「像是 X」 | X = 其真实选择（真情报） |
| `false` | 「像是 X」 | 以 `falseRate` 概率 X ≠ 真实选择（假动作） |
| `none` | — | 无破绽（但策略表本身裸奔） |

**【R-108-22】** 首发五名对手：

| # | 对手 | 策略表 | tell | 教什么 |
|---|---|---|---|---|
| 1 | **复读机** | 抄玩家上一手（权重 90/5/5 指向该手） | `none` | 教「对手是可预测的」 |
| 2 | **莽夫** | 石 50/25/25；连胜后必复读同手 | `hint` 0.6 | 教「读 tell」 |
| 3 | **学者** | 统计玩家出得最多的手 → 出其克制手，**延迟 1 拍** | `exclude` 0.5 | 教「反利用：喂假数据」 |
| 4 | **赌徒**（精英） | 常态均匀；HP<1/3 时全押高伤手；加码激进 | `hint` 0.4 | 教「加码与弃权」 |
| 5 | **拳律大师**（Boss） | 三段式：前 3 回合采样 → 镜像反制 → 半血起**每 3 回合凿改一次判定表** | `false` 0.5 | 总检 |

> 设计红线：策略表必须**可被玩家在 3-4 回合内读出来**。读不出来的 AI = 随机数发生器 = 违反支柱一。

## 6. 凿改层（遗物 = 判定表补丁）

**【R-108-30】** 遗物 = 对判定表/收益表的**数据补丁**，对局开始前按拾取顺序叠加套用。
**【R-108-31】** 首发 12 件：

| # | 遗物 | 效果（补丁） | 类型 |
|---|---|---|---|
| 1 | **反律石板** | `beats` 中 石↔布 关系反转（石克布，布不再克石） | 改表 |
| 2 | **同调** | `tie.selfDamage=0`，改为双方各回 3 血 | 改表 |
| 3 | **剪刀祭** | 剪伤害 ×2；剪判负时自伤 3 | 改收益 |
| 4 | **第四指·空手** | `throws` 增设 `void`：对任何手皆平，每场限 1 张，打出后下一手伤害 +5 | **增维** |
| 5 | **复读蓄力** | 连出同手 → 伤害 +3，且蓄力状态**对手可见** | 改收益 |
| 6 | **镜** | 本场首次判负改判为平 | 改判定 |
| 7 | **重拳** | 石伤害 6→9；石判负时受伤 +2 | 改收益 |
| 8 | **纸甲** | 布判负时受伤 −2 | 改收益 |
| 9 | **读心术** | 每场开局白给 2 洞察点 | 资源 |
| 10 | **快手** | 手牌上限 5→6 | 手牌 |
| 11 | **断牌** | 牌库减为 9 张（3/3/3）——信息更密、演绎更快 | 手牌 |
| 12 | **拳票商** | 加码上限 2→3 | B 线 |

> **4 号「第四指」是本作的技术验证物**：它证明「加一手 = 加一行一列的数据」，不是改代码。竖切必须包含它或 1 号。

## 10. 验收剧本骨架（S4 用·GD 写·PE 不许改）

固定 seed，逐步对账（详本随 S3 骨架落 `acceptance/`）：

1. **基础判定**：出石 vs 剪 → 对手 −6，玩家不掉血。
2. **平局僵持**：双方同手 → 各 −1。
3. **改表生效**：套「反律石板」后 出石 vs 布 → **石胜**（原规则应为负）。
4. **增维生效**：套「第四指」后打 `void` vs 任意手 → 判平；下一手伤害 +5。
5. **弃权递增**：连弃两次 → 依次 −2、−4，且**双方手牌张数不变、弃牌区不变**。
6. **洗回**：打空牌库与手牌 → 弃牌区洗回、公开信息清零，同 seed 双跑序列一致。
