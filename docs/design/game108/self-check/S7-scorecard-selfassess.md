## 二、性能证据（原始输出·2026-08-08）

真浏览器、真对局中采样 420 帧（弃前 5 帧暖机）：

```json
{ "frames": 415, "median_ms": 16.7, "p95_ms": 16.7, "p99_ms": 16.8, "max_ms": 16.8, "domNodes": 177 }
```

读法：`median = p95 = p99 = max = 16.7~16.8ms` —— 分布**完全平**，说明整局没有任何一帧
超出 16.7ms 的 vsync 预算。这条同时反证了一个曾经的隐患：加载条量化到 5%（21 挡）之后，
data-URI 皮不再每帧重建，`mountUI` 没有逐帧重挂面板。

像素基准：`node scripts/golden-shot.mjs capture --game game108` →
`public/games/game108/golden/boot.png`（`stable: true`·两次重拍 sha256 一致·`flaky: false`）。
⚠ 它现在是 **candidate 不是 blessed**：`bless` 是**人门语义**（note 必填 = 裁决留痕），归复查人/owner。
