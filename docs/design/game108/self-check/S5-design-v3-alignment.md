## 二、**做不到 / 有意偏离**的（逐条给理由·请设计方与 PUI 裁）

| # | 定稿要求 | 现状 | 为什么 |
|---|---|---|---|
| 1 | 注水面 = **两条错频椭圆脊**（主脊 20px scaleY 1↔.5 且左右荡 ±3%/900ms · 副脊 16px 白 55% 反向荡/1250ms）+ 整杯 `rt3-slosh` ±1.6° + **3 颗气泡** | 只做了**一条亮水线 + 四段过冲** | 水面是烤进卡皮的 SVG（闭集控件没有"按父圆角裁剪"）。逐帧改椭圆形变 = 每帧一张新皮，正是 2026-08-07 让 `networkidle` 永不收敛的那条路。**要它得开引擎单**（Panel 支持子层裁剪，或粒子器带液面件） |
| 2 | 粒子**拖尾** | 无 | **定稿自己标了**「这套 CSS 粒子拿不出真正的拖尾与随机散布，真机建议换引擎粒子器」。我们用的正是它点名的 `layout.flyTo`，同样没有拖尾——口径一致，不算偏离，但要拖尾仍需引擎粒子器 |
| 3 | 伤害跳数期间**字号从 .82 长到 1** | 字号恒定，只跳数值 | `Label.tween` 只 tween 数值，字号不在 tween 面上。可以用相位时钟逐帧算字号，但那会每帧换一张字号 → 与 #1 同一个代价。**记债** |
| 4 | 「−1」印章**每秒跳一下**（`steps(1,end) 1s`） | 静态 | 同 #3：闭集 `anim` 是固定几款，没有 steps 节拍。可用相位时钟做，排在 #3 之后 |
| 5 | 欠账牌**宽 620** | **按内容算宽**（620 当下限） | 定稿的 620 是**它自己的文案排出来的结果**；42px 主句在我们的字体下 15 字 ≈ 630px，写死 620 会折行并顶破面板（真渲染目击过一次）。口径改成「照定稿的 `padding:24px 56px 28px` 自适应列」，与定稿的生成方式一致 |
| 6 | T4 倒计时环显示「—」 | **整个不画环** | 画一圈停住的环 = 告诉玩家"时间到了"，而事实是它在等你点。判词见 `duel-screen.ts` 该处注释。**若设计方坚持画「—」，一行可改** |
| 7 | 英文一律 **Fredoka** | 仍用 Baloo 2（`bubbly`） | 字体槽未补（定稿也已知：「还没有，暂用 Baloo 2 顶着」）。单在 `REQ-108-UI-06` |
