# 「一句话产游戏」管线软件规划案 v1（Lead 2026-08-03 · 呈 owner 审批）

> owner 令：石头剪刀布新游戏为引子——把八步法从「口头约定+CLI」升级成**真软件**（开发界面/IDE 里有这条流程）；
> 生成规矩定为「数据优先·代码万不得已」；可在 Claude Code IDE 里聊着开发、也可起匿名会话跑流程。

## 一、Lead 判词：该做，且不是从零做

现状盘点：八阶段板（`scripts/game-pipeline.mjs` + workshop 生产板 UI）、机器门（gate+证据指纹）、
落盘门（manifest-check「能存必须能跑」）、验收剧本 conformance、自证仪式、TS 逃生门（cart-logic-check）
**全部已是机器强制**。「一句话游戏粗糙」的根因不在生成器，在**三个缺口**：
① 一句话没有正式入口（没接进 S1，生成=野路子一口气跑完，正是防漂移三律禁止的）；
② 阶段之间靠人肉开会话，没有编排器（每步小上下文没有软件保证）；
③ 流程只在 workshop 壳里，IDE 会话看不见板、绕得过门。
本案=补这三块，**不重写任何现有件**。

## 二、代码准入阶梯（规矩成文 · 本案第一交付）

生成方（任何 LLM 会话）产游戏时按序尝试，逐级降落须留痕：

| 级 | 允许物 | 门 |
|---|---|---|
| L0 | 纯数据 manifest（首选·最弱 LLM 尺子） | manifest-check |
| L1 | 数据 + 现有 capability 重组表达 | capability-plan 对 registry 实名 |
| L2 | 能力缺口 → capgap 提案等裁决（可先用 L0/L1 绕行出可玩版） | Lead 裁 |
| L3 | **万不得已**：受控 TS 卡带逻辑（features.tsCarts + meta.allowTs + cartCapability 契约·记债） | cart-logic-check |
| L4 | 自由代码 / 手写 UI / 自建解释器 = **禁止** | game-skill-audit 红旗 |

S2 能力计划门升级：plan 须写明**每条玩法规则落在哪一级**；申请 L3 的逐条附「为什么 L0-L2 表达不了」。

## 三、软件形态（推荐案）

单一真相不变：`pipeline.json` 台账 + `game-pipeline.mjs` 门与证据。其上加三层：

1. **向导壳（workshop 生产板升级·PST 域）**：新增「向导模式」——输入一句话 → 自动起 S1 立项卡草稿
   （名字/一句话玩法/参考自动填，人改口）→ 阶段步进器：永远只亮**第一个非绿阶段**，上关证据可点开看，
   行内按钮=「▶ 开工（派会话）」「跑机器门」「☑ 请人门」。
2. **阶段编排器（引擎 scripts 域·Lead 图纸）**：「开工」= 起一个**匿名无头 LLM 会话**（Claude Agent SDK
   headless），只喂三样：该阶段手册那一本 + 板状态 + 游戏目录——防漂移三律的软件化（状态在会话外·
   每步小上下文·绿靠门不靠嘴）。会话完 → 自动跑该阶段机器门 → 证据落台账 → 停。看门狗：600s 无进展
   标红重派。**人门永远真人点**（现红线不变）。每阶段带 token 档位预算（effort 阶梯随阶段定：S1 low →
   S4 high → S8 low）。
3. **IDE 接入（MCP 服务）**：board/gate/checklist/signoff 挂成 MCP 工具 + 斜杠命令包（/s1…/s8）——
   在 Claude Code IDE 里聊着开发时，会话用同一块板、过同一套门；推送门禁 hook 查板状态（板红拦推）。
   任何支持 MCP 的 IDE 通用。

## 四、里程碑与派工

| 期 | 内容 | 域/档位 | 体量 |
|---|---|---|---|
| P0 | 阶梯成文进 capability-plan 模板 + S2 门措辞 | 文档·Lead+低档 | 小 |
| P1 | 向导壳 + 编排器（本案主体） | PST（壳）+ Lead 图纸派工（编排） | 中大 |

| P3 | **试点：石头剪刀布**从一句话进线，全程新软件走 S1→S8，出复盘回填手册 | 全角色 | 试金石 |

P3 与剧情线合流：RPS 即「伴侣小对局」形态——M3 伴侣在场件的第一个真实消费方（一鱼两吃）。

## 五、红线

人门不可代签；生成物必过全库门禁才算数；证据指纹过期即重跑；匿名会话与 IDE 会话同板同门**无特权通道**；
阶梯降级必须留痕（S2 plan 或 capgap 记录），静默用 L3 = 审计红旗。
