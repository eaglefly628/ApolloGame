Component Agent 是什么？

每个 Capability 背后有一个 Agent。它知道这个能力需要哪些参数，通过选择题、滑块、开关引导用户填完所有配置。

用户不需要知道"DamageEvent"是什么。Agent 会问："勇士每次攻击造成多少伤害？"

🎬 Video Layer (底层)

AI 视频模型生成的画面流。Engine 通过 SceneDirective 语义指令控制。不写一行渲染代码。

📍 Scene Regions (语义区域)

屏幕划分为语义区域。每区域有参考图 + 动作描述 + 风格指令。区域间可建立语义关系（攻击、治疗、连接）。

🎮 UI Overlay (顶层)

React DOM 叠加在视频之上。血条、按钮、菜单 — 所有可交互、确定性的元素。

🔄 未来自动升级

视频模型进化 = 画质自动提升。同一套 SceneDirective，2026 和 2028 生成的画面可以完全不同。

Director Protocol

场景导演 — 语义到视频的桥梁

// Director 输出 → 视频模型的输入 { "scene": { "style": "dark fantasy, cinematic", "camera": "side-view, slight low-angle", "environment": "ancient stone arena, torchlit" }, "regions": [ { "id": "hero", "bounds": [0.05, 0.15, 0.40, 0.70], "content": "armored warrior", "reference": "ref://hero-001.png", "motion": "raising sword to strike" }, { "id": "boss", "bounds": [0.55, 0.05, 0.95, 0.75], "content": "massive red dragon", "reference": "ref://dragon-001.png", "motion": "recoiling from hit" } ], "relations": [ { "from": "hero", "to": "boss", "type": "attacks", "visual": "sword slash energy arc" } ] }

📍 SceneRegion

归一化坐标定义屏幕区域。视频模型知道"这里应该出现什么"。

🎬 SceneContent

描述 + 参考图 + 动作。参考图保证角色一致性。动作描述当前状态。

🔗 SceneRelation

区域间语义关系 → 视频模型生成跨区域视觉效果（光束、攻击弧线...）。

🎥 CameraDirective

镜头语言：俯视/侧视/特写，平移/缩放/切换。电影级叙事控制。

🔄 Temporal Coherence

参考图 + 上帧输出 = 时间连续性。角色不会帧间突变。

⚙️ Engine Systems

纯逻辑。AttackIntent → DamageEvent → Health -= 10。不知道画面长什么样。

🎬 Director System

读逻辑状态 → 写 SceneDirective。"HP 下降 → hero motion = recoiling"。也是一个 ECS Capability。

🎨 Presenter

读 SceneDirective → 调视频模型 API。读 Health → React 叠加层。两层输出合成最终画面。

💡 Director 可替换 — 不同 Director 适配不同视频模型（Sora / Kling / Runway）

Dual AI

三重 AI 架构

🤖

Component Agent

= 游戏策划助手

理解用户自然语言，引导选择 Capability，通过问答填参数。

输出：Assembly 蓝图

"你的游戏需要战斗吗？" → ✅

🧠

LLM Engine

= 游戏程序员

当现有 Capability 不够时，LLM 读 Manifest 合约，自动生成新 Capability 代码。

输出：新 Capability TS 文件

reads: [X], writes: [Y] → code

🎬

Video Model

= 渲染引擎

Director 把 ECS 状态翻译为场景描述，视频模型生成连续画面。

输出：实时视频流

SceneDirective → 📺 pixels

我们构建的核心：Protocol 层 + Engine 层 + Editor 层。
三个 AI 都围绕我们定义的 语义协议 工作 — 这是不可替代的基础设施。
