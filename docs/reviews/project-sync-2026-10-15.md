- Game113 的资料图片模块改用引擎公开包入口，消除 `games-no-relative-escape` 依赖违规；27 张正式资料照片均在仓库中。

## 另一台机器接续

```bash
git clone --branch codex/project-sync-20261015 https://github.com/eaglefly628/ApolloGame.git
cd ApolloGame
npm ci
npm run dev -- --host 127.0.0.1 --port 5173
```

使用 Node.js 22。打开 `http://127.0.0.1:5173/?game=game112` 或 `http://127.0.0.1:5173/?game=game113#/home`。Game114 和原生动画工作台的独立命令见 [根 README](../../README.md)。Game114 当前是已通过本轮巡逻检查的移动/驾驶演示；继续开发前仍应核对原会话是否有后续提交。
