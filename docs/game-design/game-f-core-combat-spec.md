# Game F · 核心战斗重做策划案 —— 三路概率卡牌对决（C1 掉头）

> 主策划 Designer F ｜ 2026-06-17 ｜ owner 在设计讨论中**钦定 C1：取代现有金铲铲式自走棋战斗**，game-f 核心改为「三路布阵 + buff 聚合 → 概率对决 → 种子骰 → 战线推进攻大本营」。
> 本文是核心玩法的**定案策划案 + 仿真台规格**。现有装备/附魔/羁绊从「喂 atk/hp」**重映射**为「喂点数/buff」。
> ⛔ 红线承袭：**点数牌人人相同=公平骨架**（强弱来自经营，不来自抽到强牌）；**小丑牌=持久收集=灵魂**（养成差异在此）。

---

## 〇、定位 / pivot

- **取代**：现有 hitbox 自走棋战斗（atk 砍 hp、星级、连续战斗）退役为核心；其数值资产（装备/附魔/羁绊）**重映射**到本模型的「点数/buff」。
- **新核心**：一场对局 = 双方在上/中/下三路用**点数牌**布阵推进，接敌时按**buff 聚合出的胜率 + 种子骰**判单场胜负，战线接力前压，先破对方**大本营 3 血**者胜。
- **小丑牌**：不上场，作 Balatro 式功能牌改写规则/数值（养成+收集层）。

---

## 一、两类牌（结构骨架）

| 类 | 上场行进? | 作用 | 公平性 |
|---|---|---|---|
| **点数牌** | ✅ 唯一战斗牌 | 带**点数**(主导战力) + **续航**(能连打几场)；沿三路 slot 行进、接敌对决 | **人人点数相同**=公平骨架 |
| **小丑牌** | ❌ 不行进 | Balatro 式功能/设计牌：克隆手牌 / 给某路某牌加 buff / 主动干涉对决 / 改续航等。**收集即灵魂** | 收集深度=养成差异(炉石调性) |

> 续航（默认值，待仿真微调）：**数字牌=1 场 ｜ 人头牌 A·J·Q·K=2 场 ｜ 小丑增益可达 3+**。

---

## 二、三路 slot 行军（战线推进）

- 三路（上/中/下），每路是一串**连续 slot**；点数牌从己方侧入场，沿 slot **逐格前进**。
- **接敌对决**：当己方最前牌与敌方最前牌进入相邻 slot → 触发一场对决。
- **赢家**：占掉敌人腾出的 slot（**向敌大本营前进一步**）→ 续航 −1。续航尽 → **沉牌底 + 进入 deploy 冷却（按回合数）**；未尽则留场继续推进。
- **输家**：进入**本局弃牌堆**（这局牌库变薄；**局外收藏不减**）。
- **战线推进而非单卡走到底**：单卡续航有限 + 冷却 → 一波波牌**接力前压**，逼近敌大本营。神牌凿几格即回家歇冷却，不能包打天下 → 逼牌组轮转。

---

## 三、对决解算（核心数学：buff 聚合 → 概率 → 种子骰）

**1. 有效战力**（每个 buff 源自带封顶 ±Δ，防膨胀）：
```
P_eff = clamp( 基础点数 + Σ buff_i , P_floor , P_ceil )
```

**2. 胜率**（点数差的 S 形 + 封顶封底）：
```
Winrate(A) = clamp( logistic( (P_eff_A − P_eff_B) / k ) , p_min , p_max )
```
- 三个旋钮：`k`(点数有多硬) ｜ `[p_min,p_max]`(爆冷缝，如 [0.03,0.97]) ｜ 各 buff `Δ`(膨胀上限)。
- **点数差大→碾压但永不 100%/0%**（S 打 7 ≈ 97%，留 3% 戏剧缝）。

**3. 种子骰**（B1，必须确定性）：
```
seededRand( seed = 局种子 ⊕ 对决序号 ) < Winrate(A) → A 胜
```
> 同种子同结果 → 镜像同步 + 回放不裂。**这是唯一引入随机的点，全靠种子化保确定性。**

---

## 四、buff 全表（聚合进 P_eff；全部扁平数据、各自 bounded）

| 类 | buff 源 | 说明 | 建议 Δ 区间 |
|---|---|---|---|
| 本体 | **基础点数** | 牌面点数（公平、双方同分布） | 主导项 |
| 相邻 | **前一张 / 后一张牌** | 阵型相邻协同（连号/同花/职业等触发） | ±小 |
| 状态 | **士气** | 该路/该牌累积值（连胜涨、被压降） | ±中 |
| 养成 | **附魔能量** | 局外 enchant 带入（现有 enchantCardSpec 重映射） | +，封顶 |
| 路 | **路 buff（上/中/下）** | 该路当前增益/减益（地形/事件/小丑） | ±中 |
| 干涉 | **主动干涉** | 玩家即时出小丑牌/技能改这场对决 | ±大，一次性 |

> 仿真台的职责就是：调每个 Δ，使没有任何组合把胜率顶破 [p_min,p_max] 或造出统治解/死牌。

---

## 五、回收 / 冷却 / 续航 经济

- **赢→沉牌底 + 回合冷却**：双重节流，强牌不能即抽即用循环。
- **续航**：数字牌1 / 人头2 / 小丑增益3+；续航尽才下场。
- **输→本局弃牌堆**：run 内损耗，牌库变薄（**收集不减**）。
- 经济乐趣 = 在"出牌→推进→对决→回收沉底/弃牌→再抽"的流动里**轮转牌组、补线、戳缺陷**。

---

## 六、胜负（皇室战争模型）

- **大本营 3 滴血**：战线推进攻到敌大本营 = 扣 1 血；**先破 3 血者胜**。
- **回合/时间上限**：到点未破 → 按**剩余血量/推进度**判胜负，**可平局**。
- ⛔ **不给大本营做大血条**（防无限拖、保节奏）。

---

## 七、两条体验支柱（非选配）

1. **胜率可读**：对决前悬停显 `A 76% : 24% B` + 可展开 **buff 明细**（点数+5/相邻+2/路−1/干涉+3…）。**天平=策略，骰子=戏剧**；无此则沦为老虎机、戳不了缺陷。
2. **单挑特写图层**：关键牌对决切入 1v1 卡牌单挑特写，给仪式感（表现层，不影响解算）。

---

## 八、仿真台规格（owner 的"开一趴"·离线平衡测试）

- **形态**：离线**蒙特卡洛**，非游戏运行时；模型参数（k / [p_min,p_max] / 各 buff Δ / 续航 / 点数表）全是**扁平数据**，仿真器=**薄确定性函数**（过宪法尺子；可直接当平衡回归测试）。
- **输入**：全小丑牌配置 × 全牌组/布阵 × 对手分布。
- **跑**：每组合 N 万次对决/对局。
- **输出**：① 胜率矩阵；② **退化告警**——任何组合把单场胜率顶破 [p_min,p_max]、或对局胜率出现统治解(>X%)/死牌(<Y%) → 红牌。
- **价值**：每改一个小丑牌/Δ → 跑一遍 → 立刻看平衡是否破。**这是拉平衡的主力工具，与策划案同期建。**

## 九、数据驱动 / 重组分析（先重组纪律）

| 件 | 怎么做 | 引擎? |
|---|---|---|
| 点数牌/小丑牌/buff全表/续航/冷却/路buff/大本营3血 | 扁平数据 | 纯数据 |
| 三路 slot 行进 / 接敌点对决 | grid-move / 行军（**game-g MARCH 先例**）+ 接触触发 | 大概率重组 |
| 回收沉牌底 / 抽牌 | `card-pile` | 重组 |
| deploy 冷却 | `Timer` | 重组 |
| 胜率可读 / 单挑特写 | 表现层读解算中间值 | 表现层 |
| **种子骰（in-sim 确定性随机）** | 需 sim 内**确定性种子 RNG**（现 loot 的 Math.random 只在 HUD、不入 sim） | **⚠️ 候评估·可能下沉薄能力** |
| **对决解算核（buff聚合→logistic→出正负）** | 纯函数 over 数据；可能薄函数、也可能下沉一个 `clash-resolve` 原子 | **⚠️ 候评估** |

> **两个真正待 Lead 评判下沉的**：① **in-sim 确定性种子 RNG**（基础原语、跨游戏可复用、B1 命门）；② **clash-resolve 解算原子**（buff-bag→概率→布尔）。其余倾向重组。出实现规格时逐项判，能重组绝不下沉；真要下沉则确定性/审计/可复用三条达标后提主程 REQ。

## 十、待 owner 微调 / 待设计子轨

- **待微调**（我已给默认，可后调）：续航精确映射（数字1/人头2/小丑3）、`[p_min,p_max]` 缝宽、回合上限、大本营 3 血。
- **❓ 待 owner 确认（唯一结构性未定）**：**小丑牌怎么用** —— (a) 被动槽（常驻 joker，一直改规则/数值）；(b) 主动出牌（手牌→干涉一场对决→消耗）；(c) 两者都有。我倾向 **(c) 被动槽 + 少量主动干涉牌**（Balatro 被动为主 + 你要的"主动干涉"）。
- **待设计子轨（独立一趴）**：**小丑牌全表细化** —— owner 钦定需非常细致设计才能拉平衡；建议小批迭代 + 每批过仿真台。
