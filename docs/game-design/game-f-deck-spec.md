## 牌组 7 ·「以战养战」(降将·混血 Recruit)

**身份**:把"PvE 敌人(太阁守军)变成你的牌库"。越收编越强,终盘滚雪球。围绕**降将机制**(`game-f-coop-sunliu.md` §2.3:`Mortal.dropTemplate` → 主公拾取 → 入席)。

**核心循环**:补刀太阁 → 掉招降标记 → 拾取入席 → `recruit_count++` → 经济/强化滚雪球 → 收编更多。

| 卡名 | 态 | 效果(首版) | 数据形(capability 映射) | 复用/缺口 |
|---|---|---|---|---|
| **招降令** ⭐钥匙 | Build | 收编的太阁入席时,使用**强化变体模板**(+1 星基础 / +15% hp·atk) | recruit_token 消费 → 装配层据码展开"强化变体" + spawn 时 **self-scope 一次性 buff**(REQ-021) | ✅复用 |
| **以战养战** | Build | 本局每收编 N 个太阁,结算追加金币(滚经济) | `recruit_count` 资源累加 → **banded** EventWhen(≥3/≥6/≥9)→ Effect modify `gold` | ✅复用(Game E banded) |
| **质子为质** | Run | 收编的太阁阵亡时,有几率返还半个招降标记(再收编链) | `mortal.dropTemplate` 概率返还 token | ✅复用 |
| **以夷制夷** | Build | 收编的太阁保留其"看家本领"(信长·天下布武 等)为你所用 | 太阁 Prefab 自带 `Caster` 技能;收编 = 重写 owner/队伍位后技能天然归你队 | ⚠️复用**但需核**:收编后 owner/`TEAM` 位重写 + 信号 self 寻址正确(REQ-021 域) |
| **先登陷阵** | Run | 你的单位 +X attack(帮你抢太阁人头) | per-unit / self-scope flat buff | ✅复用(简单版) |
| **养寇自重** | Build | 不立刻清场、留残血太阁滚利息,但承担反扑风险 | 玩法层选择:关卡数据 + 经济,无新算子 | ✅复用 |
| **降众归心** | 星球 | 太阁招降掉率全档 +1(更易收编) | 改掉落表权重(全局数值) | ✅复用(数值) |

**附魔示例**:`招降令·多彩` 收编强化 +15%→+30% ｜ `以战养战·镀金` banded 金币翻倍。
**围绕**:太阁全谱(信长/秀吉/家康/武田/上杉/真田…)+ 三国低费过渡阵把你撑到能补刀。
**克制关系**:**克**"密集低星杂兵"型守军(可收编池大、补刀容易);**被克**于"少量高星精英 Boss"型守军(可收编目标少、精英难补刀,雪球转不动)。

> **缺口小结**:几乎全复用——这印证「以战养战」是**纯数据可落地的好流派**。唯一进阶缺口是"对满血/特定状态目标加伤"(先登的进阶版),与下面「白衣渡江」同根,见末尾候选 REQ。

## 牌组 10 ·「白衣渡江」(刺客·斩首 Last-hit)

**身份**:刺客绕后秒残血 + **抢 Boss 最后一刀(贡献度)**。围绕吕蒙/甘宁 × 刺客职业。**这套是"贡献度=抢人头"机制的可构筑化身。**

**核心循环**:绕后扑残血 → 斩杀线触发处决 → 抢 last-hit → 吃高额贡献 + 收割。

| 卡名 | 态 | 效果(首版) | 数据形(capability 映射) | 复用/缺口 |
|---|---|---|---|---|
| **白衣** ⭐钥匙 | Build | 对生命 <30% 的目标,伤害 ×N(斩杀线) | hitbox 需**读目标当前 hp 比例做条件** | 🔴**缺口**:hp-条件伤害/处决算子 → 候选 **REQ-F-058** |
| **绕后奇袭** | Build | 刺客索敌改为"最高费/最远"敌方单位(直插后排) | `aggro` 现为 `nearestByTag`,需**索敌策略可选**(nearest→farthest/highest-stat) | 🔴**缺口**:aggro 索敌策略 → 候选 **REQ-F-059** |
| **断粮** | Build | 你的单位**补刀(last-hit)**太阁时,该太阁贡献额外 +X、掉金 | 依赖贡献度系统的 **kill-attribution(补刀归属)** | 🟠**系统特性**:贡献系统须钉"谁补刀谁得分"(非战斗算子,系统设计定) |
| **攻心** | Run | 对已损失生命越多的目标,伤害递增 | hp-条件伤害族,同钥匙牌缺口 | 🔴**缺口**:同 REQ-F-058 |
| **锦帆**(甘宁) | Run | 刺客攻速 +X、暴击 +X | per-unit/self buff + `Timer.duration` 调 | ⚠️复用**但需核**:暴击原语是否已存在(无则小缺口) |
| **潜行** | Run | 刺客开局 X 秒不被索敌 | status flag + 敌方 `Perception` 忽略带该 status 的单位 | ⚠️**待核**:能否用 `requireMask` 取反重组?不能则小缺口 |
| **渡江** | 星球 | 斩杀线 30%→提升档位(35%/40%) | 改钥匙牌阈值(数值) | ✅复用(数值),依赖 REQ-F-058 先落 |

**附魔示例**:`白衣·多彩` 斩杀倍率 ×N 提升 ｜ `锦帆·镀金` 暴击翻倍。
**围绕**:吕蒙/甘宁/马超等刺客 × 刺客职业羁绊(`group-count` REQ-022)。
**克制关系**:**克**"高血厚甲单核 / Boss"(斩杀无视厚血、专抢人头);**被克**于"群体铺场低血海"(刺客少、容易被海淹)+ "护盾/治疗回血"(把目标拉出斩杀线、处决落空)。

> **缺口小结**:「白衣渡江」**故意**压在缺口上——这正是价值:它证明"抢人头贡献"这个差异化爽点,需要真实引擎支持(处决 + 补刀归属),不是纯数据能糊弄的。深挖它=提前暴露了 D0 之后该立的 REQ。

## 本批暴露的引擎缺口候选(交主程评估 → D0 核对 Game E 后再入 `requests.md`)

> 纪律:**先查 Game E joker(`game-e-joker-roguelike.md`)是否已实现等价算子**,已覆盖则回驳;真缺口才下沉。下列是"待 D0 核对"的候选,不是既定 REQ。

| 候选 | 名称 | 用途 | 通用性(为什么值得下沉) | 风险 |
|---|---|---|---|---|
| **REQ-F-058** | hp-条件伤害 / 处决 | 白衣·攻心·渡江;先登进阶 | "按目标当前生命比例改伤害/触发处决"是**普适**战斗词汇(斩杀/狂暴/残血加伤,所有 ARPG 通用),非一卡专用 | 中:碰 §7 曾回驳的"伤害重定向"边界,要设计成**只读 hp 比例的条件 gate**、不引入伤害分型,范围才窄 |
| **REQ-F-059** | aggro 索敌策略 | 绕后奇袭(直插后排) | 索敌"最近/最远/最高某属性"是**普适**词汇(刺客/狙击/嘲讽都要),一个 enum 参数化现有 `nearestByTag` | 低:`aggro` 已选最近,加策略枚举即可;确定性不变 |
| **贡献系统特性** | kill-attribution(补刀归属) | 断粮;整套贡献度机制 | 贡献度=名次=胜负,**核心系统**;补刀归属是其底层(谁的伤害造成击杀 → 记谁的分) | 中:需在系统设计钉死(伤害来源 `Signal.source` 已有 → 击杀时读 source 记分,REQ-021 域内) |
| 待核·暴击 | 暴击原语 | 锦帆 | 通用 | 低:有则复用,无则小算子 |
| 待核·Perception 排除 | 按 status 屏蔽索敌 | 潜行 | 通用(隐身/潜行) | 低:可能 `requireMask` 取反可重组 |
| 既定·Gap C | 全队光环 fan-out | 任何"全队增益"卡 | —— | 守 §7 纪律:优先"全局 stat + 能力读全局"重组,不为此提前下沉 `group-effect` |
