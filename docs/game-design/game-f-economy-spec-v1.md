# Game F · 经济/商业 v1 定案(可排期工程单)

> 主策划 ｜ 2026-06-15 ｜ owner 拍板两颗钉 → 本文把经济从"绿地"定成可排期的 v1。
> 承 `game-f-economy-market.md`(蓝图/红线)与 `game-f-cards-and-decks.md`(两层卡牌/元循环)。本文是**决定版 v1 范围**。
> ⛔ 铁律:**收藏/组牌/抽卡/附魔/天梯/赛季/账号 = 服务·账号层,绝不进确定性 ECS**。游戏 sim 只吃一份"出战牌组数据";引擎只回吐一份"攻岛结算"。

---

## 〇、锁定(owner 2026-06-15)

1. **调性 = 炉石/MTG 式:收集影响牌力**(养成向)。
   → **必做配套(这个调性的安全阀,非选配)**:① 按**收集/段位分层匹配** ② **赛季轮换/格式**。二者和养成**同期做**,否则强度膨胀失衡。
2. **v1 范围 = 只做软币养成**。攻岛赚软币 → 抽卡/附魔/星球/组牌/天梯。**交易市场 + 充值 + 硬货币 → 押后 phase 3**(届时单独定案,含"强度可买"的平衡/监管/反作弊)。

## 一、货币(v1 仅一种软币)

| 货币 | 来源 | 用途 | 出局? |
|---|---|---|---|
| **gold**(局内金) | 局内经济(已有) | 备战买将/刷新 | ❌ 不出局 |
| **战功**(软币,v1 唯一局外币) | **攻岛结算**按贡献+名次产出 | 抽卡 / 附魔 / 星球牌 / (后续市场) | ✅ 持久 |
| 硬币(充值) | — | — | ⏸ **押后 phase 3** |

## 二、卡牌获取(v1 入口)

1. **Boss 宝箱掉卡**(局内 PvE 产出):打太阁 Boss → 宝箱 → 小丑牌 → **进收藏(持久)+ 可即时装入本局**(roguelike)。
2. **软币抽卡**:用战功抽,**概率公示**;v1 唯一"消耗软币换卡"口。
3. (多人掷点/竞价分卡 → 依赖多人 F,押后)

## 三、两层卡牌(承 cards-and-decks §4.1)

- **局外 Build 牌**(持久):收藏→组牌器拼 5–8 张带入,定流派身份。
- **局内 Run 牌**(本局):Boss 宝箱当场抽到、即时生效;局后入收藏。
- 一次掉卡同时喂两层。

## 四、收藏 + 组牌器(服务层,接大厅 S4/S5)

- **收藏**:账号卡库存(每卡 count + 附魔态 + 星球态)。
- **组牌器**:从收藏拼 Build 牌组 + 选初始势力(轻风味);分类/预览(已在大厅简报 S4)。

## 五、附魔 + 星球牌(Balatro,软币 + 材料)

- **附魔(单卡)**:品质升级(foil/holo/多彩 → +攻% / +经济 / +暴击 / +触发次数)。消耗:战功 + 材料(分解多余卡得)。
- **星球牌(流派)**:升某羁绊/流派档位(「星球·魏」→ 魏羁绊全档 +1)。
- 形态:数据 modifier(Game E joker 先例,REQ-011/012/013 已 done)。进卡牌数据,**不进 sim 之外的逻辑**。

## 六、天梯 / 段位(服务层)

- 按**攻岛名次**结算 LP/段位(单机 v1=自己的成绩分;多人名次押后)。
- **段位 = 难度阀**:高段位的岛,太阁守军更凶(纯换关卡表数据,roster §七)。
- **天梯之路 = 局外解锁**:爬段位解锁新三国将 / 新战役岛 / 新太阁 Boss。

## 七、★ 炉石调性的必做配套(守公平,和养成同期)

- **分层匹配**:按收集深度/段位分桶,新人不撞满收集老玩家(单机 v1 影响小,多人是硬需求——先把字段/分桶逻辑建好)。
- **赛季轮换/格式**:赛季重置部分进度 + 牌池轮换(标准/狂野式),防版本永久固化、给新卡价值。

## 八、工程分解(让它能排期)

> **这是服务/账号层的独立工程,不是主程的引擎活**(引擎不加能力)。可由"服务/前端工程"承接。

| 模块 | 内容 | v1 范围 |
|---|---|---|
| 账号/收藏存储 | 持久化 collection/decks/currency/rank | **本地账号先行**(localStorage/文件);真服务端押后 |
| 组牌器 | 接大厅 S4/S5,从收藏组 Build 牌组 | v1 做 |
| 抽卡 | 软币抽 + 概率公示 | v1 做 |
| 附魔/星球 | 软币+材料升级卡 | v1 做 |
| 天梯/段位/赛季 | 名次→LP→段位→难度阀+解锁 | v1 做(单机名次) |
| 分层匹配 | 按收集/段位分桶 | v1 建字段+逻辑(多人才真用) |
| 交易市场 / 充值 / 硬币 | TCG 二级市场 | ⏸ **phase 3** |

## 十、验收(v1 经济闭环)

打一局攻岛 → 赚战功 + Boss 宝箱掉卡进收藏 → 抽卡/附魔/组牌 → 段位涨(高段位岛更凶)→ 下一局更深。**全软币、无真钱、与 ECS 解耦**。分层匹配/赛季字段就位(多人时启用)。
