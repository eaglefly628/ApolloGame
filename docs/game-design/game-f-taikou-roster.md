# Game F · 太阁守军 Roster(关卡生产线)

> 主策划 ｜ 2026-06-13 ｜ 第二步:守岛方 = **太阁立志传战国群雄**的 PvE 阵容库。
> 用途:喂 `game-f-core-combat-dev.md` 的 **T1(太阁 PvE 对手装配)** 的关卡表;也是本作"关卡设计 = 设计太阁阵容"的内容主线。
> ⛔ 每个太阁 = 一组组件(势力/职业 Tag + hp/mana + 一招看家本领),**纯数据**。看家本领尽量映射现成能力;撞缺口的**复用玩家卡牌的同款缺口**(F-061/062)——**守军和玩家共用一套引擎词汇**,做一次两边都受益。

## 〇、关卡结构(渡海征日,三段抬难度)

```
一座岛 = 滩头 → 国人众 → 天守决战(终盘 Boss 每局轮换 → 重玩性)
  滩头(序盘)   : 足轻/杂兵海(低星 token,数量多、机制简单)——练手 + 喂贡献
  国人众(中盘) : 部将/名臣(有一招机制,开始考构筑)
  天守阁(终盘) : 太阁 Boss(高星、招牌大招;每局从池中轮换一名当最终 Boss)
```

**关卡表数据形(T1 填这个)**:每波 = `{ 太阁码列表, 落点(hex), 难度参数(星级/数量) }`;难度随段位(天梯,后置)换更凶的波。**v1 先用滩头前 2 波最简杂兵起步,不等全 roster。**

## 四、降将联动(`game-f-deck-spec.md` §7「以战养战」的内容侧)

- 上表每个太阁 = 一个可被**收编**的单位(`Mortal.dropTemplate:'recruit_<码>'`);收编后用其 Prefab(自带招牌大招)为玩家所用。
- **稀有度梯度**:足轻(易掉、弱)→ 部将(中)→ Boss(极难收、强,收一个翻盘)。掉率走 `game-f-deck-spec.md`「降众归心」星球牌调。
- **跨次元图鉴欲**:战国 Boss 混进三国阵(信长 + 赵云同队)= 留存钩子;收编池 = 上表全谱。

## 五、数据约定(Tag 位 + Prefab 字段)

- **队伍位**:太阁守军 = `TEAM_C`(与孙/刘/曹三玩家队伍位互为敌;索敌 `targetTag = 全队伍 & ~自队`)。
- **职业位**:复用 `game-f-auto-chess.md` §4.1 —— `WARRIOR/TACTICIAN/ARCHER/ASSASSIN`。
- **兵种位(数据约定新增,无引擎改动;Tag.flags 是 32 位字段还有空位)**:`CAVALRY=1<<11`、`INFANTRY=1<<12`(玩家「魏骑」连携也用这两位)。
- **Prefab 字段**(对齐 enemy 模板,纯数据):`hp`(Resource)/ `atk`(普攻 hitbox.amount)/ `攻击间隔`(Timer.duration,秒)/ `射程`(GridMover.range,hex)/ 职业·兵种 Tag / 可选大招(`EventWhen{mana≥100,self}` → caster → 技能 hitbox)。
- 数值 = **首版待平衡**(对齐金铲铲 1 星量级)。
