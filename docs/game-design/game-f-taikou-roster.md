## 〇、关卡结构(渡海征日,三段抬难度)

```
一座岛 = 滩头 → 国人众 → 天守决战(终盘 Boss 每局轮换 → 重玩性)
  滩头(序盘)   : 足轻/杂兵海(低星 token,数量多、机制简单)——练手 + 喂贡献
  国人众(中盘) : 部将/名臣(有一招机制,开始考构筑)
  天守阁(终盘) : 太阁 Boss(高星、招牌大招;每局从池中轮换一名当最终 Boss)
```

**关卡表数据形(T1 填这个)**:每波 = `{ 太阁码列表, 落点(hex), 难度参数(星级/数量) }`;难度随段位(天梯,后置)换更凶的波。**v1 先用滩头前 2 波最简杂兵起步,不等全 roster。**
