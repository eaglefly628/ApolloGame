## 一、游戏概要

玩家是一家小裁缝铺的店主。**消除针线材料 → 攒够料子 → 升级缝纫店、缝出更华丽的衣服 → 给女孩换装 → 用「爱诗」生成一段她穿着新衣的短视频展示**。一个双向循环：前台是三消爽感，后台是养成数值，出口是 AIGP 视频。

**一句话**：针线主题三消攒材料，缝纫店养成做新衣，爱诗视频秀出来。

三条支柱：

1. **主玩法 · 三消（操作层）**：6 种缝纫材料（布料/丝线/纽扣/缎带/蕾丝/亮片）在网格上三连消除，消除产出对应材料。
2. **数据玩法 · 缝纫店养成（数值层）**：材料是货币；攒够阈值解锁更高阶的衣服，逐级升级店铺（朴素围裙 → 碎花衬衫 → 缎带连衣裙 → 蕾丝礼裙 → 星夜晚礼服）。
3. **输出点 · 爱诗 AIGP 展示（表现层旁路）**：女孩的当前换装 → 翻译成一段视频生成提示词 → 爱诗输出竖屏短视频做展示/分享。

## 二、核心循环

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│   ┌──────────┐    ┌───────────┐    ┌──────────────┐          │
│   │ 三消棋盘  │──→ │ 材料结算   │──→ │ 缝纫店升级链   │          │
│   │(交换/消除)│    │(产 6 材料) │    │(阈值→解锁衣服) │          │
│   └──────────┘    └───────────┘    └──────┬───────┘          │
│        ▲                                   │                 │
│        │                                   ▼                 │
│        │                          ┌──────────────┐           │
│        └──────（继续凑料）──────────│ 换装 + 爱诗展示 │           │
│                                   │(外观→视频提示词)│           │
│                                   └──────────────┘           │
└──────────────────────────────────────────────────────────────┘
```

- **三消棋盘**：点选两个相邻棋子交换；形成 3+ 同色连线则消除；空位上方棋子下落、顶部补新（确定性随机）；连锁(cascade)叠加奖励。
- **材料结算**：每消除一颗 → 该材料 `Resource +1` + 针线币 `+5`（连锁倍率后续加）。
- **缝纫店升级链**：每件衣服一条「攒够材料(AND 阈值) → 解锁」里程碑，越华丽要求越高。
- **换装 + 爱诗展示**：当前外观（已解锁的最高档）→ 组装成爱诗视频提示词 → 生成竖屏短视频。

## 三、内容设计（数据）

### 3.1 消除元素 / 材料（`theme.ts` MATERIALS）

| 材料 | id | 字形 | 风味 |
|------|----|----|------|
| 布料 | cloth | 🧶 | 一切衣裙的底子 |
| 丝线 | thread | 🧵 | 把心意一针针缝进去 |
| 纽扣 | button | 🔘 | 收尾的小确幸 |
| 缎带 | ribbon | 🎀 | 系一个甜甜的结 |
| 蕾丝 | lace | 🌸 | 裙摆上的细腻浪花 |
| 亮片 | sequin | ✨ | 灯下闪烁的高光 |

通用货币：针线币 `coin`（任意消除 +5）。

### 3.2 缝纫店升级阶梯 / 换装线（`theme.ts` GARMENTS）

| 阶 | 衣服 | 需求（材料阈值） | 解锁后外观 lookId |
|----|------|----------------|------------------|
| 1 | 初心围裙 | 布料10 · 丝线6 | look_apron |
| 2 | 碎花衬衫 | 布料24 · 纽扣12 | look_blouse |
| 3 | 缎带连衣裙 | 布料40 · 缎带18 · 丝线20 | look_sundress |
| 4 | 蕾丝礼裙 | 蕾丝30 · 布料60 · 丝线36 | look_lace_gown |
| 5 | 星夜晚礼服 | 亮片50 · 蕾丝40 · 缎带30 · 纽扣24 | look_gala_gown |

> 阈值递增 → 越华丽越晚解锁 → 女孩外观随养成自然向上走。后续可扩展支线/季节限定/配饰槽位。

### 3.3 爱诗(AIGP)提示词表（`theme.ts` LOOK_PROMPTS）

每个 lookId → 一段英文视频生成提示词（女孩穿这件的画面）；叠加固定风格修饰（竖屏 9:16 / 动漫质感 / 推镜 / 粒子）+ negative。这张「状态→提示词」表正是周期表 **X4 ShadowDictionary** 的数据形态。

## 四、引擎能力映射（有 vs 缺）

> 这是本游戏作为「引擎验证游戏」的核心产出：暴露引擎在**网格消除 + 养成 + AIGP** 维度的缺口。

### 4.1 现成能力即可表达（v0.1 已装配为数据）

| 游戏需求 | 用什么现成能力 |
|---------|--------------|
| 材料/货币数值 | `resource`(F1) `Resource`+`ResourceModify`（全局按 id 路由，R11） |
| 缝纫店解锁判定 | `event-when` + `effect-apply`（Condition→Event→Effect）：AND 阈值 → 信号 → 置 flag + set-state |
| 当前换装外观 | `state`(J1) + `text`(L6) |
| 爱诗提示词组装 | 纯数据表 + 字符串拼接（表现层，不进 sim） |

→ 见 `src/games/game-c/blueprint.ts`，**零游戏系统代码**。`game-c.test.ts` 证明这条链在现成能力上确定性跑通。

### 4.2 引擎缺口（不在游戏层 hack，已提需求 `docs/workflow/requests.md`）

| 缺口 | 需求 | 性质 |
|------|------|------|
| 三消棋盘机制（找连/交换/重力/补块/消除产出） | **REQ-C-001** | 全新通用 Tier3 玩法 capability（任何三消复用） |
| 棋格点击命中 → 语义动作 | **REQ-C-002** | 通用「可点击实体」capability（点击器/网格通用） |
| 主动缝制消费（花材料换衣服） | **REQ-C-003** | 通用「配方/消费」经济 capability（商店/合成通用） |
| 爱诗视频生成后端（AIGP 旁路） | **REQ-C-004** | 表现层后端（类比 R1 贴图 / R8 音频后端） |

> REQ-C-001 是头号阻塞：它落地后，棋盘只需往材料 `Resource` 灌 `ResourceModify`，4.1 已装配好的升级/换装/展示链**自动点亮**，游戏数据不动一行。

## 六、引擎验证重点

Game C 给引擎引入三条 A/B 都没压过的全新维度：

| 维度 | 怎么压测 | 对引擎的意义 |
|------|---------|------------|
| **网格消除机制** | 找连/重力/补块/连锁的确定性结算 | 周期表尚无「Match-3」这格 → REQ-C-001 是否能收敛成通用 capability |
| **资源养成闭环** | 6 材料并存 + 阈值解锁链 + 主动消费 | 验证 Condition→Event→Effect 撑不撑得起养成线；消费(spend)是否需新经济原子 |
| **AIGP 输出旁路** | 世界状态(外观) → 视频提示词 → 视频后端 | 周期表「扩展 C」X4–X7 首次有真实游戏拉动 → 旁路设计能否落地 |

## 七、美术方向

- 风格：柔粉马卡龙色调 + 圆角软萌；棋子=材料字形/小图标，缝纫店=暖光小铺。

- 爱诗：竖屏 9:16 短视频，动漫质感、推镜、粒子高光。
- MVP 阶段用字形/纯色块占位（asset-flow TBF：先声明 id，缺资产也能跑，后补真图）。
