## 〇、为什么换核（病根）
现有自走棋是 **「排兵→必胜→拿道具→变强→推到一波打不过」的确定性滚雪球**：战斗被动（摆好看自动打）、单机 solitaire 无竞争、每波无悬念、失败=硬墙。owner 自陈"金铲铲我就不爱玩"。→ 换成**主动、合作、有每波悬念**的核心。

## 一、乐趣定位（押定）
- **联机为主**：两人合作打岛 + **轻竞争（岛主王冠）**。乐趣 = **合作配合的爽 + 每波 KPI 较劲**。
- **合作为主、竞争为辅**：不全程互捅；竞争是收尾王冠 + 每波 KPI 的苦甜调味。
- **单机** = 练习暖场，用 **AI 伙伴** 顶替（AI 会主动连携/援军/集火/求援）。

## 二、战场（共享、小而清晰）
- 两人**共享一条小战线**，同打一个 Boss/守军波次，**不各刷各的盒子**。
- 规模**小而可读**：每人 3 常驻 ≈ 3v3+敌，看得清、够得着、好配合。
- 适度**前后纵深**（前排扛/后排输出 + 后方轮换上场区），不摊太长（太长两人被拉远、配合断）。

## 三、阵容：3 常驻 + 1 救火（核心结构）
- **3 常驻英雄**：备战摆好，**波次之间**可从深板凳轮换。
- **1 救火英雄（当技能扔）**：不常驻，危急时**像放技能一样扔上场、限时打一段、长冷却**。是急救/clutch 操作 → 战斗里"主动的那一下"。
  - **一物两用**：扔自己面=自救；**扔伙伴面=援军救场**（互动动词，KPI 加"救场"分）。
  - 参数待定：在场时长（建议短）/ 冷却（建议长，一局放不了几次、每次都要权衡）。

## 四、轮换（去自走棋化的命门）
- 上场单位**续航/体力会耗** → 必须**换下歇（冷却）、换上新的或克制的**。
- **深板凳**从小丑牌/武将收集来 → 收集养成终于有用武之地。
- **换得准 = 打得巧 = KPI 高分**。

## 五、互动 = 得分手段（防"假互动"核心支点）
**KPI 高分项必须通过和伙伴互动才拿得到** → 你不可能无视伙伴还打得好。合作(互动)与竞争(KPI)拧成一股。
| 互动动词 | 玩法 | KPI 计分 |
|---|---|---|
| **集火标记**（先做） | 任一方标记敌人→两人兵优先打、受伤加成 | 集火效率 |
| **连携技**（先做） | 你定身→我爆发；你借东风→我火攻；掐时机接 | 连携次数 |
| **援军救场** | 救火英雄/援军扔到伙伴面救急 | 救场 |
| **能量供需** | 一人攒风/兵符/怒气，一人花放大招 | 供能/借力 |
> 先做 **集火标记 + 连携技**（最高频 + 最爽）；援军/供能随后叠。

## 六、每波 KPI（把"必胜推进"变"每波有悬念"）
- **KPI 衡量"打得巧"，不是"战力高"**（命门：算战力则滚雪球者通吃→又确定性无聊）。
- 构成：**效率（以少胜多）/ 连携次数 / 救场 / 贡献占比**。
- 流程：打完一波 → 两人各结算本波 KPI → **即时对比「你 87 : 64 伙伴」** → **本波赢家即时小奖**（先挑战利品/buff）→ 累计 → 收尾决**岛主**。

## 七、失败 / 落后（非读档硬墙）
- 一波崩 ≠ game over：是"这波 KPI 落后、伙伴 carry 了你"，**可对比的失手**，竞赛继续。
- **救火英雄 / 援军 = 逆转工具**；落后可喊伙伴救、可下波翻盘。压力来自"被拉开"，不是死局。

## 八、联机 / 同步（架构）
- **镜像同步**（已定 REQ-F-057）：同步**布局 + 英雄 + 离散指令**（整数、天然确定）；战斗 **主机权威** 或 **lockstep 定点数**，二者皆可。owner 认可。
- **真传输层（WS/WebRTC、对局架构）= 主程/联机层**（REQ-018），非纯游戏侧。
- **落地序（降风险）**：① 先用「单人 + AI 伙伴」把整套玩法做出来跑爽（**无需 netcode**，纯本地）→ ② 玩法验证好玩后，主程再上真联机。
