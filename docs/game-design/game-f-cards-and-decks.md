# Game F 设计正典 ·《三国征日》小丑牌 × 自走棋 × 炉石收藏 —— 设计哲学与牌组打样

> 主策划 ｜ 2026-06-13 ｜ **用户(项目 owner)拍板立项 + 指定落 mainbranch**
> 地位:**Game F 的方向性升级**。在 `game-f-auto-chess.md`(战斗/经济/抽卡基线)与 `game-f-flow-spec.md`(流转数值真相)之上,
> 确立这条线的**最终形态 = 三人合作攻岛 + 持久小丑牌牌组**。它**收编**了 `game-f-coop-sunliu.md` 里「三方/N阵营/降将」的有效内核,
> **取代**其中「孙刘抗曹双人合作 / 单人优先」的过期框架(详见 §7 与单独的清理说明)。
>
> ⛔ 宪法照旧 `docs/design/data-driven-manifesto.md`:**游戏是数据,代码只属引擎。** 尺子:「最弱的 LLM 能否产出一模一样的数据?」
> 每张小丑牌 = 一组 `{condition, signal, effect}` 算子;每套牌组 = 一个卡牌码数组 + 强化数据 → 能 → 数据接口。
> 局外的收藏/组牌器/交易市场/天梯 = **服务·账号·账本层,明确不进确定性 ECS**(与天梯同归元层,见 §4.4 / §5)。

## 〇、立项判断(主策划评审结论先行)

**接受立项。这是 Game F 从「复刻金铲铲」跃迁为「有独立身份的缝合体」的关键一跳。** 结论先摆:

1. **核心创新是一句话:武将是租来的,牌组才是你的灵魂。** 武将每局清零、人人平等(roguelike 公平);玩家真正收集、养成、交易、带进带出的,是一套**持久的小丑牌牌组**——它不直接给你兵,而是像 Balatro 的 joker 一样**改写规则、把你这局往某个流派"掰弯"**。这一刀把"氪金强度"和"局内公平"解耦,是整个设计的支点。

2. **它是一个「五借鉴、五层、零重叠」的结构,不是乱炖**(§1)。每个借鉴精准插进一个别人填不了的层:自走棋=战斗经营层、小丑牌=局间变量层、炉石=身份收藏层、魔兽副本=社交掉落层、交易市场=价值流通层。没有两层打架,没有功能冗余 —— 这是它能"缝"得起来的原因。

3. **绝大部分是纯数据,且有现成先例。** 小丑牌/附魔/星球牌的算子,Game E(`game-e-joker-roguelike.md`)已做过一版 Balatro roguelike,值得直接复用(⚠️ 落细节前须对一遍它已实现哪些卡牌算子,见 §5 TODO)。战斗/经济/商店复用 `game-f-auto-chess.md` §3 的映射。**新增工作量集中在:局外服务层(收藏/组牌/市场/天梯)+ 少量卡牌算子缺口。**

4. **它已经替前面悬而未决的一条线拍了板:局外养成影响强度(炉石模型),不是纯竞技模型。** 这没问题、更有粘性,但**有必然后果**:牌力=收集深度 → **天梯匹配必须按收集/段位分层**,否则新人被满收集老玩家打穿;开了交易市场后,经济与平衡必须当一等公民设计(§7)。

## 一、五借鉴五层:为什么这个缝合体成立

| 借鉴自 | 占据的层 | 回答的问题 | 引擎落地 |
|---|---|---|---|
| **自走棋(金铲铲/TFT)** | 局内·战斗与经营(**硬件层**) | 「这一局怎么打才爽」 | `game-f-auto-chess.md` 已映射,复用 |
| **小丑牌(Balatro)** | 局间·奇幻与随机(**变量层**) | 「为什么我每局都长得不一样」 | Game E joker 算子,复用 + 少量缺口 |
| **炉石传说(Hearthstone)** | 局外·构筑与收藏(**身份层**) | 「我是谁 / 我玩哪个流」 | 服务/账号层(非 ECS) |
| **魔兽世界(WoW 副本)** | 社交·合作与掉落(**关系层**) | 「三人凭什么一起打、又凭什么互抢」 | 离散同步(REQ-016/017 已验证) |
| **交易市场(TCG)** | 商业·价值与流通(**经济层**) | 「我的收藏凭什么值钱」 | 服务/账本层(非 ECS) |

---

## 二、核心原理:武将是租来的,牌组是你的灵魂

- **武将层 = 公共硬件,roguelike 清零。** 每局从零、随机商店、人人同池。保证**局内公平与博弈**——没人能靠氪金武将碾压。
- **牌组层 = 私人灵魂,持久独一。** 你带进局内的不是一支军队,而是**「一套如何组建军队的世界观」**。它通过偏置商店、强化特定势力/连携/单将,把你这局**掰向某个流派**。
- **「选哪一方」只是出生点,不是命运。** 势力(蜀/魏/吴/群)是**轻的风味选择 + 初始倾向**(选魏出生打「虎豹铁骑」=顺风;选群雄出生=逆风高收益)。**深度全在牌组,不在势力。** 这就是"选哪方不重要、卡牌包才重要"的精确含义。

## 三、元循环(串起五层的脊椎)

```
   局内打副本(自走棋骨架 + 小丑牌掰流派)
        │ 产出
        ▼
   贡献度 ──► 按贡献 roll 战利卡牌(魔兽世界式掷点)
        │ 充实
        ▼
   局外收藏 ──► 构筑 / 附魔 / 星球牌(炉石式组牌)
        │ 形成
        ▼
   更强的「身份牌组」──► 下一局打得更深
        │ 流通
        ▼
   交易市场:买卖加速构筑 / 稀有牌变现 ──┐
        └────────────(养成动力 + 商业闭环)─┘
```

**自走棋负责单局爽;小丑牌负责每局不一样;炉石负责让牌组成为身份;魔兽副本负责让三人又合作又抢夺;交易市场负责让身份有真实价值。** 五个引擎,一根脊椎。

## 四、系统设计

### 4.1 两层卡牌(关键:同时解决「持久身份」与「roguelike 新鲜感」的矛盾)

| 层 | 是什么 | 生命周期 | 数据形 |
|---|---|---|---|
| **局外·牌组(Build 牌)** | 带进场的 5–8 张小丑牌,定义流派 | **持久**,局外组牌 | 卡牌码数组 + 各卡强化数据 |
| **局内·战利牌(Run 牌)** | 打 Boss 掉宝箱当场抽到的临时小丑牌,本局生效 | **本局**,roguelike 变量 | 进局内 joker 槽(可即时生效),局后入收藏 |

→ **持久牌给"身份",战利牌给"每局的意外"。** 两层叠加 = 既有炉石构筑感,又有 Balatro/杀戮尖塔的随机爽。

### 4.2 卡牌获取 = 团队抢宝(竞合的高光时刻)

打掉太阁 Boss → 掉宝箱 → 吐出 N 张小丑牌 → **魔兽世界式分配**:

- **方案 R1·掷点(默认)**:Need / Greed / Pass,最高点得。简单、人人有戏。
- **方案 R2·贡献竞价(进阶)**:用本局累计**贡献点**对想要的卡 DKP 式竞价,价高者得。让贡献度有了第二个出口。

> 💡 **设计内核**:你们刚**联手**杀了 Boss(合作),现在为它的好卡**掷点**(竞争)——co-opetition 张力从机制自然长出,不写额外系统。掷点/竞价是**离散同步,确定性安全**(REQ-016/017 已验证)。

### 4.3 Balatro 强化层

- **附魔(单卡)**:给小丑牌上品质(foil / holo / 多彩 等价物)→ +攻击% / +经济 / +暴击 / +触发次数。数据 modifier。
- **星球牌(流派)**:升级某条**羁绊/流派**的档位收益(如「星球·魏」让魏骑羁绊全档 +1;「星球·连携」让连携阈值 -1)。= Balatro 星球牌升级牌型的同构。

### 4.4 局外:收藏 / 组牌器 / 交易市场(⚠️ 服务层,明确不进 ECS)

- **收藏**:账号名下的卡牌库存(含品质/数量)。
- **组牌器**:从收藏拼 5–8 张成一套牌组,选流派身份 + 选初始势力出生点。
- **交易市场**:卡牌在玩家间流通(挂单/求购/成交)。**商业杠杆**。
- **天梯**:按攻岛名次结算 LP/段位;**高段位 = 守岛太阁更凶(难度阀,纯换守军数据)**;爬段位解锁新三国将/新战役岛/新太阁 Boss。

> 以上四者全是**服务·账号·账本层的持久态**,**不进确定性 ECS 模拟**——与宪法一致(它们不是"一局游戏的数据",是元层基础设施)。游戏 sim 只消费"这局带进来的牌组数据"这一份输入。

| 机制 | 复用 / 缺口 | 说明 |
|---|---|---|
| 局内自走棋战斗/经济/商店 | **复用** | `game-f-auto-chess.md` §3 全套映射;不重复 |
| 小丑牌 = 改写规则的 modifier | **复用 + 待核** | Game E joker 算子(`game-e-joker-roguelike.md`)是先例;⚠️ **TODO:对一遍它已实现哪些条件/触发/施效算子,列出本作缺的** |

| 星球牌升级羁绊档位 | **待核** | 需"改某羁绊阈值/收益"的全局 stat 写入;倾向走全局资源(已有 effect-apply 全局路由),非逐单位 fan-out(守 §7 YAGNI) |
| Boss 宝箱掉卡 + 掷点/竞价 | **离散同步,复用** | REQ-016/017 双人卡牌 lockstep 已证;分配是回合间离散态 |

> **结论**:引擎侧新增**很窄**——主要是核对/补齐少量小丑牌算子 + 商店加权小缺口。重头在**局外服务层**,与确定性引擎解耦。

## 六、打样:10 套牌组(10 个流派,炉石式)

每套 = 一个流派身份;**钥匙牌**=定义这套的招牌小丑牌;**围绕**=它逼你去找的武将/羁绊。

| # | 牌组名 | 流派 | 钥匙牌(招牌小丑) | 围绕武将/羁绊 | 贡献打法 |
|---|---|---|---|---|---|
| 1 | **虎豹铁骑** | 魏·速攻 Aggro | 「虎豹骑令」每有 1 魏骑·全骑 +攻 | 魏 × 骑兵连携 | 前期滚雪球,序盘多吃杂兵贡献 |
| 2 | **桃园结义** | 蜀·连携 Combo | 「桃园三义」刘关张同场·全属性飙升 | 刘备/关羽/张飞三连 | 中期三核成型一波带走 |
| 3 | **赤壁火攻** | 吴·灼烧 Burn/AoE | 「东南风」点燃叠层·范围扩散 | 吴 × 谋士 DoT | 克密集守军,中盘 AoE 刷贡献 |
| 4 | **卧龙八阵** | 谋士·控制 Control | 「八阵图」群冻 + 法强滚雪球 | 诸葛/周瑜 × 谋士 | 苟到后期,终盘大爆发抢名将 |
| 5 | **丈八蛇矛** | 单核 High-roll | 「蛇矛」全资源喂张飞·斩杀叠攻 | **必围张飞** | 一个超级核心通杀,赌脸 |
| 6 | **乱世枭雄** | 群雄·灵活 Flex | 「枭雄」群雄越少越强 | 吕布/董卓 × 群雄(少而精) | 高 roll 灵活转型 |
| 7 | **以战养战** | 降将·混血 Recruit | 「招降」每收编 1 太阁·永久增益 | **专收战国武将**混入三国阵 | 本作独有,越打越强,终盘最肥 |
| 8 | **足轻人海** | 铺场 Go-wide | 「人海」单位数越多·全体 + | 低费杂兵 × 数量羁绊 | 铺满场吃数量,稳吃中盘贡献 |
| 9 | **屯田积粟** | 经济·贪婪 Greed | 「屯田」利息上限翻倍 | 经济过渡阵 → 后期质变 | 前期让贡献、后期接管收割 |
| 10 | **白衣渡江** | 刺客·斩首 Last-hit | 「白衣」对残血暴击 + 斩杀 | 吕蒙/甘宁 × 刺客 | **专抢 Boss 最后一刀**=直接咬合贡献度机制 |

> 覆盖 Aggro / Combo / Burn / Control / 单核 / Flex / Recruit / Go-wide / Econ / Assassin 十原型;势力(蜀魏吴群)× 职业(将谋弓刺)× 本作独有(降将/抢人头)全铺到。
> 第 7「以战养战」与第 10「白衣渡江」是**本作独有的两个流派**——前者把"PvE 敌人变成你的牌库"做成构筑主轴,后者把"贡献度=抢人头"做成可构筑的打法。建议优先深挖这两套验证差异化。

## 七、回驳 / 暂缓 / 风险(YAGNI + 重组优先 + 商业诚实账)

| 项 | 裁决 | 理由 |
|---|---|---|
| **逐单位羁绊光环 fan-out(Gap C / REQ-023)** | **暂不下沉** | 守 `game-f-auto-chess.md` §6 既定纪律:星球牌/羁绊优先走"全局 stat + 能力读全局"重组,不为想象需求提前拓宽引擎 |
| **动态等级加权商店** | **MVP 砍,押后** | 用预配权重牌袋绕;牌组的"偏势力"靠烘进洗牌实现,够 MVP |
| **共享单盘三人同屏(方案甲)** | **暂缓为"梦想版"** | 三端实时战斗 lockstep = 最硬的跨端浮点骨头(F-057)。MVP 走方案乙(分盘 + 共享岛 meta + 离散同步),验证后再议升级 |
| **交易市场即开放强度交易** | ⚠️ **需专章设计,不可裸上** | 卡牌有强度 + 可交易 = TCG 经济。强度可买 → **必须按收集/段位分层匹配 + 赛季轮换/格式**守竞技公平,否则滑向 P2W + 二级市场失衡(参考 D3 拍卖行翻车)。MTG 整个生意建在"强度可买"上 → 可行,但**经济与平衡必须一等公民**。市场/账本/反作弊全在服务层 |
| **外交结盟 / 背叛** | **押后** | 三人是"共享 PvE 目标 + 个人贡献排名"的竞合,塑料兄弟情已从机制涌现(联手杀 Boss / 掷点抢卡),不必先做外交系统 |

## 八、分阶段路线(叠在现有 MVP 队列之上,不打乱)

| 阶段 | 内容 | 依赖 | 备注 |
|---|---|---|---|
| **D0·核对** | 对一遍 Game E joker 算子,列出本作小丑牌缺口清单 | 无 | 出 REQ 候选(若有) |
| **D1·单人牌组原型** | 1–2 套牌组(如「虎豹铁骑」)在**单机**自走棋里跑通"牌组掰流派" | 现有单机 MVP | 纯数据 + 少量算子;同机确定性,安全 |
| **D2·三人攻岛(方案乙)** | 共享岛进度条 + 分盘 + 贡献度 + Boss 宝箱掷点 | 离散同步底子(8060cb9 状态同步层) | 攻岛闭环 + 抢卡闭环 |
| **D3·局外元层** | 收藏 / 组牌器 / 天梯(段位=难度阀) | 服务层 | 与 ECS 解耦 |
| **D4·交易市场** | 卡牌流通 + 经济/平衡专章 | D3 + 经济设计 | 商业层,需专门设计与风控 |

> **D1 几乎是顺水推舟**:把单机自走棋的"对手"从玩家换成"太阁守军波次",再叠一层牌组 modifier 即可——正是"用单机做地基"的延续。

> 复诵:武将是租来的,牌组才是你的灵魂。五借鉴各占一层,一根贡献度的脊椎串起合作与抢夺。游戏=数据;局外的收藏/市场/天梯是与确定性引擎解耦的服务层。**不写一行游戏 system,新增只有数据 + 少量通用卡牌算子 + 服务层基础设施。**
