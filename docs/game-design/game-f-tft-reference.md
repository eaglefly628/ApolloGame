## 一、流程图全文转录（按图，未删改语义）

### 1. 开局

- **游戏开始 → 选秀**：在三个**强化符文**里，选择一个强化符文。
- → 即将开始下个回合（回合大循环入口）。

### 2. 准备阶段（30s）

进入「回合准备」阶段拍发生：

| # | 规则 |
|---|---|
| P1 | 战场上所有棋子**恢复为默认状态**，并复位；**回合数 +1** |
| P2 | 获得**基础收入**、**利息收入**、（胜利收入）**连胜奖励/连败奖励** |
| P3 | **商店自动刷新**，在商店选择并购买棋子；也可**花费 2 金币刷新商店** |
| P4 | **购买的棋子进入备战席**；备战席共 **9 个**可用位置；位置满或金钱不足，无法购买 |
| P5 | **购买经验提升等级，提高人口上限** |
| P6 | **为棋子分配装备**（棋子被卖或用**拆卸器**回收装备） |
| P7 | 选择棋子**放置棋盘，或移回备战席**；调整棋子在棋盘的位置 |
| P8 | **售卖任意位置的棋子，按等级归还部分金钱** |
| P9 | **3 个相同的棋子自动合成升星**（最高三星）；**棋盘上棋子数 ≤ 人口上限** |
| P10 | 商店棋子来源于**公共牌库**（所有玩家共享）；可**锁定**商店（锁定后不刷新；每回合自动解锁） |

### 3. 即将开始战斗（入战检查拍）

- 若战场内棋子个数**超过人口上限**，且备战席已满 → **自动出售**多出的棋子。

### 4. 自动战斗阶段（30s，加时 15s）

- 进入「自动战斗」：**战斗开始拍，棋盘上棋子的所有羁绊效果自动激活**；双方棋子自动寻路、索敌、攻击、释放技能，直到**一方全部棋子阵亡**。
- **战斗期间**：可买棋子/刷商店/卖棋子，**但不可**把棋子放入棋盘或把棋盘上的棋子移回备战席。
- **回合种类分流**：
  - **特殊回合？是 → 野怪回合？**
    - **野怪回合**（阶段 1 的 4 个回合 + 之后**每个阶段的最后一个回合**）：对战固定阵容野怪；**击杀野怪后有几率随机掉落法球**（战利品）。
    - **否 → 选秀回合**：所有存活玩家抢夺**棋子和装备**（**血少的先选**）。
  - **非特殊回合** → 随机与一名玩家进行战斗（PvP）。
- **胜负与伤害**：
  - 败方按**对方剩余棋子（和其星级/等级）**对玩家造成伤害；
  - **加时仍未分出胜负 → 强制结束，双方都受伤害**（伤害量 = 当前还存活的敌方棋子）。

### 5. 回合收尾与终局

- **小小英雄血量为零？**
  - 是 → 玩家被淘汰；淘汰时刻的名次 = 本场排名 → 等待本场全部结束 → 展示统计与排名 → 游戏结束（前四名获排位积分奖励，排名越前越多；后四名扣分）。
  - 否 → 还有其它玩家存活？ 是 → 等待所有玩家结束本回合 → 公示对战结果 → **回到「即将开始下个回合」**； 否 → **玩家获胜，最终排名第一**。

### 6. 图中明示的小小英雄（主角）规则

- 小小英雄 = 玩家化身，**承载玩家血量**（败方扣它的血）；
- 野怪掉落**法球/战利品**在棋盘上，由小小英雄**走过去拾取**（用户拍板：可控主角捡掉落宝箱）。

## 二、由本准则导出的硬性设计约束（flow-spec v2 已对齐）

1. **商店五件套**：5 槽自动刷新 / 2 金手动刷新 / **锁店**（回合自动解锁）/ 买入→**备战席(9)** / 卖出按等级返还。
2. **人口体系**：等级 = 棋盘人口上限；买经验 4 金；**超员且备战席满 → 自动出售**。
3. **升星**：3 同名自动合成（含备战席+棋盘，连锁），**封顶三星**；
4. **经济**：基础收入 + 利息 + **连胜与连败都有奖励**（连败补偿恢复，此前单人裁掉——按准则收回）。
5. **回合种类**：PvP（剧本敌阵）/ **野怪**（阶段 1×4 回合 + 每阶段末回合，掉法球）/ **选秀**（单人化=九选一，见 §三）。
6. **伤害公式**：阶段基础 + 对方剩余棋子按**星级权重**计伤（权重=数据表，全 1 即退化为现代口径）；**加时强制双伤**。
7. **战斗期商店可用**（买/刷/卖），**不可摆子**——操作的相位可用性是流程的一部分。
8. **主角（小小英雄）**：场上可控实体、承载玩家血量、拾取掉落。
9. **开局强化符文三选一**（单人保留,无争抢语义）。

## 三、单人 PvE 化的**唯一**系统性替换（立项已定，不动摇）

| 金铲铲原义 | 单人替换 | 其余语义 |
|---|---|---|
| 8 真人互战/随机配对 | **剧本敌阵关卡表**（强度爬坡） | 不变 |
| 选秀「抢」（血少先选） | **九选一 draft**（无争抢；保留先后语义=无意义项删除） | 选棋子+装备 不变 |
| 公共牌库（玩家间共享消耗） | **有限牌袋**（自己抽走的影响自己的三星可达性） | 池大小数值不变 |
| 等待其他玩家/公示排名 | 删（单人即时进下一回合）；终局=打穿关卡表 or 血尽 | — |
