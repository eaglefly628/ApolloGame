## 一、N 阵营架构原则(⚠️ 即时生效,约束当前一切实现)

**「阵营 = N 支队伍;每支的控制者 = {人 | AI} 是数据配置」**。
三人攻岛 = 3 人(孙/刘/曹三方 invaders)+ 1 个太阁中立守岛方;人不全则空位用 AI 补——**都只是配置,不是代码分叉**。

落到纪律(PE-F 自查,策划审查盯):
1. **别写死"恰好两队/恰好一个人类"**——队伍位已是掩码(`TEAM_A|B|C` …);索敌/伤害的"敌方"一律写成 `全队伍掩码 & ~自队` 形态的数据,不硬编码对家。
2. **操作区/HUD 按 owner 参数化**:一份 UI 数据模板,实例化 N 份(owner=p1/p2…);输入按 owner 路由(card-play 已是先例)。盟友战局只读镜像走状态同步层(已落 `8060cb9`)。
3. **上阵区 = 按势力的格子范围数据**(deploy zone),不是"下半场=我方"的隐含假设。
4. **lockstep 三纪律继续守**:整数 SIM 真相(HexPos)/ 命令式输入 / 表现不进 hash。

## 二、三方混战 + 枪打出头鸟(内生难度)+ 降将

> 落到三人攻岛:三个玩家各打各的盘(方案乙),但共同凿向同一座岛(太阁中立守军)的攻陷进度;贡献度排名定岛主。
> 下列机制在"分盘 + 共享岛 meta"下同样成立(出头鸟 = 贡献领先者更难、降将 = 收编太阁)。

### 2.1 战场行为(近乎免费)
- 索敌:各方 `targetTag` 指向太阁守军(及——若启用三方互斗变体——他方);`aggro`/`hitbox` 全吃掩码,纯数据。
- 胜负:岛攻陷进度条满 → 本局结束;**贡献度才是名次**,而非互相淘汰。

### 2.2 枪打出头鸟(防龟缩 / 防雪崩的结构支点)
- 让**贡献领先者**面对更凶的守军波次(或更高威胁标记)——**领先被压制、落后有追赶**,名次悬念维持到终盘。
- 与新文档 §7「贡献权重后置(终盘太阁名将权重 >> 序盘杂兵)」配合,岛主到最后一刀才定。

### 2.3 降将(复用已上线的主角拾取)
太阁守将阵亡 `Mortal.dropTemplate:'recruit_token_<hero>'`(按掉落表几率)→ 主公碰拾 → 该武将入备战席(升星合成链自动吃)。席满则不掉/转金币。
**这是「以战养战」牌组(新文档 §6 第 7 套)与"PvE 敌人变成你的牌库"的机制根。**

### 2.4 平衡注记
- 龟缩解药 = 出头鸟;雪崩软化 = 关卡曲线 + 连败金;
- **性能**:三方单场单位多,aggro N²/overlap 已知债🟠——每方上限先压 8-10,验收时跑性能探针。

## 三、战场裁决 v3(用户终裁:**金铲铲平板,无地形**)

> 演化存档:v1 全幅长江+双桥 → v2 断续江段+四通道 → **v3 撤销全部物理地形**(过度设计:每关一份江形 = 给每关开地图工单)。

1. **棋盘 = 平板**,与金铲铲同制式。
2. **布阵区 = 唯一的"结构"**:按势力的**布阵合法区数据**(placement 规则),不是物理地形。
3. **驰援延迟靠距离涌现,不靠屏障**:走路耗时本身就是支援代价(方案乙下,跨盘支援 = 离散赠予)。
4. **征日叙事 = 零成本承载**:棋盘外视觉皮 + 战役命名与敌阵主题曲线(序盘杂兵 → … → 海岛太阁决战)。**每关变化的是"敌人是谁",不是"地长什么样"**。

**裁决理由(防后人捡回地形)**:战斗全自动 → 地形绕路/堵口玩家不可读不可控("棋子犯傻");墙挡敌也挡友;且需下沉地形能力(YAGNI)。物理墙是最贵的最后手段。

## 四、确定性探针 F-057(联机的唯一硬骨头)

- 已有底子:多人 lockstep 卡牌确定性已证(REQ-016/017);HexPos 整数 SIM;命令式输入;hash 纪律;状态同步打包层已落(`8060cb9`)。
- **唯一硬骨头**:战斗浮点(overlap/aggro 距离/投影)跨端逐位一致未验——浏览器全员 IEEE-754,风险比原生跨架构小,但**要证不要赌**。
- **REQ-F-057 确定性探针**:多实例 lockstep 跑同一战斗蓝图,逐拍 hash 对拍;失败退路 = **战斗整数化**(代价已知)。**主程随时可做,建议前置**——三人攻岛(方案乙)虽以离散同步为主,但只要走共享战斗就吃这条骨头。
