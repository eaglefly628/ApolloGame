## 三、局外养成:收藏 / 组牌 / 天梯

- **收藏**:账号名下卡牌库存(含品质/数量)。
- **组牌器**:从收藏拼 5–8 张 Build 牌组 + 选初始势力。
- **天梯**:
  - 按攻岛名次结算 LP/段位(岛主最多,递减)。
  - **段位 = 难度阀**:高段位的岛,太阁守军更凶(纯换关卡表数据,见 `game-f-taikou-roster.md`)。
  - **天梯之路 = 局外解锁**:爬段位解锁新三国将 / 新战役岛(征九州→本州→近畿…)/ 新太阁 Boss → "什么都体验到"。

## 四、交易市场(TCG 式,**非 crypto**)

- 卡牌在玩家间流通:挂单 / 求购 / 成交,平台抽成。
- **定位**:Steam 市场 / MTG Arena 那类**封闭实钱市场**,**不是链上/GameFi**(用户已明确"不是 fi")。
- 商业入口候选:抽卡(获取)× 直购(加速)× 市场抽成(流通税)。

## 五、⚠️ 红线:强度可买 → 必须正面设计平衡

> 这是本章存在的真正理由。前面我标过、这里钉死:

1. **牌组强度 = 收集深度**(炉石模型,用户已选)→ 一旦开交易市场,强度可买。
2. **后果**:不设防 = pay-to-win + 二级市场失衡(参考暴雪 D3 拍卖行翻车)。
3. **解药(必须做)**:
   - **按收集/段位分层匹配**——新人不撞满收集老玩家。
   - **赛季轮换 / 格式**(标准/狂野式)——防版本永久固化、给新卡价值。
   - **武将侧永远公平**(局内 roguelike 清零、人人同池)——强度只在牌组"流派倾向",不在"数值碾压";钥匙牌给"方向"不给"无脑数值",是平衡的安全阀。
4. **MTG 整个生意建在"强度可买"上 → 模式可行**,但**经济与平衡必须当一等公民**,不能裸上。

## 六、服务层边界(架构纪律)

```
   确定性 ECS(引擎)         │   服务 · 账号 · 账本层(后置)
   ─────────────────────────┼──────────────────────────────
   一局战斗 sim              │   收藏 / 组牌器
   局内经济(banded)         │   天梯段位 / LP / 解锁
   消费:牌组数据(输入)     │   交易市场 / 挂单 / 成交 / 抽成
                            │   反作弊 / 账本 / 风控
   ──────────────────────────────────────────────────────
   单向:服务层 →(组好的牌组数据)→ 喂给引擎一局;引擎不反向依赖服务层
```

> 与宪法一致:这些都不是"一局游戏的数据",是元层基础设施。**不污染确定性边界。**
