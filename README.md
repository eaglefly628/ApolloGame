# ApolloGame

小游戏合集。每个游戏放在 `games/` 下自己的目录里，纯静态、可独立打开。

## 游戏列表

| 编号 | 名称 | 说明 | 目录 |
|---|---|---|---|
| 106 | 你画我猜 | 图片从马赛克逐渐变清晰，四选一，越早猜中分越高 | [`games/game-106-guess-image/`](games/game-106-guess-image/) |

## 目录约定

```
games/game-<编号>-<短名>/
├── README.md      玩法与实现说明
├── index.html     入口
├── css/
└── js/
```
